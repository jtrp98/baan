# REQ-010 — งาน batch คำนวณสถิติเครือข่าย

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `business-analyst` · ไฟล์นี้ = 1 REQ + AC ของมัน · สถานะอยู่ที่ `requirement\index.md` เท่านั้น

สั่งแล้วทำงานเบื้องหลัง มีสถานะให้ตามดู (`idle`/`running`/`done`/`failed`) กันการสั่งซ้อน
โรงเรียนที่คำนวณพลาดต้องไม่ทำให้ทั้ง batch ล้ม (นับเป็น failed แล้วไปต่อ)
ทุกครั้งที่รัน จะ **ล้างตารางสถิติทั้งหมดแล้วเขียนใหม่**

**Acceptance criteria (ทดสอบได้)**
1. (AC-010.1) งาน batch สั่งแล้วทำงานเบื้องหลัง มีสถานะ `idle`/`running`/`done`/`failed` ให้ตามดู และสั่งซ้อนขณะรันอยู่ไม่ได้
2. (AC-010.2) โรงเรียนที่คำนวณพลาดถูกนับเป็น failed แล้ว batch ไปต่อได้ — ไม่ทำให้ทั้ง batch ล้ม
3. (AC-010.3) ทุกครั้งที่รัน ระบบล้างตารางสถิติทั้งหมดแล้วเขียนใหม่
