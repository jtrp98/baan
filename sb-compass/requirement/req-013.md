# REQ-013 — ฟีเจอร์ Premium ต้องถูกกั้นสิทธิ์ที่ฝั่ง API ด้วย (must-fix รอบนี้)

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `business-analyst` · ไฟล์นี้ = 1 REQ + AC ของมัน · สถานะอยู่ที่ `requirement\index.md` เท่านั้น

ปัจจุบันการกั้น Premium อยู่ **เฉพาะฝั่งหน้าจอ** ทำให้คนที่ยิง API ตรงได้ข้อมูล Premium ฟรี
ผู้ใช้ยืนยันแล้วว่า **เป็นช่องโหว่จริงที่ต้องแก้ในรอบนี้** (ยกระดับจาก OQ-06 → requirement)
- ทุก endpoint ที่ให้ข้อมูล Premium (REQ-003, REQ-004, REQ-005, REQ-006, REQ-007, REQ-008)
  ต้องตรวจสิทธิ์ Premium ที่ฝั่งเซิร์ฟเวอร์ก่อนคืนข้อมูล ไม่ใช่เชื่อฝั่งหน้าจอ
- ไม่มีสิทธิ์ → ต้องไม่คืนข้อมูล Premium เลย (ไม่ใช่คืนข้อมูลแล้วให้หน้าจอซ่อน)
- ตัวกลไก entitlement ยังเป็นของภายนอก Compass — Compass แค่ **เรียกตรวจและบังคับผล**

**Acceptance criteria (ทดสอบได้)**
1. (AC-013.1) ทุก endpoint ที่ให้ข้อมูล Premium (REQ-003, REQ-004, REQ-005, REQ-006, REQ-007, REQ-008) ตรวจสิทธิ์ Premium ที่ฝั่งเซิร์ฟเวอร์ก่อนคืนข้อมูลเสมอ
2. (AC-013.2) ผู้ใช้ที่ไม่มีสิทธิ์ยิง API ตรงแล้วต้องไม่ได้ข้อมูล Premium กลับไปเลย — ไม่ใช่คืนข้อมูลแล้วให้หน้าจอซ่อน
