# REQ-011 — ใบรับรองเส้นทางการเรียน → แยกเป็น module ต่างหาก

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `business-analyst` · ไฟล์นี้ = 1 REQ + AC ของมัน · สถานะอยู่ที่ `requirement\index.md` เท่านั้น

มี stub อยู่ในโค้ดแล้ว (สร้างเลขใบรับรอง + รหัสตรวจสอบจากเลขนักเรียน) แต่ **ยังไม่มีการตรวจว่า
เด็กสอบผ่านจริงก่อนออกใบ** และเลขที่ออกยัง **เดาได้จากเลขนักเรียน**
**ไม่อยู่ในขอบเขต module นี้** — กติกาการอนุมัติ/ตรวจสอบย้อนกลับต่างจากส่วนอื่นอย่างชัดเจน
จะทำเป็น module `sb-compass-certificate` แยกรอบสัมภาษณ์ต่างหาก (ยังไม่ได้เริ่ม)
**ยืนยันเมื่อ 2026-08-24**: ทำ interview ของ module นั้น "รอบถัดไป แยกต่างหาก" ไม่รวมในเอกสารนี้
(ปิด OQ-11)

**Acceptance criteria (ทดสอบได้)**
1. (AC-011.1) ใบรับรองเส้นทางการเรียนไม่ถูกพัฒนาต่อในโมดูลนี้ — กติกาการอนุมัติ/ตรวจสอบย้อนกลับทำใน module `sb-compass-certificate` แยกต่างหาก (ยืนยัน 2026-08-24)
