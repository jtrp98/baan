# REQ-006 — Gap Report ของสายที่เลือก (Premium, โหมด "รู้แล้วว่าจะไปสายไหน")

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `business-analyst` · ไฟล์นี้ = 1 REQ + AC ของมัน · สถานะอยู่ที่ `requirement\index.md` เท่านั้น

> **แก้ไข 2026-09-02**: ข้อนี้ **retire แล้ว ในรูปแบบเดิม** (Fit Score ของสาย 8 สายเดิม + แท่ง Gap
> รายวิชา) — ผู้ใช้ยืนยันตรง (สัมภาษณ์ตรงในรอบนี้ ไม่ใช่ relay) ว่าเนื้อหานี้ย้ายไปเป็นขั้นตอน
> **"แผนพัฒนา" (development plan) หลังตั้งเป้าหมาย** ใน flow ใหม่ของ `sb-compass-faculty-match`
> (RIASEC + T-Score → cluster → คำถามเฉพาะสาย (วิชาการ+พฤติกรรม) → จัดอันดับคณะ/สาขาในคลัสเตอร์ →
> ตั้งเป้าหมาย REQ-017 → **แผนพัฒนา**) — ดู REQ-019 ข้อ 3
> **⚠ ยังไม่มี REQ ใดนิยามขั้นตอน "แผนพัฒนา" นี้ในเอกสารของ `sb-compass-faculty-match`**
> (หยุดที่ REQ-017) — เป็นช่องว่างเปิดค้างที่ต้องเปิดรอบสัมภาษณ์ `business-analyst` ตามมาที่โมดูลนั้น
> เพื่อเพิ่ม REQ ถัดไป (คาดว่าเป็น REQ-018 ของ `sb-compass-faculty-match` แต่ยังไม่ได้ยืนยันเลขจริง)
> เนื้อหาด้านล่างนี้ **คงไว้เพื่อประวัติ/อ้างอิงรูปร่างของ Gap Report เดิมเท่านั้น** ไม่ใช่ทิศทางที่
> จะเดินต่อในรูปแบบนี้ — mockup แท็บ "แผนพัฒนา" (`gap`/`goals` tab ใน `compass-design.js`) มี gap
> rows + "Orbit Tutor" block ที่อาจเป็นรูปร่างของขั้นตอนใหม่ แต่ **ยังไม่ถูกยืนยันเป็น requirement**

เมื่อเด็กเลือกสายเอง แสดง Fit Score ของสายนั้น + แท่ง Gap รายวิชา (คะแนนปัจจุบัน / เป้าหมาย /
ห่างอีกกี่คะแนน) เรียงจากช่องว่างมากสุด และข้อความว่าต้องเร่งวิชาไหนก่อน
แสดงแท่ง Gap **เฉพาะวิชาที่เด็กมีคะแนนแล้ว** เท่านั้น

**Acceptance criteria (ทดสอบได้)**
1. (AC-006.1) รูปแบบเดิมของ Gap Report (Fit Score ของสาย 8 สายเดิม + แท่ง Gap รายวิชา) ไม่ถูกพัฒนาต่อในโมดูลนี้ — retire แล้ว ย้ายไปเป็นขั้นตอน "แผนพัฒนา" หลังตั้งเป้าหมายของ `sb-compass-faculty-match` ซึ่งยังรอ REQ มานิยาม (OQ-23)
