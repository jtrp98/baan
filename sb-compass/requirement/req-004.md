# REQ-004 — สถิติเทียบเครือข่ายทั่วประเทศ + อันดับ (Premium)

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `business-analyst` · ไฟล์นี้ = 1 REQ + AC ของมัน · สถานะอยู่ที่ `requirement\index.md` เท่านั้น

เทียบคะแนนเด็กกับ **ค่าเฉลี่ยของนักเรียนระดับชั้นเดียวกันทั้งเครือข่าย** และบอกอันดับ
- ระดับชั้นของเด็กตัดสินจาก **ห้องที่คะแนนของเด็กกระจุกอยู่มากที่สุด** และเทียบข้ามโรงเรียนด้วย
  รหัสระดับชั้นกลาง (`MasterCode` → `mc:XXX`; ถ้าโรงเรียนไม่ได้กรอก จะถอดจากชื่อชั้นภาษาไทย
  เช่น "(HKT)ประถมศึกษา 4" → `mc:214`)
- คำนวณล่วงหน้าเป็น batch (คำนวณสดต่อ request ไม่ได้ เพราะข้อมูลอยู่คนละฐาน) เก็บลง
  `compass_level_subject_stat` และ `compass_student_level_score` แล้วตอนใช้งานอ่านจากตารางนั้น
- อันดับ = จำนวนคนที่คะแนนรวมสูงกว่า + 1 ภายในระดับชั้นเดียวกัน
- **ยังไม่มี percentile รายวิชา** — ฟิลด์ `Percentile` ส่งค่า 0 คงที่ เพราะยังไม่ได้เก็บ
  การกระจายรายวิชา (OQ-05)
- ถ้าตารางยังไม่เคยถูกคำนวณ ต้องไม่ error — ส่งค่าว่าง/0 กลับไปแบบไม่ล้ม
- **ไม่มีเกณฑ์ขนาดกลุ่มตัวอย่างขั้นต่ำ และยืนยันแล้วว่าไม่ต้องมี (2026-08-24)** — แม้ระดับชั้นนั้น
  จะมีนักเรียนน้อยกว่า 10 คน หรือมาจากไม่กี่โรงเรียน ก็ยัง **แสดงอันดับ/สถิติตามปกติ**
  ไม่ต้องซ่อน ไม่ต้องมีคำเตือน ไม่มี minimum sample size (ปิด OQ-05)
- **การเทียบ/จัดอันดับทั่วประเทศคำนวณที่ระดับกลุ่มสาระ (canonical subject) เท่านั้นโดยเจตนา
  ไม่ลงถึงระดับรายวิชา** (ยืนยัน 2026-08-24) — **นี่คือการตัดสินใจที่ปิดแล้ว ไม่ใช่ scope ที่ยังไม่
  ตัดสินใจ** เหตุผล: ชื่อ/รหัสรายวิชาดิบของแต่ละโรงเรียนไม่ตรงกันเป๊ะ (ดู Constraints → กลไก
  matching) การเทียบตรงที่ระดับรายวิชาข้ามโรงเรียนจึงไม่ fair และไม่แม่น กลุ่มสาระเป็นหน่วยที่
  เทียบข้ามโรงเรียนได้จริง · `system-analyst`/`qa-engineer` ไม่ต้องยกเรื่องนี้ขึ้นมาเสนออีก
  · **หมายเหตุความสัมพันธ์กับ REQ-016**: REQ-016 เพิ่มการ *แสดง* รายละเอียดรายวิชาของเด็กเอง
  เท่านั้น ไม่ได้เปิดให้ *เทียบ/จัดอันดับ* ที่ระดับรายวิชา

**Acceptance criteria (ทดสอบได้)**
1. (AC-004.1) อันดับ = จำนวนคนที่คะแนนรวมสูงกว่า + 1 ภายในระดับชั้นเดียวกัน
2. (AC-004.2) สถิติเทียบเครือข่ายคำนวณล่วงหน้าเป็น batch เก็บลง `compass_level_subject_stat` และ `compass_student_level_score` แล้วตอนใช้งานอ่านจากตารางนั้น
3. (AC-004.3) ถ้าตารางสถิติยังไม่เคยถูกคำนวณ ต้องไม่ error — ส่งค่าว่าง/0 กลับไปแบบไม่ล้ม
4. (AC-004.4) แม้ระดับชั้นนั้นมีนักเรียนน้อยกว่า 10 คนหรือมาจากไม่กี่โรงเรียน ยังแสดงอันดับ/สถิติตามปกติ — ไม่ซ่อน ไม่มีคำเตือน ไม่มี minimum sample size (ปิด OQ-05)
5. (AC-004.5) การเทียบ/จัดอันดับทั่วประเทศทำที่ระดับกลุ่มสาระเท่านั้น (ไม่ลงถึงรายวิชา) และฟิลด์ `Percentile` รายวิชาส่งค่า 0 คงที่
