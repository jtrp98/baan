# BE-015 — RecomputeAsync OverallAvg from already-weighted values

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `project-manager` · Owner/Phase/Depends/Status → `plan\index.md` (index ชนะ)

## Goal

`RecomputeAsync` (`:365`): เปลี่ยนค่า overall ต่อนักเรียนจาก `subjAvgs.Average(a => a.AverageScore)` เป็นค่าเฉลี่ยธรรมดาของคะแนนกลุ่มสาระที่**ถ่วงน้ำหนักมาแล้ว** (ไม่ถ่วงน้ำหนักซ้ำอีกชั้น) — ผู้ implement ต้องยืนยันด้วยว่าจำเป็นต้องแก้บรรทัดจริงหรือไม่ (ขึ้นกับว่า `subjAvgs` มาจากเมธอดถ่วงน้ำหนักของ BE-014 แล้วหรือยัง) — นิยามของ overall ใน batch คือเฉลี่ยของค่ากลุ่มสาระที่ถ่วงน้ำหนักแล้ว — หน่วยกิตถูกใช้ไปแล้วตอนยุบวิชาย่อยเข้ากลุ่มสาระ (DES-021 ตาราง `:365`); gate schema/breaking-contract มาจาก parity ของหัวข้อ DES-021 ทั้งหัวข้อ (Phase 3 ลง rename + DDL รอบเดียวกัน)

## References

REQ-004, AC-004.1, AC-004.2, DES-021

## Scope

แก้เฉพาะสูตร overall ต่อนักเรียนใน batch — ค่าที่เขียนลง `public."TCompassStudentLevelScore"` ต้องมาจากค่ากลุ่มสาระถ่วงน้ำหนักชุดเดียวกับ
ที่ BE-014 คำนวณ; ยืนยันก่อนแก้ว่าค่าอินพุตเป็นค่าถ่วงน้ำหนักแล้วจริง กันการถ่วงซ้ำสองชั้น

- Security-sensitive: no

## Out of Scope

ห้ามถ่วงน้ำหนักซ้ำอีกชั้น; ห้ามแตะสูตรรายกลุ่มสาระของ BE-014; ห้ามแตะ `RankInLevel` นอกเหนือจากที่ค่าอินพุตเปลี่ยนตาม

## Expected Output

none

## Acceptance

AC-004.1: อันดับ = จำนวนคนที่ overall สูงกว่า + 1 ภายในระดับชั้นเดียวกัน — ค่า overall ที่ใช้จัดอันดับต้องมาจากสูตรใหม่นี้
AC-004.2: ค่า overall ที่เขียนลงตารางมาจาก batch รอบนี้ ไม่ใช่ค่าคำนวณสดต่างสูตร

## Dependencies

BE-014

## Handoff

ตรวจ AC-004.1 และ AC-004.2 ด้วยชุดข้อมูลที่ค่าถ่วงน้ำหนักต่างจากค่าดิบชัดเจน — เทียบ overall ก่อน/หลังแก้และยืนยันว่าไม่เท่ากับ
การถ่วงซ้ำ; บันทึกค่าที่เขียนลงตารางจริงหลัง batch
