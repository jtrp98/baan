## 5. ภารกิจ: ส่งงานและผลประเมิน (REQ-038 · DES-005)

อ้างอิง: [BR-038-01 (Activity ภารกิจ Code/Block ใช้ระบบประเมินตามเกณฑ์ ไม่ถือว่ารันสำเร็จเท่ากับผ่านทุกภารกิจ)](../../shared/requirements/req-038.md) ถึง [BR-038-03 (ผล Cloud ผูกนักเรียน Activity/revision งาน/วิธีตรวจ)](../../shared/requirements/req-038.md) · [AC-038-01 (Code/Block ที่มีเกณฑ์ภารกิจกำหนดแล้วได้รับผลอัตโนมัติตรงกับตัวอย่างผ่านและไม่ผ่านของเกณฑ์นั้น)](../../shared/requirements/req-038.md), [AC-038-02 (ส่งภารกิจ Arm แล้วไม่กลายเป็นผ่านเองก่อนมีผลตรวจจากครู)](../../shared/requirements/req-038.md) · [AC-036-05 (ครูทดลองภารกิจ/ข้อสอบ local และเก็บโครงงาน Cloud ได้ แต่ส่ง submission/attempt ไป Cloud ทั้งทางตรงและนำเข้าประวัติไม่ได้)](../../../app-shell/shared/requirements/req-036.md) (ครู) · [BR-039-03 (ผลที่ยังรอครูตรวจไม่แสดงเป็นผ่าน)](../../shared/requirements/req-039.md)

- หน้าภารกิจ: คำสอนภารกิจ + **เกณฑ์ที่เปิดเผยได้** (คำอธิบายเกณฑ์ public — hidden expected trace ไม่แสดงตาม DES-005) + ปุ่ม "เปิดพื้นที่ทำงาน <โหมด>" (เข้า Lab ตามโหมด — int-002) + ปุ่ม "ส่งงานตรวจ" ใช้โครงงาน/revision ปัจจุบัน; ส่งซ้ำ/retry ใช้ Idempotency-Key เดิม ไม่สร้างซ้ำ (DES-005)

| State | ผู้ใช้ | คำ copy (ข้อเสนอ) |
|---|---|---|
| รอคิวตรวจ (Code/Block) | นักเรียน | chip "รอคิวตรวจอัตโนมัติ" → "กำลังตรวจ…" (`aria-live="polite"`) |
| ผลอัตโนมัติออก | นักเรียน | "ผ่าน" พร้อมผลรายเกณฑ์ (rule results) หรือ "ยังไม่ผ่าน — <เหตุจากเกณฑ์>" — รันสำเร็จ ≠ ผ่านทุกภารกิจ (BR-038-01, AC-038-01) |
| ผิดพลาด | นักเรียน | "ระบบตรวจไม่พร้อม (GRADER_UNAVAILABLE) — ยังไม่นับผล ลองส่งใหม่ได้โดยไม่เกิดรายการซ้ำ" |
| ส่งงาน Arm | นักเรียน | ส่งแล้ว = chip **"รอครูตรวจ"** ค้างจนครูบันทึกผล — ไม่กลายเป็นผ่านเอง (AC-038-02, [BR-038-02 (Activity ภารกิจ Arm ต้องมีครูตรวจและให้ผล ไม่ใช้ OS write ภาพจำลอง หรือ timer เป็นผลผ่าน)](../../shared/requirements/req-038.md)) → ผลครู: "ผ่าน/ไม่ผ่าน โดย <ผู้ตรวจ>" (ตรวจย้อนได้ [AC-038-03 (ครูที่มีสิทธิ์บันทึกผล Arm แล้วเรียกดูผลที่บันทึก พร้อมผู้ตรวจและงานที่ตรวจได้)](../../shared/requirements/req-038.md)) |
| ครู (employee) บน Desktop | ครู | ปุ่ม "ส่งงานตรวจ" **disabled** + "โหมดครู: ทดลองทำในเครื่องได้ แต่ไม่สร้างผลเรียน/คะแนนบน Cloud ([มติ 032 (ผลทดลองของครูและ cardinality/การล็อก mapping คะแนน)](../../../../shared/decisions/decisions-032.md))" (AC-036-05) |

## 6. ดาวตาม rubric ที่ยืนยันแล้ว ([pack-content-inventory-001 (ชุดเนื้อหาสามโหมด เกณฑ์ผ่านและดาว)](../../../../shared/pack-content-inventory-001.md) §2 · [มติ 038 (sign-off UX ครบทั้งสองไฟล์ + spec Q1/Q2/Q4/Q5)](../../../../shared/decisions/decisions-038.md) คำถาม spec Q2 (นิยามดาวหนึ่งถึงสามดวง))

- นิยาม **ยืนยันแล้ว**: ดาว 1 = ผ่านเกณฑ์ขั้นต่ำ · ดาว 2 = ผ่าน + อยู่ในโควตา (จำนวนคำสั่ง/บล็อก/เวลาตามรายภารกิจ) · ดาว 3 = ผ่าน + ภารกิจเสริม/ทางเลือก · **ดาวไม่ใช่เงื่อนไขเลื่อน Level**
- การนำเสนอ (ข้อเสนอ — Q24 (แสดงดาวจากผลตรวจจริง)): แสดงดาว **เฉพาะเมื่อมีผลตรวจจริง** (ยังไม่มีผล = ขีดว่าง ไม่ใช่ดาวจางตามค่าคงที่ — [BR-039-03 (ผลที่ยังรอครูตรวจไม่แสดงเป็นผ่าน)](../../shared/requirements/req-039.md)) · tooltip/`aria-label` "ได้ 2 ดาวจาก 3 — ผ่านและอยู่ในโควตา" · ข้อความกำกับหน้าผล: "ดาวเป็นสัญลักษณ์ความสำเร็จของภารกิจ ไม่ใช่เกณฑ์เลื่อนระดับ" · ค่าดาวมาจากผลตรวจตาม rubric ที่อนุมัติ ไม่คำนวณที่ client ([BR-042-04 (ไม่เชื่อผลผ่านจาก client)](../../../my-work/shared/requirements/req-042.md))
