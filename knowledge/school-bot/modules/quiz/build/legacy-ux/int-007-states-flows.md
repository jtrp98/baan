# 1. State ของแต่ละ flow

> แก้ล่าสุด 2026-11-02 · แก้โดย int · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

[กลับเอกสารหลัก](int-007-states.md)


ทุกแถวใช้ auth/conflict/unknown และ a11y ใน §2–§4 ร่วมกัน Empty แสดงข้อความอย่างเดียว ไม่มี CTA ในพื้นที่ empty

แยก loading ตาม repo: Desktop และ admin ส่วนกลางใน school-bot คงกติกาของตน; เว็บครู/Level/หน้าเกณฑ์ admin ที่อยู่ web-system ใช้ P9 ตาม AGENTS → project-policy → CLAUDE → DESIGN และ loading.md ซึ่งมีลำดับสูงกว่า skill ทั่วไป โหลดข้อมูลใช้ shared Skeleton รูปร่างตรงข้อมูลเฉพาะส่วนที่ยังโหลด ไม่บังส่วนที่พร้อมแล้ว ไม่ใช้ Spinner หรือข้อความโหลดแทนโครงข้อมูล กลุ่มใช้ SkeletonStatus (role=status, aria-busy, ข้อความ sr-only) และ shape เป็น aria-hidden; error จบ Skeleton แล้วแสดงทางแก้ ข้อมูลใหม่ใช้ sb-reveal ตาม repo; refresh หลังบันทึกในบริบทเดิมคงข้อมูลเดิม งานบันทึกปิดปุ่มซ้ำด้วย disabled; หากต้องบังพื้นที่ใช้ .sb-progress-track > .sb-progress-bar พร้อมข้อความ ไม่ใช้ Spinner ตารางด้านล่างระบุข้อความสถานะเพื่อ i18n/a11y; บน web-system ข้อความอ่านข้อมูลเป็น sr-only ของ Skeleton

| Flow | Loading | Empty | Disabled / abnormal / error |
|---|---|---|---|
| เริ่มข้อสอบ | กำลังเปิดข้อสอบ… | ยังไม่มีข้อสอบที่เผยแพร่ | ยังไม่เปิด/ปิดแล้ว/ครบครั้ง แสดงเหตุผล; policy หรือเวลา Test ขาดให้หยุด ไม่ใช้ค่าที่เดา |
| ทำ/บันทึก/ทำต่อ | กำลังอ่านข้อสอบครั้งเดิม… / กำลังบันทึก… | ครั้งนี้ไม่มีข้อมูลข้อสอบให้แสดง | โจทย์ว่าง/ชนิดไม่รองรับหยุดส่ง; บันทึกล้ม “ยังไม่ได้บันทึกคำตอบ — ตรวจสอบการเชื่อมต่อแล้วลองอีกครั้ง”; ไม่ล้างคำตอบที่กำลังทำ |
| ส่ง/ผลครั้งเดิม | กำลังส่งคำตอบ… / กำลังอ่านผล… | ยังไม่มีผลที่เปิดดูได้ | submitted อ่านอย่างเดียว; expired อ่านผลตาม [ผลข้อสอบเมื่อหมดเวลา](int-007-recovery-a11y.md#expired-result); voided แจ้งถูกยกเลิก; feedback null ไม่แปลว่าไม่มีข้อผิด |
| ตั้งเวลา | Skeleton ช่องเวลาเมื่ออ่าน; บันทึกใช้ disabled — กำลังอ่าน/บันทึกเวลา… | ยังไม่มีกิจกรรมในรอบนี้ | ปิดก่อนเปิดหรือเวลาไม่ถูกต้อง ชี้ field; override ต้องห้ามแจ้ง “แก้ได้เฉพาะเวลาทำและช่วงเปิด–ปิด” ไม่บันทึกส่วนที่เหลือ |
| เปิดซ่อม | Skeleton รายชื่อเมื่ออ่าน; เปิดสิทธิ์ใช้ disabled — กำลังอ่านรายชื่อ/เปิดสิทธิ์… | ไม่มีนักเรียนในขอบเขตที่เลือกได้ | ผู้รับหายจาก roster หยุดยืนยันและโหลดสิทธิ์ใหม่; ห้ามเลือกนอกขอบเขต |
| น้ำหนัก/คะแนน | Skeleton แถวตั้งค่า/ตารางคะแนนเมื่ออ่าน; บันทึกใช้ disabled — กำลังอ่านนโยบาย/ผลคะแนน… | ยังไม่มีนโยบายคะแนน / ยังไม่มีผลคะแนน | ยอดไม่ครบ 100% แสดงยอดจริงและ field; active แล้วอ่านอย่างเดียว; คะแนนเกินเต็ม/เต็ม≤0/พิสูจน์ run ไม่ได้ หยุดสรุป ไม่แก้เป็น 0 |
| Level | Skeleton ผลข้อเสนอเมื่ออ่าน; ประเมิน/ยืนยันใช้ disabled — กำลังประเมิน/อ่านข้อเสนอ/ยืนยัน… | ไม่พบนักเรียนใน roster | ROSTER_EMPTY ไม่สร้างรอบ; ยังไม่สิ้นเทอม/ไม่มีเทอมหน้า/ขาด policy บอกเหตุและให้ผู้ดูแลแก้ก่อนประเมินใหม่ |
| เกณฑ์ admin | ใช้กฎ repo ที่หน้านี้อยู่: web-system อ่านเป็น Skeleton และบันทึกใช้ disabled; ส่วนกลางคงกติกาของตน — กำลังอ่าน/บันทึกเกณฑ์… | ยังไม่มีเกณฑ์สำหรับ Level นี้ | ไม่ใช่ level_policy_admin กั้นการแก้; ค่าเกิน 0–100 หรือเหตุผลผิดรูปแบบชี้ field ไม่บันทึก |

Error ที่โหลดข้อมูลไม่สำเร็จต้องแยกจาก empty: แสดงสาเหตุและ “ลองโหลดอีกครั้ง” เฉพาะการอ่าน ไม่ใช้ปุ่มนี้ส่ง mutation ใหม่
