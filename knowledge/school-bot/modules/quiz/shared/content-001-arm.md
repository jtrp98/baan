# ร่างรายการเนื้อหา Arm จากบทเรียนและ sample เดิม

> Rev 1 · แก้ล่าสุด 2026-11-03 · แก้โดย spec · ขอโดย ผู้ใช้ (มติ 053 — ร่างเนื้อหาจาก source)

ทุกรายการต่อไปนี้เป็น **(สมมติฐาน — ยังไม่ยืนยัน)** source มีหัวข้อ/เป้าหมาย/คำแนะนำบางส่วน แต่ไม่ใช่ approved inventory ดู [ข้อที่ต้องเซ็น](content-001.md) และ [rubric/ข้อมูลอุปกรณ์ที่ขาด](content-001-arm-rubric.md)

## พบใน source: LearnMap 7 stages

LearnMap เปิดผ่านตัวเลือก Arm แต่ข้อมูลภายในมี area=arm/block/quiz จึงไม่ควรนำทั้งเจ็ดรายการไปสร้างเป็น project mission โหมด Arm ทั้งหมด รูปแบบ Activity ที่ระบุด้านล่างเป็นร่างให้ผู้ใช้ยืนยัน ไม่ได้เปลี่ยนสัญญาข้อมูล

| รายการ (ทุกแถวเป็นสมมติฐาน — ยังไม่ยืนยัน) | เป้าหมายและคำแนะนำที่ถอดความจาก source | ร่างกิจกรรม/สิ่งที่ยังขาด |
|---|---|---|
| ARM-001 รู้จักแขนกล | สำรวจส่วนประกอบ อ่านแล้วกดต่อ | สื่อ instruction; ยังขาดบทอ่าน/ภาพและเกณฑ์ตรวจความเข้าใจ การกดต่อไม่สร้างผลผ่านภารกิจ |
| ARM-002 ข้อต่อ S0–S5 | เรียนชื่อข้อต่อ อ่านโจทย์และเลือกคำตอบ | Quiz; ยังขาดโจทย์ ตัวเลือก เฉลยและแหล่งยืนยันชื่อข้อต่อ ห้ามแต่งเฉลยจากชื่อ stage |
| ARM-003 จับคู่ข้อต่อ | รู้หน้าที่ข้อต่อ จับคู่กับชื่อ | แบบฝึกจับคู่; ยังขาดรายการชื่อ/หน้าที่ ภาพและเฉลยที่ทีมอุปกรณ์รับรอง |
| ARM-004 ขยับ S1 ยกแขน | ทดลองยกแขน: เชื่อมหุ่นกลุ่ม → เลือกท่า 1 และ S1 → ตรวจว่าแขนยก → บันทึกท่าใหม่ | ร่าง project Arm ครูตรวจ; ห้ามขยับของจริงจนได้ profile/calibration และอนุญาต ขาดท่าเริ่ม/ปลายและช่วงมุม |
| ARM-005 ต่อบล็อกยกของ | ใช้บล็อกให้แขนยกวัตถุ ต่อแล้วส่งให้หุ่น | source ระบุ area=block; ยังขาดชุดบล็อกควบคุม Arm และเกณฑ์วัดการยก อย่านับว่า BlockMode ปัจจุบันทำได้จากชื่อ stage |
| ARM-006 หยิบกล่อง | ให้แขนหยิบและวางกล่อง ทำตามภารกิจแล้วตรวจว่าหยิบได้ | ร่าง project Arm ครูตรวจ; ขาดวัตถุ/ตำแหน่ง/น้ำหนัก/ลำดับท่า/ช่วงมุมและหลักฐานว่าหยิบวางสำเร็จ |
| ARM-007 ด่านสุดท้าย | ใช้สิ่งที่เรียนในหน่วย ทำภารกิจสุดท้าย | source ระบุ area=quiz; มีเพียงหัวข้อ ยังไม่มีรายละเอียดภารกิจ/ข้อสอบ ห้ามเติมเป็น mission สำเร็จรูป |

## พบใน source: sample workspaces อีก 3 ชุด

ชุดเหล่านี้เป็นตัวเลือกใน merge dialog ของ Sample mode ไม่ใช่บทเรียนใน LearnMap และตัวเลขในชุดไม่ใช่ calibration ของอุปกรณ์ ห้ามใช้เป็นค่าปลอดภัย

| รายการ (ทุกแถวเป็นสมมติฐาน — ยังไม่ยืนยัน) | เป้าหมายและคำแนะนำที่เสนอจากชื่อท่า | ร่างภารกิจ |
|---|---|---|
| ARM-008 โบกมือทักทาย | ฝึกเรียงท่า: ยกแขน → โบกซ้าย → โบกขวา → ท่าทักทาย → ท่าพัก | จัดลำดับครบห้าท่า ให้ครูตรวจจากผลงาน; ท่า/ค่าของจริงรอทีมอุปกรณ์ ไม่สั่ง HOME/ท่าพักจาก sample |
| ARM-009 แยกบล็อกสี | ฝึกเรียงหยิบสีแดง → ยกสีแดง → วางสีแดง | จัดลำดับสามท่า ให้ครูตรวจ; source มีตัวอย่างสีแดงเท่านั้น ไม่อ้างว่ามีระบบตรวจสีหรือสื่อทุกสี |
| ARM-010 ส่งลูกบอล | ฝึกเรียงรับลูกบอล → เหวี่ยง ตามชื่อท่าในตัวอย่าง | ร่างลำดับสองท่าเพื่อทบทวนบน simulator เท่านั้น การเหวี่ยงของจริงยังขาด safety/พื้นที่/วัสดุและผู้รับรอง ไม่ให้ถือว่าพร้อมใช้ในชั้นเรียน |

## ยังขาด

ไม่มี Lesson/Activity/revision ที่เซ็นแล้วหรือชุดสื่อเต็มสำหรับรายการเหล่านี้ ชื่อท่าและค่า sample ไม่ใช่หลักฐานความสำเร็จทางกายภาพ ARM-002/003/007 ยังไม่มีข้อคำถามและเฉลยครบ; ARM-005 ยังขาดสัญญาควบคุมแขนด้วยบล็อก; ARM-004/006/008–010 ยังขาดค่าจริงตาม rubric จึงร่าง/ทดลอง stub ได้ แต่ไม่ประกาศเป็นเนื้อหาจริงที่อนุมัติแล้ว
