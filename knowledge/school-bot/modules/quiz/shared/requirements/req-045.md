# REQ-045 — นำเข้า Course Plan Sheet

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

การนำเข้า Course Plan Sheet ต้องรักษาความหมายของการอนุมัติจากต้นทางและสื่อแต่ละชุด ทุกแถวต้องเข้าเป็น draft เพื่อให้ตรวจและอนุมัติผ่านวงจรหลักสูตรก่อนเผยแพร่

## Business Rules

- BR-045-01: นำเข้าเป็น draft ตาม [REQ-044 (รหัสบทเรียนและ revision หลักสูตร)](req-044.md); D=TRUE หมายถึงตรวจ/อนุมัติแล้วจากต้นทาง ไม่ใช่คำสั่ง publish
- BR-045-02: ไม่นำคอลัมน์ O เข้าเป็นข้อมูลหลักสูตรหรือรหัส/ลำดับ
- BR-045-03: P–X เป็นสื่อชุดที่ 2 ของ Lesson เดิม ไม่สร้าง Level/ภาคเรียนใหม่
- BR-045-04: เลขหน่วย/ชื่อ Unit ไม่ใช้แทนรหัสถาวร; แถวที่ D ไม่เป็น TRUE นำเข้าเป็น draft เช่นเดียวกับทุกแถว ตาม [มติ 023 (writer คะแนน, ปัดเศษ, นำเข้า Sheet และเจ้าของ mapping)](../../../../shared/decisions/decisions-023.md)
- BR-045-05: นำเข้าทุกแถวเป็น draft; แถว D=TRUE ติดป้ายอนุมัติจากต้นทาง ไม่มีแถวใด publish เอง ตาม มติ 023

## Acceptance Criteria

- AC-045-01: นำเข้าแถว D=TRUE แล้วเห็นเป็น draft พร้อมที่มาและความหมายว่าอนุมัติจากต้นทาง; ยังไม่เผยแพร่เอง
- AC-045-02: เปลี่ยนเฉพาะ O ในข้อมูลทดสอบแล้วข้อมูลหลักสูตรที่นำเข้าไม่เปลี่ยน
- AC-045-03: แถวที่มีสื่อทั้งสองชุดแสดงสื่อครบภายใต้ Lesson เดิม โดยไม่เกิด Course/Level ใหม่จาก P–X
- AC-045-04: นำเข้าแถวที่เลข C ไม่ตรง Unit ในชื่อแผนแล้วแสดงรหัส Lesson แยกจากทั้งสองค่า; สลับลำดับแล้วรหัสเดิมคงเดิม

## ยังไม่ยืนยัน

ไม่มีข้อสมมติฐานหรือคำถามธุรกิจที่ยังไม่ยืนยันเพิ่มเติมในข้อกำหนดนี้
