## Edge cases
- (P2) ส่งคะแนน Quiz เข้า SchoolBright ไม่สำเร็จ (EC-05): คะแนนไม่หาย เข้าคิว แสดง "รอส่งคะแนน" (ST-16) · รายละเอียดการลองซ้ำ → OQ8 (เลื่อน phase 2)
- เน็ตหลุดระหว่างเล่นด่าน: เล่นต่อได้ (ทำงานแบบออฟไลน์หลัง login) · ผลเข้าคิว sync (Proposed)
- นักเรียนเปลี่ยนเครื่อง (EC-04): ความคืบหน้าบทเรียนผูกกับบัญชี/cloud ของ School Bot (ผู้ใช้ยืนยัน 2026-10-31)
- นักเรียน ป.1 อ่านคำถามไม่ออก (EC-06): ไม่มีตัวช่วยเพิ่มและไม่มีเสียงอ่านใน MVP (ความเสี่ยงที่ยอมรับ RSK-04) · เนื้อหาต้องเรียบง่ายตามระดับ ป.1 · ใช้ภาพช่วยในโจทย์
- นักเรียนเข้า level ที่**สูงกว่าสิทธิ์ (N)**: เข้าไม่ได้ เห็นการ์ดล็อกพร้อมเหตุผล จนกว่าครูเปลี่ยน N · **level ต่ำกว่าหรือเท่ากับ N เข้าได้** (R7 · OQ38 · แก้ 2026-11-06 ตาม ruler) · ผลนับเข้า SchoolBright ใน phase 2 → OQ21
- ครูปิดหน่วยขณะนักเรียนกำลังเล่น/เคยผ่านแล้ว: ยังไม่กำหนด → OQ10, OQ22
- โหลดเนื้อหาจาก cloud ไม่สำเร็จ (ST-12): ลองใหม่ ไม่ทำให้ผลที่เล่นไปแล้วหาย
- เนื้อหา 22 ด่านต่อเทอมไม่เท่ากันตาม level (คาบต่อสัปดาห์ต่างกัน): แผนที่ต้องรองรับจำนวนด่านไม่เท่ากัน ไม่ fix 22 → OQ18
- ติดใน item เกม: รันใหม่ได้ไม่จำกัด + ใบ้ 3 ขั้น ไม่มีข้าม (R3 · OQ48)
- เล่นด่านที่ผ่านแล้วซ้ำและรอบนั้นไม่ผ่าน: สถานะคงเป็นผ่าน ดาว/เป้าเสริมเก็บค่าที่ดีที่สุด/สะสม หน้าผลบอก "ภารกิจนี้ผ่านไว้แล้ว" (OQ51 · OQ12)
- เปิดแผนที่หลังผ่านครบทั้ง 2 เทอม: แสดงสถานะจบ level (เส้นชัย) + ไปที่ด่านสุดท้าย

คำถามที่ยังไม่ตัดสินอยู่ใน `oq.md`
