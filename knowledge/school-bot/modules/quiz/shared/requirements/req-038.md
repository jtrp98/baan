# REQ-038 — ประเมิน Code/Block อัตโนมัติและ Arm โดยครู

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

คำย่อในเอกสาร: OS = Operating System หรือระบบปฏิบัติการ

ระบบต้องประเมินภารกิจ Code/Block อัตโนมัติตามเกณฑ์ และให้ครูที่มีสิทธิ์เป็นผู้ตรวจภารกิจ Arm ผลที่บันทึกต้องอ้างผู้เรียน งาน และ revision ที่ถูกต้อง เพื่อให้ตรวจย้อนกลับได้และไม่ถือว่าการรันสำเร็จเป็นผลผ่านทุกภารกิจ

## Business Rules

- BR-038-01: Activity ภารกิจ Code/Block ใช้ระบบประเมินตามเกณฑ์ ไม่ถือว่ารันสำเร็จเท่ากับผ่านทุกภารกิจ
- BR-038-02: Activity ภารกิจ Arm ต้องมีครูตรวจและให้ผล ไม่ใช้ OS write ภาพจำลอง หรือ timer เป็นผลผ่าน
- BR-038-03: ผล Cloud ผูกนักเรียน Activity/revision งาน/วิธีตรวจ; Guest ตาม [REQ-042 (ประวัติเรียน Guest และตรวจผลใหม่)](../../../my-work/shared/requirements/req-042.md); ครูทดลอง local ไม่สร้างผล Cloud ([มติ 032 (ผลทดลองของครูและ cardinality/การล็อก mapping คะแนน)](../../../../shared/decisions/decisions-032.md))
- BR-038-04: ครูตรวจ Arm เฉพาะนักเรียนที่ผู้ดูแลกำหนดให้ครูคนนั้น ภายในโรงเรียน/บัญชีเดิม; เกณฑ์ตาม [REQ-037 (หลักสูตรและภารกิจสามโหมด)](req-037.md) ไม่อนุมัติ grant table ใหม่จากนโยบายนี้
- BR-038-05: Quiz/Test ใช้ [REQ-046 (Quiz/Test และคลังข้อสอบแบบ revision)](req-046.md) / [REQ-047 (การนับคะแนน Quiz รายหลักสูตร)](req-047.md); Mode ของภารกิจไม่ใช้กำหนด policy ข้อสอบ
- BR-038-06: หน้าครูตรวจภารกิจ Arm อยู่ใน sb-tech-upgrade-web-system ไม่อยู่ใน Desktop ตาม [มติ 022 (ที่อยู่ของหน้าจอ Admin / ครู / Desktop)](../../../../shared/decisions/decisions-022.md)

## Acceptance Criteria

- AC-038-01: Code/Block ที่มีเกณฑ์ภารกิจกำหนดแล้วได้รับผลอัตโนมัติตรงกับตัวอย่างผ่านและไม่ผ่านของเกณฑ์นั้น
- AC-038-02: ส่งภารกิจ Arm แล้วไม่กลายเป็นผ่านเองก่อนมีผลตรวจจากครู
- AC-038-03: ครูที่มีสิทธิ์บันทึกผล Arm แล้วเรียกดูผลที่บันทึก พร้อมผู้ตรวจและงานที่ตรวจได้
- AC-038-04: ผล Cloud อ้างนักเรียน Activity/Mode/revision และงานถูกต้อง ไม่ปนผลครู/ดาวตัวอย่าง

- AC-038-05: ครูตรวจ Arm ของนักเรียนนอกรายชื่อที่ได้รับมอบหมายหรือข้ามโรงเรียนไม่ได้ แม้อยู่ห้องเดียวกันหรือรู้รหัสงาน; ผลเดิมไม่เปลี่ยน

## ยังไม่ยืนยัน

เกณฑ์เฉพาะภารกิจต้องอ้างฉบับที่ได้รับอนุมัติ การมีข้อกำหนดวิธีตรวจไม่ใช่การอนุมัติ rubric รายภารกิจ
