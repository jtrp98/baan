## สิ่งที่ออกแบบ (เล่นได้จริง 5 ข้อ: Tweak `show = live`)
- **โครง:** ✕ ออก (48) · แถบ progress 16px + มาสคอตเล็กอยู่ปลายแถบ (ท่าวิ่ง · placeholder) + "ข้อ x/5" (รองรับ 5–8 ข้อ) · โจทย์ 28/700 · เนื้อหาตามกลุ่ม · แถบล่าง
- **(ก) เลือกตอบข้อความ:** 2×2 การ์ดสูง 88 มีเลข 1–4 · เลือก = ขอบ 3px น้ำเงิน+พื้นอ่อน · radiogroup
- **(ก) เลือกตอบภาพ:** 4 การ์ดภาพ (เวกเตอร์สมมติ แมว/หุ่นยนต์/ต้นไม้/รถ) มีเลขและ aria-label ("ภาพที่ n: …") ไม่มีข้อความเฉลยบนจอ
- **(ข) เรียงบล็อก:** ซ้าย "ลำดับของโปรแกรม" 4 ช่อง · ขวา "ที่ต้องวาง" · **ทางแตะ-แตะ:** แตะบล็อก (เลือก) → แตะช่อง (วาง) · แตะช่องที่มีบล็อก = หยิบกลับ · **ลาก** (HTML5 drag) เป็นทางเสริม · คีย์บอร์ด Tab + Enter/Space · "ล้างทั้งหมด" ก่อนตรวจ (ไม่ใช่ลองซ้ำ) · ข้อความช่วยที่แถบล่าง aria-live ("เลือก 'x' แล้ว แตะช่องที่จะวาง")
- **(ค) ลากป้ายวางตำแหน่ง:** รูปหุ่นยนต์ 3 ช่องชี้ตา/หู/ล้อด้วยเส้นประ · ป้าย "กล้อง/ไมโครโฟน/ล้อ" · กลไกเดียวกับ (ข) · ≤3 คู่ (OQ13 ก)
- **(ง) สไลเดอร์ตรงเงา:** แขนกลเวกเตอร์ + เงาเทา · 2 สไลเดอร์ (ไหล่ −90…90 · ศอก 0…120 · step 5) จุดจับ 44 + **ปุ่ม ‹ › คู่เสมอ** (48) · ค่าเป้าอยู่บนกริด step (−30, 60) · tolerance ±10° ถูกทั้งข้อ (OQ20 Proposed) · การ์ดสถานะ "ใกล้แล้ว · ห่างจากเงา n°" ไอคอน `target` (Lucide แทน 🎯) คงไว้เป็น feedback (OQ20) · อ่านออกเสียงด้วย aria-live ต้องหน่วงเมื่อหยุดปรับ (ฝั่ง dev ไม่ใช่ใน frame)
- **ปุ่ม "ตรวจ":** `aria-disabled` จนตอบครบ + ข้อความเหตุผลอยู่ข้างปุ่ม (เห็นตลอด) · ตรวจแล้วล็อกคำตอบ ไม่ย้อนแก้ ไม่มีลองซ้ำ ไม่มีใบ้ ไม่มีข้าม
- **ตอบถูก:** แถบล่างพื้นเขียวอ่อน + ขอบบน 4px เขียว + ไอคอน check + "เก่งมาก! ถูกต้อง" + เฉลยสั้น + มาสคอตชูกำปั้น + ปุ่ม "ไปต่อ"
- **ตอบผิด (ไม่ลงโทษ):** แถบล่างพื้นแดงอ่อน + ขอบบนแดง + ไอคอน x + **"ไม่เป็นไรนะ ข้อนี้ยังไม่ถูก"** (ไม่ใช้ "ลองใหม่นะ" · R9) + เฉลยสั้น + มาสคอตคิด(?) · ข้อเลือก: ขึ้นป้าย "คำตอบที่ถูก" ที่ตัวเลือกที่ถูก และ "ที่เลือก" ที่ข้อที่ผิด · ข้อเรียง/จับคู่: ช่องผิดมี x + "ที่ถูกคือ …" · สไลเดอร์: แสดงเงา + "ท่าที่ถูก: ไหล่ −30° ศอก 60°"
- **ออกกลางด่าน:** ✕ และปุ่ม home บนแถบหน้าต่าง เปิด popover ยืนยัน **ใต้ปุ่มที่กด** (design-taste ข้อ 12) role=alertdialog · "ออกจากภารกิจนี้ไหม? ถ้าออกตอนนี้ ความคืบหน้าในภารกิจนี้จะหาย ต้องเริ่มข้อแรกใหม่ ดาวที่เคยได้ไม่หาย" · โฟกัสเริ่มที่ "อยู่ต่อ" (ปุ่มปลอดภัย) · "ออกจากภารกิจ" = ปุ่มรอง ไปแผนที่
- **Tweaks:** `lang` · `show` = live / choiceText / choiceImage / order / match / slider / exit · `force` = answering / correct / wrong (ใช้เมื่อ show ไม่ใช่ live: ดูทีละชนิดและทีละสถานะ) · `net` ออฟไลน์ (ชิปบนแถบ · เล่นต่อได้ R5)

## ค่าที่ใช้
- brand: `action-primary` เลือก/ปุ่มหลัก · `success #2E7D32` ถูก · `danger #D32F2F` ผิด (ไอคอน x + ข้อความ ไม่ใช้รูปทรง stop) · ปุ่มนูนสูง 56 (แถบล่าง) · การ์ด radius-lg 16 · chip/ช่อง radius-md 12 · ขอบ default 2px / selected 3px · type: โจทย์ 28 · ตัวเลือก 20/700 · เฉลย 16 · หัว 24/700 · ฉากหลัง popover ไม่มี (ใช้ clickaway โปร่ง) · shadow-float
