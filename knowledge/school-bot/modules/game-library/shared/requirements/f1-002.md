# ข้อกำหนด game-library (กฎ/Logic, การตัดสินใจ และ Edge cases)

## กฎ/Logic
- **UJ-G1 เล่นเกม:** หน้าหลัก → เกม (หน้าคลัง) → กรองหมวด (ถ้าต้องการ) → การ์ด → หน้าเกม → เล่นต่อ / เลือกด่าน / ด่านวันนี้ → เล่น → หน้าจบด่าน → ด่านถัดไป / เล่นอีกครั้ง / หน้าเกม
- **sidebar:** หน้าคลังเกม highlight "เกม" · หน้าเล่นเกมเป็น N2 ไม่มี sidebar (ปุ่ม home + ปุ่มกลับหน้าเกม) · เกมในด่านบทเรียน highlight "บทเรียน" (`app-shell` R7)
- **"ผ่าน x/y ด่าน"** นับเฉพาะด่านที่ทีมทำไว้ ไม่นับด่านวันนี้
- **ลำดับการ์ด:** กลุ่มที่ชั้นแนะนำตรงชั้นก่อน · ภายในกลุ่มเรียงตามลำดับที่ทีมกำหนด (ไม่เรียงตามการเล่นล่าสุด · Proposed)
- **ผลที่เก็บต่อการเล่น:** นักเรียน, เกม, ด่าน (ID คงที่ หรือวันที่ของด่านวันนี้), ผ่าน/ไม่ผ่าน, เป้าเสริมที่ทำได้, ค่าสถิติ, เวลาที่เล่น · แก้ไขไม่ได้ (log)
- **สถานะ:** กำลังโหลดหน้าคลัง/ความคืบหน้า (DS `Skeleton` v22) · โหลดความคืบหน้าจาก cloud ไม่ได้ → ห้ามแสดงเหมือนยังไม่เคยเล่น แสดง "ยังโหลดผลเดิมไม่ได้" + ลองอีกครั้ง **แต่ยังเล่นได้** (R8 · OQ8) · โหลดเนื้อหาเกมไม่สำเร็จ → ข้อความ + ลองใหม่ · ออฟไลน์/กำลัง sync แสดงที่แถบหน้าต่าง (`app-shell`)
- ถ้อยคำภาษาเด็ก ไม่ลงโทษความผิดพลาด ไม่ใช้คำบทเรียน ("แบบทดสอบ", "คะแนน") · ตาราง "คำที่ตัดสินแล้ว" `../../brand.md` §7

## การตัดสินใจที่ผูกกับ module (ผู้ใช้ 2026-11-06 · `/pencil`)
- เพิ่ม (หลัง ruler 2026-11-06): ช่วงชั้นแนะนำ 2 ชั้น · แสดงเฉพาะเกมที่พร้อม · โหลดผลเดิมไม่ได้ยังเล่นได้ · ออกกลางด่านถามเมื่อแก้แล้ว
- ครูไม่เห็นการเล่นในคลังเกม · ไม่มีของรางวัลจากบทเรียนในรอบแรก · ไม่แชร์ · เทียบสถิติกับตัวเอง · โหมดรอบแรก = เล่นตามด่าน + ด่านวันนี้ · เกมละความยากระดับเดียว · เลือกด่านอิสระ · ออกกลางด่านเก็บเฉพาะด่านที่จบ (ถามยืนยันเมื่อแก้แล้ว · OQ9) · จำลองบนจออย่างเดียว · ใบ้ 3 ขั้น · ด่านวันนี้เหมือนกันทุกคน · 3 ภาษา · ตัด G12 · ยังไม่มี canvas (ถามก่อนออกแบบ)

## Edge cases
- เด็กชั้นเล็กเปิดเกมของชั้นสูง: เล่นได้ ด่านแรกเป็นด่านสอนวิธีเล่น · ชั้นแนะนำเห็นชัดบนการ์ดและหน้าเกม (R4)
- เน็ตหลุดระหว่างเล่น: เล่นต่อได้ ผลเข้าคิว sync (R8)
- เปลี่ยนเครื่อง: เห็นความคืบหน้าเดิมหลัง sync · ผลที่ยังไม่ sync จากเครื่องเก่าอยู่ในคิวของเครื่องนั้น
- เครื่องห้องคอมใช้ร่วม: ผลแยกตามบัญชี · logout ตอนมีผลค้าง sync ต้องเตือน (แบบ quiz R5)
- ข้ามเที่ยงคืนระหว่างเล่นด่านวันนี้: เล่นด่านเดิมจนจบ ผลนับเป็นด่านของวันที่เริ่ม (Proposed)
- นาฬิกาเครื่องผิด: ด่านวันนี้อาจไม่ตรงกับเพื่อน → OQ5
- ด่านใหม่/ด่านที่ทีมแก้มาถึงเครื่องทางไหน → OQ12 (รอถาม dev)
- ทีมแก้/ลบด่านหลังเด็กผ่านแล้ว: ผลเดิมเก็บไว้ · y ใน "ผ่าน x/y" เปลี่ยนตามชุดด่านปัจจุบัน (Proposed)
- ไม่รู้ชั้นของนักเรียน → OQ3

คำถามที่ยังไม่ตัดสินอยู่ใน `oq.md`
