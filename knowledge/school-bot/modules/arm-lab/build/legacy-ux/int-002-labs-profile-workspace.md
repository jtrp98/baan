### 2.2 โปรไฟล์หกข้อต่อ — REQ-015 · DES-006

ฟอร์ม: ชื่อโปรไฟล์ + ตาราง 6 แถว servo `{ID, PWM ปลายซ้าย, PWM ปลายขวา}`

| State | คำ copy/validation (ข้อเสนอ) |
|---|---|
| empty | 6 แถวว่าง + ค่าตั้งต้น nominal (ตามโค้ดเดิม engineAdapter) |
| error: ID ซ้ำ / ไม่ครบ 6 / PWM นอก 500–2500 / ปลายเท่ากัน | inline ใต้ช่อง: "ID ซ้ำกับข้อต่อที่ 3" · "ต้องมี servo ครบ 6 ตัว" · "PWM ต้องอยู่ระหว่าง 500–2500" · "ค่าปลายทางสองค่าต้องไม่เท่ากัน (กลับทิศซ้าย-ขวาได้)" — ปุ่มยืนยัน disabled จนผ่าน ([AC-015-01 (โปรไฟล์ที่มี ID ซ้ำ, servo ไม่ครบหก, PWM นอกช่วง หรือปลาย PWM เท่ากัน ถูกปฏิเสธก่อนเชื่อมต่อ)](../../shared/requirements/req-015.md), [AC-015-02 (โปรไฟล์ที่ถูกต้องและกำหนด PWM กลับทิศผ่านการตรวจรูปแบบได้)](../../shared/requirements/req-015.md)) |
| abnormal: แก้หลังยืนยัน | ป้ายเหลือง "โปรไฟล์ถูกแก้ — ต้องยืนยันใหม่ก่อนเชื่อมต่อ" ปุ่มเชื่อมต่อ disabled ([AC-015-03 (เมื่อแก้ชื่อโปรไฟล์หรือค่า servo หลังยืนยัน ต้องยืนยันใหม่ก่อนเชื่อมต่อ)](../../shared/requirements/req-015.md)) |
| ป้ายกำกับความหมาย | ใต้ปุ่มยืนยัน: "การยืนยันโปรไฟล์เป็นการตรวจรูปแบบ ไม่ใช่การสอบเทียบจริงบนหุ่น" ([BR-015-03 (การกดยืนยันโปรไฟล์ไม่ใช่หลักฐานว่าผ่าน calibration ทางกายภาพ)](../../shared/requirements/req-015.md)) |

### 2.3 Workspace — ส่งท่า / ปรับข้อต่อ ([REQ-016 (ส่งท่าและปรับข้อต่อ)](../../shared/requirements/req-016.md))

- แผงข้อต่อ 6 ตัว + ภาพหุ่นจำลอง (ใช้ ArmSimulator เดิม) — ภาพหลังส่งเป็น "ค่าคาดการณ์" ไม่ใช่ telemetry ([BR-016-03 (ภาพหลังส่งเป็นค่าคาดการณ์ ไม่ใช่ telemetry)](../../shared/requirements/req-016.md)): ป้ายเล็กใต้ภาพ "ภาพเคลื่อนตามค่าที่ส่ง ไม่ใช่ค่าที่วัดกลับ"
- disabled: disconnected หรือปลดแรงบิด → ปุ่มส่งท่า disabled + ข้อความ "ล็อกแรงบิดก่อนจึงส่งท่าได้" ([AC-016-01 (เมื่อ disconnected หรือปลดแรงบิด การส่งท่าไม่สร้างคำสั่งเคลื่อนไหวและมีข้อความอธิบาย)](../../shared/requirements/req-016.md), [AC-023-02 (หลังปลดสำเร็จ การส่งท่า เล่น และอัปโหลดถูกกันไว้พร้อมข้อความให้ล็อกก่อน)](../../shared/requirements/req-023.md))
- ปรับถี่: แสดง "ค่าล่าสุดที่ยอมรับ" ระบบรวมคำสั่งระหว่างค้าง ทำงานครั้งละหนึ่งรายการ ([BR-016-02 (ไม่ส่งคำสั่งข้อต่อซ้อนกัน)](../../shared/requirements/req-016.md), [AC-016-03 (ปรับข้อต่อถี่ผ่าน test bridge แล้ว trace มีคำสั่งทำงานครั้งละหนึ่งรายการ)](../../shared/requirements/req-016.md))
- error ส่งล้ม: ภาพจำลอง **ไม่เริ่มเคลื่อน** + "ส่งคำสั่งไม่สำเร็จ — ไม่มีการส่งซ้ำอัตโนมัติ" ([AC-016-02 (เมื่อจำลองการส่งล้มเหลว ภาพไม่เริ่มเคลื่อนไปตามท่าราวกับส่งสำเร็จ และมีข้อผิดพลาด)](../../shared/requirements/req-016.md), [BR-024-02 (ความผิดพลาดการสื่อสารต้องแสดงให้ผู้ใช้เห็น และไม่ retry การเคลื่อนไหวเอง)](../../shared/requirements/req-024.md))
