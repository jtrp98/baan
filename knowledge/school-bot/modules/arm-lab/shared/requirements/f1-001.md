# Arm Lab: Requirements (จาก role 1)

> นำเข้ารายละเอียดจากระบบเก่า (`Handoff/01_REQUIREMENT` v3.1 + ผลหลังจากนั้นถึง 2026-10-21) · **sketchbook เป็นแหล่งความจริงแล้ว** ไม่ต้องเปิดโฟลเดอร์เดิม · ID เดิม (FR/NFR/EC/AC/DEC/ST/SCR) เก็บไว้ในวงเล็บเพื่อ grep ข้ามไฟล์ · ป้ายหลักฐาน (Confirmed/Observed/Proposed ฯลฯ) ดู `../../context.md`
> R1–R11 ID เดิม ไม่เปลี่ยนความหมาย · R12–R17 เพิ่มวันนี้ (นำรายละเอียดฟังก์ชัน 6A ที่ผู้ใช้อนุมัติแล้ว และผล CR-11 เข้ามา) ดู CHANGELOG

## เป้าหมาย
นักเรียน ป.1–6 (UI เดียวกันทุกชั้น) สอนท่าแขนกล 6 ข้อต่อ (S0–S5) แล้วเล่นเป็นลำดับ กับหุ่นที่มีบอร์ด Raspberry Pi ผ่าน USB · ครูตั้งค่าขั้นสูงแบบ Zide ในโหมดครู · ฐานงานออกแบบ: frame 6A แขนกล (MainV6A) ที่ผู้ใช้อนุมัติแล้ว (รีดีไซน์จาก Zide)

## Requirements
ลำดับ: M = Must · ? = ยังไม่ยืนยัน (ดู OQ)

- R1 (M): ใช้ frame 6A แขนกล (MainV6A) เป็นฐานฟังก์ชันและ layout · **อนุมัติแล้ว (DEC-08)** แก้ผ่านใบสั่งแก้เท่านั้น ห้ามทำใหม่ทั้งหน้า · ฟังก์ชันและพฤติกรรมความปลอดภัยต้องครบตาม R5, R12–R16 หลังปรับให้เข้ากับ cloud, Raspberry Pi และ ป.1–6 · **ขนาดปุ่ม/ตัวอักษรคงตาม 6A เดิม ไม่ปรับให้ผ่านเกณฑ์ ≥16px/44px** (ผู้ใช้ตัดสิน 2026-10-21 · OQ20) · โน้ตเพื่อทบทวนอนาคต: ใน 6A มี control ต่ำกว่า 16px อยู่ 129 จาก 152 ตัว ไม่ผ่านเกณฑ์เด็กของ brand/context.md (ความเสี่ยงที่ยอมรับ ร่วมกับ RSK-04) · (FR-10, AC-07, DEL-04) · **ข้อยกเว้นความปลอดภัยที่ผู้ใช้ตัดสิน (2026-11-04/05/06):** ปุ่มหยุดที่มุมกดไม่ได้ขณะมีฉากหลังของ dialog lab (ใช้ปุ่มหยุดใน dialog แทน) และปิดตลอดที่สายหลุด (2026-11-06 · OQ79/OQ80 · R5) · ถอดเตือน 30° ทุกก้าว (เหลือรายการใน popup ขยับครั้งแรก) · ถอด ST-48 บังคับท่าพัก · ติ๊กครั้งเดียวต่อการเชื่อม (R15)
- R2 (M): ใช้กับแขนกลที่มีบอร์ด Raspberry Pi · โปรโตคอล "ใกล้เคียง Zide" (ผู้ใช้ตอบ 2026-10-20 → คง 6A เกือบทั้งหมด) · 6A สมมติ COM7 ที่ 115200, PWM 500–2500, คำสั่งรูปแบบ `{G0001#000P1500T3000!}` [Observed EV-03] · รายการค่าตั้งขั้นสูงยืนยันกับ firmware → OQ1, OQ12 · (FR-11, DEC-07)
- R3 (M): แขนกลบนจอ**ไม่ขยับไม่ว่ากรณีใด** (ไม่มีการจำลอง) ทั้งเล่นท่า ขยับข้อต่อ หรือทำอะไรก็ตาม · (FR-12, AC-08, CON-07)
- R4 (M): โหมดครูของ Arm Lab: การตั้งค่าขั้นสูงแบบ Zide · ครู**ของโรงเรียนเดียวกับนักเรียนที่ login อยู่** เข้าได้โดย login ด้วยบัญชี SchoolBright ของตัวเองใน dialog (แทน "ใส่รหัส") · (FR-13, AC-09, DEC-09, UJ-06) · การจบเซสชันครู → OQ9
- R5 (M): ปุ่มหยุดเห็นได้ตลอด กดได้โดยไม่ผ่าน popup ใด ๆ (`z-stop` เหนือทุกชั้น ยกเว้นเมื่อมีฉากหลังของ dialog lab และขณะสายหลุด ดูด้านล่าง) · **ขณะ dialog lab เปิด (แก้ 2026-11-06 · design-taste ข้อ 19 · OQ79):** ของหลังฉากหลังมืดกดไม่ได้ทั้งหมด รวมปุ่มหยุดที่มุม (ฉากหลังเว้นเฉพาะแถบ nav) → dialog/modal ที่เปิดขณะหุ่นกำลังขยับ (หรือหุ่นไม่ตอบแต่พอร์ตยังเปิด) มี**ปุ่มหยุดสีแดงในตัว บนสุดใต้หัว เต็มกว้าง** · dialog ตอนหุ่นนิ่งไม่มี · **สายหลุด/พอร์ตหาย (OQ80):** ปุ่มหยุดปิด (`aria-disabled`) ตลอดที่หลุด แม้ปิด modal แล้ว กดแล้วปุ่ม "เชื่อมหุ่น" บนแถบ nav สั่น (OQ85) · **ปุ่มหยุดใน dialog เมื่อสถานะหุ่นเปลี่ยนขณะ dialog เปิด (OQ88):** โผล่ทันทีที่หุ่นเริ่มขยับหรือกลายเป็นไม่ตอบ และคงไว้จน dialog ปิด · พอร์ตหาย = ปุ่มหยุดใน dialog `aria-disabled` · ห้าม dropdown จาก nav ทับปุ่มหยุด คลิกแรกที่ปุ่มหยุดหยุดทันที · เตือนก่อนสั่งขยับด้วย popup ขยับครั้งแรก (R15) · เตือนเล่นวนไม่หยุดเป็นข้อความค้างในแผงเล่น (R15) · **เมื่อยังไม่เชื่อม/หลุด:** ปุ่มที่ส่งคำสั่งถึงหุ่นปิดแบบ `aria-disabled` พร้อมเหตุผลสำหรับผู้อ่านจอ (ไม่รวมปุ่มหยุด) กดแล้วปุ่ม "เชื่อมหุ่น" บนแถบ nav สั่น (R11) · ห้ามเขียน "หุ่นหยุดแล้ว" จนกว่า firmware ยืนยัน · (FR-14, NFR-04, AC-07)
- R6 (M): งานบันทึกบน cloud ผูกกับบัญชีเป็นค่าเริ่มต้น · (FR-22, AC-13, DEC-13) · รายละเอียดหน้ารวมงาน/sync อยู่ module `my-work`
- R7 (M): export งานเป็นไฟล์ .ini ได้ (Arm Lab = .ini ที่เปิดใน Zide ได้ · ผู้ใช้ตอบ 2026-10-20) · ค่า S5 ใน .ini เป็น PWM ตรงตัว ไม่ผ่านการปัดเป็น % (R13 · 2026-11-04) · (FR-23, AC-13)
  - **แก้ 2026-11-05 (OQ54 ก):** ชื่อไฟล์ export .ini = ชื่อไฟล์งาน (รวม " (2)")
- R8 (M): กู้คืนงานสำรองที่อยู่ในเครื่องได้ (6A สำรองอัตโนมัติทุก 10 วินาที) · (FR-24, AC-13)
- R9 (?): นำท่าหรืองานจากไฟล์ .ini เข้ามาได้ · Inferred จาก frame (Ctrl+A) · frame ปัจจุบันทำปุ่ม "นำเข้าจากไฟล์ .ini…" แล้ว · → OQ4 · (FR-25)
- R10 (M): ใช้ UI เดียวกันทั้ง ป.1–6 ต้องอ่านและใช้ได้สำหรับ ป.1 · เป้า WCAG 2.2 AA + เกณฑ์เด็ก (`../../context.md`) · ไม่มีตัวช่วยเพิ่มสำหรับ ป.1–3 ใน MVP (RSK-04 ยอมรับ) · frame เดิมสมมติผู้ใช้ ป.4–6 ต้องปรับข้อความ/ความซับซ้อน (CF-02) · **ยกเว้นขนาดปุ่ม/ตัวอักษร: คง 6A เดิมตาม R1 (ยังไม่ผ่านเกณฑ์ 16px/44px · ทบทวนภายหลัง)** · (NFR-02, DEC-06, DEC-19, EC-06, AC-15)
- R11 (M): เชื่อมต่อหุ่นผ่าน USB ในโปรแกรมติดตั้ง Windows/Mac · ไม่ต้องติดตั้ง driver (ฝังใน installer) · (NFR-03, EC-03, FR-11, ST-19, ST-20) · **สถานะ:** ยังไม่เชื่อม · กำลังเชื่อมต่อ · เชื่อมแล้ว · เชื่อมไม่สำเร็จ (หุ่นไม่ตอบ/พอร์ตถูกใช้ → กลับ "ยังไม่เชื่อม" + ข้อความผลบนหน้าเชื่อมต่อ) · หลุด/รอหุ่นเดิม (R16) · **ชิปหุ่นบนแถบ nav (OQ41, OQ75):** แสดงเฉพาะในหน้า Arm Lab และ Block Lab · ยังไม่เคยเชื่อมในไฟล์นี้ = ชิป "ยังไม่เชื่อมต่อ" + ปุ่ม **"เชื่อมหุ่น"** ไฮไลต์ · เชื่อมแล้ว = ชื่อ + พอร์ต + สถานะ (เช่น "หุ่นกลุ่ม 3 · COM7") + ปุ่ม **"เปลี่ยนหุ่น"** ข้างชิป · หลุด/หลังกด "ปิดไว้ก่อน" = ชื่อหุ่นเดิม + พอร์ต + "การเชื่อมต่อขาดหาย" (`warning-strong`) + ปุ่ม "เชื่อมหุ่น" จนออกจากไฟล์ · กำลังต่อ = spinner "กำลังเชื่อมต่อ..." · **ทางเข้า (OQ30, OQ43):** เข้า Arm Lab เห็นหน้างาน ไม่บังคับผ่านหน้าเชื่อมต่อก่อน · **ยังไม่เชื่อม/หลุด อะไรใช้ได้ (OQ58 ง, OQ74):** **ยังไม่เคยเชื่อม:** ปิดเฉพาะคำสั่งที่ส่งถึงหุ่น (เล่น · ไปท่านี้ · กลับท่าพัก · ปลดล็อกข้อต่อ · อ่านท่าปัจจุบัน · อัปโหลดลงบอร์ด · เล่นจากบอร์ด · slider/มือคีบ) · เลือก/ดู/เพิ่ม/คัดลอก/ลบ/เรียงท่า/แก้เวลา/บันทึก/ส่งออก/เมนู ใช้ได้ · **หลุด (แถบเหลือง R16 แสดง · แก้ 2026-11-06 OQ93/review F11):** ปิดทั้ง body (`aria-disabled` + tooltip ยัง Tab ได้ · OQ95) เหลือแถบ nav (บันทึก/ส่งออก/เมนูบน nav ใช้ได้) · กดปุ่มที่ปิด **ไม่ขึ้น popup** ปุ่ม "เชื่อมหุ่น" สั่นครั้งเดียว (`dur-shake` · ลดการเคลื่อนไหว = Attention Ring นิ่ง · DS gap OQ78) · **flow เริ่มต้น (2026-11-04):** กด "เชื่อมหุ่น" ในหน้า Arm Lab → หน้าเชื่อมต่อ → เลือกหุ่น → เชื่อมต่อ → กลับหน้า Arm Lab ทันที **ไม่มีขั้นพาไปท่าพัก ไม่มีขั้นตั้งชื่อไฟล์ ไม่มีติ๊กในหน้าเชื่อมต่อ** (ยกเว้น popup ขยับครั้งแรกของ R15 เมื่อกด "พับแขนลงกล่อง/ตัดการเชื่อมต่อ" ขณะยังไม่ติ๊ก · OQ58 ค) · เชื่อมสำเร็จ: เน้น+สั่น "เพิ่มท่า" เฉพาะไฟล์ที่ไม่มีท่า G#### ที่ผู้ใช้เพิ่ม (ไม่นับท่า 0) · หน้าเชื่อมต่อมีปุ่ม **"กลับ Arm Lab" ทุกสถานะ** รวมเชื่อมไม่สำเร็จ (OQ58 จ) · **ไฟล์และการเชื่อม (OQ54, OQ57 ง, OQ65 ข, OQ73):** **ทุกครั้งที่เข้า Arm Lab โดยไม่ได้เปิดไฟล์ (กดจากหน้าหลัก) แล้วเชื่อมสำเร็จ** → สร้างไฟล์ชื่อ `Arm Lab <วันที่>` (ค.ศ. ISO เช่น `Arm Lab 2026-11-05`) ซ้ำในบัญชี → ต่อท้าย ` (2)` ใช้เลขว่างถัดไป ไม่ใช้เลขที่ลบแล้วซ้ำ · **บันทึกจริงเมื่อมีการแก้ครั้งแรก** (เชื่อมแล้วออกโดยไม่แก้ = ไม่เกิดไฟล์ ไม่มี leave guard) · เลขต่อท้ายคำนวณตอนบันทึกจริง · เปิดไฟล์จากงานของฉัน = ใช้ไฟล์นั้น **ต้องเชื่อมหุ่นใหม่** (ไม่มี popup ใช้หุ่นเดิม/ใหม่) · เปิดไฟล์อื่น/งานใหม่ (Ctrl/⌘+N) → แอปตัดการเชื่อมต่อเอง ต้องเชื่อมใหม่ · กด "เปลี่ยนหุ่น"/เชื่อมกลับ → กลับไฟล์เดิม ไม่สร้างใหม่ ไม่เปลี่ยนชื่อ · เปลี่ยนชื่อด้วยมือใน my-work ที่ชื่อซ้ำ = ปฏิเสธตามเดิม · **ชื่อหุ่น (OQ49, OQ55):** default **"หุ่น 1", "หุ่น 2" ตามลำดับที่เจอ** · ตั้ง/แก้ชื่อได้**เฉพาะในหน้าเชื่อมต่อ** · แสดงพอร์ตต่อท้ายชื่อเพื่อแยกตัว · **ความเสี่ยงที่ผู้ใช้รับ:** ลำดับอาจเปลี่ยนทุกครั้งที่เสียบใหม่ ทุกเครื่องได้ "หุ่น 1" เหมือนกัน · การผูกชื่อกับหุ่น ⟨OQ5, OQ61⟩ · **เชื่อมกลับเองเมื่อเป็นหุ่นตัวเดิม (มี ID เฉพาะตัว):** ดู R16 (OQ64) · **กด "เปลี่ยนหุ่น" ไม่ขึ้น popup "งานยังไม่ได้บันทึก" (OQ42):** ไปหน้าเชื่อมต่อได้ทันที (ท่าและค่าอยู่ในไฟล์ ไม่ใช่ในหุ่น · งานไม่หาย)

### รายละเอียดฟังก์ชัน 6A (Observed EV-03 · frame อนุมัติแล้ว ต้องรักษาไว้)

- R12 (M) **ท่าและท่าชุด:** ท่ามีรหัส `G####` · ท่าชุด (action group) สีม่วง `K####` (tooltip เดิมเขียนสลับ = BUG-05) · ท่า 0 "แขนตั้งตรง" **แก้ไขไม่ได้** · ท่า 0 กับท่าพักเป็นคนละท่า · เพิ่มท่า · คัดลอก ตัด วาง ลบ · เลิกทำได้ **6 วินาที** · ลำดับท่าแสดงเป็นการ์ดหรือตาราง · เลือกท่าด้วยแถบ ‹ › หรือแตะจุด S0–S5 บนเวทีหุ่น · **เรียงลำดับท่าด้วยปุ่มขึ้น/ลงบนการ์ดท่า (ไม่ต้องลาก · WCAG 2.5.7) โดย UI ต้องไม่เทอะทะ** · **ท่าชุด K#### คงอยู่ใน MVP** Designer เสนอวิธีสร้าง/เล่นที่เด็ก ป.1–6 เข้าใจง่าย (ผู้ใช้ตัดสิน 2026-10-21 · OQ20) · (ENT-14, ENT-15)
