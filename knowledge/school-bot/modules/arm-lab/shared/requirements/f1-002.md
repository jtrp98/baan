# ข้อกำหนด arm-lab (R13–R15)

- R13 (M) **ข้อต่อและขีดจำกัด:** ข้อต่อ 6 ตัว S0–S5 · **S0 ±180° · S1–S4 ±135° · มือคีบ 0–100%** · เวลาเข้าท่า **1000–9000 ms (ค่าตั้งต้น 3000)** · ค่าเกินขีดจำกัดต้องถูกป้องกันหรือเตือน · แก้ค่าได้ 3 ทาง: กดค้าง (ขยับทีละ 3°) พิมพ์หรือใช้ลูกศร (ทีละ 1° · ต่างกัน = BUG-11 ต้องทำให้สม่ำเสมอ) · **มือคีบ (S5) ไม่ใช้องศา (ผู้ใช้สั่ง 2026-11-04):** หน่วย % ทุกที่ (slider, ช่องพิมพ์, ตารางลำดับท่า, ข้อความ) ห้ามมีสัญลักษณ์ ° · แถบ slider เป็นแบบหนึ่งทิศ 0% ซ้ายสุด = ปิด (หุบ) → 100% ขวาสุด = เปิด (อ้า) (ผู้ใช้ตัดสิน · OQ23) มีป้ายคำ "ปิด"/"เปิด" ที่ปลายแถบ **ไม่มีจุดกึ่งกลาง 0 ไม่มีตัวเลข 0 กลางแถบ** (จุดกึ่งกลาง 0 เป็นของ S0–S4 ที่เป็น ±) · ขั้นแก้ของมือคีบ: กดค้าง 5% · พิมพ์/ลูกศร 1% (ผู้ใช้ตัดสิน · แทน 3°/1°) · **ค่าที่เก็บ (ผู้ใช้ตัดสิน 2026-11-04 · OQ22):** เก็บเป็น PWM จำนวนเต็ม 500–2500 (**สูตรเชิงเส้น 0–100% ผู้ใช้เลือก 2026-11-04:** PWM = 500 + 20 × % · % = (PWM − 500) ÷ 20 · **500 = 0% = ปิด (หุบ) · 1500 = 50% · 2500 = 100% = เปิด (อ้า)** · 1% = 20 PWM พอดี ไม่ใช้ 1–100% เพราะได้ช่วงละ 20.2 และกลางเป็น 50.5%) · **เงื่อนไขก่อนส่ง dev:** ตรวจกับหุ่นจริงว่ากลไกมือคีบรับเต็ม 500–2500 ไม่ชน/ค้าง (ถ้าชน ปรับ 0%/100% เป็นปลายช่วงที่รับได้ หรือให้ครูตั้งขีดจำกัดในโหมดครู R4 = ต้องเพิ่ม requirement) ทั้งในงานและ .ini แล้วแสดงเป็น % (ปัดเฉพาะตอนแสดง) · ขั้น 5%/1% = 100/20 PWM จากค่าปัจจุบัน · พิมพ์ % = PWM ตามสูตรเชิงเส้น · นำเข้า/ส่งออกต้องตรงตัว (ไม่ปัดค่าที่นำเข้า) · ค่านอก 500–2500 = ไฟล์ผิดสำหรับทุก servo (ปฏิเสธพร้อมบอกท่า/บรรทัดตาม R9) · กดค้างบวก/ลบ 5 ตรง ๆ แล้วหยุดที่ 0/100 ไม่ snap (เช่น 47 → 52) · Shift+ลูกศร ±10% (ผู้ใช้ตัดสิน 2026-11-04 · เหมือน S0–S4) · ช่องพิมพ์รับ "50" หรือ "50%" ค่าที่รับคือ 50% (ตัด % ก่อนอ่านค่า · ทศนิยม/ลบ/ตัวอักษรอื่นไม่รับ · ค่านอก 0–100 clamp พร้อมแจ้ง) · ค่าเริ่มต้นไม่สอดคล้อง: ตารางแสดงเวลาท่า 0 = 2000 แต่ `POSE0.t` = 3000 · ท่าแรกที่เพิ่มได้มือคีบ 0% แต่ท่า 0 ใช้ 50% (BUG-06)
- R14 (M) **แก้ท่า อ่านค่า ประวัติ:** ต้องให้หุ่นอยู่ที่ท่านั้นก่อนจึงแก้ได้ (แก้แล้วมีผลทันที) · **slider ล็อกเมื่อไม่รู้ตำแหน่งแขน (OQ43, OQ58 ข, OQ72):** หลังเชื่อม/เชื่อมกลับแล้วกด "ข้าม" · หลังเล่นจากบอร์ด · หลังกู้คืนงาน · หลังปลดล็อกข้อต่อแล้วยังไม่ได้อ่านท่า → ยังเลือกท่าเดิม slider คงค่าที่บันทึกไว้ แต่**ล็อก**พร้อมข้อความว่าหุ่นยังไม่ได้อยู่ที่ท่านี้ จนกด "ไปท่านี้" (ผ่าน popup ขยับครั้งแรกถ้ายังไม่ติ๊ก ตาม R15) หุ่นไปถึงแล้วจึงปลดล็อก · **ปลดล็อกข้อต่อแล้วอ่านท่าปัจจุบันสำเร็จ = รู้ตำแหน่ง ไม่ล็อก** (OQ72 ข) · **หลังถึงท่าพัก:** ไม่ล็อก แต่**ไม่มีท่าที่เลือก** slider ขยับหุ่นจากค่าท่าพักโดยไม่เขียนทับท่าใด จนกด "เพิ่มท่า" (บันทึกเป็นท่าใหม่) หรือเลือกท่าแล้วกด "ไปท่านี้" (OQ72 ก) · slider ไม่ใช่ตำแหน่งจริงของหุ่น ห้ามลากแล้วสั่งหุ่นกระโดดทันที · **ปลดล็อกข้อต่อ (คลายแรงบิด) เพื่ออ่านท่าปัจจุบันจากหุ่น:** **ไม่ผ่าน popup ขยับครั้งแรก** (OQ58 ก) ใช้เตือน "แขนอ่อน" + นับถอยหลังเสมอ · ระหว่างนับมีปุ่ม "ยกเลิก" ตลอด และเวลานับต้องนานพอให้เตรียมตัว · นักเรียนใช้ได้เอง ตาม 6A เดิม (OQ18 บางส่วน) · ไม่รีเซ็ตติ๊ก (OQ57 ข) · **ถ้าสายหลุดตอนแขนอ่อนอยู่ (ล็อกกลับไม่ได้):** ขึ้นหน้าจอเตือนแยก "ประคองแขนไว้ก่อน แขนยังอ่อนอยู่" + บอกให้เรียกครู (ถาวร ไม่หายเอง · ขึ้นก่อน modal หลุดของ R16 · เว้นแถบ nav ให้กดได้ · **ปิดได้** (กดรับทราบ หรือถูกปิดตามกติกา OQ82) หลังปิดหน้าเป็นสถานะยังไม่เชื่อม (disable) + แถบเหลือง `sb-banner-warn` ที่เติมบรรทัดเตือน "แขนยังอ่อนอยู่ ประคองไว้/เรียกครู" · **ปุ่มปลดล็อกข้อต่อใช้ไม่ได้จนเชื่อมหุ่นใหม่ (ปิดตาม R11 · รวมเชื่อมกลับเอง)** · OQ87 แทน "ตามไปทุกหน้า" ของ OQ83) · **ยังไม่ตัดสิน (พับไว้):** วิธีล็อกแขนกลับ — ก) กดค้างปุ่มเดียว ปล่อยแล้วล็อก+อ่านท่าเอง (มีทางเลือกสำหรับคนกดค้างไม่ถนัด เช่น Space ค้าง) ข) กดครั้งเดียว มีแถบ "แขนอ่อนอยู่ จับแขนไว้" และล็อกเองเมื่อครบเวลา/กด "เสร็จ" ค) ตามเดิม: ล็อกอัตโนมัติหลังกด "อ่านท่าปัจจุบัน" + ปุ่ม "ล็อกแขนกลับ" · ทุกวิธีต้องมีข้อความถาวรว่า "แขนล็อกอยู่ ห้ามบิดด้วยมือ ถ้าจะจับแขน กดปุ่มนี้ก่อน" · ผลต่อ OQ1: ถ้า Pi อ่านค่าตอนคลายแขนไม่ได้ ตัดขั้นปลดล็อกทั้งชุดและใช้กรอกมุมแทน ⟨OQ1, OQ12⟩ · ประวัติการใช้งาน (ENT-23) · ใช้คำว่า "อ่านท่าปัจจุบัน" (ห้าม "อ่านท่าจากหุ่น")
- R15 (M) **การเล่น:** **popup ขยับครั้งแรก (OQ43–OQ46, OQ50, OQ56, OQ57 · แทน ST-24 และเตือน >30° ST-23 แบบแยก):** **trigger** = control ที่ส่งคำสั่งให้หุ่นขยับ: เล่น · ไปท่านี้ · กลับท่าพัก · เล่นจากบอร์ด · มือคีบ % · slider · คีย์ลัดที่สั่งขยับ · พับแขนลงกล่อง/ตัดการเชื่อมต่อ (หน้าเชื่อมต่อ) · **ไม่ใช่ trigger:** ปลดล็อกข้อต่อ (ใช้ขั้นของ R14) · อ่านท่าปัจจุบัน · ปุ่มหยุด · ขึ้นครั้งแรกหลังเชื่อม/เชื่อมกลับ เป็น **popup เดียว**: ข้อความหลักเหมือนกันทุก control (เก็บมือ นิ้ว ของออกจากแขนและมือคีบ · ถ้อยคำให้ crayon ร่าง) + **รายการก้าวไกลเกิน 30° เฉพาะ "เล่นลำดับ" กับ "ไปท่านี้"** · ตอนไม่รู้ตำแหน่ง ก้าวแรกระบุ "ไม่ทราบตำแหน่งแขน" + ก้าวถัดไปที่ >30° ตามลำดับ (OQ56 ค) · รายการยาว/ป.1/3 ภาษา: designer จัด · + checkbox "ดูรอบหุ่นแล้ว" (ปุ่มหลักปิดจนติ๊ก) + "ยกเลิก" (ไม่ส่งคำสั่งใด) + "กลับท่าพัก" ท้ายสุด (ปลดด้วย checkbox เดียวกัน) · popup ที่เกิดจากกด "กลับท่าพัก" เองมีปุ่มหลักปุ่มเดียว (OQ52 ก) · **หลังติ๊กและกดปุ่มหลัก:** คำสั่งเล่น/ไปท่านี้ส่งต่อ · slider/กดค้าง/คีย์ลัดต้องกดใหม่ · key-repeat ขณะ popup เปิดไม่สะสม (OQ50 ค) · Esc ขณะ popup เปิด = ยกเลิก popup (ไม่ส่งคำสั่ง ไม่ใช่หยุดหุ่น) · **ติ๊กไม่มีเวลาหมดอายุ รีเซ็ตเฉพาะ (OQ57 ข):** เชื่อมใหม่/เชื่อมกลับ (รวมเปลี่ยนหุ่นและเชื่อมกลับเองอัตโนมัติ · checkbox ใน modal ต่อกลับแล้วของ R16 นับเป็นติ๊ก) · logout · **ไม่รีเซ็ต** เมื่อปลดล็อกข้อต่อ/เล่นจากบอร์ด/กู้คืนงาน/แก้ลำดับ · **ไม่มีเตือน >30° แยกจาก popup (OQ50 ข)** · วัดต่อข้อต่อตามเส้นทางจริงที่ข้อต่อหมุน (S0 หมุนอ้อมนับตามจริง · OQ16) · **ไม่นับมือคีบ** · การขยับจากท่าสุดท้ายกลับท่าแรกเมื่อเล่นหลายรอบ/วนไม่หยุดนับด้วย · **เตือน "วนไม่หยุด" (OQ56 ข, OQ77):** ข้อความเตือนค้างในแผงเล่นตลอดที่เลือกโหมดวน ไม่ต้องกดยืนยัน + ปุ่มหยุดเด่น · **ก้าวแรกใช้ความเร็วปกติ** (เวลาเข้าท่าของท่านั้น · OQ44) · "กลับท่าพัก": ท่าพักเป็นค่าของหุ่น (ไม่ใช่ท่าในไฟล์) เวลาเข้าท่าพัก **3000 ms ไม่ต่ำกว่า 1000 ms** (OQ52 ข) · ท่าพัก = ท่า 0 หรือไม่ ⟨OQ11 · OQ57 ค⟩ · **เล่นจากบอร์ด (OQ71):** หลังสั่ง แอปอยู่สถานะ **"บอร์ดกำลังเล่น"** ปุ่มสั่งขยับทั้งหมดปิดพร้อมเหตุผล จนกดหยุด (ส่งคำสั่งหยุด) หรือ firmware แจ้งว่าจบ ⟨OQ1/OQ14⟩ · ไม่มีติ๊กเพิ่ม · หลังจากนั้น slider ล็อกตาม R14 · **ปุ่มหยุดกดได้โดยไม่ผ่าน popup** (ขณะ popup/dialog เปิดและหุ่นกำลังขยับ ใช้ปุ่มหยุดใน dialog ตาม R5) · **ความปลอดภัยมือคีบ (OQ24):** popup มีข้อความถาวรให้เก็บนิ้วออกจากมือคีบ · เวลาเข้าท่า ≥ 1000 ms · จำกัดอัตราซ้ำตอนกดค้าง · ไม่มีเตือนแยกสำหรับมือคีบ · เล่น**จากโปรแกรม**หรือ**จากบอร์ด** ("เล่นจากบอร์ด" ขึ้นกับ firmware = OQ1) · เลือกช่วงท่าและ**จำนวนรอบ 1–9 หรือวนไม่หยุด** · ปุ่มหยุดสีแดงอยู่ข้างปุ่มเล่น · ระหว่างเล่น (ST-22): ปุ่มหยุดเด่นชัด รูปแขนนิ่ง · อัปโหลดลำดับท่าลงบอร์ดได้ (ใช้คำ "อัปโหลดลงบอร์ด") · **เงื่อนไขก่อนส่ง dev:** ยืนยันกับ firmware (OQ11/OQ14) ว่าก้าวแรกจากตำแหน่งใดก็ได้ไม่ทำให้หุ่นเสียหาย/ชน และค่าท่าพัก/3000 ms ปลอดภัย · **ความเสี่ยงที่ผู้ใช้รับ (ธงให้ highlighter):** หลังติ๊กแล้วก้าวไกลครั้งต่อไปไม่มีเตือนอีก · หลังเล่นจากบอร์ด/ปลดล็อกข้อต่อ/กู้คืนงาน ตำแหน่งไม่ทราบแต่ไม่มี popup กั้น (มี slider ล็อกอย่างเดียว) · ตำแหน่งเปลี่ยนโดยแอปไม่รู้ (ดับไฟ/จับแขนด้วยมือ/เครื่องอื่นสั่ง) ไม่รีเซ็ต · ติ๊กไม่หมดอายุบนเครื่องห้องเรียนใช้ร่วม · ก้าวแรกเร็ว · เปิดไฟล์ต้องเชื่อมและติ๊กใหม่ทุกไฟล์ ·
