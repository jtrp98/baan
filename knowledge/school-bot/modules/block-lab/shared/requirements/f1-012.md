## Edge cases
- EC-07 ส่งโปรแกรมที่มีบล็อก Stage ลง Uno จริง: ส่งได้ · บล็อก Stage ไม่ถูกแปลงเป็นโค้ด · แจ้งสั้น ๆ "บล็อกตัวละครทำงานเฉพาะในจอ" (Confirmed DEC-23)
- EC-08 อุปกรณ์ในตัวจำลองเสีย (เช่น LED ไม่มีตัวต้านทาน): หยุดจำลอง · อุปกรณ์แสดงสถานะเสีย · บอกสาเหตุและวิธีแก้ภาษาเด็ก · ปุ่ม "เปลี่ยนอุปกรณ์ใหม่" · ไม่กะพริบ ไม่มีเอฟเฟกต์ระเบิด (Confirmed DEC-22 · ระดับ OQ1)
- EC-09 ส่งลง Uno จริงแต่สายจริงต่อไม่ตรงกับวงจรในจอ: แอปตรวจสายจริงไม่ได้ · ก่อนส่งแจ้งให้ต่อสายตามวงจรในจอ (Confirmed DEC-27)
- EC-01/EC-04 เน็ตหลุด/เปลี่ยนเครื่อง: ดู my-work (FR-22–24 · ฉบับใหม่กว่าชนะ) · ENT-17 ต้องรวมวงจรใน export ของ Block (รูปแบบไฟล์ → OQ5)
- EC-06 เด็ก ป.1–2 เข้ามาใช้ (เปลี่ยน 2026-10-22): ไม่ปิดกั้น · ไม่ออกแบบให้ · ไม่รับประกันว่าอ่าน/ใช้ได้ (R12)
- EC-10 วงจรถูกแก้หลังกดเริ่มจำลองแล้วเตือน: ปฏิบัติตาม R10 (หยุดจำลองอัตโนมัติ) · เริ่มใหม่ = ตรวจใหม่ (R17)
- แก้วงจร/บล็อกระหว่างจำลอง: หยุดอัตโนมัติ (R10 · Proposed)
- CF-01 Block Lab ใน frame (ESP32/MixGo/Python/แถบภารกิจ) ขัด requirement → ต้องทำรายการบล็อกและตัวสร้างโค้ดใหม่ทั้งชุด ตัดแถบภารกิจ (Open → Designer แก้ใน Canvas C · หมวดยืนยันแล้ว DEC-20)

คำถามที่ยังไม่ตัดสินอยู่ใน `../oq.md`
