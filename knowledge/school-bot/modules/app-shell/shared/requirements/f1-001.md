## Requirements
ลำดับ: M = Must · ? = ยังไม่ยืนยัน (ดู OQ)

- R1 (M): **Installer** สำหรับ Windows และ Mac หน้าตาทันสมัย เรียบ เป็นมิตร มีขั้นตอนชัดเจน (ถัดไป → ติดตั้ง → เปิดโปรแกรม) แสดงเวอร์ชันและความคืบหน้า · **ไม่มีขั้นติดตั้ง driver** (ฝังทุกอย่างใน installer · ผู้ใช้ตอบ 2026-10-20) · ต้องมีสถานะติดตั้งสำเร็จ / ไม่สำเร็จ (ไม่มีสิทธิ์ · พื้นที่ไม่พอ) พร้อมสาเหตุและ "ลองใหม่" · (FR-01, AC-01, SCR-01, ST-01, ST-02, DEC-05, DSG-08)
- R2 (M): **แถบหน้าต่างของโปรแกรมเอง** พร้อมปุ่ม ปิด / ย่อ / ซ่อน ใช้ได้ทั้ง Windows และ Mac · ปุ่มวางตามธรรมเนียมแต่ละ OS: **Mac ปุ่มอยู่ซ้าย (ปิด ย่อ ซ่อน) · Windows ปุ่มอยู่ขวา (ย่อ ซ่อน ปิด · ผู้ใช้ตัดสิน 2026-10-22 ตามภาพอ้างอิง · เดิม ซ่อน ย่อ ปิด)** · "ซ่อน" = ย่อลง tray (Windows) / menu bar (Mac) (ผู้ใช้ตอบ 2026-10-20) · (FR-02, AC-02, SCR-02, DEC-05, DSG-03, DSG-11, DEV-Q11, ARC-I19) · **แก้ 2026-10-26 (OQ17, OQ18):** ปุ่มกลางเปลี่ยนจาก "ซ่อน" เป็น **"ขยาย/คืนขนาด" ใช้งานได้จริง** และ **ไม่มีฟังก์ชันซ่อนลง tray/menu bar แล้ว** (ลบข้อความ "ซ่อน = ย่อลง tray/menu bar" ด้านบน) · ลำดับ Windows: **ย่อ / ขยาย / ปิด** · Mac ซ้าย: ปิด / ย่อ / ขยาย · ส่วนหัวทุก lab เหมือนกัน: home › ☰ › โลโก้ School Bot + ชื่อ lab › | › เว้นว่าง › | › เปลี่ยน (อุปกรณ์) › | › ชื่องาน + สถานะบันทึก › | › ปุ่มหน้าต่าง · **ปุ่ม home มีทั้ง Arm Lab และ Block Lab** (ผ่าน leave guard) · แถบเดียวสูง 60
- R3 (M): **ตัวบอกสถานะการบันทึกบนแถบหน้าต่าง** 4 แบบ (ออนไลน์/บันทึกแล้ว · กำลังบันทึก · ออฟไลน์ · บันทึกไม่สำเร็จ) ใช้ไอคอน + ข้อความ ไม่ใช้สีอย่างเดียว · กดแล้วเห็นรายละเอียดและ "ลองอีกครั้ง" เมื่อไม่สำเร็จ · **แสดงสถานะคลาวด์ที่แถบหน้าต่างที่เดียว** ไม่ซ้ำที่หน้าอื่น · (ST-03, ARC-I05, DSG-03, EDIT-09) · **แก้ 2026-10-26 (block-lab OQ115):** ชิปสถานะคลาวด์แสดง **เฉพาะเมื่อผิดปกติ** (ออฟไลน์ / บันทึกไม่สำเร็จ + ลองอีกครั้ง) ปกติแสดงเป็นข้อความ "บันทึกแล้ว HH:MM" ใต้ชื่องานเท่านั้น · "กำลังบันทึก" ไม่แสดงชิป (block-lab OQ124 open)
- R4 (M): **ชิปอุปกรณ์บนแถบหน้าต่าง แสดงเฉพาะใน lab ที่เปิดอยู่:** Block Lab = บอร์ด Uno (ชนิด พอร์ต สถานะ) · Arm Lab = ชื่อหุ่น พอร์ต สถานะ · **นอก lab ไม่แสดงชิปอุปกรณ์** · รับ prop ชนิด/ชื่อ/พอร์ตจริง ห้ามตายตัว · 4 สถานะ: ยังไม่เชื่อม / กำลังเชื่อม / เชื่อมแล้ว / หลุด · (CR-08, ARC-I32, ST-39, ENT-19, FR-02 · ผู้ใช้ตอบ 2026-10-21)
- R5 (M): **การปิดโปรแกรมอย่างปลอดภัย:** ปิดตอนหุ่นกำลังขยับ → dialog หยุดหุ่นแล้วจึงปิด · ปิดตอนงานยังไม่ขึ้นคลาวด์ → แจ้งว่างานอยู่ในเครื่อง (ไม่หาย) · **ปุ่มหยุดทั้งหมดต้องกดได้เสมอ แม้ dialog/popover ของแถบหน้าต่างเปิดอยู่** (AUD-F01 ระดับ C · CR-10 ตัดสินทาง ก) · (NFR-04, AC-02, FRM-05, CR-10)
- R6 (M): **Login 3 ขั้น:** เลือกโรงเรียน (ค้นหา) → กรอก username → กรอก password · กรอกผิดเห็นข้อความบอกวิธีแก้ · ลืมรหัสนักเรียนบอกให้ "บอกครูให้ช่วยรีเซ็ต" (Proposed) · login **ต้องออนไลน์** (Proposed) · ครูใช้บัญชี SchoolBright เดียวกัน · (FR-03, AC-03, EC-02, UJ-01, SCR-03, SCR-04, DEC-03, ST-04–08, ARC-I13)
