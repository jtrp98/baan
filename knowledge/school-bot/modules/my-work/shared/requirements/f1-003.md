## กฎ/Logic
- **AC-13:** งานบันทึกบน cloud อัตโนมัติหรือเมื่อกดบันทึก · export .ini ได้ · กู้คืนสำรองในเครื่องได้
- **AC-04 (ส่วนงานล่าสุด · ของ app-shell):** หน้าหลักแสดงงานล่าสุดแยก 2 กลุ่ม Arm Lab / Block Lab เรียงเวลาแก้ล่าสุด กลุ่มละ ≤ 3 ใบ "ดูทั้งหมด →" ไปหน้างานของฉันของโปรแกรมนั้น · ไม่มีปุ่มสร้าง
- งาน Arm/Block ไม่มีคะแนน และไม่ส่งเข้า SchoolBright (DEC-18) · เว็บครูไม่แสดงงาน Lab ใน MVP
- สถานะ sync ใช้ถ้อยคำ "บันทึกขึ้นคลาวด์" (ไม่ใช้ Sync/อัปโหลดคำเดียว) · error มีรหัส + วิธีแก้ (E-CLOUD)

## การตัดสินใจที่ผูกกับ module
DEC-13 งานบันทึกบน cloud เป็นหลัก export .ini ได้ กู้คืนสำรองได้ (CHG-03) · DEC-14 ครูจัดการผ่านเว็บ (งานนักเรียนไม่เกี่ยว) · DEC-18 งาน Lab ไม่มีคะแนน · DEC-27 วงจรในตัวจำลองบันทึกกับงานบน cloud และเป็นแบบให้ดู · CHG-03 (2026-10-20): การเก็บงานเปลี่ยนจาก "cloud อย่างเดียว" เป็น cloud เป็นหลัก + export .ini + กู้คืนสำรองในเครื่อง

## Edge cases
- EC-01 เน็ตหลุดระหว่างทำงาน: ไม่เสียงาน มีสำรองในเครื่องให้กู้คืน (R3, R7) · รายละเอียด OQ2
- EC-04 เปลี่ยนเครื่องคอมพิวเตอร์: เปิดงานต่อจาก cloud (R1) · ถ้ามีฉบับใหม่กว่า ฉบับใหม่กว่าชนะ + แจ้ง (R8)
- ปิดโปรแกรมตอนยังไม่ได้บันทึกขึ้นคลาวด์: แถบหน้าต่างแจ้งว่างานอยู่ในเครื่อง (ของ app-shell)
- เปิดโปรแกรมหลังปิดผิดปกติ: พบสำรองใหม่กว่า cloud → R3
- ลบงานโดยพลาด: toast + เลิกทำ (ระยะเวลาเลิกทำ Unknown → OQ6)
- ความขัดแย้งในต้นฉบับ: CF-03 (6A เก็บแบบโฟลเดอร์ ขัด cloud) แก้แล้วผ่าน CR-05 · ARC-I17 ยืนยันก่อนลบ vs FRM-03 toast + เลิกทำ (OQ6)
