## 2. รายการโครงงาน: สร้าง / เปิด / สลับ / บันทึก (REQ-011 · REQ-012 · DES-003)

ใช้ [ข้อกำหนดร่วมของการสร้าง เปิด สลับ และบันทึกโครงงาน](int-003-projects-save-list.md) ชุดเดียวกัน ตารางด้านล่างต่อด้วยไฟล์ผิดรูป การสลับงาน Arm และการย้ายข้อมูลเดิม

| State | เงื่อนไข | UI + คำ copy (ข้อเสนอ) |
|---|---|---|
| เปิดไฟล์เสีย/เกิน | [AC-011-03 (เปิดไฟล์ JSON เสียหรือเกิน 1 MiB แล้วมีข้อผิดพลาด)](../../shared/requirements/req-011.md) | "เปิดงานไม่สำเร็จ — ไฟล์เสียหายหรือใหญ่กว่า 1 MiB (PROJECT_INVALID / PROJECT_TOO_LARGE)" ไม่แสดงว่าเปิดสำเร็จ; งานอื่นในรายการยังใช้ได้ |
| สลับงานใน Arm Lab | เชื่อมต่อหุ่นอยู่ | สถานะบนบอร์ดรีเซ็ต: ป้าย "สถานะบนบอร์ด: ยังไม่ได้อัปโหลดใน session นี้" ([AC-017-03 (บันทึกและเปิดใหม่แล้วไม่มีสถานะยืนยันว่าอัปโหลดตรงกับบอร์ดหรืออยู่ตรงท่าที่บันทึกโดยอัตโนมัติ)](../../../arm-lab/shared/requirements/req-017.md)) + ออกจาก workspace เดิมส่ง stop อัตโนมัติ ([AC-021-04 (เมื่อออกจาก native workspace ที่เชื่อมต่ออยู่ พบคำขอ stop แม้ไม่มีคำสั่งกำลังรอผล)](../../../arm-lab/shared/requirements/req-021.md)) |
| migration ครั้งแรก | มีข้อมูลแอปเก่า | toast "นำเข้างานเดิม X รายการจากแอปเดิม" · ไฟล์เสียแจ้งแยก "ไฟล์งานเก่าบางรายการไม่รองรับ — ข้ามไว้ (MIGRATION_UNSUPPORTED)" ไม่ขัดขวางงานอื่น; ไม่ทับข้อมูลใหม่ ต้นฉบับคงอยู่ ([AC-011-04 (เมื่อมีข้อมูลทั้งชื่อแอปเก่าและใหม่ การเริ่มแอปไม่ทับข้อมูลใหม่)](../../shared/requirements/req-011.md), [BR-011-03 (ย้ายข้อมูลเดิมโดยไม่ทับข้อมูลใหม่และไม่ลบต้นฉบับ)](../../shared/requirements/req-011.md)) |

หมายเหตุ: บันทึกงานหนึ่งไม่แทนอีกงานอัตโนมัติ — แก้ A แล้ว B ในโหมดเดียวกันไม่เปลี่ยน ([BR-011-01 (แต่ละโหมดมีหลายโครงงานแยกกันได้)](../../shared/requirements/req-011.md), [AC-011-02 (บันทึกการแก้ไขงาน A แล้วเปิดใหม่ได้ค่าล่าสุดของ A โดยงาน B ในโหมดเดียวกันไม่เปลี่ยน)](../../shared/requirements/req-011.md)) · ครู (employee) Login ใช้หน้านี้เก็บโครงงาน Cloud ของตนได้ ([DES-005 (หลักสูตร ภารกิจ และผลประเมิน)](../../../../build/design/des-005.md)) · "บันทึกเป็นสำเนา" (Save As) ใช้แทนข้อความ single-project เดิมของ NativeWorkspace
