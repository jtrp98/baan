# มติด้านผลิตภัณฑ์และการเรียนรู้

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่)

SchoolBot เป็นระบบใช้งานจริงสำหรับนักเรียนและครู มีสามโหมด พร้อมโครงงาน บทเรียน และการส่งคะแนนกลับโรงเรียน มติต่อไปนี้แสดงเฉพาะส่วนที่ยังใช้ รายละเอียดคำตอบและข้อจำกัดอยู่ในไฟล์มติแต่ละรายการ

## เป้าหมาย ผู้ใช้ และโครงงาน

- [มติ 001 (ผู้ใช้และเป้าหมายการเรียนรู้)](decisions-001.md) · 2026-10-21 · นักเรียนและครูเรียนเขียนโปรแกรมและควบคุมหุ่น โดย Guest เก็บงานในเครื่อง ส่วน Login เก็บบนฐานข้อมูลหรือ Cloud
- [มติ 002 (ระบบใช้งานจริงครบทุกส่วน)](decisions-002.md) · 2026-10-21 · พัฒนาระบบเต็ม โดยใช้ข้อจำกัดฐานเดิมเป็นช่องว่างที่ต้องเติม
- [มติ 003 (โครงสร้างสามโหมด)](decisions-003.md) · 2026-10-21 · ผลิตภัณฑ์มี Block / Arm / Code และแยกหน้าบทเรียนจากพื้นที่สร้างงาน
- [มติ 008 (หุ่นจริงบนสองระบบปฏิบัติการ)](decisions-008.md) · 2026-10-21 · Windows และ macOS ต้องควบคุมหุ่นจริงได้ทั้งคู่
- [มติ 009 (หลายโครงงานและผู้ประเมิน)](decisions-009.md) · 2026-10-21 · Guest และ Login เก็บหลายโครงงานได้ทุกโหมด โดย Code/Block ตรวจอัตโนมัติและ Arm ให้ครูตรวจ
- [มติ 014 (พื้นที่ Guest ร่วมและนำเข้าบัญชี)](decisions-014.md) · 2026-10-21 · Guest ใช้พื้นที่ร่วม เก็บจนสั่งลบ ส่งออกได้ และเลือกนำงานหรือประวัติเข้าบัญชีเองโดยคงต้นฉบับ กันซ้ำ และตรวจผลใหม่
- [มติ 015 (ถังขยะ เนื้อหา และขอบเขตครู)](decisions-015.md) · 2026-10-21 · Guest กู้จากถังขยะได้ 30 วัน ทีมร่างเนื้อหาสามโหมดให้ผู้ใช้หรือผู้ที่ผู้ใช้ระบุอนุมัติ และครูดูแลเฉพาะนักเรียนที่ผู้ดูแลกำหนด
- [มติ 016 (ผู้อนุมัติภาพรวม)](decisions-016.md) · 2026-10-21 · ผู้ใช้อนุมัติข้อกำหนด หน้าจอ และตรวจรับภาพรวม โดยทีมเตรียมข้อเสนอหุ่นและระบบปฏิบัติการให้ตรวจ
- [มติ 019 (ระบบปฏิบัติการเป้าหมาย)](decisions-019.md) · 2026-10-21 · รองรับ Windows 11 25H2 x64 และ macOS 15+ ทั้ง Intel/Apple Silicon โดยยุติเป้าหมาย Windows 10
- [มติ 022 (ที่อยู่หน้าจัดการและหน้าครู)](decisions-022.md) · 2026-10-22 · หน้าจัดการส่วนกลางใช้ Next.js ใน school-bot/web หน้าครูอยู่ sb-tech-upgrade-web-system และ Desktop ใช้เรียนรู้

## License

- [มติ 004 (บังคับ License และชื่อข้อมูล)](decisions-004.md) · 2026-10-21 · ทุกโหมดทั้ง Guest/Login ต้องมี License และใช้ชื่อตาราง SchoolBot พร้อมฟิลด์มาตรฐาน
- [มติ 005 (สิทธิ์ออฟไลน์สามวัน)](decisions-005.md) · 2026-10-21 · ครั้งแรกต้องตรวจออนไลน์ แล้วใช้ออฟไลน์ได้สามวันนับจากการตรวจออนไลน์สำเร็จล่าสุด
- [มติ 006 (หนึ่ง Key ต่อหนึ่งเครื่อง)](decisions-006.md) · 2026-10-21 · หนึ่ง License Key ผูกกับเครื่องปัจจุบันได้หนึ่งเครื่อง และเปิดซ้ำจากเครื่องเดิมได้
- [มติ 007 (ย้าย License โดยผู้ดูแล)](decisions-007.md) · 2026-10-21 · ผู้ดูแลปลดเครื่องก่อนย้าย Key เดิมได้ทันที โดยเครื่องเดิมอาจใช้ออฟไลน์จนสิทธิ์เดิมหมด

## หลักสูตร การประเมิน และคะแนน

- [มติ 020 (หลักสูตรกลางและเลื่อนระดับทั้งห้อง)](decisions-020.md) · 2026-10-22 · หลักสูตรกลางหนึ่ง Level ใช้หนึ่งเทอม ผูกชั้นและวิชาได้ โรงเรียนไม่แก้เนื้อหา และระบบเสนอเลื่อนทั้งห้องเมื่อค่าเฉลี่ยสูงกว่าเกณฑ์ให้ครูยืนยัน
- [มติ 021 (ส่งคะแนนเข้าช่องย่อย)](decisions-021.md) · 2026-10-22 · SchoolBot เขียนคะแนนช่องย่อยที่จับคู่ไว้เมื่อครูยืนยัน โดยไม่เปลี่ยนโครงสร้างเกรด และให้ครูเลือกเมื่อคะแนนชน
- [มติ 023 (เขียนคะแนน ปัดเศษ และนำเข้า Sheet)](decisions-023.md) · 2026-10-22 · SchoolBot เขียนคะแนนเอง ปัดจำนวนเต็มแบบ half-up นำเข้าทุกแถวเป็นร่าง และให้เฉพาะผู้ดูแลโรงเรียนแก้การจับคู่ช่องคะแนน
- [มติ 024 (เกณฑ์เลื่อนระดับและค่าเริ่มข้อสอบ)](decisions-024.md) · 2026-10-22 · ส่วนกลางตั้งเกณฑ์ราย Level เริ่ม 70% ประเมินสิ้นเทอมโดยนับทุกคนและงานขาดเป็นศูนย์ พร้อมค่าเริ่ม Quiz ไม่จำกัดครั้งและ Test หนึ่งครั้งที่เปิดสอบซ่อมรายคนได้
- [มติ 032 (ครูทดลองและการจับคู่ช่องคะแนน)](decisions-032.md) · 2026-10-23 · ครูเก็บโครงงาน Cloud ได้แต่ไม่ส่งงานหรือสอบบน Cloud กิจกรรมหนึ่งได้หลายช่อง ช่องหนึ่งได้กิจกรรมเดียว และการจับคู่ที่ส่งแล้วต้องล็อก
- [มติ 033 (ช่องเดิมและแปลงคะแนนเต็ม)](decisions-033.md) · 2026-10-23 · เลือกเฉพาะช่องเกรดเดิม ส่งตามสัดส่วนคะแนนเต็มแล้วปัด half-up และข้ามผู้ที่ยังไม่มีผลโดยคงคะแนนเดิม
- [มติ 034 (สูตรรวมและขอบเขตครูปรับข้อสอบ)](decisions-034.md) · 2026-10-23 · น้ำหนักกิจกรรมรวม 100% เปลี่ยนได้เฉพาะรอบเรียนใหม่ และครูปรับเฉพาะเวลาสอบกับช่วงเปิด–ปิดโดยคงสิทธิ์สอบซ่อมรายคน
