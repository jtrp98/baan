# มติที่ 053 — เปิดงานถัดไปบน stub และวิธีปิดประตูมนุษย์ 4 จุดของรอบพัฒนา 2026-11-03

วันที่ 2026-11-03 · ผู้ตอบ: ผู้ใช้ในแชต · ผู้บันทึก: นายช่าง

## มติ

1. **งานที่ต่อจาก Login และ web-principal เปิดบน stub ได้** — BE-006 (Login/session) และ BE-039 (web-principal/BFF/session) ผ่านการตรวจและการตรวจความปลอดภัยเฉพาะส่วนในเครื่องแล้ว เหลือรอ H5 (เงื่อนไข route/env/network/trust) กับ production · ให้เปิด BE-003 (License ฝั่ง admin แบบเก็บถาวร) และ BE-008 (หลายโครงงานผ่าน Cloud API) บน stub ได้ · การเชื่อม production/H5 ผูกกับงานที่ต่อของจริงเท่านั้น
2. **หลักฐานฐานข้อมูลของ DBA-003 (ตรวจ core หลังรัน SQL)** — vault เขียน query อ่านอย่างเดียว (SELECT เท่านั้น) ผู้ใช้เป็นคนรันบน PostgreSQL 15.19 แล้วส่งผลกลับ ทีม AI ไม่รัน SQL เอง
3. **เนื้อหาบทเรียน BA-005 (Block/Code) และ BA-006 (Arm/rubric)** — spec ร่างรายการเนื้อหาจาก source และบทเรียนเดิม ติดป้าย (สมมติฐาน — ยังไม่ยืนยัน) งานพัฒนาเดินต่อบนร่างนี้ได้ ผู้ใช้เซ็นรับเนื้อหาจริงก่อน BE-015 (ระบบหลักสูตร) และ FE-013 (หน้าจอบทเรียน) ต่อของจริง
4. **สัญญา Host/IPC/หุ่น (SA-003)** — arch เตรียมผลทบทวนได้ทันที ประตู G-ROBOT-CONTRACT (คนทบทวน breaking change) ผูกที่ BE-010 (Host engine) เท่านั้น งาน Labs ใช้ fake transport/simulator · ยังไม่อนุญาตทดสอบหุ่นจริงตาม [มติ 038 (ผู้อนุมัติและเกณฑ์ตรวจรับ)](decisions-038.md)

## ผลต่อแผน

ไม่เพิ่มหรือลดขอบเขต 44 ข้อกำหนด / 187 เกณฑ์ตรวจรับ · เปลี่ยนเฉพาะจุดที่ประตูมนุษย์ผูกอยู่ ตามกติกา "ทำบน stub ก่อน ประตูผูกที่ task ที่ต่อของจริง"
