# มติแหล่งสิทธิ์แอดมินโรงเรียน

## คำตอบผู้ใช้ — 2026-10-23

ผู้ตอบ: ผู้ใช้ในแชตนี้ ผ่าน request_user_input_async

คำถาม: SchoolBot ควรให้สิทธิ์แอดมินโรงเรียนจากแหล่งใด? JWT ของสมาชิกกลุ่มแอดมินโรงเรียนปกติในระบบเดิมส่ง IsAdmin=0

คำตอบตรง:

> ตรวจกลุ่ม “แอดมิน/ผู้บริหาร” ฝั่ง server และคง super admin เดิม (แนะนำ: รักษาสิทธิ์แอดมินโรงเรียนเดิม)

## ข้อที่ผู้ใช้เลือก

- เลือกทาง A ใน [Gateway integration Rev1](../../build/design/gateway-integration-001.md): ตรวจกลุ่มสิทธิ์ฝั่ง server เพื่อรักษาสิทธิ์แอดมินโรงเรียนเดิม และคง super admin เดิม
- ไม่เลือกทาง JWT-only ที่จะทำให้สมาชิกกลุ่มแอดมินโรงเรียนปกติซึ่งได้ IsAdmin=0 ไม่ได้รับสิทธิ์จัดการ SchoolBot
- เป็นข้อยุติแหล่ง is_admin ที่ถามในรอบ002 ไม่ถามทางเลือกนี้ซ้ำ

## การส่งต่อและขอบเขต

arch รับไป amend DES-012/auth-evidence/Gateway addendum ให้ตรงมติและหลักฐาน legacy เดิม รวมสิ่งที่ยังต้องพิสูจน์ก่อนเปิดใช้. ปิดเฉพาะคำถามนโยบายแหล่งสิทธิ์ ไม่ปิด G-AUTH/H5/ข้อเท็จจริง mapping/SQL/runtime/QA/security; ไม่รับความเสี่ยงใหม่ ไม่อนุมัติ GRANT/สร้างตารางหรือ deploy จากคำตอบนี้

ข้อเท็จจริง session/JWT ที่เป็นเหตุให้ถามอยู่ใน หลักฐานต้นฉบับ (memory: planning/legacy-auth-review-002.md); มติเดิม025/026เรื่อง token exchange/Channel/License และรูปแบบ service ผ่านgatewayยังคงเดิม
