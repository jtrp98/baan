# มติทดสอบแพ็กเกจเดิมก่อนปรับตัว Setup
> ถูกแทนด้วย มติ 019 (ยุติการเตรียมทดสอบ Windows 10; ผลตรวจแพ็กเกจเดิมยังเป็นหลักฐานตามวันที่) — [มติ 019](decisions-019.md)

## คำตอบผู้ใช้ — 2026-10-21

ผู้ตอบ: ผู้ใช้ในแชตนี้ ผ่าน คำถามแนวทาง Home/Pro (memory: planning/human-questions-005.md)

คำตอบ: "ทดสอบแพ็กเกจเดิมและสำรวจเครื่องก่อน แล้วเสนอผลกับข้อจำกัดให้ตัดสินอีกครั้ง (แนะนำ)"

ผู้ใช้เลือกตรวจแพ็กเกจและสภาพแวดล้อมเดิมก่อน ยังไม่ได้เลือกเปลี่ยน runtime ของ Setup หรือจำกัด Windows 10 ให้เป็น LTSC เท่านั้น และไม่ได้ยอมรับความเสี่ยงล่วงหน้า

## ผลก่อนมีคำชี้แจงถัดไป

ตรวจพบ Setup/MSI 0.1.5, SHA256 ตรง sidecar ทั้งคู่ และ MSI structural checks ผ่านบนเครื่องปัจจุบันโดยไม่ติดตั้งหรือเปิดแอป ไม่มี Windows 10/VM ที่พร้อมใช้จาก inventory ที่ตรวจ จึงถามเรื่องสภาพแวดล้อม ดู preflight (memory: planning/installer-preflight-001.md)

## มติถัดมา

หลังคำถามสภาพแวดล้อม ผู้ใช้เลือกให้ฝั่ง Windows รองรับเฉพาะ Windows 11 ตามข้อเสนอแรก ดู [decisions-019](decisions-019.md) มติใหม่ยุติงานเตรียมทดสอบ Windows 10 ของสาขานี้ ไม่บันทึกว่ามีผล runtime test Win10 หรือเปลี่ยน Setup แล้ว
