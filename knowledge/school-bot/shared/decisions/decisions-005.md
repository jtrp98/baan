# License ออฟไลน์ 3 วัน — 2026-10-21

## คำตอบผู้ใช้

ผู้ใช้ในแชตตอบว่า ครั้งแรกจำเป็นต้องใช้อินเทอร์เน็ต ครั้งถัดไปที่ออฟไลน์ให้ตรวจจากค่าในเครื่อง ค่าดังกล่าวหมดอายุได้ใน 3 วัน แล้วนำ Key ในเครื่องไปตรวจว่ายัง Active อยู่

## กติกาที่บันทึก

1. เปิดใช้ครั้งแรกต้องออนไลน์และตรวจ License ผ่านก่อนเข้าใช้งานแอป
2. เก็บสิทธิ์ที่ตรวจผ่านและข้อมูลที่จำเป็นสำหรับส่ง Key เดิมไปตรวจใหม่ไว้ในเครื่อง
3. ครั้งถัดไปใช้ออฟไลน์จากสิทธิ์ในเครื่องได้ภายใน 3 วันนับจากการตรวจออนไลน์สำเร็จล่าสุด การเปิดแอปใหม่ไม่เริ่มนับ 3 วันใหม่
4. เมื่อสิทธิ์ในเครื่องครบ 3 วัน ต้องต่ออินเทอร์เน็ตเพื่อตรวจ Key อีกครั้ง
5. ถ้ายัง Active ให้ต่ออายุสิทธิ์ในเครื่องอีก 3 วันจากการตรวจครั้งใหม่; ถ้าติดต่อไม่ได้หรือไม่ Active ไม่ออกสิทธิ์ใหม่และไม่ปลดล็อกแอปจากสิทธิ์ในเครื่องที่หมดอายุ
6. ใช้กับ Block / Arm / Code ทั้ง Guest และ Login ตามมติบังคับ License เดิม; ไม่ใช้ค่าที่รู้ว่าหมดอายุหรือถูกเพิกถอนเพื่อปลดล็อก

นี่คือข้อกำหนดที่ต้องพัฒนา ยังไม่ใช่พฤติกรรมที่ implement หรือผลทดสอบ
