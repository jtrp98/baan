### spec

- **Q1**: ผู้รับผิดชอบตรวจอนุมัติเนื้อหา/เกณฑ์ revision บทเรียน = **ผู้ใช้** (บันทึกลงช่องผู้อนุมัติของ pack-content-inventory; การอนุมัติราย revision จริงยังต้องทำทีละฉบับเมื่อมีเนื้อหา BA-005/006)
- **Q2**: ยืนยัน rubric ดาว 1/2/3 + ตารางคู่ผ่าน–ไม่ผ่านทั้งชุด (ดาวไม่ใช่เงื่อนไขเลื่อน Level) — ป้ายสมมติฐานของ rubric ถอดออกเฉพาะส่วนที่ยืนยัน; ค่าที่ผูกกับหุ่นจริงยังค้างตาม Q3
- **Q4**: **ยังไม่อนุญาตทดสอบอุปกรณ์จริง** — ทุกงาน robot ใช้ dry-run/fake bridge ต่อจนกว่าจะมีคำสั่งอนุญาตเป็นลายลักษณ์อักษร (บันทึกลง pack-hardware §3)
- **Q5**: ยังไม่ระบุผู้ถือใบรับรอง code signing / ช่องทางแจกจ่าย — G-DELIVERY ค้างเรื่อง signing/custody ต่อไปตามเดิม
