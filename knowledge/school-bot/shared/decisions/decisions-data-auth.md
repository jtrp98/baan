﻿# มติด้านบัญชี สิทธิ์ และฐานข้อมูล

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (บันทึกมติ 052 — อายุ Desktop session นับจากเวลา bind สำเร็จ)

SchoolBot ใช้บัญชีและข้อมูลเดิมของ SchoolBright ร่วมกับฐานข้อมูล SchoolBot แยกต่างหาก รายการนี้สรุปส่วนที่ยังใช้ โดยเงื่อนไขและการยอมรับความเสี่ยงอ่านจากไฟล์มติที่ลิงก์ไว้

## Login และสิทธิ์

- [มติ 010 (ใช้บัญชีเดิมและ API ของ SchoolBot)](decisions-010.md) · 2026-10-21 · API (Application Programming Interface) รวม Login อยู่ school-bot/web และใช้บัญชีเดิมโดยไม่สร้าง SchoolBotUser
- [มติ 025 (ยืนยันตัวตนและสิทธิ์ข้ามระบบ)](decisions-025.md) · 2026-10-22 · เว็บแลก token เป็น session ผ่าน Gateway ผู้ใช้รับความเสี่ยง token เดิมไม่มีวันหมดอายุ หน้าเว็บต้องมี License โรงเรียน การเผยแพร่ต้องมีผู้อนุมัติคนที่สอง ย้าย admin API ไป /v2/admin สอบซ่อมใช้คะแนนสูงสุดไม่มีเพดาน และ Desktop ให้นักเรียนกับครูใช้เรียนหรือทดลอง
- [มติ 035 (แหล่งสิทธิ์ผู้ดูแลโรงเรียน)](decisions-035.md) · 2026-10-23 · ตรวจกลุ่มแอดมินและผู้บริหารฝั่ง server พร้อมคง super admin เดิม แทนการพิจารณา IsAdmin ใน token เพียงอย่างเดียว

- [มติ 052 (อายุ Desktop session นับจากเวลา bind สำเร็จ)](decisions-052.md) · 2026-11-02 · Desktop login ได้ session ชั่วคราว 5 นาทีเพื่อเลือกตัวตน เมื่อ bind สำเร็จให้ `ExpiresAt = เวลาที่ bind + 8 ชั่วโมง`; งานที่เริ่มตรวจด้วย DES-004 Rev12 คงเกณฑ์เดิม

## ฐานข้อมูลและตำแหน่งระบบ

- [มติ 011 (ใช้ฐานข้อมูลเดิมสี่ตัว)](decisions-011.md) · 2026-10-21 · SchoolBot ใช้ข้อมูลจาก Master, School, Logs และ PGGradeDB เดิมร่วมกัน โดยตำแหน่งตารางใหม่และสิทธิ์เขียนเกรดใช้มติที่ตอบภายหลัง
- [มติ 012 (ชนิดรหัสหลักและแผนภาพข้อมูล)](decisions-012.md) · 2026-10-21 · PK (Primary Key) ของตาราง SchoolBot เป็น int4 และ FK (Foreign Key) ที่อ้างถึงใช้ชนิดเดียวกัน พร้อมจัดทำ DBML (Database Markup Language) สำหรับแผนภาพ
- [มติ 026 (อนุมัติแบบข้อมูลที่ปรับใหม่)](decisions-026.md) · 2026-10-22 · อนุมัติแบบข้อมูลจากข้อเสนอปรับปรุงสองฉบับ โดยแก้ให้เว็บตรวจ License โรงเรียนและ Desktop รองรับทั้งนักเรียนกับครู
- [มติ 027 (ฐานข้อมูล SchoolBot แยก)](decisions-027.md) · 2026-10-22 · ตาราง SchoolBot อยู่ฐานข้อมูลของตัวเองที่ 10.0.0.128:9499 เพิ่มจากฐานข้อมูลเดิมสี่ตัว
- [มติ 028 (ชนิดผู้สร้างและผู้แก้ข้อมูล)](decisions-028.md) · 2026-10-22 · CreateBy/UpdateBy เป็น integer ที่รับ NULL ได้ โดยใช้รหัสผู้ทำรายการและให้ NULL เมื่อระบบทำเอง
- [มติ 029 (ใช้บัญชีฐานข้อมูลเดิม)](decisions-029.md) · 2026-10-22 · ไม่เพิ่มหรือถอนสิทธิ์ด้วย GRANT/REVOKE และไม่สร้าง role ใน School DB หรือ PGGradeDB โดย backend ใช้บัญชีเดิม
- [มติ 030 (กันแก้ทับด้วย UpdateDate)](decisions-030.md) · 2026-10-22 · ถอนคอลัมน์ Version และใช้ UpdateDate ที่ server กำหนดเป็นตัวตรวจการแก้ไขพร้อมกัน
- [มติ 031 (เหลือ repository เดียว)](decisions-031.md) · 2026-10-23 · target เหลือ school-bot และให้อ่านพาธ school-bot-v2 ในเอกสารเก่าเป็น school-bot
- [มติ 044 (ข้อบังคับฐานข้อมูลเหลือรหัสหลัก)](decisions-044.md) · 2026-10-26 · คง PRIMARY KEY 32 ตาราง ถอน UNIQUE/FOREIGN KEY/CHECK โดยคงคอลัมน์ ชนิดข้อมูล การรับค่าว่าง ค่าเริ่มต้น และ identity เดิม
- [บันทึก 045 (ผู้ใช้สร้างฐานข้อมูลแล้ว)](decisions-045.md) · 2026-10-26 · ผู้ใช้ยืนยันรัน schoolbot_db.sql สร้างตารางแล้ว ส่วนการตรวจโครงสร้างและเชื่อม API ยังต้องมีหลักฐานแยก
