# หลายโครงงานและผู้ประเมินภารกิจ — 2026-10-21

## คำตอบผู้ใช้

ผู้ใช้ในแชตตอบคำถามสองข้อสุดท้ายก่อนให้ SA เริ่มออกแบบ:

- "เก็บหลายโครงงานได้ทั้ง Guest และ Login"
- "Code/Block ให้ระบบตรวจอัตโนมัติ ส่วน Arm ให้ครูตรวจ"

## ข้อกำหนดที่ยืนยัน

- Block / Arm / Code รองรับหลายโครงงานต่อโหมดทั้ง Guest และ Login
- Guest เก็บ Local; Login เก็บ DB/Cloud ตามมติเดิม การบันทึกงานหนึ่งไม่แทนงานอื่นโดยอัตโนมัติ
- มีหลักสูตร ภารกิจ ผลประเมินจริง ความคืบหน้า และครูติดตามผลตามมติเดิม
- Code/Block ประเมินอัตโนมัติ; Arm รอครูตรวจ ไม่ใช้คลิกจบหรือภาพจำลองยืนยันว่าภารกิจหุ่นผ่าน
- Windows และ macOS ต้องควบคุมหุ่นจริงได้ทั้งคู่ตาม decisions-008.md

## การส่งต่อ SA

คำตอบหลักที่ถามก่อนเริ่ม SA ครบแล้ว ผู้ใช้อนุญาตให้เรียก SA ต่อโดยไม่ถามยืนยันซ้ำ ให้ SA ตรวจ source และเสนอแบบระบบเต็มที่ตรวจทานได้ แยกสิ่งที่พบจริง ข้อเสนอ และรายละเอียดรอยืนยันก่อน implementation

ชื่อผู้ตรวจรับ รุ่นหุ่น/ผลทดสอบจริง เกณฑ์คะแนนรายบทเรียน การย้ายงาน Guest เข้า Login และรายละเอียดสิทธิ์ครูยังไม่ได้กำหนด ให้บันทึกจุดตัดสินโดยไม่เลือกแทนธุรกิจหรืออ้างว่าได้รับการอนุมัติแล้ว และดำเนินการออกแบบส่วนที่ไม่ขึ้นกับข้อมูลนั้น
