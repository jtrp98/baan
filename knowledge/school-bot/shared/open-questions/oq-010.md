# OQ-010 — นโยบาย license และวงจรอุปกรณ์

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

License นับอุปกรณ์อย่างไร ย้ายเครื่องอย่างไร และเมื่อหมดอายุ ถูกเพิกถอน หรือ API ใช้ไม่ได้ จะอนุญาตให้ใช้งานต่อภายใต้เงื่อนไขใด?

สถานะ: ปิด — ผู้ใช้ตอบครบเมื่อ 2026-10-21 ตาม [มติ 004 (License และมาตรฐานชื่อข้อมูล — 2026-10-21)](../decisions/decisions-004.md), [มติ 005 (License ออฟไลน์ 3 วัน — 2026-10-21)](../decisions/decisions-005.md), [มติ 006 (จำนวนเครื่องต่อ License — 2026-10-21)](../decisions/decisions-006.md), [มติ 007 (ผู้ดูแลย้าย License และสิทธิ์ออฟไลน์เดิม — 2026-10-21)](../decisions/decisions-007.md)

## ถามใคร

ผู้ใช้ในแชตนี้ ในฐานะเจ้าของธุรกิจ License

## ถ้าไม่ตอบกระทบอะไร

หากยังไม่ตอบ จะกำหนดสิทธิ์เข้าใช้ จำนวนเครื่อง ออฟไลน์ และการย้ายเครื่องไม่ได้ ข้อนี้ใช้มติผู้ใช้แทนข้อจำกัดโค้ดเดิมแล้ว

## ข้อสรุปที่ยืนยันแล้ว

ทุกโหมดทั้ง Guest และ Login ต้องมี License ก่อนใช้แอป ชื่อและฟิลด์ตารางรวม SchoolId ใช้ decisions-004 ครั้งแรกต้องออนไลน์ จากนั้นใช้สิทธิ์ในเครื่องได้ 3 วันนับจากตรวจออนไลน์สำเร็จล่าสุด ก่อนตรวจ Key ว่ายัง Active ใหม่ตาม decisions-005 หนึ่ง Key ใช้ได้หนึ่งเครื่องตาม decisions-006 ผู้ดูแลปลดเครื่องเดิมและย้าย Key เดิมไปเครื่องใหม่ได้ทันที โดยยอมให้เครื่องเดิมออฟไลน์จนสิทธิ์เดิมหมดตาม decisions-007
