# dialog + ฉากหลัง

> Rev 1 · แก้ล่าสุด 2026-11-02 · แก้โดย นายช่าง · ขอโดย ผู้ใช้ (แตกจาก brand.md ของ sketchbook ให้อ่านได้ทีละไฟล์)
> ใช้ที่: เรื่องที่ต้องหยุดทั้งหน้า (ออกจากงาน ลบ ฯลฯ) · ยืนยันเรื่องเล็กใช้ popover ยืนยัน ([popover.md](popover.md))

- กว้าง 520 · padding `space-6` · `radius-lg` · พื้น `surface` · `shadow-modal` · gap `space-3` · `z-dialog`
- หัว 24/700 `lh-heading` + กล่องไอคอน 40×40 `radius-md` ตามความหมาย (เตือน = พื้น `warning-bg` ไอคอน `warning-strong`)
- ตัว 16 `lh-body`
- ปุ่มสูง 48 · padding 0 `space-4` · `radius-md` · 16/700 · ชิดขวา gap `space-3` · ปุ่มหลัก = ปุ่มนูน `action-primary` · ลบ/อันตราย = `danger` (ห้ามรูปทรงปุ่มหยุด)
- `role=alertdialog` `aria-modal` · โฟกัสเริ่มที่ปุ่มปลอดภัย ("อยู่ต่อ" / "ยกเลิก") · Esc ปิด
- ฉากหลัง: `text-primary` alpha 0.35 · `z-backdrop` · **ห้ามคลุมปุ่มหยุด** (เว้นพื้นที่ปุ่มหยุด · CR-10)


## ฉากหลัง Dialog บนหน้า Lab (2026-11-06)
- ฉากหลังของหน้า Lab (ที่มีหุ่นยนต์หรือบอร์ดจริง) เว้นปุ่มหยุดทั้งหมดไว้ให้กดได้ตลอดเวลา
- หน้าที่ไม่มีหุ่นยนต์ให้ฉากหลังคลุมเต็มหน้าต่างปกติ
