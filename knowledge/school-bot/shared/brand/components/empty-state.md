# Component: สถานะว่าง / กำลังโหลด / มาสคอต

> เพิ่ม 2026-11-03 · AU23, AU24

## 1. สถานะว่าง (Empty State)
- ใช้เมื่อ: ไม่มีงาน, ยังไม่มีประวัติ, ค้นหาไม่พบ ฯลฯ
- องค์ประกอบ:
  - ภาพมาสคอตในท่าทางที่เหมาะสมกับบริบท
  - ข้อความอธิบายที่เข้าใจง่าย (ภาษาเด็กประถม ป.1–6)
  - ปุ่มนำทางสำหรับทำรายการต่อ (Call to Action) ถ้ามี

## 2. สถานะกำลังโหลด (Loading State)
- ใช้ Spinner (`dur-spin` พร้อมรองรับ reduced-motion)
- **ไม่ใช้มาสคอต** ในสถานะกำลังโหลดทั่วไป

## 3. หน้าเชื่อมต่ออุปกรณ์
- ใช้ภาพมาสคอตแสดงสถานะ แทนการใช้รูปหุ่นวาด SVG
