# Component: Sidebar หลัก (N3)

> ใช้กับหน้าหลัก, บทเรียน, งานของฉัน, คลังเกม, หน้าเกม (ก่อนเล่น) · เพิ่ม 2026-11-06 app-shell R7, game-library OQ15

## ข้อกำหนด
- **โครงสร้าง:** 5 รายการ ไม่มีหัวกลุ่ม (app-shell OQ21)
  1. หน้าหลัก (Home)
  2. บทเรียน (Quiz / Lessons)
  3. เกม (Game Library)
  4. Block Lab
  5. Arm Lab
- **ขนาดและสี:**
  - ป้ายตัวอักษร **16px** (`text-md`) สี token (`text-secondary` ปกติ · `action-primary` เมื่อเลือก)
  - ความกว้าง: **120px** (เมื่อหุบ)
  - พื้นหลัง sidebar: **`background` #F4F7FB** (ให้รายการที่เลือกเด่นขึ้น)
- **สถานะ Selected:**
  - ใช้รูปแบบ Tab (§11.7) พื้นขาว `surface` + เงาเบา (`shadow-tab`) ไม่ใช้กรอบฟ้า
  - Avatar และปุ่มเปลี่ยนภาษาด้านล่างใช้สี token
- **ข้อยกเว้น:**
  - หน้าเล่นเกม = N2 ไม่มี sidebar
  - เกมในด่านบทเรียน highlight ที่เมนู "บทเรียน"
  - ไม่มีกล่องโลโก้ "SB" บนสุดของ sidebar (แบรนด์และโลโก้อยู่ที่แถบบนที่เดียว)
