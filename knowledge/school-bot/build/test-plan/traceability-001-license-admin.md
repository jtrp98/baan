ส่วนบังคับของ [TP001-007 — สร้างและแสดงรายการ License](tp-001-cases-license-2.md#tp001-007) ครอบ AC-027-01 (auth/สิทธิ์), AC-027-02 (สร้าง Key หนึ่งเครื่อง) และ AC-027-03 (list metadata ที่ไม่รั่ว key/hash/device IDs) ใช้ DES-002 (License/device binding) Rev4 และ license-admin-security-001 (สิทธิ์และ replay) Rev1
เงื่อนไขก่อนตรวจ: ใช้ [S-LIC/S-OBS/S-GATE — topology/reader/ประตู](traceability-001-license-setup.md): หนึ่ง process, สอง adapter/service, memory store เดียว หรือ file สอง object directory เดียว; create ผ่าน instance แรก list/replay ผ่านอีก instance และยืนยัน persisted state ด้วย instance ที่สาม/reopen file แยก fixture ต่อ actor/payload ตั้งต้นไม่มี License/binding และบันทึกจำนวน audit/idempotency; P1 มี staff_admin session + license_admin active, actor อื่นใช้ scope ตาม fixture ไม่สวมสิทธิ์ P1; ไม่มีจุดพักในชุดลำดับปกติ; staff auth ของ /v2/admin ไม่ configured/configured; staff session (staff_admin) ขาด/ไม่ถูกต้อง/หมดอายุ; session ที่ไม่มี StaffRole active ที่มีสิทธิ์ License (role อื่น/ถูกถอน/valid_until หมด); token school_web/desktop; static bearer เดิมของ /v1/admin; ผู้เรียกมีสิทธิ์ + payload valid, ชื่อว่าง/whitespace, expires_at อดีต/=now, ฟิลด์ limit>1; fake clock ฝั่ง API สำหรับ TTL replay; role `license_admin` active (ValidFrom/ValidUntil ครอบช่วง), role `staff_admin`/`release_publisher` เพียงอย่างเดียว, role ถูกถอน/IsDelete

ขั้นตอน: POST/GET /v2/admin/licenses ตามแต่ละ fixture; POST/GET /v1/admin ด้วย static bearer และด้วย staff session; replay create;  replay create โดย fixture ตั้ง TTL=900 วินาทีชัดเจน **(ผู้ใช้อนุมัติตาม [มติ 046 (Gateway dev และระยะเวลา replay ของ License)](../../shared/decisions/decisions-046.md))** แล้วทดสอบที่ `ReplayUntil−1s / ReplayUntil / ReplayUntil+1s` (สัญญากำหนดเพียง `ReplayUntil ≤ CompletedAt+900s` จึงห้ามคาดหวังจาก offset จาก CompletedAt โดยตรง )
