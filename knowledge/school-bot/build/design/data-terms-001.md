## ชื่อใกล้กัน แต่เก็บคนละเรื่อง

| ชื่อที่สับสน | ความต่าง |
|---|---|
| `Activity` / `Mission` | Activity คือกิจกรรมที่วางในบทเรียน; Mission คือโจทย์ส่งโครงงานของกิจกรรมแบบ project พร้อมวิธีประเมิน |
| `Project` / `ProjectRevision` | Project คือแฟ้มงานและเจ้าของ; Revision คือเนื้อหาฉบับหนึ่งที่เก็บไว้เพื่อเปิดกลับหรือตรวจงาน |
| `Submission` / `Attempt` | Submission คือการส่งโครงงานตามโจทย์; Attempt คือการทำ Quiz/Test หนึ่งครั้งพร้อมคำถามและคำตอบ |
| `SchoolBotAssessment` / `PGTAssessment` | ตัวแรกคือผลตรวจงานใน SchoolBot; ตัวหลังคือตารางหัวข้อ/ช่องคะแนนในระบบเกรดเดิม ไม่ใช่ผลตรวจงานตารางเดียวกัน |
| `GradeSlot` / `ScoreMapping` | Slot ระบุช่องปลายทางและสิทธิ์การดูแลช่อง; Mapping ระบุผลกิจกรรมต้นทางและน้ำหนักที่จะลงช่องนั้น |
| `ScorePreview` / `ScoreExport` / `ScoreOutbox` | Preview คือชุดคะแนนให้ตรวจ; Export คือคำยืนยันส่งทั้งชุด; Outbox คือรายการรอส่งและผลการส่งแต่ละรายการ |
