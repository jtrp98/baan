# DES-011 — ระบบเสนอเลื่อน Level และครูยืนยันทั้งห้อง

> Rev 7 · แก้ล่าสุด 2026-11-02 · แก้โดย arch · ขอโดย ผู้ใช้ (มติ 044 — SQL constraints เหลือเฉพาะ Primary Key)

สัญญานี้กำหนดการเสนอเลื่อน Level จากคะแนนรวมทั้งห้องและการยืนยันของครู โดยไม่เปลี่ยนทะเบียนชั้นเรียนเดิม

SchoolBot ทั้ง 32 ตารางคงเฉพาะ PRIMARY KEY ไม่มี SQL FOREIGN KEY, UNIQUE หรือ CHECK ตาม [มติ 044 (SQL constraints เหลือเฉพาะ Primary Key)](../../shared/decisions/decisions-044.md) ความสัมพันธ์และการอยู่ `SchoolId` เดียวกันต้องตรวจที่ application ใน SchoolBot DB transaction เดียวกับการเขียน โดยการตรวจข้อมูลข้ามฐานยังใช้การ re-check ก่อน commit ตามสัญญาเดิม

## หลักฐาน

- ตรวจร่าง SQL ซ้ำ 2026-11-02: `db/schoolbot_db.sql:30–676` มี 32 ตารางและ PRIMARY KEY 32 รายการ; เมื่อตัดคอมเมนต์ออกไม่มี FOREIGN KEY, REFERENCES, UNIQUE หรือ CHECK ที่บังคับข้อมูล การตรวจนี้ไม่ใช่ผลรันฐานข้อมูลหรือหลักฐาน application enforcement
- [มติ 044 (SQL constraints เหลือเฉพาะ Primary Key)](../../shared/decisions/decisions-044.md) ยืนยันให้ความสัมพันธ์และ validation เป็นกฎของ application

หลักฐาน legacy ต่อไปนี้คงจากเอกสารเดิมตามวันที่ที่ระบุ ไม่ได้ตรวจ legacy source หรือ runtime ซ้ำในงานนี้

- ขอบเขตการออกแบบร่วมเดิม: planning/arch-091-learning-001.md (memory).

กฎการตรวจความสัมพันธ์และ tenant ใช้ application ตามมติ 044; db/review-005.md (memory) เป็นหลักฐานเดิมก่อนถอน SQL constraints.
