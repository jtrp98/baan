## กฎ/Logic
- AC-14: **When** ครูเลือกปีการศึกษา เทอม และห้อง **Then** เห็นความคืบหน้าและคะแนน Quiz ตามตัวเลือกนั้น ทั้งแบบรายเทอมและรายปี
- ตัวกรองบังคับทุกหน้า: ปี → เทอม/ทั้งปี → ห้อง (SCR-22 ตัวกรองบังคับ · SCR-23 ตามหน้า SCR-22 · SCR-24, SCR-25 กรองตามห้อง)
- ไม่มีข้อมูลในช่วงที่เลือก (เทอมใหม่/นักเรียนยังไม่เล่น) → บอกว่าไม่มีข้อมูลช่วงนี้ (ST-36)
- SchoolBright ล้มเหลว → กำลังโหลด/โหลดไม่สำเร็จ + ลองใหม่ (ST-35)
- ใช้ตารางข้อมูลที่ค้น เรียง กรองได้ และแถวเยอะ (DSG-07 ต้องเพิ่ม component ใหม่)
- login ครูในแอป (Arm Lab) ใช้บัญชี SchoolBright ตัวเดียวกัน (module `arm-lab` · FR-13)
- ดาว 0–3 ต่อด่าน: ≥60% = 1 ดาว · ≥80% = 2 ดาว · 100% = 3 ดาว (ที่มา quiz · ARC-I02 Closed) · เกณฑ์เหรียญยัง Delegated → Designer เสนอ (quiz · DSG-10)

## การตัดสินใจที่ผูกกับ module
- DEC-14 ครูจัดการทุกอย่างผ่านเว็บ School Bot ที่แยกออกมา ซึ่งออกแบบในรอบนี้ ส่วนแอปเป็นพื้นที่ให้นักเรียน
- DEC-15 เว็บครูดูผลได้ทั้งรายเทอมและรายปี จัดตามห้องจาก SchoolBright
- DEC-18 คะแนนที่ส่ง SchoolBright และผลบนเว็บครูมาจาก Quiz อย่างเดียว (CHG-06)
- DEC-29 ไม่ใช้มาสคอตบนเว็บครู
- DSG-01 (ผู้ใช้ตัดสิน 2026-10-20): D-14 ใช้กับแอปเท่านั้น เว็บครูยืดได้ตั้งแต่ 1024px หลัก 1280px · ต้องบันทึกเป็น D ใหม่ใน DECISIONS.md ผ่านเจ้าของ design system (ยังไม่ทำ)

## Edge cases
- ลืมรหัสของครู (EC-02 ส่วนครู): ไปที่ SchoolBright (ST-08) · นักเรียนลืมรหัส → ข้อความ "บอกครูให้ช่วยรีเซ็ต" (Proposed · module `app-shell`) ซึ่งทำให้ต้องรู้ว่าครูรีเซ็ตที่ไหน → OQ8
- ส่งคะแนนเข้า SchoolBright ไม่สำเร็จ (EC-05): เว็บครูต้องแสดงสถานะส่งรายด่าน (R4) · กลไกคิวอยู่ module `quiz`
- เทอมใหม่/ไม่มีข้อมูล (ST-36) · ไม่มีสิทธิ์ดูห้องนี้ (ST-37) · นักเรียนย้ายห้องระหว่างเทอม → OQ9
- ไม่มีรายงานสถานะหุ่น (DEV-Q08 ไม่ทำงาน/ยังไม่มีข้อมูล) → คู่มืออย่างเดียว (R6)
- ความขัดแย้งที่เปิด: CF-06 (เมนูครูในแอปครอบคลุมหลายเรื่อง ขัดกับ "ครูจัดการผ่านเว็บ") → OQ14

คำถามที่ยังไม่ตัดสินอยู่ใน `../oq.md`
