# นำเข้า Course Plan Sheet และจัดคลังข้อสอบ

> แก้ล่าสุด 2026-11-02 · แก้โดย int · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

เอกสารนี้กำหนดลำดับพรีวิวและนำเข้า Course Plan Sheet รวมการจัดคลังข้อสอบและ policy แยกตาม revision ตามขอบเขต Q40 และ Q41 ที่อนุมัติแล้ว

## 4. นำเข้า Course Plan Sheet — Q40 (พรีวิวนำเข้า Course Plan Sheet)

ข้อเสนอ flow: ระบุต้นทาง → ดูตัวอย่าง → ตรวจข้อมูล → ตรวจสรุป → ยืนยันนำเข้าเป็นร่าง → อ่านผลยืนยัน ไม่กำหนดชนิดไฟล์ ช่องเชื่อมต่อ หรือ endpoint เพิ่มเอง

ตาราง preview แสดงตำแหน่งแถวต้นทาง ชื่อ ระดับชั้น เลข C/ชื่อ Unit ที่อาจไม่ตรงกัน รหัส Lesson ถาวรที่ตรวจยืนยันได้ สื่อชุด 1/2 และความหมายของ D ค่านี้เป็นข้อมูลแสดงประกอบ ไม่ใช่ฟิลด์ใหม่ในคำขอ

- นำเข้าทุกแถวเป็น draft; D=TRUE ใช้ป้าย “ตรวจแล้วจากต้นทาง — ยังไม่เผยแพร่”; แถวอื่น “ยังไม่ยืนยันการตรวจจากต้นทาง” ไม่ตัดทิ้งเอง
- O ไม่ใช้สร้างข้อมูล รหัส หรือลำดับ เปลี่ยนเฉพาะ O ต้องไม่เปลี่ยนผลนำเข้า
- P–X อยู่ใต้ Lesson เดิมในกลุ่ม “สื่อชุดที่ 2” ไม่สร้าง Course/Level ใหม่
- ตรวจแถวหัวตาราง/ช่อง merged/ข้อความที่ไม่ใช่ URL/สื่อหาย และแยก “ไม่มีสื่อ” จาก “อ่านสื่อไม่ได้” ห้ามเติมค่าหรือเดารหัสจาก C/Unit/O

ข้อเสนอเมื่อข้อมูลผิด: สรุปจำนวนและชี้แถว “ยังนำเข้าไม่ได้ — แก้รายการที่ระบุก่อน” ไม่เขียนเฉพาะแถวที่ผ่าน เป้าหมายคือยืนยันทั้งชุดหรือไม่เปลี่ยนข้อมูลเลย แต่ **ยังไม่อ้างว่าสัญญาปัจจุบันรับประกัน atomic import** ต้องให้ arch ระบุหน่วย transaction ก่อนเชื่อม

กรณีซ้ำ: แสดงรายการที่ตรวจยืนยันว่าเคยนำเข้าแล้ว หรือ “ยังตรวจรายการซ้ำไม่ได้” ไม่เลือกข้าม/ทับ/รวม/สร้างใหม่เอง ปิดการยืนยันส่วนนี้จนสัญญากันซ้ำพร้อม การส่งคำขอเดิมซ้ำเพื่อรับผลเดิมแยกจากการนำเข้าต้นทางเดิมด้วยคำขอใหม่

## 5. คลังข้อสอบและ policy — Q41 (คลังข้อสอบและ policy ราย revision)

ข้อเสนอ flow: เตรียม bank revision → ตรวจข้อ/ตัวเลือก/เฉลย/คะแนนเต็ม/ที่มา → บันทึกร่าง → ผู้ตรวจอีกคนเผยแพร่ แก้ฉบับ published โดยสร้าง revision ใหม่เท่านั้น ไม่แก้ประวัติ attempt

รองรับ single_choice และ boolean เท่านั้น; ข้อปรนัยมีอย่างน้อย 2 ตัวเลือก เฉลยเดียว ถูก/ผิดมี 2 ตัวเลือก เฉลยเดียว คะแนนเต็มมากกว่า 0 ตรวจ key ซ้ำและเฉลยที่ไม่มีในตัวเลือกก่อนบันทึก

แผง policy อยู่กับ Activity ที่เลือก bank/question_keys ไม่ผูก policy กับชื่อ bank แสดงจำนวนครั้ง การเลือกคะแนน เวลาเปิดเฉลย เวลาสอบ การสุ่มข้อและสุ่มตัวเลือกครบ:

| ค่าเริ่ม | Quiz | Test |
|---|---|---|
| ครั้ง/คะแนน | ไม่จำกัด/สูงสุด | 1 ครั้ง/ครั้งแรก; เมื่อมีซ่อมใช้สูงสุดรวมซ่อม |
| เวลา/เฉลย | ไม่จับเวลา/หลังส่ง | ต้องตั้งเวลา/หลังปิดสอบ |
| สุ่มข้อ/ตัวเลือก | ไม่สุ่ม/ไม่สุ่ม | สุ่มข้อ/ไม่สุ่มตัวเลือก |

แสดงค่าที่บันทึกจริงเมื่อเปลี่ยน policy ไม่สรุปจากชื่อ Quiz/Test ครูปรับได้เฉพาะเวลาและช่วงเปิด–ปิดในเว็บครู เรื่องน้ำหนักรายรอบ/สอบซ่อมส่ง UX-007 ไม่เพิ่มใน admin นี้

ข้อความก่อนเผยแพร่: “การแก้ข้อสอบนี้ใช้กับฉบับใหม่ การทำข้อสอบที่เริ่มแล้วคงคำถาม ลำดับ เกณฑ์ และ policy เดิม” ไม่สร้าง attempt ทดลองของครูบน Cloud
