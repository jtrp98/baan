### 2.3 ขั้นที่ 2 — ผูกกิจกรรมเข้าช่อง (ScoreMapping) — G8

อ้างอิง: [BR-049-02 (กิจกรรมหนึ่งได้หลายช่องข้ามวิชา แต่ช่องหนึ่งในบริบทโรงเรียน/เทอม/วิชารับกิจกรรมเดียว ไม่รวมหลายกิจกรรม)](../../shared/requirements/req-049.md), [BR-049-04 (ส่งเฉพาะช่องที่แมพ ไม่เดาหมวดจาก Quiz/Test หรือแก้โครงสร้างเกรด)](../../shared/requirements/req-049.md) · [AC-049-02 (กิจกรรม A แมพช่องวิชา X และ Y ได้)](../../shared/requirements/req-049.md), [AC-049-04 (Preview ตรงคู่กิจกรรม–ช่องที่แมพ ไม่เพิ่มช่อง/เดาหมวดเอง)](../../shared/requirements/req-049.md) · G8 ([มติ 032 (ผลทดลองของครูและ cardinality/การล็อก mapping คะแนน)](../../../../../school-bot/shared/decisions/decisions-032.md) ข้อ 2–3) · [DES-008 (Mapping หลักสูตรกับช่องคะแนน SchoolBright)](../../../../../school-bot/build/design/des-008.md) (Sources ยาว 1 ถาวร)

- จากแถวช่อง: ปุ่ม "เลือกกิจกรรม" → แผงเลือก: เลือก Lesson (กลุ่ม) → ระบบ**ขยายเป็นรายการ activity ที่แน่นอน** ให้ยืนยันก่อนบันทึก พร้อมตัวกรองตัวชี้วัด (indicator) — publish revision ใหม่ **ไม่ remap อัตโนมัติ** (DES-008) · บันทึกแล้ว source ต้องเหลือกิจกรรมเดียวเสมอ (ไม่มีช่องกรอกน้ำหนัก — weight_bps=10000 ถาวรตาม มติ 032)
- คำอธิบายคงที่บนหน้า (ตาม G8): "กิจกรรมหนึ่งส่งได้หลายช่องข้ามวิชา · ช่องหนึ่ง (ต่อ โรงเรียน/เทอม/วิชา) รับกิจกรรมเดียวเท่านั้น"
- 1 กิจกรรม → หลายช่อง: แผงกิจกรรมแสดงข้อมูล "กิจกรรมนี้ถูกใช้ที่ช่องอื่นแล้ว (วิชา X)" เป็นการแจ้งเท่านั้น ไม่ปิดกั้น (BR-049-02)

| State | เงื่อนไข | UI + คำ copy (ข้อเสนอ) |
|---|---|---|
| loading | อ่าน mapping-sources | "กำลังโหลดกิจกรรมจากหลักสูตร…" |
| empty | ยังไม่มีกิจกรรม published ใน revision ของ run | "ยังไม่มีกิจกรรมที่เผยแพร่ในหลักสูตรฉบับนี้ (CONTENT_NOT_PUBLISHED)" |
| disabled: กิจกรรมไม่นับคะแนน | has_numeric_score=false / ScoringPolicy ไม่นับคะแนน | แถวกดไม่ได้: "กิจกรรมนี้ไม่มีคะแนนตัวเลข นำมาแมพไม่ได้ (SOURCE_NOT_SCORABLE)" — ไม่แปลง passed→100 (DES-008/[DES-010 (Question Bank, Attempt และนโยบายคะแนน)](../../../../../school-bot/build/design/des-010.md)) |
| error: POLICY_NOT_CONFIGURED | quiz ยังไม่ตั้งค่าการให้คะแนน | "กิจกรรมนี้ยังไม่ได้ตั้งค่าการให้คะแนน (POLICY_NOT_CONFIGURED)" |
| success | บันทึก mapping สำเร็จ | "ผูกกิจกรรม '<ชื่อกิจกรรม>' → ช่อง '<ชื่อช่อง>' แล้ว" |

### 2.4 การตรวจชน (validation)

อ้างอิง: [AC-049-02 (กิจกรรม A แมพช่องวิชา X และ Y ได้)](../../shared/requirements/req-049.md) · [DES-008 (Mapping หลักสูตรกับช่องคะแนน SchoolBright)](../../../../../school-bot/build/design/des-008.md) · grade-rules ("หนึ่งช่องกิจกรรมเดียว")

- ก่อนบันทึก หน้าเว็บตรวจก่อน: ช่องนี้มี active mapping ของกิจกรรมอื่นหรือยัง → ถ้ามี ปุ่มบันทึก disabled + "ช่องนี้ผูกกับกิจกรรม '<A>' อยู่ — ใช้ช่องอื่น หรือจัดการชุดเดิมก่อน (§2.5)" (client เป็น UX เท่านั้น server ยึดกันซ้ำเป็นหลัก — ทั้งแก้ชุดเดิมและสร้างชุดใหม่ถูกปฏิเสธเหมือนกัน: AC-049-02)
- สลับโรงเรียน/เทอมแล้วโหลดใหม่ทั้งหมด ไม่พก mapping ข้ามบริบท ([AC-049-03 (สลับโรงเรียน/เทอมแล้ว mapping ไม่ถูกใช้ข้ามบริบทอัตโนมัติ)](../../shared/requirements/req-049.md))
