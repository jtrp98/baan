# L1. ประเมินสิ้นเทอมและยืนยัน — Q46

> แก้ล่าสุด 2026-11-02 · แก้โดย int · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

[กลับเอกสารหลัก](int-007-teacher-score.md)


ปุ่ม “ประเมินปลายเทอม” ใช้ได้เมื่อ closing/closed ก่อนกดแจ้งว่าหากไม่ผ่าน ระบบจะเตรียมรอบ Level เดิมสำหรับเทอมถัดไปตามสัญญา จึงไม่เรียกการทำรายการนี้ว่า preview ที่ไม่มีผล

หน้าผลแสดงจำนวนสมาชิก roster ค่าเฉลี่ย เกณฑ์ ส่วนที่ขาด และวันที่มีผลจาก proposal ที่ server คืน ไม่ให้เอานักเรียน/งานขาดออกเพื่อเพิ่มเฉลี่ย

- ตัวอย่าง AC: roster 2 คน ได้ 80 และ 0 → เฉลี่ย 40 เกณฑ์ 70 ขาด 30 อยู่เดิม
- เฉลี่ย 70 เท่ากับเกณฑ์ 70 → ไม่เสนอเลื่อน ส่วนที่ขาด 0 พร้อมคำว่า “เท่ากับเกณฑ์ จึงยังไม่เสนอเลื่อน”; เปรียบเทียบ strict > ก่อนปัดและเปิดดูค่าละเอียดได้
- ผ่านและมีระดับถัดไป → proposed แสดง “รอครูยืนยัน” กล่องยืนยันสรุปทั้งห้อง Level เดิม→ใหม่ และเทอมที่จะมีผล ไม่มีตัวเลือกบางคน ก่อนยืนยันทุกคนยัง Level เดิม เทอมปัจจุบันไม่เปลี่ยน
- ไม่ผ่าน → retained; ระดับสูงสุด → max_level พร้อม “ระดับสูงสุด — เรียน Level เดิมต่อ” ไม่มีปุ่มเลื่อนเกินระดับ
- เลือกไม่เลื่อนข้อเสนอที่ผ่าน ใช้ decline พร้อมเหตุผล; ยกเลิกกล่องยังไม่ส่งคำสั่ง ไม่เปลี่ยนข้อเสนอ

proposal stale ต้องประเมินใหม่และตรวจทานใหม่; ยังไม่มีเทอมหน้าไม่สร้าง successor ไม่เดาปี/เทอมขึ้นเอง เมื่อสำเร็จอ่านผลเดิมเพื่อแสดงสถานะ ไม่สร้างรอบซ้ำ

## A1. เกณฑ์ส่วนกลาง — Q46

เฉพาะ level_policy_admin บนเว็บ admin ตั้ง threshold ราย Level ช่วง 0–100 ค่าเริ่ม Level ใหม่ 70 แสดงฉบับปัจจุบัน ค่าใหม่ และเหตุผลก่อนบันทึกเป็น revision ใหม่ ไม่เขียนทับเกณฑ์ snapshot เดิม การสร้าง/เผยแพร่คลังข้อสอบอยู่ UX-005 และใช้ four-eyes เดิม
