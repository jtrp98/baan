# REQ-018 — ครูประจำชั้นสอนเฉพาะห้องที่รับผิดชอบ (Homeroom-restricted Teaching) — แก้ REQ-006

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `business-analyst` · ไฟล์นี้ = 1 REQ + AC ของมัน · สถานะอยู่ที่ `index.md` เท่านั้น


**การตัดสินใจทางธุรกิจที่ยืนยันแล้ว:** UI ใหม่เอาแท็บ "ครูที่ปรึกษาประจำระดับ/ห้อง" (Main Teaching Grade, REQ-006 เดิม) และ checkbox กติกาครูที่ปรึกษาของ REQ-002 (ใช้ทุกคน/ยกเว้น/เฉพาะระดับ) ออก แทนด้วยแนวคิดใหม่ **"ครูประจำชั้นสอนเฉพาะห้องที่รับผิดชอบ"**:

- ครูประจำวิชายังคงถูกกำหนดสิทธิ์สอนแต่ละวิชาแยกตามแผน/ห้องได้ตามปกติ (เทียบเท่า `TPlanCourseTeacher` เดิม — REQ-005/REQ-006 พื้นฐานยังใช้ได้)
- เพิ่มตัวเลือกใหม่ **ระดับครูรายบุคคล**: ตั้งค่าให้ครูคนหนึ่ง **"สอนได้เฉพาะห้องที่ตนรับผิดชอบ (ห้องประจำ) เท่านั้น ห้ามไปสอนห้องอื่น"** — ออกแบบมาให้โรงเรียนขนาดเล็ก หรือครูอนุบาล/ประถมที่สอนหลายวิชาให้ห้องเดียวใช้งาน (ครูประจำชั้นคนหนึ่งสอนได้ทุกวิชาของห้องตัวเอง แต่สอนห้องอื่นไม่ได้)
- ครูที่ไม่ได้ตั้งค่านี้ ยังคงสอนได้ตามสิทธิ์รายวิชา/แผนตามปกติ (ไม่ถูกจำกัดห้อง)

**Acceptance criteria:**

- AC-044 — ครูที่ถูกตั้งค่า "สอนเฉพาะห้องที่รับผิดชอบ" ไม่สามารถถูกวางสอนห้องอื่นได้ ทั้ง Generate อัตโนมัติและวางมือ แม้จะมีสิทธิ์สอนวิชานั้นในแผนก็ตาม · **แก้ 2026-09-28 (ปิด OQ-17 (ก)(ข)(ค)):** (ก) "ห้องที่รับผิดชอบ" **ดึงจาก school DB (`TClassMember`) โดยอัตโนมัติ** ไม่ต้องให้ผู้ใช้ตั้งคู่ (ห้อง, ครู) เองในโมดูลนี้ (ข) flag นี้**เป็นตัวจำกัดสิทธิ์อย่างเดียว ไม่ได้ให้สิทธิ์สอนเพิ่ม** — ครูยังต้องมีชื่ออยู่ใน `TPlanCourseTeacher` ของวิชานั้นเหมือนครูทั่วไป เพียงแต่ถูกจำกัดให้สอนได้แค่ห้องประจำของตัวเองเท่านั้น (ค) ครูกลุ่มนี้**ไม่ได้รับยกเว้น**เพดาน/วัน-สัปดาห์ (REQ-017) และคาบต่อเนื่องไม่พัก (BR-9) — ยังถูกบังคับเหมือนครูคนอื่นทุกประการ ข้อความ tooltip เดิมใน UI ที่บอกว่ายกเว้น (D43) **ผิด ต้องแก้ข้อความ UI**
- AC-045 — **แก้ 2026-09-28 (ปิด OQ-17 (ง)):** ครูที่ไม่ได้ตั้ง flag นี้ **สอนได้ทุกห้องของแผน (Plan) ที่ตนมีชื่ออยู่ใน `TPlanCourseTeacher` ของวิชานั้น** — ไม่ผูกกับ `Tbl_TeacherClassAssignment` เดิมอีกต่อไป (แหล่งนั้นถูกยกเลิกโดย AC-046a) การกันครูสอนซ้อนเวลาเดียวกันยังใช้กติกาเดิมของ BR-17 (นับรวมข้ามทุกตารางสอนของปี — เช่น หลักสูตร A แผน A ถูกจัดสอนจันทร์ 8 โมงในตารางชุดหนึ่งแล้ว ครูคนเดียวกันสอนซ้ำเวลานั้นในตารางชุดอื่นไม่ได้)
- AC-046 — การตั้งค่านี้เป็นแบบรายครู (ไม่ใช่รายระดับชั้นเหมือน Main Teaching Grade เดิม) และแก้ไขได้อิสระ
- **ยกเลิก REQ-006 เดิมในฐานะ UI**: wizard 3 ขั้น (ระดับ→ห้อง→ครูที่ปรึกษา) และ checkbox กติกาครูที่ปรึกษา 5 แบบของ REQ-002 (ใช้ทุกคน/ยกเว้น/เฉพาะประถม/ม.ต้น/ม.ปลาย) ไม่มี UI ให้ตั้งค่าอีกต่อไปในโฉมใหม่
- **AC-046a — ข้อมูลเดิม `Tbl_TeacherClassAssignment` ไม่ migrate เป็น flag ใหม่ (ยืนยันธุรกิจ 2026-09-23, ปิด OQ-10)** — ผู้ใช้ต้องตั้งค่า "สอนเฉพาะห้องที่รับผิดชอบ" ใหม่ทั้งหมดหลังเปลี่ยนมาใช้โฉมนี้ ไม่มีการนำ assignment เดิมมาเติม flag ให้อัตโนมัติ (ข้อมูลเดิมค้างอยู่เฉยๆ ไม่ถูกอ่านใช้ต่อ — ให้ system-analyst ตัดสินใจว่าจะลบทิ้งหรือคงไว้เป็น dead data)

**แก้ข้อเท็จจริง — ปิดแล้ว 2026-09-28 (ผลตรวจโค้ดของ SA — design.md §40.1, D44, EVD-058/059/060 + คำยืนยันธุรกิจที่ OQ-17 (ง)):** bullet แรกข้างบนที่เขียนว่าสิทธิ์รายวิชา/แผน "เทียบเท่า `TPlanCourseTeacher` เดิม — REQ-005/REQ-006 พื้นฐานยังใช้ได้" ไม่ตรงข้อเท็จจริงทั้งหมด เพราะ `TPlanCourseTeacher` ใน as-built ให้เฉพาะ "วิชาที่ครูรับผิดชอบ" ไม่ใช่ "ห้องที่ครูสอนได้" (สิทธิ์ห้องเดิมมาจาก `Tbl_TeacherClassAssignment` แหล่งเดียวซึ่งถูกยกเลิกแล้ว) — **ผู้ใช้ยืนยันกติกาทดแทนแล้ว (ตรงกับข้อเสนอ BR-41 ของ SA):** ตั้งแต่นี้ไป **`TPlanCourseTeacher` ถูกขยายความหมายให้เป็นทั้ง "สิทธิ์วิชา" และ "สิทธิ์ห้อง" ในตัว** — ครูที่มีชื่อในแผนใดของวิชาใด สอนได้ทุกห้องของแผนนั้น ดู AC-045 (แก้ใหม่)

**หมายเหตุสำคัญ — ต้องส่งต่อ system-analyst:** เป็นการเปลี่ยนโมเดลสิทธิ์ครูทั้งกระบวนทัศน์ (จาก "กำหนดครูที่ปรึกษาระดับ/ห้อง" เป็น "flag รายครู") กระทบ `timetable-helpers.ts` ตรรกะ eligibility ทั้งฟังก์ชัน (REQ-008 §3, BR-10) และอาจกระทบ schema (`Tbl_TeacherClassAssignment` กับ homeroom flag ใหม่) — เข้าเงื่อนไข schema/business-rule change routing (system-analyst amend → test-planner → engineer → qa-engineer) · ไม่ต้องออกแบบ migration script เพราะยืนยันแล้วว่าไม่ migrate ข้อมูลเดิม
