## User Flow

1. **การตั้งค่าเพดานชั่วโมงสอนครู (`/timetable/settings` — Section 1 & 2):**
   - ผู้ใช้เปิดหน้า "เงื่อนไขระบบ" (Settings)
   - ส่วนที่ 1: **เพดานชั่วโมงสอนรวมของครูทุกคน (Global Teaching Caps)**
     - ช่องกรอก: "ชั่วโมงสอนสูงสุดต่อวัน" และ "ชั่วโมงสอนสูงสุดต่อสัปดาห์"
     - หน่วยระบุชัดเจน: **ชั่วโมง (จำนวนเต็ม)** — ปฏิเสธทศนิยมหรือเศษนาที (ค่ารวม 0 = ไม่กำหนด; ค่ารายคน 0 = ใช้ค่ารวมของฟิลด์นั้น แล้วจึงไม่จำกัดถ้าค่ารวม 0)
     - มี Validation ตรวจสอบ: ค่าต่อวันต้องไม่มากกว่าค่าต่อสัปดาห์ (เมื่อทั้งคู่ > 0)
   - ส่วนที่ 2: **เพดานชั่วโมงสอนรายบุคคล (Individual Teaching Caps Table)**
     - ตารางแสดงรายชื่อครู พร้อมช่องกรอกชั่วโมง/วัน และชั่วโมง/สัปดาห์รายคน
     - ลำดับความสำคัญ: ค่ารายบุคคล (> 0) ชนะค่ารวมเสมอ หากรายคนตั้งเฉพาะต่อวัน ค่าต่อสัปดาห์จะใช้ค่ารวมอัตโนมัติ
   - ยกเลิกการตั้งค่าแบบ "ข้อยกเว้น (Exemptions)" เดิม เพื่อความชัดเจนและเรียบง่าย

2. **การตั้งค่าครูประจำชั้นสอนเฉพาะห้องที่รับผิดชอบ (`/timetable/settings` — Section 3):**
   - ส่วนที่ 3: **การ์ด "ครูประจำชั้นสอนเฉพาะห้องที่รับผิดชอบ"**
     - ตารางแสดงรายชื่อครูจากข้อมูลจริงและห้องที่รับผิดชอบจาก `TClassMember` ทั้ง 3 บทบาท: ครูประจำชั้น, ผู้ช่วย 1, ผู้ช่วย 2; ถ้าไม่มีห้องแสดง "ไม่มีห้องที่รับผิดชอบในเทอมนี้" ไม่เดาจาก mock
     - คอลัมน์ "ห้องที่รับผิดชอบ": แสดงชื่อห้องที่ดึงจากระบบแบบ Read-only (เช่น ป.1/1)
     - สวิตช์/Checkbox: "จำกัดการสอนเฉพาะห้องที่รับผิดชอบ" ให้เลือกเปิด-ปิดรายบุคคล
     - **ข้อความ Tooltip ที่แก้ไขถูกต้อง (BR-44):**
       - "เมื่อเปิดใช้งาน ครูจะถูกจัดสอนได้เฉพาะห้องที่ตนเองเป็นครูประจำชั้น/ผู้ช่วยเท่านั้น โดยเพดานชั่วโมงสอนและข้อกำหนดคาบต่อเนื่องยังคงมีผลบังคับใช้ตามปกติ" (ลบข้อความเดิมที่บอกว่ายกเว้นเพดาน)

3. **การบังคับใช้ในหน้าจัดตารางสอน (`/timetable/manage-teaching-schedule`):**
   - ระบบคำนวณภาระสอนจากเวลาจริง (นาทีสอนจริงของแต่ละคาบ \(\div 60\))
   - หากการวางทำให้ครูมีชั่วโมงสอนเกินเพดาน:
     - ปฏิเสธการวางพร้อมแสดงข้อผิดพลาด `teacherMaxHoursPerDay` หรือ `teacherMaxHoursPerWeek`
   - หากพยายามเลือกครูประจำชั้นที่เปิด flag ไปสอนห้องอื่นที่ตนไม่ได้เป็นประจำชั้น:
     - ตัวเลือกครูจะไม่ปรากฏใน AddCourseModal
     - หากพยายามลากวาง จะปฏิเสธพร้อมข้อความ ข้อความจำกัดห้อง (UI copy draft; DES-015 ไม่ได้เพิ่ม error code ชื่อนี้)

## Layout & Interaction

- **Settings Page Layout:**
  - Card 1: เพดานชั่วโมงสอนทั่วไป (Inputs สองช่อง: ต่อวัน, ต่อสัปดาห์ พร้อม label ชัดเจน)
  - Card 2: เพดานชั่วโมงสอนรายบุคคล (ตารางค้นหาครูได้ + pagination)
  - Card 3: เงื่อนไขครูประจำชั้น (ตารางแสดงชื่อครู, ห้องที่สังกัด, Toggle สวิตช์จำกัดห้อง)
- **Tooltip Hover Interaction:**
  - เพิ่มไอคอน `info` ข้างหัวข้อ Card 3 พร้อม Tooltip แสดงรายละเอียดกติกา BR-44 อย่างชัดเจน

## Accessibility

- Input fields มี label เชื่อมโยงด้วย `htmlFor` และ `aria-describedby`
- Toggle switch มี `role="switch"` และ `aria-checked`
- Error message มี `role="alert"` อ่านออกทันทีเมื่อ submit ผิดพลาด
- รองรับการเข้าถึงด้วย Keyboard และ Touch screen บนอุปกรณ์ Tablet

### รายละเอียดที่อนุมัติ / transition (UX sign-off แยกจาก schema/deploy)

- ช่องรวม label "ชั่วโมงสอนสูงสุดต่อวัน/ต่อสัปดาห์"; hint draft "จำนวนเต็มชั่วโมง; 0 = ไม่กำหนด". รายคน hint "0 = ใช้ค่ารวมของรายการนั้น" และแสดง effective cap/แหล่งค่า (รายคนหรือรวม) ให้เข้าใจ fallback ต่อฟิลด์; ไม่ใช้ checkbox ยกเว้นเพดานเดิม. **คาบต่อเนื่องไม่พักยังหน่วยคาบ** (BR40) ไม่แปลงเป็นชั่วโมง.
- VR12 Submit: จำนวนเต็ม≥0 ทั้งรวม/รายคน, วัน≤สัปดาห์เมื่อทั้งคู่>0; ไม่ปัด/ตัดทศนิยม/parse เป็น 0 เงียบ. Error summary ชี้ teacher/field; focus จุดผิดแรก. VR13 ครูไม่อยู่โรงเรียน → InvalidHomeroomRestriction, คง edits และให้ตรวจทะเบียนใหม่. Save success เฉพาะ status1 และ response ใช้ได้; required settings load ล้มปิด Save ไม่เอาค่าว่างทับ.
- **M1 / AC043b (ธุรกิจยืนยันแล้ว):** หลัง cutover ไม่แปลงเพดานเดิมจากคาบหรืออ่านเลขเดิมเป็นชั่วโมง. ข้อความ draft "เพดานเดิมที่ตั้งเป็นคาบไม่มีผลกับเพดานชั่วโมง กรุณาตั้งค่าเพดานใหม่; ระหว่างยังไม่ตั้งค่าใหม่ไม่มีการกำหนดเพดานชั่วโมง". AC046a: "การตั้งครูที่ปรึกษาเดิมไม่ถูกนำมาเปิดข้อจำกัดนี้ กรุณาเลือกครูใหม่ตามต้องการ". ไม่ migrate/ลบ Tbl_TeacherClassAssignment เอง.
- flag รายครูคง `[{nTeacherID}]` H1; ห้องอ่านอย่างเดียว ไม่ใช้ H2 หรือ wizard เก่า. ไม่มี flag → สอนได้ทุกห้องของแผนที่มีชื่อสำหรับวิชานั้น (BR41), flag → intersect ห้องรับผิดชอบ (BR42), ยังต้องผ่านผู้ดูแลห้อง BR71/เพดาน/กติกาอื่น. BR42 สามบทบาทผู้ใช้ยืนยันแล้ว ไม่ถามซ้ำ. ครูที่เปิด flag และไม่มี TClassMember ของเทอมนั้น → ไม่มีห้องที่สอนได้/NoEligibleTeacher ไม่ปลด flag เอง.
- Teacher load คำนวณนาทีจริงตาม template รวมตารางปัจจุบัน+external S1 (รวม legacy NULL) ทั้ง 7 วัน; Link Subject สอนหลายห้องสล็อตเดียวคิดครั้งเดียว. Error draft แสดงครู, ผลรวมหลังวาง (ชั่วโมง+นาที), effective cap และวัน/สัปดาห์; ช่วงเวลาจริงขาดสำหรับครูมีเพดาน → วางไม่ได้ ไม่คิดเป็น 0 นาที.
