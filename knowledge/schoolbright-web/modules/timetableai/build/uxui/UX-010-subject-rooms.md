## User Flow

1. **การตั้งค่าห้องเรียนและผู้ดูแลห้อง (`/timetable/subject-settings`):**
   - ผู้ใช้เปิดหน้า "เงื่อนไขวิชา" (Subject Settings)
   - แท็บ "ห้องเรียนประจำวิชา" (Subject Rooms & Room Settings):
     - ตารางที่ 1: **การจับคู่วิชาและห้องเรียน (Subject-Room Mapping)**
       - แต่ละวิชาสามารถเลือกห้องเรียนประจำวิชาได้ 1 ห้อง (Dropdown รายการห้องจาก `TRoom`) หรือเลือก "ไม่กำหนดห้อง"
       - กฎ 1 วิชา : 1 ห้อง (ไม่มี pool)
     - ตารางที่ 2: **ความจุห้องและครูผู้ดูแลห้อง (Room Capacity & Caretakers)**
       - แสดงรายการห้องทั้งหมดในโรงเรียนสำหรับปี/เทอมที่เลือก
       - กำหนดค่าความจุจำนวนเต็ม \(K \ge 1\); fallback K=1 เป็นข้อเสนอ BR-54 ที่ยังรอ schema confirmation ไม่ใช่ default ที่คนเซ็นแล้ว
       - ~~เลือก "ครูผู้ดูแลห้อง" (Dropdown ครู) — ระบบมี Tooltip ระบุชัดเจน: "วิชาที่ใช้ห้องนี้ ต้องมีผู้สอนเป็นครูผู้ดูแลห้องเท่านั้น"~~ **[แทนที่โดย fold — ดูหัวข้อ "Fold จาก UX-014" ท้ายไฟล์ก่อน Sign-off]**
   - ผู้ใช้กดปุ่ม "บันทึกเงื่อนไขห้องเรียน"

2. **การจัดตารางสอนและกันห้องชน (`/timetable/manage-teaching-schedule`):**
   - ห้องเรียนของแต่ละเซลล์จะถูกผูกอัตโนมัติตามวิชา (ผู้ใช้เปลี่ยนห้องรายเซลล์ไม่ได้)
   - การตรวจความจุ \(K\):
     - เมื่อลากวางหรือคำนวณอัตโนมัติ ระบบจะนับจำนวนห้องเรียนที่ใช้ห้องนั้นพร้อมกัน (รวมจากตารางปัจจุบัน + ตารางอื่นในปี/เทอม + ตาราง `/academic`) ต้องไม่เกิน \(K\)
     - หากเกิน \(K\) → ปฏิเสธการวางพร้อมแสดงข้อผิดพลาด `roomCapacityExceeded`
   - การบังคับครูผู้ดูแล:
     - ใน AddCourseModal ตัวเลือกครูผ่าน BR-41/BR-42 และผู้ดูแลห้องร่วมกัน; ผู้ดูแลไม่ได้สิทธิ์เพิ่ม ถ้าไม่อยู่ในแผน/ถูกจำกัดห้องจะไม่มีครูให้เลือก
     - หากลากวิชาที่ครูไม่ใช่ผู้ดูแลไปลงในห้อง → ปฏิเสธพร้อมข้อผิดพลาด `roomCaretakerMismatch`
   - หากระบบไม่สามารถโหลดข้อมูลการใช้ห้องจาก `/academic` ได้ (fail-closed) → ระงับการ Generate และบล็อกการวางวิชาที่มีห้อง พร้อมข้อความ `academicRoomUsageUnavailable`

## Layout & Interaction

- **Subject Settings Table:**
  - เพิ่มส่วน Card "การตั้งค่าห้องเรียนประจำวิชาและความจุ" (Clean card UI พร้อมไอคอน `meeting_room`)
  - แยกตาราง mapping (รหัส/ชื่อวิชา/ห้องประจำวิชา) กับตารางค่าต่อห้อง (ชื่อห้อง/ความจุ/ผู้ดูแล) เพื่อไม่ตั้งความจุซ้ำต่อวิชา; editor ค่าห้องเป็น proposal C2 เท่านั้น
- **Timetable Cell Display:**
  - เซลล์ที่มีห้องประจำวิชาจะแสดงชื่อห้องย่อมุมขวาบนของเซลล์ เช่น `[LAB-1]`
- **Conflict Highlighting:**
  - เมื่อเกิดการชนเรื่องห้อง ระบบจะ highlight แดงที่ชื่อห้องในเซลล์ที่ชน

## Accessibility

- Table มี header ชัดเจนพร้อม `scope="col"`
- Input ความจุเป็น number field พร้อม `min="1"` และ `aria-label="ความจุห้อง {roomName}"`
- Modal เตือนข้อผิดพลาดอ่านออกเสียงผ่าน Screen Reader ด้วย `role="alertdialog"`
- รองรับการใช้งานผ่านคีย์บอร์ดทุกจุด (Tab, Enter, Arrow keys)

**ตัด C2 editor ผู้ดูแล (OD-6 ก):** ผู้ดูแลเป็น **อ่านอย่างเดียวเสมอ** (DES-013 §38.3) — ไม่มี dropdown/ปุ่มแก้ผู้ดูแล, ไม่มีปุ่ม "บันทึกความจุและผู้ดูแล", ไม่มีแถว no-permission ของ controls ผู้ดูแล. ข้อความ C2 ในหัวข้อ "ขอบเขต conditional" (ส่วนผู้ดูแล/Save draft ผู้ดูแล) ถูกแทนด้วยบล็อกนี้. ข้อความช่วยเหลือใต้หัวตาราง: "ข้อมูลความจุและผู้ดูแลตั้งค่าจากระบบอื่น หน้านี้แสดงอย่างเดียว".

**คอลัมน์ "ผู้ดูแลห้อง" (รายการหลายคน):** `<ul>` ในเซลล์ — ชื่อครู + (ถ้าไม่นับ) ไอคอนเตือน + ป้ายข้อความ "ไม่อยู่ในแผน — ไม่นับ" (ไม่ใช้สีอย่างเดียว). เรียง "นับได้" ก่อน "ไม่นับ" ภายในกลุ่มเรียงชื่อไทย (OD-3 ก). บรรทัดสรุปเล็ก "นับเป็นผู้ดูแล {x} จาก {y} คน" เมื่อ y>1 หรือมีผู้ไม่นับ. เกิน 3 คน → "และอีก {m} คน" + ปุ่ม "ดูผู้ดูแลทั้งหมด ({y})"/"ย่อรายการ" ขยายในแถว (`aria-expanded`/`aria-controls`; OD-2 ก).
