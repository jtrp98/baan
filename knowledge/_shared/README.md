# ความรู้เฉพาะองค์กร

พื้นที่สำหรับข้อกำหนดร่วมขององค์กรที่หลาย project ใช้ ขณะนี้ยังไม่มีชุดกลางที่ตกลงเพิ่ม ความรู้ UX ทั่วไปมากับ package BAAN ที่ ux-knowledge/

เริ่มจาก [คู่มือ knowledge](../README.md) สำหรับโครงสร้าง เอกสารจาก runner เดิม และการใช้กับ BAAN ปัจจุบัน; `_shared/` ไม่ใช่ที่เก็บ config ของ workspace หรือ evidence ของ run ใหม่
