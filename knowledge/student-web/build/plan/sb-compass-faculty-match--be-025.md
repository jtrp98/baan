# BE-025 — Per-program advice

> module: student-web/sb-compass-faculty-match

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `project-manager` · Owner/Phase/Depends/Status → `INDEX.md` (index ชนะ)

## Goal

คำแนะนำต่อสาขา — จุดแข็ง (กลุ่มสาระ weight สูงสุดในกลุ่มที่ score ≥ 90% ของเป้า), จุดต้องเร่ง (กลุ่มที่ (เป้า − score) × weight มากที่สุดในกลุ่มที่ score < เป้า), ยังไม่มีคะแนน (weight สูงสุดในกลุ่มที่เด็กไม่มีคะแนน) — เสมอกันเลือกตามลำดับตัวอักษรชื่อกลุ่มสาระ เพื่อให้ข้อความนิ่ง (หมวด Program Matching §5) — คำแนะนำคือครึ่งหลังของ "10 อันดับ + % + คำแนะนำ" — ข้อความที่ไม่นิ่งทำให้เด็กเห็นคำแนะนำต่างกันทุกครั้งที่เปิดหน้าเดียวกัน

## References

REQ-006, AC-006.1, DES-020, DEC-020

## Scope

กติกาสามชนิดคงตามสัญญา · นิ่งเมื่อเสมอกัน (เรียงตามชื่อกลุ่มสาระ) · ใช้ค่าคะแนนชุดเดียวกับ %

- Security-sensitive: yes

## Out of Scope

รูปแบบคำแนะนำเดิมของ 8 สายที่ใช้ต้นแบบ (เปลี่ยนแค่หน่วยเป็นสาขา) · สูตร % · สคีมา

## Expected Output

none

## Acceptance

AC-006.1 (ฐานคำแนะนำ): สาขาแต่ละอันดับมีคำแนะนำตามกติกาสัญญา และข้อความนิ่งทุกครั้งที่เปิดซ้ำ (เสมอกันเรียงถูก)

## Dependencies

BE-023

## Handoff

ตรวจ AC-006.1 (ฐานคำแนะนำ) ด้วยชุดค่าทดสอบ: จุดแข็ง/จุดเร่ง/ไม่มีคะแนน/เสมอกัน — เทียบข้อความที่สร้างกับกติกา + เปิดซ้ำตรวจความนิ่ง — เก็บผลเป็นหลักฐาน
เป็นขั้นสร้างข้อความ — revert ได้ ไม่เขียนข้อมูลถาวร
