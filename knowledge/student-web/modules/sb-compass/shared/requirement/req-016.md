# REQ-016 — Premium ต้องโชว์รายละเอียดระดับ "รายวิชา" เพิ่มจากระดับกลุ่มสาระ (งานใหม่ รอบนี้)

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `business-analyst` · ไฟล์นี้ = 1 REQ + AC ของมัน · สถานะอยู่ที่ `index.md` เท่านั้น


**ปัญหาที่ต้องแก้**: หน้า Premium (REQ-004 "สถิติเทียบเครือข่ายทั่วประเทศ" และหน้าที่แสดงคะแนน
กลุ่มสาระฝั่ง Premium) ปัจจุบันแสดง **แค่ระดับกลุ่มสาระ** (canonical subject เช่น "คณิตศาสตร์")
เด็กจึงเห็นเป็นก้อนเดียว ไม่รู้ว่าเลขนั้นมาจากวิชาอะไรบ้าง

**สิ่งที่ต้องทำ**: Premium ต้องแสดง **ทั้งสองระดับ** คู่กัน
1. **(ก) ระดับกลุ่มสาระ** — คะแนนที่ถ่วงน้ำหนักหน่วยกิตแล้วตาม REQ-012 (รวม fallback ตาม
   acceptance criteria ข้อ 4 ของ REQ-012)
2. **(ข) ระดับรายวิชา** — รายวิชาย่อยแต่ละวิชาที่ประกอบเป็นกลุ่มสาระนั้น พร้อม **คะแนนดิบ**
   และ **หน่วยกิต** ของแต่ละวิชา

**แหล่งข้อมูล — เป็นข้อมูลที่ระบบมีอยู่แล้ว ไม่ใช่ข้อมูลใหม่ที่ต้องหาแหล่งเพิ่ม**:
`CompassScoreService.CompassSubjectScore` มี `CourseName`, `Score100`, `Credit` ต่อวิชาอยู่แล้ว
ก่อนถูก aggregate เป็นกลุ่มสาระ (ยืนยันจากโค้ดจริง — `Helper/CompassScoreService.cs:44,46,47`
และการ aggregate ที่บรรทัด 215-225) ข้อนี้จึงเป็นการ **โชว์ข้อมูลที่มีอยู่แล้วเพิ่มเติม**
ไม่ต้องเพิ่มแหล่งข้อมูล ไม่ต้องเพิ่มคอลัมน์ในฐานข้อมูลเกรด

**Premium-only — ฝั่งฟรีไม่เปลี่ยน**: REQ-001/REQ-002 (ฟรี) **ยังแสดงแค่ระดับกลุ่มสาระด้วย
ค่าเฉลี่ยดิบธรรมดาตามเดิม ไม่เปลี่ยนอะไรเลย** และต้องกั้นสิทธิ์ที่ฝั่ง API ตาม REQ-013 ด้วย
(breakdown รายวิชาเป็นข้อมูล Premium ห้ามหลุดให้ผู้ที่ไม่มีสิทธิ์)

**สถานะ: ยังไม่ทำ (งานใหม่)** — ปัจจุบัน `VMSubjectScore` / response ของ `calculate/score`
**ยังไม่มี breakdown ระดับรายวิชา** ต้องเพิ่ม field ใหม่ในชั้นการแสดงผล (view model + response +
หน้าจอ) รายละเอียดรูปร่างของ field/response เป็นงานของ `system-analyst` → `backend-engineer` /
`frontend-engineer` ในรอบถัดไป — เอกสารนี้กำหนดเฉพาะผลลัพธ์ทางธุรกิจที่ต้องได้

**Acceptance criteria (ทดสอบได้)**
1. (AC-016.1) นักเรียนที่มีวิชา "คณิตศาสตร์" (คะแนน 75) และ "คณิตศาสตร์เพิ่มเติม" (คะแนน 90) ซึ่งทั้งสอง
   ถูก map เข้ากลุ่มสาระ "คณิตศาสตร์" → หน้า Premium ต้องแสดง **ทั้ง 2 วิชาแยกกัน** พร้อม
   คะแนนและหน่วยกิตของแต่ละวิชา **นอกเหนือจาก** คะแนนกลุ่มสาระที่ถ่วงน้ำหนักแล้ว
   (ไม่ใช่แสดงแค่ค่าเฉลี่ยถ่วงน้ำหนักก้อนเดียว)
2. (AC-016.2) กลุ่มสาระที่มีวิชาเดียว → แสดงวิชานั้น 1 รายการ ไม่ใช่ซ่อน breakdown
3. (AC-016.3) วิชาที่ไม่มีคะแนนเป็นตัวเลข → ไม่แสดงใน breakdown (สอดคล้องกับ REQ-001 ที่ตัดออกจากการคำนวณ)
4. (AC-016.4) วิชาที่มีคะแนนแต่ **ไม่มีข้อมูลหน่วยกิต** → ยังต้องแสดงในรายการ โดยช่องหน่วยกิตแสดงว่าไม่มีข้อมูล
   ห้ามแสดง 0 เป็นเลขจริง และห้ามซ่อนวิชานั้นทิ้ง
5. (AC-016.5) ผู้ใช้ที่ **ไม่มีสิทธิ์ Premium** ยิง API ตรง → ไม่ได้ breakdown รายวิชากลับไปเลย (REQ-013)
6. (AC-016.6) หน้าฟรี (REQ-001/REQ-002) **ต้องไม่เปลี่ยนแปลง** — ยังเป็นกลุ่มสาระ + ค่าเฉลี่ยดิบธรรมดา
7. (AC-016.7) การแสดงผลในหน้าจอ Premium แสดงเป็น **ตารางบรรจุอยู่ภายในการ์ดกลุ่มสาระ (Table in Card)** และกรณีวิชาที่ไม่มีข้อมูลหน่วยกิต ให้แสดงข้อความ `"ไม่มีข้อมูลหน่วยกิต"` ชัดเจน (ยืนยันสัมภาษณ์ตรง 2026-09-15 ปิด OQ-16)
