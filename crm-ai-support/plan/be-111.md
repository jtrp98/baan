# BE-111 — POST /cases/[id]/classify pipeline

## Goal

เพิ่ม `POST /api/v2/support/crm-ai/cases/[id]/classify` — เช็ค `TCrmSafetyKeyword` (Active=true) ก่อนเสมอ (ตรง = บังคับ `AiCategory=BUG` + `SafetyOverride=true`) → ไม่ตรงเรียก Gemini จำแนก 4 หมวดพร้อม confidence/reasoning → เขียน `TCrmCaseAiAssessment` + แถว `TCrmAiDecisionLog` (`CLASSIFICATION`/`SAFETY_OVERRIDE`) — confidence ต่ำกว่า threshold ตั้ง `ReviewStatus=NEEDS_HUMAN` — เป็นหัวใจการจำแนกของโมดูล — ลำดับ keyword-ก่อน-AI และ audit คู่ทุกผลต้องผูกเป็นสัญญาเดียวที่เส้นทางอื่น (backfill/review/trigger) อ้างอิง

## References

## Scope

pipeline เดียวจบใน endpoint นี้ — เขียน assessment + decision log คู่กันทุกครั้ง ไม่มีทางเขียนครึ่ง ๆ ด้วยค่าเดา · TASK ส่งตรงเข้า Dev ไม่ผ่าน safety gate (AC-004.3 เป็นพฤติกรรมของ flow ปลายทาง)

- Security-sensitive: yes

## Out of Scope
