# BE-427 — hook: เปลี่ยน role_id ของ user → sync คนนั้น

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `project-manager` · Owner/Phase/Depends/Status → `plan\index.md` (index ชนะ)

Original Task ID: `BE-crm-ai-support-P4-18`

## Goal

hook เข้าจุดเปลี่ยน `role_id` ของ user คนหนึ่ง → sync เฉพาะคนนั้น (ทั้งบทบาทที่ได้ใหม่และที่ต้องปิด) — รวมกรณี `user.is_deleted=true` → ปิดทุกบทบาทของคนนั้นเป็น `Active=false` — การย้ายทีม/ลาออกเปลี่ยนบทบาทเฉพาะบุคคล — ห้ามลามไป sync คนอื่นและห้ามทิ้งบทบาทค้างของคนที่ลบไปแล้ว

## References

REQ-016, AC-016.3, DES-006, DEC-006

## Scope

ต่อ hook ที่จุดเปลี่ยน role_id — sync ขอบเขตคนเดียว · is_deleted ปิดทุกบทบาท · best-effort log error เท่านั้น

- Security-sensitive: no

## Out of Scope

พฤติกรรมเปลี่ยน role เดิม · การ sync คนอื่นใน role (ขอบเขตคนเดียว) · การ delete แถวบทบาท

## Expected Output

none

## Acceptance

AC-016.3: เปลี่ยน/ถอดบทบาทของคนหนึ่งแล้วเฉพาะคนนั้นสะท้อนถูกต้อง — คนที่ลบไปแล้วบทบาทถูกปิดทั้งหมด
