# REQ-013 — คัดลอกกติกา/ตารางไปยังเทอม-ปีที่ต้องการ — **New requirement (ยืนยันธุรกิจแล้ว 2026-09-21 — ยังไม่ผ่านการออกแบบ schema, ขึ้นกับ REQ-012)**

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `business-analyst` · ไฟล์นี้ = 1 REQ + AC ของมัน · สถานะอยู่ที่ `index.md` เท่านั้น


ปุ่มคัดลอกจากเทอม-ปีต้นทาง ไปยัง**เทอม-ปีปลายทางใดก็ได้ที่ผู้ใช้เลือกเอง** ไม่จำกัดว่าต้องเป็นปี/เทอมถัดไป — คำขอนี้กลับสมมติฐาน as-built เดิมที่ระบุว่าระบบยังไม่มี "copy ตารางจากปีก่อน" (ดู `## Declined / Not Pursuing`)

**กลไกการเข้าถึง — 5 จุดเข้า แยกตามหน้า (ยืนยันธุรกิจ 2026-09-23, แก้ไขจากฉบับ 2026-09-21 ที่เคยระบุเป็น "เลือกได้จากรายการเดียว"):** ปุ่ม Copy ปรากฏบน 5 หน้า list-page ของโมดูล (หน้าเดียวกับที่ใช้เลือกปีการศึกษา) แต่ละจุดคัดลอกขอบเขตต่างกันตามหน้าที่กด **ไม่ใช่ modal เดียวที่มี checkbox เลือก 4 เมนู**:

| หน้าที่กด Copy | ขอบเขตที่คัดลอก |
|---|---|
| `/timetable` (hub เลือกปี) | **ทั้งหมด** — เงื่อนไขระบบ + กติกาวิชา + โครงคาบเรียน + เงื่อนไขครู + ตารางสอนที่สร้างเสร็จแล้ว รวมเป็นชุดเดียวเสมอ (เลือกแยกเมนูจากจุดนี้ไม่ได้) |
| `/timetable/settings` | เฉพาะเงื่อนไขระบบ (System Conditions, REQ-002) |
| `/timetable/subject-settings` | เฉพาะกติกาวิชา (Subject Conditions, REQ-003) รวม mapping วิชา→ห้องของ REQ-016; ไม่รวมความจุ/ครูผู้ดูแลที่อ่านจาก School DB |
| `/timetable/create-class-period` | เฉพาะโครงคาบเรียน (Class Period templates, REQ-004) |
| `/timetable/manage-timetable` | เฉพาะเงื่อนไขครู (Teacher Conditions — กลุ่มครู+เวลาไม่ว่าง REQ-005) · *แก้ 2026-09-28:* ฉบับก่อนหน้ารวมครูที่ปรึกษาประจำระดับ/ห้อง (REQ-006) ไว้ในเมนูนี้ด้วย แต่ REQ-018 ยกเลิก REQ-006 แล้ว (ไม่มี UI และข้อมูล `Tbl_TeacherClassAssignment` ไม่ถูกอ่านใช้ต่อ — AC-046a) จึงไม่อยู่ในขอบเขตคัดลอกนี้อีก |

**การตัดสินใจทางธุรกิจที่ยืนยันแล้ว:**

- เป้าหมายคัดลอก: เทอม/ปีใดก็ได้ที่ผู้ใช้เลือกเอง ไม่จำกัดเงื่อนไข (ทุกจุดเข้า)
- **"เลือกคัดลอกเป็นรายเมนู" ทำโดยเลือกว่าจะกดปุ่ม Copy จากหน้าไหน** ไม่ใช่ติ๊กเลือกในฟอร์มเดียว — ต้องการคัดลอกเฉพาะโครงคาบเรียน ให้ไปกด Copy ที่ `/timetable/create-class-period`; ต้องการคัดลอกทุกอย่างพร้อมตารางสอน ให้กด Copy ที่ `/timetable`
- **การตั้งค่า "ครูสอนเฉพาะห้องที่รับผิดชอบ" ของ REQ-018 คัดลอกไปกับเมนู "เงื่อนไขระบบ" (`/timetable/settings`)** (ยืนยันธุรกิจ 2026-09-28, ปิด OQ-20 (ข)) — ไม่ใช่เมนูเงื่อนไขครู
- Conflict handling: หากเทอม-ปีปลายทางมีข้อมูลในขอบเขตที่กำลังคัดลอกอยู่แล้ว **ต้องเตือนและให้ผู้ใช้ยืนยันก่อนเขียนทับ แล้วแทนที่ทั้งหมด (ไม่ใช่เพิ่มซ้อน)** (ยืนยันธุรกิจ 2026-09-28, ปิด OQ-22) — ที่ `/timetable` ตรวจครอบคลุมทุกเมนู+ตาราง, ที่อีก 4 หน้าตรวจเฉพาะเมนูของหน้านั้น
- **ปลายทางไม่มี template คาบที่ link subject/กลุ่มครูอ้างอิง → บล็อกการคัดลอกทั้งหมด** (ยืนยันธุรกิจ 2026-09-28, ปิด OQ-20 (ก)) ไม่ใช่ข้ามพร้อมรายงานหรือนำ template มาด้วย
- **ห้อง/หลักสูตร/แผนที่ปลายทางจับคู่ไม่ได้ (เช่น ไม่มีชื่อห้องเดิม) → เตือนผู้ใช้ก่อน ถ้าผู้ใช้ยืนยันให้คัดลอกต่อตามที่จับคู่ได้** (ยืนยันธุรกิจ 2026-09-28, ปิด OQ-23) — ไม่บล็อกทั้งหมดเหมือน OQ-20(ก) เพราะเป็นคนละสถานการณ์ (นี่คือ "ข้อมูลบางส่วนจับคู่ไม่ได้" ไม่ใช่ "template หลักหายไปทั้งอัน")

- **แก้ 2026-10-11 (jtrp98, แทน OQ-31 (ค)/OQ-33 เฉพาะค่าความจุ/ครูผู้ดูแล):** ค่าทั้งสองเก็บใน School DB ต่อ (โรงเรียน, ปี, เทอม, ห้อง) และโมดูลอ่านอย่างเดียว ผู้ใช้จัดค่าผ่านระบบอื่นหรือ SQL เอง จึงไม่อยู่ในขอบเขตแก้/คัดลอกจากทุกจุดเข้า รวม hub `all` และ `subjectConditions` และไม่ลบ/ทับค่าปลายทาง · **mapping วิชา→ห้องยังตั้งในโมดูลและคัดลอกกับ `subjectConditions`/`all` ตามเดิม**; ทะเบียน `TRoom` เดิมอ่านอย่างเดียว · คำตอบตามตัวอักษรและบริบทอยู่ใน `req-016.md` / `../open-questions/oq-1.md` · ประวัติคำยืนยัน 2026-09-29 ยังคงอยู่และถูกแทนเฉพาะส่วนนี้

**Acceptance criteria (ระดับ requirement — schema/implementation ให้ system-analyst ออกแบบต่อ):**

- AC-029 — ผู้ใช้เลือกเทอม-ปีต้นทางและปลายทางได้อิสระ (รวมข้ามปี) ก่อนคัดลอก ที่ทุกจุดเข้าทั้ง 5 จุด
- AC-030 — ปุ่ม Copy บน `/timetable` คัดลอกทั้ง 4 เมนู + ตารางสอนเป็นชุดเดียวเสมอ **แต่เลือกได้ว่าจะคัดลอกตารางสอนชุดใดบ้าง** (ไม่บังคับคัดลอกทุกชุดที่ `isActive` — ยืนยันธุรกิจ 2026-09-28, ปิด OQ-20 (ค)); ปุ่ม Copy บนอีก 4 หน้าคัดลอกเฉพาะเมนูของหน้านั้นหน้าเดียว — ไม่มี UI ให้เลือกเมนูแบบผสมเอง · flag ของ REQ-018 อยู่ในเมนู "เงื่อนไขระบบ" · แก้ 2026-10-11: รวม mapping วิชา→ห้อง แต่ไม่คัดลอกความจุ/ครูผู้ดูแลจาก School DB ทั้ง `all` และ `subjectConditions`
- AC-031 — หากปลายทางมีข้อมูลอยู่แล้วในขอบเขตที่กำลังคัดลอก (ตามจุดเข้าที่กด) ระบบต้องแสดงคำเตือนและรอการยืนยันจากผู้ใช้ก่อนเขียนทับเสมอ แล้ว**แทนที่ทั้งหมด** — ห้ามคัดลอกทับโดยไม่แจ้ง ห้ามเพิ่มซ้อน · แก้ 2026-10-11: ขอบเขตนี้ไม่ลบ/ทับค่าความจุ/ครูผู้ดูแลใน School DB
- AC-032 — ข้อมูลที่คัดลอกแล้วเป็นอิสระจากต้นทาง (แก้ปลายทางไม่กระทบต้นทาง) สอดคล้องกับหลัก snapshot ของ REQ-010
- **AC-050 (ใหม่, 2026-09-28)** — ปลายทางไม่มี template คาบที่กติกาที่จะคัดลอกอ้างอิง → บล็อกการคัดลอกทั้งหมด พร้อมข้อความอธิบายว่าเป็น template ใดที่ขาด · *หมายเหตุ 2026-09-29:* กติกาจับคู่ template และกรณีคัดลอกโครงคาบเรียนทับขณะที่ข้อมูลปลายทางอื่นยังอ้าง template เดิม **ยังเปิดอยู่ที่ OQ-28** (design.md Rev 6 §35.8)
- **AC-051 (ใหม่, 2026-09-28)** — ห้อง/หลักสูตร/แผนบางรายการที่ปลายทางจับคู่ไม่ได้ (ไม่ใช่ template หลักที่ขาดทั้งหมด) → แสดงคำเตือนรายการที่จับคู่ไม่ได้ รอผู้ใช้ยืนยัน แล้วคัดลอกส่วนที่จับคู่ได้ตามที่ยืนยัน

**หมายเหตุสำคัญ — ต้องส่งต่อ system-analyst ก่อน implement ใด ๆ:** REQ-013 ขึ้นกับ REQ-012 (ต้องมี term dimension ก่อนจึงจะมี "เทอม-ปีปลายทาง" ให้เลือก) และเพิ่ม endpoint/flow ใหม่ (copy) ที่ไม่มีอยู่ใน as-built ปัจจุบัน — เข้าเงื่อนไข schema/feature-change routing เดียวกับ REQ-012 (system-analyst amend → test-planner → engineer → qa-engineer +security)
