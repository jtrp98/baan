## User Flow

1. **subject-settings (อ่านอย่างเดียว):** ผู้ใช้เลือกปี/เทอม (UX-007) → หน้าโหลด Rooms ของหน่วยนั้น → ตาราง "ค่าต่อห้อง" แสดง ชื่อห้อง / ความจุ / ผู้ดูแล (รายการ) ต่อห้อง → ผู้ใช้เห็นว่าผู้ดูแลคนใดนับ/ไม่นับ และรู้ว่าต้องแก้ที่ระบบอื่น/ผู้ตั้งค่า (โมดูลไม่มีปุ่มแก้ — ไม่สร้าง CTA ที่ไม่มีปลายทาง)
2. **จัดตาราง (workspace):** ห้องที่มีผู้ดูแลที่นับได้ → AddCourseModal แสดงเฉพาะครูที่ผ่านตัวกรอง; ลาก/สลับที่ทำให้ครูของเซลล์ไม่อยู่ในชุด → modal `roomCaretakerMismatch`; ใช้ห้องพร้อมกัน ≥2 ห้องเรียนโดยไม่เป็นกลุ่ม Link Subject เดียวกัน → modal `roomCaretakerLinkRequired`
3. **Precheck (UX-012):** warning `RoomCaretakerNotInPlan` อยู่ในส่วน Warning (ไม่บล็อก); blocker `NoEligibleTeacher (RoomCaretaker)` ระบุชุดผู้ดูแลที่นับได้
4. **เปิดตารางเดิม:** เซลล์ที่ครู snapshot ไม่อยู่ในชุดปัจจุบัน → รายการแจ้งเดียวกับ BR-35; ไม่เปลี่ยนครูให้ (DES-013 BR-71)

## States

### A. ตาราง/คอลัมน์ "ผู้ดูแลห้อง" บน subject-settings (read-only)

| State | ผู้ใช้เห็นอะไร | ข้อความ (copy) |
|---|---|---|
| loading | skeleton/spinner ในตารางค่าห้อง; selector ห้องประจำวิชาปิดใช้งานตาม UX-010 | "กำลังโหลดข้อมูลห้องและผู้ดูแล…" |
| มีผู้ดูแลที่นับได้ทั้งหมด (success) | รายการชื่อ (เรียงตามชื่อ) ไม่มีป้าย; บรรทัดสรุป | "ผู้ดูแล {n} คน" |
| มีทั้งนับได้และไม่นับ | รายการเรียง "นับได้" ก่อน "ไม่นับ"; ผู้ดูแลที่ไม่นับมีไอคอนเตือน + ป้ายข้อความ (ไม่ใช้สีอย่างเดียว) + บรรทัดสรุป | ป้าย "ไม่อยู่ในแผน — ไม่นับ" · สรุป "นับเป็นผู้ดูแล {x} จาก {y} คน" · คำเตือนใต้แถว "ผู้ดูแล {ชื่อ} ไม่ได้เป็นผู้สอนในแผน/หลักสูตรของภาคเรียนนี้ จึงไม่ถูกนับ (ไม่ส่งผลให้จัดตารางไม่ได้)" |
| ไม่ตั้งผู้ดูแล (`lstCaretakers = []`) | ข้อความจาง ไม่ใช่ error | "ยังไม่ได้ตั้งผู้ดูแล — ห้องนี้ใช้ตามความจุ ไม่มีข้อบังคับผู้ดูแล" (ใช้ร่วมกับ warning `RoomSettingMissing` ของส่วนผู้ดูแล เมื่อแสดงคำเตือนรวม) |
| ไม่มีผู้ดูแลที่นับได้ (ทุกคน isInPlan=false) | แสดงรายชื่อทั้งหมดพร้อมป้าย "ไม่นับ" + คำเตือน (ใช้ `RoomCaretakerNotInPlan` ไม่ใช่ `RoomSettingMissing` ตาม DES-013 §BR-71 ชุดว่าง) | "ห้องนี้ไม่มีผู้ดูแลที่นับได้ จึงใช้ตามความจุและไม่บังคับ Link Subject — ตรวจผู้ดูแลกับการมอบหมายครูในแผน" |
| ความจุไม่ตั้ง (null) | ช่องความจุว่าง + คำเตือนเดิม (ไม่เปลี่ยนจาก UX-010) แยกจากผู้ดูแล | "ห้อง {ห้อง} ยังไม่ตั้งความจุ ระบบใช้ความจุ 1" (K=1 ยืนยันแล้ว: successful absence/NULL เท่านั้น) |
| ชื่อครูไม่มี (`sTeacherName = null`) | DES-013 §38.5a ข้อ 2: ส่งชื่อเสมอสำหรับครูที่ยังไม่ถูกลบของโรงเรียนเดียวกัน (ไม่ขึ้นกับ isInPlan); null = ครูถูกลบหรือชื่อว่าง — FE แยกสองกรณีไม่ได้ จึงใช้ข้อความกลาง ไม่ระบุว่า "ถูกลบ" และไม่เดาชื่อ; รายการยังคงนับ/ไม่นับตาม `isInPlan` เดิม | "ไม่พบข้อมูลชื่อครู (รหัส {nTeacherID})" |
| error โหลดล้มเหลว (`status = −1` / `RoomSettingReadFailed`, timeout/query error) | ตารางค่าห้องถูกแทนด้วย error state + ปุ่ม "โหลดใหม่"; ไม่แสดงช่องว่างราวกับไม่มีผู้ดูแล; selector ห้องประจำวิชาและ Generate/วางมือวิชาที่มีห้องถูกระงับตาม BR-57 | "โหลดข้อมูลห้องและผู้ดูแลไม่สำเร็จ จึงยังตรวจสิทธิ์ผู้ดูแลไม่ได้ กรุณาโหลดใหม่" |
| error ข้อมูลไม่ถูกต้อง (`status = 0` ทุก key รวม `InvalidRoomSetting`/`TermNotInYear`/`TermRequired`) | FE แยก state ด้วย `status` เท่านั้น ไม่ parse ข้อความ (§38.5a ข้อ 1); เหมือนแถวบน แต่ไม่ชี้รายละเอียดฐานข้อมูล/รหัสครู และไม่มีปุ่มแก้ในโมดูล | "ข้อมูลความจุหรือผู้ดูแลห้องที่ตั้งไว้ไม่ถูกต้อง ระบบจึงยังไม่ใช้ข้อมูลนี้ กรุณาแจ้งผู้ดูแลระบบหรือผู้ตั้งค่าห้องให้ตรวจสอบ แล้วโหลดใหม่" |
| จำนวนมาก (truncation) | แสดงชื่อแรก 3 คนในเซลล์ + ปุ่ม disclosure ขยายเป็นรายการเต็มในแถวเดียวกัน (ไม่ใช่ popup); เรียง "นับได้" ก่อนเสมอ เพื่อไม่ซ่อนผู้ดูแลที่นับไว้หลังคำว่า "และอีก…" | "และอีก {m} คน" · ปุ่ม "ดูผู้ดูแลทั้งหมด" / "ย่อรายการ" |
| ไม่มีห้องในทะเบียน | ใช้ข้อความ UX-010 เดิม | "ยังไม่มีห้องในทะเบียนโรงเรียน" |
| no permission / auth | ใช้ UX-004 (401 SessionExpired; 403 ช่องทางเดิม) ไม่มี permission scheme ใหม่ | ตาม UX-004 |

สรุปรวมระดับหน้า (ไม่บล็อก): แถบเตือนบนตารางเมื่อมีห้องที่ผู้ดูแลไม่นับ ≥1 — "มี {n} ห้องที่ผู้ดูแลบางคนไม่ได้อยู่ในแผน (ไม่นับ) — ดูรายละเอียดในแถวของห้อง"; แถบนี้ไม่ใช่ alert (ไม่ขัดจังหวะ), ใช้ `role="status"`.

## Layout & Interaction

- ตารางค่าต่อห้อง (UX-010): คอลัมน์ "ผู้ดูแลห้อง" เป็น `<ul>` ในเซลล์ — แต่ละรายการ = ชื่อครู + (ถ้าไม่นับ) ไอคอนเตือน + ป้ายข้อความ "ไม่อยู่ในแผน — ไม่นับ". เรียง: นับได้ก่อน แล้วไม่นับ; ภายในกลุ่มเรียงชื่อตามภาษาไทย. ใต้รายการมีบรรทัดสรุปเล็ก (ขนาดตัวอักษรรอง) "นับเป็นผู้ดูแล {x} จาก {y} คน" เมื่อ y>1 หรือมีผู้ไม่นับ.
- Truncation: เกิน 3 คน → ปุ่มข้อความ "ดูผู้ดูแลทั้งหมด ({y})" ขยายในแถว (disclosure, `aria-expanded`); ค่าเริ่มต้น 3 ตาม OD-2 (ก) ที่ jtrp98 ยืนยันแล้ว (2026-10-11).
- ไม่มีปุ่มแก้/เพิ่ม/ลบผู้ดูแลใน UI; ข้อความช่วยเหลือเล็กใต้หัวตาราง: "ข้อมูลความจุและผู้ดูแลตั้งค่าจากระบบอื่น หน้านี้แสดงอย่างเดียว".
- Mobile (<768px): ตารางค่าห้องเรียงเป็นการ์ดต่อห้อง (ชื่อห้อง → ความจุ → ผู้ดูแล); รายการผู้ดูแลเรียงลงและ wrap; ไม่มี horizontal scroll ของเนื้อหาอ่าน.
- Modal เหตุปฏิเสธ: reuse ModalConfirm/alertdialog เดิม; รายชื่อผู้ดูแลที่ขยายภายใน modal ต้องไม่ทำให้ปุ่มปิดหลุดจอ (เนื้อหา scroll ภายใน modal).

## Accessibility

- รายชื่อผู้ดูแลเป็น `<ul>/<li>` จริง; สถานะ "ไม่นับ" สื่อด้วยข้อความ + ไอคอน (ไอคอน `aria-hidden`) ไม่พึ่งสีอย่างเดียว; contrast ของป้ายเตือนและข้อความจางตรวจ WCAG 2.2 AA ตาม `policies/ux.md` §1 จริงภายหลัง.
- ปุ่ม disclosure เป็น `<button>` มี `aria-expanded`/`aria-controls` และชื่อที่เข้าใจได้ เช่น "ดูผู้ดูแลห้อง {ห้อง} ทั้งหมด {y} คน"; เป้าหมายสัมผัส ≥ 48px ตามโครงเดิม.
- Error โหลดล้มเหลว/ข้อมูลไม่ถูกต้อง: `role="alert"` ครั้งเดียวต่อการโหลด; ปุ่ม "โหลดใหม่" รับ focus; แถบสรุปไม่บล็อกเป็น `role="status"`.
- Modal `roomCaretakerMismatch`/`roomCaretakerLinkRequired`: `role="alertdialog"`, focus เข้า dialog แล้วคืนไปยังเซลล์/ตัวควบคุมที่ trigger, Esc ปิดได้, อ่านเหตุผลครบ (ห้อง/ผู้ดูแล/ครู) จากข้อความ ไม่ใช่สีแดง.
- ชื่อไทยยาวและจำนวนผู้ดูแลมาก wrap ได้; รองรับตัวอักษรขยาย 200% โดยไม่ตัดข้อมูลสำคัญ.
