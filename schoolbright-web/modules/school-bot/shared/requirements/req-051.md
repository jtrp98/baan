# REQ-051 — คะแนนชนและการคุ้มครองคะแนนครู

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

เมื่อช่องคะแนน SchoolBot ถูกครูแก้หรือปลายทางเปลี่ยนหลัง preview ระบบต้องหยุดให้ครูตัดสินรายการชน ต้องรักษาช่องครู override และผลพิเศษ เพื่อไม่ให้การส่งคะแนนทับค่าที่ได้รับการคุ้มครองหรือแทนการไม่มีผลด้วยศูนย์

## Business Rules

- BR-051-01: ช่องที่ SchoolBot ดูแลถูกครูแก้หลังรอบก่อน หรือปลายทางเปลี่ยนหลัง preview ให้หยุดส่งและแสดงรายการชน
- BR-051-02: ครูเลือกทับ/คงค่าได้รายคนเฉพาะช่อง SchoolBot ที่ชน; แสดงค่าปัจจุบันและค่าที่เสนอให้ยืนยันอีกครั้ง
- BR-051-03: ห้ามทับช่องที่ครูกรอกเองนอกช่อง SchoolBot, PgtgradeEdit override และผลพิเศษ เช่น รอผล/ขาดสอบ; ห้ามแปลงเป็นศูนย์
- BR-051-04: การเลือกทับไม่ข้ามข้อห้าม BR-051-03; ข้อมูลเปลี่ยนอีกก่อนบันทึกต้องตรวจชนใหม่

- BR-051-05: ไม่มีผลประเมินกิจกรรมให้ข้าม คงช่องเดิม ไม่แทน 0; มีผลภายหลังส่งตาม preview/สิทธิ์/ตรวจชนเดิม ([มติ 033 (ช่องคะแนนเดิม การแปลงคะแนนเต็ม และผลประเมินที่ยังไม่มี)](../../../../../school-bot/shared/decisions/decisions-033.md))

## Acceptance Criteria

- AC-051-01: ครูแก้ช่อง SchoolBot หลังส่งรอบก่อนแล้วส่งอีกครั้ง ระบบหยุดและแสดงรายการชนก่อนเปลี่ยนคะแนน
- AC-051-02: เลือกทับนักเรียน A และคงค่า B แล้วยืนยันอีกครั้ง A ได้ค่าที่เสนอ B คงค่าครู
- AC-051-03: แก้ปลายทางหลัง preview หรือหลังเลือกแก้ชนแล้ว ระบบหยุดให้ตรวจใหม่ ไม่เขียนทับค่าล่าสุดเงียบ
- AC-051-04: ส่งคะแนนในข้อมูลที่มีช่องครู override และผลพิเศษแล้วค่าคุ้มครองคงเดิม ไม่มีการแทนด้วยศูนย์

- AC-051-05: A ยังไม่มีผลกิจกรรมแต่ช่องเดิมมี 5 ส่งแล้วคง 5 และแสดงข้าม; เมื่อมีผลจึงส่งภายหลังตาม [REQ-050 (Preview และยืนยันส่งคะแนนกิจกรรม)](req-050.md) / [REQ-052 (สิทธิ์ การส่งซ้ำ และ audit คะแนน)](req-052.md) ได้; คนที่มีผลจริง 0 ไม่ถูกข้ามเพราะคะแนนเป็น 0

## ยังไม่ยืนยัน

ไม่มีข้อสมมติฐานหรือคำถามธุรกิจที่ยังไม่ยืนยันเพิ่มเติมในข้อกำหนดนี้
