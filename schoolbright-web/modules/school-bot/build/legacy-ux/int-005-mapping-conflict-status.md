### 3.5 คะแนนชน (conflict) → แก้ชน (resolve) — พรีวิวใหม่ / CAS / owned-only

อ้างอิง: [BR-051-01 (ช่องที่ SchoolBot ดูแลถูกครูแก้หลังรอบก่อน หรือปลายทางเปลี่ยนหลัง preview ให้หยุดส่งและแสดงรายการชน)](../../shared/requirements/req-051.md) ถึง [BR-051-04 (การเลือกทับไม่ข้ามข้อห้าม BR-051-03)](../../shared/requirements/req-051.md) · [AC-051-01 (ครูแก้ช่อง SchoolBot หลังส่งรอบก่อนแล้วส่งอีกครั้ง ระบบหยุดและแสดงรายการชนก่อนเปลี่ยนคะแนน)](../../shared/requirements/req-051.md) ถึง [AC-051-03 (แก้ปลายทางหลัง preview หรือหลังเลือกแก้ชนแล้ว ระบบหยุดให้ตรวจใหม่ ไม่เขียนทับค่าล่าสุดเงียบ)](../../shared/requirements/req-051.md) · [DES-009 (Preview ยืนยัน และส่งคะแนนกลับ SchoolBright)](../../../../../school-bot/build/design/des-009.md) (resolve / xmin CAS)

| State | เงื่อนไข | UI + คำ copy (ข้อเสนอ) |
|---|---|---|
| พบชน (conflict) | ครูแก้ช่อง SchoolBot หลังรอบก่อน · ค่าปลายทางเปลี่ยนหลังพรีวิว · ระหว่าง apply เทียบ xmin ของแถวระบบเกรดกับค่าตอนพรีวิว (CAS) ไม่ตรง | แถว/เซลล์ "ชน" แสดงคู่ค่า: "ค่าปัจจุบันในระบบเกรด <X> — ค่าที่ SchoolBot เสนอ <Y>" · หยุดส่งรายการชนก่อน คงผลที่สำเร็จแล้ว (BR-051-01) |
| เลือกวิธีแก้ | รายการ conflict | radio รายคน: "คงค่าปัจจุบัน (keep_destination)" / "ใช้ค่า SchoolBot ทับ (replace_owned)" + ช่องเหตุผล · ปุ่มลัด "คงค่าปัจจุบันทั้งหมด" — **ไม่มีปุ่ม "ทับทั้งหมด"** กันพลาด (Q35 (แก้คะแนนชนรายคน)) |
| ขอบเขตการทับ | replace_owned | ทับได้เฉพาะช่อง SchoolBot ที่เป็นเจ้าของ — ช่องครูกรอกเอง/ผลพิเศษ/PgtgradeEdit ยังถูกกั้นเสมอ ไม่ข้ามข้อห้าม ([BR-051-03 (ห้ามทับช่องที่ครูกรอกเองนอกช่อง SchoolBot, PgtgradeEdit override และผลพิเศษ เช่น รอผล/ขาดสอบ)](../../shared/requirements/req-051.md), [BR-051-04 (การเลือกทับไม่ข้ามข้อห้าม BR-051-03)](../../shared/requirements/req-051.md)) |
| ส่ง resolve | กด "สร้างพรีวิวใหม่จากการเลือกนี้" | ระบบสร้าง**พรีวิวใหม่** (แทนใบเดิม — Supersedes) → "สร้างพรีวิวใหม่แล้ว กรุณาตรวจและยืนยันส่งอีกครั้ง" — resolve ไม่ใช่การส่ง (DES-009) |
| ข้อมูลเปลี่ยนอีกระหว่างแก้ | หลังเลือก/หลังพรีวิวใหม่ | ตรวจชนใหม่เสมอ → PREVIEW_STALE/TARGET_CHANGED → พรีวิวใหม่อีกครั้ง ไม่เขียนทับค่าล่าสุดเงียบ (BR-051-04, [AC-051-03 (แก้ปลายทางหลัง preview หรือหลังเลือกแก้ชนแล้ว ระบบหยุดให้ตรวจใหม่ ไม่เขียนทับค่าล่าสุดเงียบ)](../../shared/requirements/req-051.md)) |

### 3.6 สถานะการส่ง (export status) + outbox

อ้างอิง: [BR-052-02 (ส่งซ้ำไม่บวกหรือสร้างผลซ้ำ)](../../shared/requirements/req-052.md) · [AC-052-04 (เมื่อส่งสำเร็จบางรายการ ระบบแสดงผลจริงแยกรายการ)](../../shared/requirements/req-052.md) · [DES-009 (Preview ยืนยัน และส่งคะแนนกลับ SchoolBright)](../../../../../school-bot/build/design/des-009.md) (export states/items) · grade-rules (recheck/partial)

หน้า "ผลการส่ง" ต่อจาก confirm — poll อัตโนมัติทุก 5 วินาทีเฉพาะยังไม่จบ (Q37 (ติดตามผลส่งทุกห้าวินาทีและส่งต่อส่วนค้าง)):

| State ของ export | คำ copy + UI (ข้อเสนอ) |
|---|---|
| queued | "อยู่ในคิวส่ง… (export <id>)" |
| running | "กำลังเขียนคะแนน… สำเร็จแล้ว <applied>/<ทั้งหมด>" |
| paused_conflict | "หยุดชั่วคราว — พบคะแนนชน <n> รายการ" + ปุ่ม "ไปแก้ชน" (→ §3.5) · ผลที่สำเร็จแล้วคงเดิม |
| reconciling | "กำลังกระทบยอดผลกับระบบเกรด… (หลังขัดข้อง — ยังไม่ส่งซ้ำจนกว่าจะชัดเจน)" — unknown ไม่ใช่ failed (grade-rules) |
| completed | "ส่งครบทุกรายการแล้ว" + ลิงก์ดู receipt รายคน |
| completed_with_skips | "ส่งเสร็จ — มีรายการข้าม <n> (ยังไม่มีผล) คงคะแนนเดิม · เมื่อมีผลแล้วส่งภายหลังได้" (grade-rules) |
| failed | "ส่งไม่สำเร็จ — รายการที่ยังไม่เริ่มถูกหยุดไว้ ไม่มีคะแนนเสียหาย" + "ติดต่อผู้ดูแล หรือสร้างพรีวิวใหม่เฉพาะส่วนค้าง" |

รายละเอียดรายคน (items): สถานะ queued|applied|skipped|conflict|blocked|unknown + reason_code + receipt_id ของที่ applied · **ส่งต่อส่วนค้าง**: ปุ่ม "สร้างพรีวิวเฉพาะรายการค้าง" — ระบบล็อก outbox เก่า (SUPERSEDED_BY_PREVIEW) ส่วนที่ applied ไม่ส่งซ้ำ (AC-052-04) · มีงานค้างซ้อนช่อง+คนเดิม → 409 EXPORT_IN_PROGRESS: "มีการส่งชุดเดิมค้างอยู่ — รอผลก่อน" · **ไม่มีปุ่ม "ส่งซ้ำทั้งชุด"** มีเพียง "ตรวจสอบสถานะใหม่" (retry เป็นหน้าที่ของ outbox ระบบ — DES-009) — Q37
