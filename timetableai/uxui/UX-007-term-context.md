## หลักการ (ตรงกับ AC-027)

1. **แหล่งเดียวของรายการเทอม = `GET School/{schoolid}/Year/{yearid}/Terms`** (ผ่าน proxy ใหม่ `/api/school/[schoolId]/years/[yearId]/terms`) — ทุกตัวเลือกเทอมในทุกหน้าสร้างจากผลลัพธ์นี้ ไม่มี option ที่เขียนตายตัว ไม่มีจำนวนเทอมตายตัว ไม่มีข้อความ "เทอม 1/2" ในโค้ด UI
2. **แสดงชื่อเทอมจากฟิลด์ของ endpoint เท่านั้น:** `sTermNumber` แสดง**ตามที่ได้รับ ไม่แปลง/ไม่ localize/ไม่คำนวณ** (BR-23, บทเรียน §19-3) + `dStart` เป็นข้อความรอง (จัดรูปแบบวันที่ตาม locale ได้ — ตัวคีย์ไม่แปลง) · ลำดับตัวเลือก = ตามลำดับที่ endpoint คืน (ไม่ re-sort ด้วยกฎของ UI)
3. **ไม่เดาเทอม:** ไม่มีค่าเริ่มต้น "เทอม 1" · ค่าที่ preselect ได้มีเพียง (ก) เทอมเดียวที่ `TTerm` คืนมา หรือ (ข) เทอมที่ผู้ใช้เลือกไว้ก่อนและยังอยู่ในชุดที่โหลดมาใหม่ (ดู OD-2)
4. เทอม = ส่วนหนึ่งของ context ของหน้าเสมอ (ปี + เทอม) แสดงให้เห็นตลอด และส่งไปทุก call (§34.2 ฝั่ง FE ข้อ 2)

## User Flow

1. `/timetable` (hub): ผู้ใช้เลือกปี (as-built) → ระบบโหลดเทอมของปีนั้น → ผู้ใช้เลือกเทอม → ปุ่ม "เข้าสู่ตารางสอน" (เปิดเมื่อมีทั้งปีและเทอม) พาไป `/timetable/[year]` พร้อมเทอมที่เลือก
2. ในหน้าที่มี `[year]` ทั้ง 5 หน้า (`[year]`, `settings`, `subject-settings`, `create-class-period`, `manage-timetable`): แถบ context ใต้หัวหน้าแสดง "ปีการศึกษา {ปี} · ภาคเรียน [ตัวเลือก]" — เปลี่ยนเทอมได้จากแถบนี้
3. เปลี่ยนเทอม → (ถ้ามีการแก้ที่ยังไม่บันทึก: dialog ยืนยัน) → หน้าโหลดข้อมูลของเทอมใหม่ทั้งหมด (ทุก tab/ทุกส่วนของหน้า)
4. จาก `/timetable/[year]` กด สร้าง/แก้ตาราง → `manage-teaching-schedule`: เทอมถูกพาไปด้วยสะพานข้ามหน้า (`localStorage` ต้องพา `sTermID` ควบคู่ `nScheduleID`/`nYear` — §34.2 ข้อ 3) · หน้านี้แสดงเทอม**แบบอ่านอย่างเดียว** (ดูด้านล่าง)
5. เปลี่ยนเทอมของบริบทระหว่างหน้า: ผ่านแถบ context ของหน้าที่มีตัวเลือก — เทอมที่เลือกค้างข้ามหน้าในปีเดียวกัน (วิธีค้าง = OD-1)

## ผลของการเปลี่ยนเทอมต่อ state ของหน้า

- **ข้อมูลที่ยังไม่บันทึก:** dialog ก่อนสลับ — "ยังมีการแก้ไขที่ยังไม่บันทึกในภาคเรียน {เทอมเดิม} ถ้าเปลี่ยนภาคเรียนจะสูญเสียการแก้ไขนี้" ปุ่ม "อยู่ต่อ" (default/โฟกัส) · "เปลี่ยนภาคเรียน" · ยกเลิก = ตัวเลือกคงค่าเดิม
- **หลังสลับ:** state ฟอร์ม/modal/wizard/selection ทั้งหมดรีเซ็ต แล้วโหลดจาก DB ของเทอมใหม่ (DB = source of truth — §25.2) · tab ที่เลือกใน `manage-timetable` คงเดิม · ห้ามแสดงข้อมูลเทอมเดิมค้างระหว่างโหลด (แสดง loading)
- **race:** สลับเทอมเร็วหลายครั้ง → ผลของ request เทอมเก่าที่ตอบช้าต้องถูกทิ้ง (แสดงเฉพาะของเทอมปัจจุบัน)
- **หน้า workspace (route 7):** ไม่มีการสลับ → ไม่มี dialog · ออกจากหน้าตามกติกาเดิมของหน้า
- **ข้อความยืนยันการบันทึก/เขียนทับทุกจุดต้องระบุเทอมที่จะถูกเขียน** เช่น "บันทึกการตั้งค่าของภาคเรียน {sTermNumber}" — กันเขียนผิดเทอมโดยไม่รู้ตัว · **ขั้นยืนยันการเขียนทับข้ามเทอม/ปี (Copy — สัญญา §35.2) ไม่อยู่ในไฟล์นี้ → UX-008**

## Layout & Interaction

- **แถบ context** (component เดียวใช้ซ้ำใน route 2–6): ตำแหน่ง = ใต้หัวหน้า เหนือเนื้อหา · ซ้าย "ปีการศึกษา {ปี}" (ข้อความ) · ขวาของมัน dropdown "ภาคเรียน" (ใช้ Select/Dropdown ที่โปรเจกต์มีอยู่ ไม่ใช้ style ใหม่) · เลื่อนตามหน้าไม่ได้ (ไม่ sticky เกินที่ header เดิมทำ — ตัดสินตาม as-built)
- **Hub:** ตัวเลือกปีเดิม + dropdown เทอมต่อกัน (แนวตั้งบน mobile) · เปลี่ยนปีทีหลัง → ล้างเทอมที่เลือกแล้วโหลดเทอมของปีใหม่
- **Route 7:** chip อ่านอย่างเดียวพร้อมคำอธิบายใน tooltip "ภาคเรียนถูกกำหนดจากตารางที่เปิด — เปลี่ยนได้ที่หน้ารายการตาราง"
- ตัวเลือกเทอมเป็น `string` ทึบ — UI ไม่ตีความ/เรียง/แปลงค่าของ `sTermID` (SA-Q1 ยังไม่ปิดชื่อ/ชนิดคีย์) · สลับเทอมไม่ทำให้ URL ของหน้าเปลี่ยนเป็นนัยอื่นนอกจาก OD-1

## Accessibility

- ตัวเลือกเทอมเป็น native-like select / combobox มี label ที่เชื่อมจริง "ภาคเรียน" · ใช้คีย์บอร์ดครบ (Tab โฟกัส, ลูกศรเลือก, Enter/Space ยืนยัน, Esc ปิด) · ค่าที่เลือกประกาศผ่านชื่อ accessible "ภาคเรียน: {sTermNumber}"
- เปลี่ยนเทอมแล้วประกาศผ่าน `aria-live="polite"`: "โหลดข้อมูลภาคเรียน {sTermNumber} แล้ว" / ผิดพลาด → `role="alert"`
- กล่อง empty/error เป็น `role="alert"` ปุ่ม "ลองใหม่"/"เลือกปีอื่น" โฟกัสได้ · dialog ยืนยันดักโฟกัส เริ่มที่ "อยู่ต่อ" ปิดด้วย Esc = อยู่ต่อ
- ไม่ใช้สีอย่างเดียวบอกสถานะ (error มีไอคอน + ข้อความ) · chip อ่านอย่างเดียว route 7 เข้าถึงได้ด้วย tooltip ที่เปิดด้วย focus · contrast ตามค่า design token เดิมของโปรเจกต์ (ไม่เพิ่มสีใหม่) · responsive: แถบ context ห่อบรรทัดบนจอแคบ ไม่ตัดชื่อเทอม
