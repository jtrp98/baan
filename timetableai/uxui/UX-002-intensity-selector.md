# UX-002 — ตัวเลือก `nCourseIntensity` ใน modal สร้าง/แก้ตาราง + แก้ป้ายใน `/timetable/settings` (D51)

Status: **เซ็นแล้ว — ผู้ใช้อนุมัติ 2026-10-04** (ตอบในแชตของ orchestrator: "UX sign-off ยืนยัน" — อนุมัติ as-is ไม่มีแก้ไข · ครอบ UX-001..UX-004, UX-006 · บันทึกโดย orchestrator) · UX sign-off เป็นการกระทำของคน
วันที่ร่าง: 2026-09-29 · แก้ 2026-09-30 (วันที่ของ session ที่ผู้เรียกระบุ) — ลบหมายเหตุ SA-Q16/BR-81a ที่ล้าสมัย
Traceability: DES-019 §44.3 ("ตั้งค่าที่ modal สร้าง/แก้ตาราง — ตำแหน่ง = `uxui-designer`"), BR-78, D51 · REQ-002, AC-054
As-built basis: ป้ายปัจจุบันใน `/timetable/settings/[year]` เลื่อนระดับหนึ่งชั้น (TH: 0="ไม่กำหนดเงื่อนไข", 1="ความเข้มข้นต่ำ…", 2="ความเข้มข้นปานกลาง…") และนิยาม "สลับ พื้นฐาน↔เพิ่มเติม" — design D51 ระบุว่าผิดและต้องแก้ตาม BR-78; `nCourseIntensity` วันนี้ไม่มีตัวอ่านต่อ (orphan)

## ปัญหาที่ร่างนี้แก้

1. ป้ายระดับปัจจุบันทำให้ผู้ใช้เลือกได้ค่าที่ไม่ตรงความตั้งใจ (ค่าเก็บ 0/1/2 สลับกับสิ่งที่เห็น)
2. ค่าควบคุมจริงของตารางต้องอยู่ที่ **ตาราง** (ต่อตาราง ตามคำตอบธุรกิจ OQ-30/DES-019) — ปัจจุบันมีแต่ค่าต่อหน่วยใน settings ที่ไม่มีผลกับการจัด

## ขอบเขต

- เพิ่ม field ระดับความเข้มข้นใน modal สร้าง/แก้ตาราง (`SelectCurriculumModal` ของหน้า generate)
- แก้ป้ายตัวเลือก + label/tooltip ของ row เดิมใน `/timetable/settings/[year]` ให้เป็น "ค่าเริ่มต้นของตารางใหม่"
- กติกา prefill

## ไม่อยู่ในขอบเขต

- ช่องกรอกความหนักรายวิชา — **ไม่มี** (BR-77 "ระบบคำนวณเท่านั้น")
- การคำนวณเกณฑ์ "หนักเกิน" BR-81a (ยืนยันแล้ว 2026-09-30 — แสดงผลลัพธ์ที่ UX-001/UX-003) · การจำแนกหมวดวิชา (SA-Q16 ปิดแล้ว — `TCourseGroup`) · ตรรกะ solver (FE-003) · สคีมา (คอลัมน์ผู้ใช้ยืนยันแล้ว 2026-09-29; DDL เป็นของ `devops`)

## ข้อกำหนด UI

### ใน modal สร้าง/แก้ตาราง (`SelectCurriculumModal`)

- ตำแหน่ง (ข้อเสนอ): dropdown 1 ช่อง ใต้การ์ดเทมเพลต "แบบมาตรฐาน / แบบกำหนดเวลาและเงื่อนไขเอง"
- Label (ข้อเสนอ): TH **"ระดับการกระจายวิชาหนัก"** / EN **"Heavy-course spread level"**
- ตัวเลือก (ค่า = คำนิยาม BR-78 ที่ผู้ใช้ยืนยันแล้ว · ถ้อยคำ = ข้อเสนอรอเซ็น):

| ค่า | TH | EN |
|---|---|---|
| 0 | ไม่กระจาย (ไม่มีเป้าหมายการจัด) | No spread (no scheduling goal) |
| 1 | พยายามกระจายวิชาหนักให้ทั่ววัน | Try to spread heavy subjects across days |
| 2 | กระจายข้ามวัน และพยายามไม่จัดวิชาหนักติดกันในวันเดียว | Spread across days and avoid consecutive heavy periods |

- ข้อความช่วยเหลือ (ข้อเสนอ): TH "เป้าหมายแบบไม่บังคับ — ระบบพยายามจัดตามระดับ แต่จะไม่ทำให้มีวิชาค้างเพิ่ม และไม่ปฏิเสธการวาง/สลับด้วยมือ" (AC-054)
- Prefill: สร้างใหม่ ← ค่า `Tbl_Setting.nCourseIntensity` ปัจจุบันของหน่วย (dropdown เดิมใน settings) · แก้ตาราง ← ค่าของตารางเอง (ไม่มีค่า/NULL → 0)
- ส่งค่าผ่าน `Timetable/Set` `nCourseIntensity?: 0|1|2` (BE-003) — request ที่ไม่ส่งฟิลด์ต้องไม่เปลี่ยนค่าเดิมของแถว

### ใน `/timetable/settings/[year]` (การ์ด "ตั้งค่าการจัดตารางสอน")

- แก้ป้ายตัวเลือกทั้ง 3 ให้ตรงตารางข้างบน — **ห้ามคงป้ายเดิม** ("ไม่กำหนดเงื่อนไข / ความเข้มข้นต่ำ… / ความเข้มข้นปานกลาง…") (D51)
- Label row (ข้อเสนอ): TH **"ค่าเริ่มต้นระดับการกระจายวิชาหนัก (สำหรับตารางใหม่)"** — สื่อว่าไม่ใช่ตัวควบคุมตารางที่มีอยู่
- Tooltip ใหม่ (แทนข้อความ "ความเข้มข้นของการจัดตารางสอน เช่นวิชาหลัก 2 คาบสลับวิชาเสริม 1 คาบ…" ที่ผิดนิยาม): TH "ระดับนี้เป็นค่าเริ่มต้นเมื่อสร้างตารางใหม่ ระบบพยายามจัดตามระดับแบบไม่บังคับ — จะไม่ทำให้มีวิชาค้างเพิ่ม และไม่ปฏิเสธการวาง/สลับด้วยมือ"

## สิ่งที่ต้องการการตัดสินของคน

- ถ้อยคำป้าย/label/tooltip ทั้งหมดเป็นข้อเสนอ — ป้าย UI ไม่ใช่การยืนยันธุรกิจ (บทเรียน D43) · คำนิยาม 3 ระดับถือว่ายืนยันแล้วตาม BR-78
