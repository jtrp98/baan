# REQ-005 — กลุ่มครู + เวลาไม่ว่าง

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `business-analyst` · ไฟล์นี้ = 1 REQ + AC ของมัน · สถานะอยู่ที่ `requirement\index.md` เท่านั้น


สร้างกลุ่มครูผูกกับ template คาบเรียน เพิ่ม/ถอดครูในกลุ่ม (บันทึก = แทนที่รายชื่อทั้งชุด — BR-14) และปิด/เปิดสล็อตเวลารายวันรายคาบ (`isOn=false` = ครูไม่รับงาน — กลไกหลัก "ครูลา/ติดธุระ" ที่ generator ใช้จริง) · เปลี่ยน template ของกลุ่ม = backend ล้างตารางเวลาทั้ง 7 วันทิ้ง (BR-15) (design.md §5.5, DES-007)

**Acceptance criteria:**

- AC-010 — สล็อตที่ปิด (`isOn=false`) ถูกถือเป็นครูไม่ว่าง ทั้งตอน Generate และตอนวางมือ — ไม่มีทางวางครูในสล็อตนั้นได้
- AC-011 — การบันทึกสมาชิกกลุ่มแทนที่รายชื่อทั้งชุดเสมอ และการเปลี่ยน template ของกลุ่มล้างเวลาไม่ว่างครบ 7 วัน
