# ชิป

> Rev 1 · แก้ล่าสุด 2026-11-02 · แก้โดย นายช่าง · ขอโดย ผู้ใช้ (แตกจาก brand.md ของ sketchbook ให้อ่านได้ทีละไฟล์)
> ใช้ที่: สถานะอุปกรณ์ · สถานะคลาวด์

สีสถานะ + ไอคอน + ข้อความคู่กันเสมอ · สถานะที่ต้องกดหรือเปลี่ยนการตัดสินใจ = ชิปมีกรอบเสมอ (เปิด popover)

## ชิปมีกรอบ (กดได้)

- สูง 32 (พื้นที่กด 44) · padding 0 `space-3` · `radius-pill` · `border-default` · ไอคอน `icon-md` + ข้อความ 16/600 · gap `space-2` · hover ขอบ `action-primary`

| สถานะ | พื้น | ขอบ | ไอคอน |
|---|---|---|---|
| ปกติ / มีค่า | `surface` | `border` | ตามเรื่อง |
| ไม่มี / ปิด | `off-bg` | `border` | ตามเรื่อง |
| กำลังทำ | `action-primary-subtle` | `border-strong` | spinner `action-primary` |
| เตือน / ออฟไลน์ | `warning-bg` | `warning-strong` | `triangle-alert` / `cloud-off` |
| ผิดพลาด / หลุด | `surface` | `danger` | `circle-alert` |

## ชิปไม่มีกรอบ (อ่านอย่างเดียว · ชิปอุปกรณ์บนส่วนหัว)

- จุด 8–10 สีตามความหมาย + ข้อความ 14–16/600 สีตามความหมาย (`success` / `text-secondary` / `warning-strong`) · ไม่มีพื้น
- ใช้กับข้อมูลที่ไม่ต้องกด · ชิปอุปกรณ์บนส่วนหัวหน้าตาเหมือน Arm Lab แต่ไม่มีกรอบ (OQ109) · การเปลี่ยนอุปกรณ์ทำผ่านปุ่ม "เปลี่ยน" ข้างชิป
