# ปุ่มหน้าต่าง

> Rev 1 · แก้ล่าสุด 2026-11-02 · แก้โดย นายช่าง · ขอโดย ผู้ใช้ (แตกจาก brand.md ของ sketchbook ให้อ่านได้ทีละไฟล์)
> ใช้ที่: ปลายส่วนหัว (Windows ขวา · Mac ซ้าย)

## Windows (ขวา)

- **ย่อ · ขยาย/คืนขนาด · ปิด** (ไม่มีปุ่มซ่อนลง tray · OQ119)
- ปุ่ม 48×44 · หน้าปุ่ม 40×36 `radius-sm` · ขอบ `border-default` โปร่ง · ไอคอน `icon-md` · ตัว `text-secondary`
- hover/focus: พื้น `action-primary-subtle` ขอบ + ตัว `action-primary` · active: พื้น + ขอบ `action-primary` ตัวขาว · tooltip ใต้ปุ่ม
- ขยาย/คืนขนาดใช้งานได้จริง (ขั้นต่ำ 1440×900) · ไอคอน: ปกติ = สี่เหลี่ยมมนเดี่ยว · ขยายแล้ว = สี่เหลี่ยมซ้อน 2 อัน · `aria-label` บอกผล

## Mac (ซ้าย)

- **ใช้ปุ่มระบบจริงของ macOS** (OQ188/OQ189) · dev ใช้ปุ่ม native ได้ = ไม่วาดเอง design เว้นพื้นที่ตามระบบ
- ต้องวาดเอง: ตามภาพอ้างอิงที่ผู้ใช้ส่ง (เฉดสี ขอบ ระยะวัดจากภาพ ไม่เดา) + hover/inactive ตามระบบ และบันทึกว่าไม่ใช่ 100%
- ข้อยกเว้นเฉพาะปุ่มนี้: ไม่ใช้เป้ากด ≥ 44 และความต่างสี 3:1 (เป็นปุ่มของระบบ)
