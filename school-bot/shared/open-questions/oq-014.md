# OQ-014 — สูตรคะแนนและการปัดก่อนส่ง

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

สูตรคะแนนรวมหลักสูตรถ่วงน้ำหนักอย่างไร การแก้น้ำหนักย้อนหลังหรือไม่ และก่อนส่งเกรดต้องแปลงคะแนนเต็ม ปัด หรือข้ามผู้ที่ยังไม่มีผลอย่างไร?

สถานะ: ปิด — คำตอบครบตาม [มติ 033 (มติช่องคะแนนเดิม การแปลงคะแนนเต็ม และผลประเมินที่ยังไม่มี)](../decisions/decisions-033.md) และ [มติ 034 (มติสูตรรวมหลักสูตร น้ำหนักรอบเรียน และขอบเขตครูปรับ policy ข้อสอบ)](../decisions/decisions-034.md) ร่วมกับมติเดิม

## ถามใคร

ผู้ใช้ในแชตนี้ ร่วมกับผู้รับผิดชอบการเรียนรู้หรือคะแนนที่ผู้ใช้ระบุ

## ถ้าไม่ตอบกระทบอะไร

หากยังไม่ตอบ จะตรวจสูตรรวมตาม [AC-047-04 (กิจกรรม 8/10 น้ำหนัก 20%, Quiz 6/10 น้ำหนัก 30%, Test 18/20 น้ำหนัก 50% ได้รวม 79/100 และแสดงส่วน 16+18+45 (ตัวเลขทดสอบจากสูตร ไม่ใช่ค่าเริ่ม))](../../modules/quiz/shared/requirements/req-047.md#acceptance-criteria) และแปลง/ปัดตาม [AC-050-03 (กิจกรรม 8/10 ไปช่องเต็ม 20 ได้ 16)](../../../schoolbright-web/modules/school-bot/shared/requirements/req-050.md#acceptance-criteria) ไม่ได้ คำตอบธุรกิจครบแล้ว แต่ยังไม่ใช่ผลตรวจรับสัญญาหรือ implementation

## ข้อสรุปที่ยืนยันแล้ว

คะแนนแต่ละกิจกรรม/Quiz/Test แปลงเป็น 0–100 และถ่วงน้ำหนักรวม 100%; Quiz ที่ไม่นับมีน้ำหนัก 0 การแก้น้ำหนักมีผลเฉพาะรอบเรียนใหม่ รอบปัจจุบันคงเดิม ตาม decisions-034 Quiz ใช้คะแนนสูงสุดเป็นค่าเริ่มตาม [มติ 024 (มติเกณฑ์เลื่อน Level และ policy Quiz/Test)](../decisions/decisions-024.md); สอบซ่อม Test ใช้คะแนนสูงสุดไม่มีเพดานตาม [มติ 025 (มติ auth ข้ามระบบ, admin โรงเรียน, publish, สอบซ่อม และ Desktop)](../decisions/decisions-025.md) ส่งเกรดตามสัดส่วนคะแนนเต็มของแต่ละช่องและปัด half-up เช่น 8/10 ไปช่องเต็ม 20 ได้ 16 ข้ามนักเรียนที่ยังไม่มีผล คงคะแนนเดิม และส่งภายหลังได้ตาม decisions-033 การเลื่อน Level เป็นคนละบริบท: นับทุกคนใน roster และงานขาดเป็น 0 ตาม decisions-024

## ข้อกำหนดที่เกี่ยวข้อง

[REQ-047 (การนับคะแนน Quiz รายหลักสูตร)](../../modules/quiz/shared/requirements/req-047.md) · [REQ-050 (Preview และยืนยันส่งคะแนนกิจกรรม)](../../../schoolbright-web/modules/school-bot/shared/requirements/req-050.md); ครูตั้งการนับ Quiz และสัดส่วนรายหลักสูตร และส่งคะแนนจำนวนเต็มตาม [มติ 020 (มติหลักสูตรแบบ Level, quiz/test และการส่งคะแนนกลับ SchoolBright)](../decisions/decisions-020.md) และ [มติ 021 (มติการส่งคะแนนเข้าระบบเกรด SchoolBright)](../decisions/decisions-021.md)

## ยังไม่ยืนยัน

ไม่มีคำถามธุรกิจค้างในรายการนี้
