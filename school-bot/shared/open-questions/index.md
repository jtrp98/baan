# คำถามธุรกิจของ SchoolBot

> แก้ล่าสุด 2026-11-03 · แก้โดย spec · ขอโดย ผู้ใช้ (มติ 053 — แนบร่างเนื้อหาเพื่อให้ผู้ใช้ตัดสิน)

ทะเบียน OQ (Open Question) เก็บคำถามที่ต้องอาศัยมนุษย์ตัดสิน คงสถานะเดิม 3 รายการที่ตอบบางส่วน และ 9 รายการที่ปิดตามคำตอบผู้ใช้ การปิดคำถามธุรกิจไม่ใช่การตรวจรับ implementation หรืออนุญาตเชื่อมระบบจริง

| OQ | คำถาม | สถานะ |
|---|---|---|
| [OQ-006](oq-006.md) | ผลิตภัณฑ์นี้ต้องแก้ปัญหาใดให้ใคร ผลลัพธ์ที่ต้องการคืออะไร และใครยืนยันข้อกำหนดกับขอบเขตส่งมอบ? | ปิด |
| [OQ-007](oq-007.md) | Guest และ Login เก็บหลายโครงงานที่ใด และเมื่อใช้เครื่องร่วมกันจะเก็บ ลบ กู้คืน หรือนำงานกับประวัติเข้าบัญชีอย่างไร? | ปิด |
| [OQ-008](oq-008.md) | ทีมเสนอหุ่นรุ่นใด firmware ใด วิธี calibration และเกณฑ์หยุดหรือเหตุฉุกเฉินแบบใด และใครจะรับรองให้ใช้กับผู้เรียน? ดู [ช่องข้อมูล spec Q3 ที่ต้องตอบ](../../modules/quiz/shared/content-001-arm-rubric.md) | ตอบแล้วบางส่วนในมติ 016 และ 038 |
| [OQ-009](oq-009.md) | ผู้ใช้อนุมัติเนื้อหา ภารกิจ และเกณฑ์ผ่าน–ไม่ผ่านของบทเรียนสามโหมดฉบับใด เพื่อให้ประเมินผลและติดตามความคืบหน้าได้จริง? [ร่างพร้อมรายการที่ต้องเซ็น](../../modules/quiz/shared/content-001.md) ยังรอคำตอบผู้ใช้ | ตอบแล้วบางส่วนในมติ 009, 015 และ 038 |
| [OQ-010](oq-010.md) | License นับอุปกรณ์อย่างไร ย้ายเครื่องอย่างไร และเมื่อหมดอายุ ถูกเพิกถอน หรือ API ใช้ไม่ได้ จะอนุญาตให้ใช้งานต่อภายใต้เงื่อนไขใด? | ปิด |
| [OQ-011](oq-011.md) | ผู้ใช้ยอมรับเกณฑ์เครือข่าย วิธีวัด performance การลงนามและช่องทางแจกจ่ายชุดใด และใครตรวจรับการติดตั้งจริงแต่ละแพลตฟอร์ม? | ตอบแล้วบางส่วนในมติ 019, 037 และ 038 |
| [OQ-012](oq-012.md) | คะแนน Quiz, Test และภารกิจของ SchoolBot ส่งลงส่วนใดของระบบเกรด SchoolBright และส่งในรูปแบบใด? | ปิด |
| [OQ-013](oq-013.md) | แต่ละ Level ใช้เกณฑ์เท่าไร นับนักเรียนและงานที่ขาดอย่างไร ประเมินเมื่อใด และห้องที่ไม่ถึงเกณฑ์ต้องทำอย่างไร? | ปิด |
| [OQ-014](oq-014.md) | สูตรคะแนนรวมหลักสูตรถ่วงน้ำหนักอย่างไร การแก้น้ำหนักย้อนหลังหรือไม่ และก่อนส่งเกรดต้องแปลงคะแนนเต็ม ปัด หรือข้ามผู้ที่ยังไม่มีผลอย่างไร? | ปิด |
| [OQ-015](oq-015.md) | ใครกำหนดนโยบาย Quiz/Test จำนวนครั้ง เฉลย เวลา และการสุ่มข้อ และครูปรับส่วนใดได้โดยไม่แก้หลักสูตรกลาง? | ปิด |
| [OQ-016](oq-016.md) | ใครแก้ mapping คะแนนได้ กิจกรรมหนึ่งผูกได้กี่ช่อง ใช้เฉพาะช่องเดิมหรือสร้างใหม่ได้ และหลังส่งคะแนนแล้วยังเปลี่ยนได้หรือไม่? | ปิด |
| [OQ-017](oq-017.md) | นำเข้า Sheet เฉพาะแถว D=TRUE หรือรวมแถว D=FALSE และแถวที่ D ว่างเป็นร่างด้วย? | ปิด |

OQ-007 (พื้นที่ Guest และการนำเข้างานเข้าบัญชี) ปิดเฉพาะคำถามธุรกิจ ไม่ได้ยืนยันเงื่อนไขรับรองพื้นที่ Guest (G-GUEST) หรืออนุมัติสัญญา storage
