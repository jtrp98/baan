# มติจากคำตอบผู้ใช้ — 2026-10-21

แหล่งที่มา: คำตอบของผู้ใช้ในแชตนี้; บันทึกเฉพาะส่วนที่ตอบจริง ยังไม่ได้อนุมัติ REQ ทั้งชุดหรือเลือก release ส่งมอบ

## ผู้ใช้และเป้าหมาย — OQ-006

นักเรียนและครูในโรงเรียน เรียนเขียนโปรแกรมและควบคุมหุ่น

## การเก็บงาน — OQ-007

Guest เก็บงานในเครื่อง; Login เก็บงานบนฐานข้อมูลหรือคลาวด์ เป็นความต้องการเพิ่มเติมจาก PoC ยังไม่ได้เลือกเทคโนโลยี จำนวนโครงงาน นโยบายซิงก์ หรือการย้ายงานระหว่างโหมด

## หุ่นและการตรวจก่อนใช้ — OQ-008

รองรับหุ่นรุ่นที่ทีมกำหนด โดยผู้ดูแลตรวจ calibration และการหยุดก่อนใช้กับผู้เรียน ยังไม่ระบุรายชื่อรุ่น ผู้รับผิดชอบที่เป็นบุคคล หรือเกณฑ์ตรวจรับ ไม่ใช่ผลทดสอบหรือการยอมรับความเสี่ยง

## การเรียนรู้ — OQ-009

มีหลักสูตร ภารกิจและประเมินผลจริง บันทึกความคืบหน้า และให้ครูติดตามผล ยังไม่ได้กำหนดคะแนน เกณฑ์ผ่าน ความหมายของดาว หรือสิทธิ์เข้าถึงข้อมูล

## ผลต่อเอกสาร

REQ-009..032 อธิบาย draft จากระบบปัจจุบัน ความต้องการ Login/Cloud และระบบเรียนรู้จริงข้างต้นยังไม่ได้ implement ต้องกลั่นเป็น REQ/AC เพิ่มเติมโดย BA โดยไม่ถือว่าได้รับคำตอบเรื่องนโยบาย License หรือ OS แล้ว
