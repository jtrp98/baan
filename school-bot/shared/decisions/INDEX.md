﻿# มติที่ใช้อยู่ของ SchoolBot

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (บันทึกมติ 052 และแก้ความสัมพันธ์ของมติ 011)

มติผู้ใช้ครอบคลุมระบบเรียนรู้สามโหมด License บัญชีเดิม ฐานข้อมูล การส่งคะแนน หน้าจอ และขอบเขตการพัฒนา รายการที่ยังใช้แยกตามหัวข้อด้านล่าง แต่ละบรรทัดมีความหมาย วันที่ผู้ใช้ตอบ และลิงก์บันทึกคำตอบเดิม

| หมวด | เนื้อหา |
|---|---|
| [ผลิตภัณฑ์และการเรียนรู้](decisions-product.md) | เป้าหมาย ผู้ใช้ โครงงาน Guest License หลักสูตร การประเมิน และคะแนน |
| [บัญชี สิทธิ์ และฐานข้อมูล](decisions-data-auth.md) | Login สิทธิ์ข้ามระบบ ฐานข้อมูล ชนิดข้อมูล และตำแหน่ง repository รวมมติ 052 (Desktop session อายุ 8 ชั่วโมงหลัง bind สำเร็จ) |
| [หน้าจอ การส่งมอบ และการทำงาน](decisions-delivery.md) | อนุมัติหน้าจอ เกณฑ์ส่งมอบ เส้นทางบริการ และงานที่ผู้ใช้อนุญาต |

มติที่ถูกแทนทั้งฉบับอยู่เฉพาะรายการท้ายหน้านี้ มติที่ถูกแทนเพียงบางส่วนยังอยู่ในหมวดตามส่วนที่มีผล พาธ school-bot-v2 ในบันทึกเก่าให้อ่านเป็น school-bot ตาม [มติ 031 (เหลือ repository เดียว)](decisions-031.md)

## มติเดิมที่ยังมีผลและมีรายละเอียดกำหนดภายหลัง

- [มติ 011 (ใช้ฐานข้อมูลเดิมสี่ตัว)](decisions-011.md) · 2026-10-21 ยังคงมีผล; ที่ตั้งตารางกำหนดโดย [มติ 027 (ฐานข้อมูล SchoolBot แยก)](decisions-027.md) · 2026-10-22 และสิทธิ์เขียนช่องคะแนนย่อยกำหนดโดย [มติ 021 (ส่งคะแนนเข้าช่องย่อย)](decisions-021.md) · 2026-10-22 ข้อความที่สองมตินี้แทนอยู่ใน `../../build/design/data-model.md` ฉบับก่อน ไม่ได้อยู่ในตัวมติ 011
