# มติด้านหน้าจอ การส่งมอบ และกติกาการทำงาน

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่)

หน้าจอได้รับอนุมัติครบเจ็ดชุดตามมติที่ระบุด้านล่าง การอนุมัติแต่ละเรื่องมีขอบเขตตามบันทึกต้นทาง และเงื่อนไขก่อนใช้ระบบจริงยังคงตามแผน

## หน้าจอและเกณฑ์ส่งมอบ

- [มติ 036 (ขั้นตอนเตรียมและติดตั้งอัปเดต)](decisions-036.md) · 2026-10-24 · คง PrepareUpdate/InstallPreparedUpdate แยกจากการตรวจรุ่น ยืนยัน License เป็นด่านแรก และเมื่อสิทธิ์หมดระหว่างใช้ให้บันทึกงานกับขอหยุดหุ่นก่อนล็อก
- [มติ 037 (ตรวจรับการอัปเดตและสมรรถนะ)](decisions-037.md) · 2026-10-24 · ตรวจรับเกณฑ์อัปเดตแอปห้าข้อ ให้เลือก Guest/Login ทุกครั้ง ติดป้ายจำลองตลอดการใช้งาน และใช้ขนาด 300 MB เปิดภายใน 5 วินาที กับ 30 FPS เป็นเกณฑ์ส่งมอบ
- [มติ 038 (อนุมัติหน้าทางเข้าและพื้นที่ทำงาน)](decisions-038.md) · 2026-10-24 · อนุมัติหน้าทางเข้าและพื้นที่ทำงาน ผู้ใช้เป็นผู้อนุมัติเนื้อหาและยืนยันเกณฑ์ดาว แต่ยังไม่อนุญาตทดสอบหุ่นจริงและยังไม่ระบุผู้ถือใบรับรองลงนาม
- [มติ 039 (หน้าจัดการโครงงานและบทเรียน)](decisions-039.md) · 2026-10-24 · อนุมัติหน้าจัดการโครงงานครบ และส่วนทางเข้าบทเรียน สถานะเนื้อหา ดาว และผลส่งงาน
- [มติ 040 (หน้าบทเรียนครบส่วนที่เหลือ)](decisions-040.md) · 2026-10-24 · อนุมัติข้อสอบ ความคืบหน้า ข้อความเลื่อนระดับ และการเข้าถึงได้ ทำให้หน้าบทเรียนอนุมัติครบโดยแสดงเฉพาะผลตนเองบน Desktop
- [มติ 041 (หน้าจับคู่และส่งคะแนน)](decisions-041.md) · 2026-10-24 · อนุมัติหน้าจับคู่ช่องคะแนน ดูตัวอย่าง แก้คะแนนชน ตรวจเงื่อนไขก่อนส่ง และอ่านประวัติการส่งคะแนนครบ
- [มติ 042 (ตรวจข้อสอบเมื่อหมดเวลา)](decisions-042.md) · 2026-10-26 · หมดเวลาแล้วตรวจเฉพาะคำตอบที่ server บันทึกทันอัตโนมัติ ข้อว่างเป็นศูนย์ คะแนนเต็มคงเดิม นับครั้งและสิทธิ์ซ่อม และไม่รับคำตอบย้อนหลัง
- [มติ 043 (หน้าจอหลักสูตร ข้อสอบ และเครื่องมือทีม)](decisions-043.md) · 2026-10-26 · อนุมัติหน้าจัดการหลักสูตรและหน้าข้อสอบ/นโยบาย/ครูรวมข้อความหมดเวลาจนครบเจ็ดชุด และกำหนดระดับงาน T0–T2 ใช้ Codex ส่วน T3–T5 ใช้ AGY โดยไม่สลับเครื่องมือสำรอง

## เส้นทางบริการ License และการทำงานที่อนุญาต

gRPC (Remote Procedure Call) คือการเรียกงานระหว่าง Gateway กับบริการ SchoolBot

- [มติ 046 (พัฒนา Gateway และกู้ License Key)](decisions-046.md) · 2026-10-26 · อนุญาตพัฒนา Gateway บน branch ที่เตรียมไว้ และกู้ Key เดิมจากคำขอสร้าง License ซ้ำภายใน 15 นาที โดยยังไม่อนุญาต production
- [มติ 047 (พักเรื่องกุญแจเซ็น)](decisions-047.md) · 2026-10-26 · พักการเลือกที่เก็บกุญแจเซ็นและผู้ดูแลก่อนใช้กุญแจจริง โดยงานที่ไม่พึ่งกุญแจเดินต่อได้
- [มติ 048 (หยุดหลังจบงานที่เปิดอยู่)](decisions-048.md) · 2026-10-26 · ปิดผลสามงานที่กำลังทำและบันทึกข้อค้างแล้วหยุด โดยไม่เปิดงานถัดไปจากคำสั่งเดินงานต่อเนื่องเดิม
- [มติ 049 (อนุญาตแก้ขอบเขต logout เพิ่ม)](decisions-049.md) · 2026-10-28 · อนุญาตแก้ขอบเขตข้อมูลรับส่งของ gRPC และขอบเขต log/channel ของ Gateway เพิ่มตามรายการที่กำหนด รวมแก้การดัดแปลง channel อีกหนึ่งจุด โดยคงเกณฑ์ตรวจเดิมและต้องถามผู้ใช้หากยังไม่ผ่าน
- [มติ 050 (ใช้ controller ของ Gateway)](decisions-050.md) · 2026-10-28 · เส้น HTTP ของ SchoolBot ใช้ controller ตามรูปแบบเดิมของ Gateway โดย Gateway เรียกบริการ SchoolBot ผ่าน gRPC และเว็บผ่าน BFF (Backend for Frontend)
- [มติ 051 (บันทึกโครงงานและฉบับพร้อมกัน)](decisions-051.md) · 2026-11-02 · อนุมัติ CommitProjectAsync ให้โครงงานและฉบับบันทึกเป็นหน่วยเดียว อนุญาตแก้อีกหนึ่งรอบตามขอบเขตเดิม และยืนยันว่าไม่มีข้อมูล file store เดิมต้องนำเข้า
