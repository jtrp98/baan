# License และมาตรฐานชื่อข้อมูล — 2026-10-21

## มติผู้ใช้

ผู้ใช้ในแชตยืนยันว่า "license ถ้าไม่ใส่ก็ใช้ app ไม่ได้นะ" และระบุชื่อกับฟิลด์ฐานข้อมูลดังนี้

- ต้องมี License ก่อนใช้แอป ครอบคลุม Block / Arm / Code และการใช้งานทั้ง Guest กับ Login; Guest ไม่ใช่ข้อยกเว้นเรื่อง License
- ข้อมูลของผลิตภัณฑ์อยู่ภายใต้ชื่อ `SchoolBot`; ชื่อตารางใช้ `SchoolBot<Entity>`
- ตาราง License ชื่อ `SchoolBotLicense` และ PK ชื่อ `SchoolBotLicenseId`
- ฟิลด์มาตรฐาน: `IsDelete`, `CreateBy`, `CreateDate`, `UpdateBy`, `UpdateDate`, `SchoolId`
- มตินี้แทนกติกาเดิมที่ให้ใช้แอปต่อโดยไม่ activate License หรือให้ข้อมูล License หายเมื่อ restart API

## ขอบเขตที่ยังไม่กำหนด

- ผู้ใช้ตอบนโยบายออฟไลน์เพิ่มเติมแล้วใน [decisions-005.md](decisions-005.md): ครั้งแรกออนไลน์ แล้วใช้สิทธิ์ในเครื่อง 3 วัน
- ผู้ใช้ยืนยัน 1 เครื่องต่อ Key ตาม [decisions-006.md](decisions-006.md) และผู้ดูแลย้ายทันทีตาม [decisions-007.md](decisions-007.md); OQ-010 ได้ข้อยุติแล้ว
- ยังไม่กำหนดชื่อ database/schema ทางกายภาพ ชนิดข้อมูล ค่าเริ่มต้น nullability หรือปลายทาง FK; ไม่อนุมานจาก prefix ตาราง
- ไม่มีการสร้างหรือแก้ฐานข้อมูลจากมตินี้

## ผลต่อ requirement

ปรับ REQ-009, REQ-027 และ REQ-028 ให้บังคับ License และเก็บข้อมูลถาวร; เพิ่ม REQ-033 บันทึกข้อกำหนดชื่อตารางและฟิลด์ การอ้างโค้ดเก่าใน REQ เป็นหลักฐานช่องว่าง ไม่ใช่ข้อยกเว้นจากมติล่าสุด
