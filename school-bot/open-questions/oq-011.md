# OQ-011 — กลุ่มเครื่องและเกณฑ์ยอมรับการส่งมอบ

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

ผู้ใช้ยอมรับเกณฑ์เครือข่าย วิธีวัด performance การลงนามและช่องทางแจกจ่ายชุดใด และใครตรวจรับการติดตั้งจริงแต่ละแพลตฟอร์ม?

สถานะ: ตอบแล้วบางส่วนในมติ 019, 037 และ 038; คงสถานะ PARTIAL ตามทะเบียนเดิม

## ถามใคร

ผู้ใช้ตรวจภาพรวม; ทีมต้องเสนอผู้ตรวจรับแต่ละแพลตฟอร์มและผู้ถือใบรับรอง signing

## ถ้าไม่ตอบกระทบอะไร

หากยังไม่ตอบเรื่องผู้รับรอง การลงนามและหลักฐานจริง จะยืนยันการส่งมอบไม่ได้ เป้าหมายระบบปฏิบัติการและตัวเลข performance ที่ผู้ใช้ตอบแล้วไม่ต้องถามซ้ำ

## ข้อสรุปที่ยืนยันแล้ว

ผู้ใช้ยืนยัน Windows และ macOS ต้องควบคุมหุ่นจริงได้ตาม [มติ 008 (Windows และ macOS ควบคุมหุ่นจริง — 2026-10-21)](../requirement/decisions-008.md) และเป็นผู้ตรวจรับภาพรวมตาม [มติ 016 (มติผู้อนุมัติภาพรวมและการจัดทำข้อเสนอหุ่น/OS)](../requirement/decisions-016.md) เป้าหมายปัจจุบันคือ Windows 11 25H2 x64 และ macOS 15+ Intel/Apple Silicon ตาม [มติ 019 (มติ Windows 11 ตามข้อเสนอแรก)](../requirement/decisions-019.md) แทน Windows 10; Home/Pro/เครื่องเสมือนในบันทึกเก่าเป็นประวัติ ไม่ใช่ผลทดสอบ มติ [มติ 037 (ตรวจรับ AC-030-04..08 + UX Q5/Q9 + เกณฑ์ performance)](../requirement/decisions-037.md) ยืนยัน 300 MB, startup 5 วินาที และ 30 FPS เป็นเกณฑ์ตรวจรับ พร้อมวิธีวัด cold/warm start และสเปกเครื่องอ้างอิงตามร่างทีมแล้ว มติ [มติ 038 (sign-off UX ครบทั้งสองไฟล์ + spec Q1/Q2/Q4/Q5)](../requirement/decisions-038.md) ยังไม่ระบุผู้ถือใบรับรองหรือช่องทางแจกจ่าย

## ยังไม่ยืนยัน

รอเกณฑ์เครือข่ายและเงื่อนไขติดตั้ง/อัปเกรด/ถอนที่ยังไม่มีข้อยุติ ผู้ตรวจรับรายแพลตฟอร์ม ผู้ถือใบรับรอง ช่องทางแจกจ่าย และหลักฐานติดตั้ง/วัดผลจริง
