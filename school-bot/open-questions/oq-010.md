# OQ-010 — นโยบาย license และวงจรอุปกรณ์

## คำถามสำหรับมนุษย์

License ควรให้สิทธิ์ใครและนับอุปกรณ์อย่างไร เมื่อเปลี่ยนหรือติดตั้งเครื่องใหม่จะคืนหรือย้าย seat อย่างไร และเมื่อหมดอายุ ถูกเพิกถอน หรือ API ใช้ไม่ได้ ต้องให้ใช้งาน local ต่อภายใต้เงื่อนไขใด?

ผู้ตอบ: เจ้าของธุรกิจ license

## เหตุผลและหลักฐาน

- `web/src/SchoolBot.Domain/Licensing/SchoolLicense.cs:20` นับ device ID และไม่เพิ่มจำนวนเมื่อ ID เดิม activate ซ้ำ
- `app/desktopservice.go:70` ID เป็นข้อมูล installation ในเครื่อง
- `README.md:111` ไม่มี offline token หรือ enforcement
- `web/README.md:29` ข้อมูล license หายเมื่อ API restart

## ผลต่อ requirement

ครอบคลุม REQ-009/027/028/034/035; ใช้มติผู้ใช้แทนข้อจำกัดโค้ดเดิม

## คำตอบที่ต้องบันทึก

คำตอบผู้ใช้และวันที่ พร้อมมติจำนวนเครื่อง ออฟไลน์ และการย้าย

## คำตอบผู้ใช้ — 2026-10-21

- ผู้ตอบ: ผู้ใช้ในแชต ยืนยัน "license ถ้าไม่ใส่ก็ใช้ app ไม่ได้นะ"
- ต้องมี License ก่อนใช้แอป ทั้ง Guest และ Login
- ชื่อ/ฟิลด์ตารางรวม `SchoolId` ดู [มติ DB](../requirement/decisions-004.md)
- ผู้ใช้ตอบนโยบายออฟไลน์แล้ว: ครั้งแรกออนไลน์ ครั้งถัดไปตรวจค่าในเครื่อง ใช้ได้ 3 วันแล้วตรวจ Key ว่ายัง Active ใหม่ ดู [มติ](../requirement/decisions-005.md) และ REQ-034
- 1 เครื่องต่อ Key ตาม [มติ](../requirement/decisions-006.md)
- ผู้ดูแลปลดเครื่องเดิมแล้วใช้ Key เดิมกับเครื่องใหม่ได้ทันที; ยอมให้เครื่องเดิมออฟไลน์จนสิทธิ์เดิมหมด ดู [มติ](../requirement/decisions-007.md) และ REQ-035
