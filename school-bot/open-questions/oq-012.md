# OQ-012 — ปลายทางคะแนนใน SchoolBright

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

คะแนน Quiz, Test และภารกิจของ SchoolBot ส่งลงส่วนใดของระบบเกรด SchoolBright และส่งในรูปแบบใด?

สถานะ: ปิด — คำตอบธุรกิจครบตาม [มติ 021 (มติการส่งคะแนนเข้าระบบเกรด SchoolBright)](../requirement/decisions-021.md)

## ถามใคร

ผู้ใช้ในแชตนี้ ในฐานะเจ้าของผลิตภัณฑ์

## ถ้าไม่ตอบกระทบอะไร

หากยังไม่ตอบ จะระบุปลายทางและรูปแบบส่งคะแนนไม่ได้ คำถามธุรกิจตอบแล้ว; การเชื่อมระบบจริงยังเป็นงาน arch และทีมพัฒนา

## ข้อสรุปที่ยืนยันแล้ว

ระบบเกรดมี 4 หมวด: คะแนนเก็บ คะแนนเก็บหลังกลางภาค กลางภาค และปลายภาค การส่งเกิดเมื่อครูกดยืนยันตาม [มติ 020 (มติหลักสูตรแบบ Level, quiz/test และการส่งคะแนนกลับ SchoolBright)](../requirement/decisions-020.md) ผู้ใช้เลือกทาง A ตาม decisions-021 ให้ SchoolBot เขียนคะแนนเองผ่านหน้า mapping ชนแล้วให้ครูเลือก และปัดเป็นจำนวนเต็ม ข้อเสนอเริ่มต้น Quiz → คะแนนเก็บ และ Test → คะแนนสอบยังเป็นเพียงแนวคิดเดิม; ใช้ช่องคะแนนที่จับคู่ตามมติเป็นข้อกำหนด

## ข้อกำหนดที่เกี่ยวข้อง

การส่งคะแนนไป SchoolBright

## ยังไม่ยืนยัน

ไม่มีคำถามธุรกิจค้างในรายการนี้

ผลตรวจระบบเดิม: [Source review 004 (ระบบเกรด SchoolBright)](../design/source-review-004.md) พบ 4 หมวดใน ScoreData และไม่พบ API เขียนคะแนนใน academic repository ข้อเท็จจริงนี้เป็นผลตรวจฐานเดิม ไม่ใช่การยืนยัน production
