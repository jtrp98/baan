# SchoolBot — สภาพแวดล้อมทดสอบ Windows 10

## คำถามที่ส่ง — 2026-10-21

การทดสอบติดตั้งจริงต้องใช้ Windows 10 แยกจากเครื่องใช้งานหลัก ขณะนี้พบเฉพาะ Windows 11 และยังไม่พบ VM ที่พร้อมใช้ จะใช้สภาพแวดล้อมใด? หากมีแล้ว โปรดระบุชื่อ/path ของ VM หรือวิธีเข้าถึงเครื่องทดสอบในคำตอบด้วย

1. มี VM Windows 10 พร้อมใช้ ฉันจะระบุ provider และชื่อ/path ของ VM
2. มีเครื่อง Windows 10 แยกสำหรับทดสอบ ฉันจะระบุวิธีเข้าถึงหรือผู้ประสาน
3. ยังไม่มี Windows 10 ให้เตรียมชุดทดสอบและคำสั่งสำหรับทีม IT รันก่อน

## คำตอบและข้อยุติ

ผู้ใช้ตอบ: "งั้นให้รอบรับแค่ 11 ละกัน ตามที่เสนอไปตอนแรก"

บันทึกเป็น [decisions-019](../requirement/decisions-019.md) แทนการเลือกสภาพแวดล้อม ไม่รอ VM/เครื่อง Windows10 เพิ่ม และไม่ลงว่าทดสอบ Windows10 ผ่าน มีเพียง [preflight](installer-preflight-001.md) ที่ทำก่อนมติเปลี่ยนขอบเขต
