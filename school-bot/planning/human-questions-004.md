# SchoolBot — ตรวจข้อเสนอ OS ขั้นต่ำ

## สถานะ

- วันที่: 2026-10-21
- ผู้ใช้ตอบคำถามชุด 1–3 ครบแล้ว ดู decisions-014/015/016
- ผู้ใช้เลือกข้อ 2 ให้รองรับ Windows 10 x64 ด้วย และตรวจ edition/build ก่อนปรับข้อเสนอขั้นต่ำ ดู [decisions-017](../requirement/decisions-017.md)
- Gate G-DELIVERY / OQ-011; เป็นการเลือกเป้าหมายก่อนงานที่พึ่งพา ไม่ใช่การรับรอง compatibility ที่ยังไม่ได้ทดสอบ

## คำถาม

จากร่าง SA เสนอ Windows 11 25H2 x64 และ macOS 15+ ทั้ง Intel/Apple Silicon เป็นเป้าหมายพัฒนาและทดสอบ ยังไม่ใช่ผลรับรองว่าใช้งานได้แล้ว ต้องการเลือกแนวทางใด?

1. รับชุดรุ่นที่ SA เสนอเป็นเป้าหมายขั้นต่ำ โดยต้องผ่านการทดสอบจริงก่อนส่งมอบ
2. ต้องรองรับ Windows 10 x64 ด้วย ให้ทีมตรวจ edition/build และปรับข้อเสนอขั้นต่ำก่อนยืนยัน
3. รอข้อมูลเครื่องของโรงเรียนจริงก่อน ยังไม่กำหนดรุ่นขั้นต่ำ

## ขอบเขตการใช้คำตอบ

คำตอบจะเป็นมติผู้ใช้ ไม่เลือกแทนผู้ใช้และไม่ประกาศ hardware/native macOS support จาก build configuration ดูข้อจำกัดและผลตรวจเพิ่มที่ [survey review](sa-survey-review-001.md) ตัวเลือกที่ 1 เป็น product target ไม่ใช่ข้อพิสูจน์ว่า framework ทำงานบน OS ต่ำกว่านั้นไม่ได้
