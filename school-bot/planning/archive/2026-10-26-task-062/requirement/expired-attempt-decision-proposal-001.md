## ผลตรวจมติ

ผู้ใช้ยืนยัน policy Test 1 ครั้งและเปิดซ่อมรายคนใน decisions-024:15–27; คะแนนซ่อมใช้ค่าสูงสุดใน decisions-025:24; สูตรรวมและขอบเขตครูใน decisions-034:13–19 แต่ยังไม่ตัดสินคะแนน/การนับครั้งของ expired ที่ไม่ได้กดส่ง

REQ-046:22–28 ระบุจำกัดเวลา ส่วน DES-010:95–100,116 มี state/deadline/error จึงยังสรุปว่า auto-score ไม่ได้ ตรวจ OQ registry ครบ 12 แถวแล้ว ไม่สร้างหรือปิด OQ และไม่เปิดคำถาม policy เดิมซ้ำ

## คำถามเดียวรอมนุษย์

ผู้ตอบ: ผู้ใช้ในแชต — เจ้าของผลิตภัณฑ์

เมื่อหมดเวลาโดยยังไม่กดส่ง ให้ปิดการทำแล้วจัดการคะแนนและนับครั้งอย่างไร โดยรับเข้าสอบเฉพาะคำตอบที่ server รับและบันทึกทันเวลา?

| ทางเลือก | ผลที่เสนอ |
|---|---|
| A — แนะนำ รอผู้ใช้ยืนยัน | ตรวจอัตโนมัติจากคำตอบที่ server บันทึกทันเวลา แม้ไม่กดส่ง; ข้อไม่มีคำตอบได้ 0 คะแนนเต็มคงทั้งชุด; นับครั้งตาม policy/snapshot และใช้สิทธิ์ซ่อมหากเป็นรอบซ่อม |
| B — รอผู้ใช้ยืนยัน | ปิดโดยไม่มีผลคะแนน แต่นับครั้ง/สิทธิ์ซ่อมเช่นเดียวกับ A; คำตอบที่บันทึกบางส่วนไม่กลายเป็นคะแนน ครูเปิดซ่อมรายคนได้ตามสิทธิ์เดิม |

แนะนำ A เพื่อรักษาผลงานที่บันทึกแล้วและไม่ให้การไม่กดส่งเลี่ยงจำนวนครั้ง (สมมติฐาน — ยังไม่ยืนยัน) ไม่เพิ่มการตรวจข้อสอบด้วยมือโดยครู

## ตัวอย่างสมมติ

Test 10 ข้อ ข้อละ 1 คะแนน: server บันทึก 6 ข้อ ถูก 4; อีก 2 ข้อค้างในเครื่องเมื่อเน็ตขาด และ 2 ข้อยังไม่ตอบ พอหมดเวลา A ได้ 4/10; B ไม่มีผลคะแนน ทั้งคู่ใช้ไป 1 ครั้ง Test จำกัด 1 ครั้งจึงต้องมีสิทธิ์ซ่อมจึงทำเพิ่มได้ หาก server ไม่บันทึกคำตอบเลย A ได้ 0/10 ส่วน B ยังไม่มีผลคะแนน

คำตอบค้างในเครื่องหรือส่งไม่ทันไม่รับเข้าสอบ ไม่เสนอ offline ส่งย้อนหลัง B ไม่เท่ากับคะแนนศูนย์สำหรับ export; กฎงานขาดเพื่อเลื่อน Level แยกตาม REQ-048

## ผลกระทบหลังผู้ใช้ตัดสินเท่านั้น

| หมวด | จุดที่ต้องทบทวน |
|---|---|
| REQ | REQ-046 เพิ่มกฎ/AC expired; REQ-047/048 ตรวจผลต่อคะแนนรวม/งานขาด |
| DES | DES-010 ผลและนับครั้ง; DES-011 ตรวจผลต่อการเลื่อน Level |
| TP | inspect ผูก ID เดิมและเพิ่มกรณีหมดเวลา/บันทึกบางข้อ/เน็ตขาด/นับครั้ง ไม่เดา TP ID |
| UX | int ตรวจ UX-004/007: แจ้งบันทึกสำเร็จ หมดเวลา ผลคะแนนและสิทธิ์คงเหลือ; ตรวจ sign-off ส่วนที่เปลี่ยน |

arch/sys รับรายละเอียด clock/race/retry/DTO และ recovery ต่อ ไม่ให้มนุษย์เลือกวิธีเทคนิค ไม่มีการรับรอง implementation หรือปิด gate
