## Backlog ส่ง sys

**เมธอดอ่าน published curriculum ไม่ตรวจ active license — Minor ในขอบเขต local stub นี้; ต้องประเมินผลกระทบอีกครั้งตอนเชื่อม endpoint**

- อ้างอิง DES-012 Rev9 §3 ข้อ 6 และ §4 ตรวจทุก request
- ทำซ้ำ: `SchoolWithoutActiveLicenseCannotReadPublishedCurriculum` ส่ง school_web principal/session ที่ใช้ได้, SchoolId=1001, IsSchoolAdmin=true, HasActiveSchoolLicense=false และ isCurriculumPublished=true เข้า `EvaluateReadCurriculum`
- คาดหวัง: denied/403 LICENSE_REQUIRED; จริง: IsAllowed=true และเส้นทาง return เป็น 200 ที่ `CurriculumAuthorizationService.cs:162–168` ไม่มี license guard ขณะที่ `EvaluateSelectCurriculum` มี guard ที่บรรทัด 136
- หลักฐาน: `direct-results.json` และ `direct-run.log` เคสสุดท้ายไม่ผ่านจริง
- เหตุที่ไม่ทำให้ slice ตก: AC ด้านการเลือกใช้/สร้าง/แก้ผ่านครบ; finding เป็น guard การอ่านเพิ่มเติมบน isolated evaluator ยังไม่มีหลักฐานการเข้าถึงผ่าน client→HTTP G→gRPC B หรือการข้าม guard upstream ใน deployment ที่ออกแบบ ใบงานแยก H5 ออกแล้ว ไม่อ้างว่าเป็นช่องโหว่ production ที่พิสูจน์ได้
- ส่ง sys ให้ตรวจ fresh license ที่ read entry/guard ในงานเชื่อมต่อถัดไป พร้อมกรณี license ถูกถอนหลังสร้าง session ไม่เปิด task ใหม่หรือขยาย AC ในรอบนี้

## ความครบถ้วนและส่งต่อ

ตรวจ SHA256 ไฟล์เป้าหมายทั้ง 4 ก่อน/หลังตรงกัน (`source-before.json`/`source-after.json`) ไม่แก้ production code, test ใน repo, deliverable ของผู้เขียน, plan Status หรือ git state ไม่มี DB/transaction ให้ตรวจใน evaluator นี้ จึงไม่อ้าง DB runtime หรือ atomicity

ส่งนายช่างลงผลเฉพาะ slice AC-043-01 และส่ง backlog ให้ sys; ไม่มี Critical/Important ที่พิสูจน์ reachable ตามเกณฑ์ใบงาน ไม่มี security gate เพิ่ม ส่วน full regression ผ่าน VSTest และ H5 ยังไม่รับรอง
