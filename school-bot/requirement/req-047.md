# REQ-047 — การนับคะแนน Quiz รายหลักสูตร

## Purpose

ให้ครูเลือกบทบาทของ Quiz ต่อคะแนนหลักสูตร

## แหล่งยืนยัน

ผู้ใช้ในแชต 2026-10-22: [decisions-020](decisions-020.md):10,32 ยืนยันให้ครูตั้งว่าคิดคะแนนหรือไม่และสัดส่วนรายหลักสูตร

## Business Rules

- BR-047-01: ครูตั้งการนับ Quiz/น้ำหนักรายหลักสูตร; น้ำหนักแต่ละกิจกรรม/Quiz/Test รวม 100% ตาม decisions-034
- BR-047-02: Quiz ไม่นับมีน้ำหนัก 0 แต่ดูผลได้; ค่าเริ่ม Quiz ใช้คะแนนสูงสุด Test ซ่อมใช้คะแนนสูงสุดไม่มีเพดาน (decisions-024/025)
- BR-047-03: การนับคะแนนหลักสูตรไม่กำหนดหมวดเกรดปลายทางอัตโนมัติ; ใช้ mapping ตาม REQ-049
- BR-047-04: คะแนนรวม 0–100 = SUM((earned_i/max_i) × weight_i) โดย weight เป็นเปอร์เซ็นต์รวม 100; เปลี่ยนน้ำหนักใช้เฉพาะ CourseRun ใหม่ รอบเดิมคงค่า/ผลเดิม (decisions-034); งานขาดตอนเลื่อน Level ใช้ 0 ตาม REQ-048 แยกจาก export ตาม REQ-050/051

## Acceptance Criteria

- AC-047-01: ครูตั้ง A ให้นับ Quiz และ B ไม่นับ แล้วเห็นค่ารายหลักสูตร; แต่ละชุดน้ำหนักบันทึกใช้ได้เมื่อรวม 100% เท่านั้น
- AC-047-02: Quiz ของ B มีผลให้ดูและน้ำหนัก 0; เปลี่ยนคะแนน Quiz อย่างเดียวแล้วคะแนนรวม B ไม่เปลี่ยน
- AC-047-03: ครูกำหนดสัดส่วน A แล้วเรียกดูสัดส่วนที่บันทึกได้ โดยไม่เปลี่ยน B
- AC-047-04: กิจกรรม 8/10 น้ำหนัก 20%, Quiz 6/10 น้ำหนัก 30%, Test 18/20 น้ำหนัก 50% ได้รวม 79/100 และแสดงส่วน 16+18+45 (ตัวเลขทดสอบจากสูตร ไม่ใช่ค่าเริ่ม)

- AC-047-05: เปลี่ยนน้ำหนักจาก 20/30/50 เป็น 30/20/50 แล้ว CourseRun เดิมยังได้ 79/100 ด้วยค่าเดิม; CourseRun ใหม่ใช้ค่าใหม่ได้ 81/100 เมื่อคะแนนเท่ากัน
