## 2. เกณฑ์ผ่าน/ดาว — แยกมติยืนยันจากข้อเสนอ

มติยืนยันแล้ว:

- เกณฑ์เลื่อน Level เป็นข้อมูลราย Level ที่ admin ส่วนกลางตั้ง ค่าเริ่มต้น 70% เทียบคะแนนรวม 0–100; สิ้นเทอมมีผลเทอมถัดไปทั้งห้อง; ไม่ถึงอยู่ Level เดิม; ค่าเฉลี่ยห้องนับทุกคนใน roster งานที่ไม่ส่งนับ 0 (decisions-024)
- สูตรรวม: ถ่วงน้ำหนักรายกิจกรรมรวม 100%; แก้น้ำหนักใช้รอบใหม่ (decisions-034)
- Code/Block ประเมินอัตโนมัติตามเกณฑ์; Arm ครูตรวจ; รันสำเร็จ ≠ ผ่านทุกภารกิจ (decisions-009, BR-038-01)
- Policy ข้อสอบ (ค่าเริ่ม): Quiz ไม่จำกัดครั้ง/เฉลยทันที/ใช้คะแนนสูงสุด/ไม่จับเวลา/ไม่สุ่ม; Test 1 ครั้ง/จับเวลา/สุ่มข้อ/เฉลยหลังปิดสอบ; ครูปรับได้เฉพาะเวลาสอบ/ช่วงเปิด–ปิด (decisions-024, decisions-034)
- Scope ครู: ตรวจ/ดูความคืบหน้าเฉพาะนักเรียนที่ผู้ดูแลกำหนด (decisions-015)

ข้อเสนอ rubric ดาว (สมมติฐาน — ยังไม่ยืนยัน ทั้งหมดรอผู้อนุมัติตาม G10 ตัดสิน):

- ดาว 1 = ผ่านเกณฑ์ขั้นต่ำของภารกิจ · ดาว 2 = ผ่าน + อยู่ในโควตา (จำนวนคำสั่ง/บล็อก/เวลา ตามที่ระบุรายภารกิจ) · ดาว 3 = ผ่าน + ภารกิจเสริม/ทางเลือกที่ rubric กำหนด
- ดาวไม่ใช่เงื่อนไขเลื่อน Level (การเลื่อนใช้คะแนนรวมถ่วงน้ำหนักเทียบเกณฑ์ราย Level เท่านั้น) — ข้อเสนอนี้ตามมติที่มีอยู่ ไม่เปิดมติใหม่
