# REQ-032 — ติดตั้งแอปบน macOS

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

คำย่อในเอกสาร: API = Application Programming Interface หรือส่วนเชื่อมต่อบริการ

ผู้ใช้ต้องติดตั้ง Desktop บน macOS และควบคุมหุ่นจริงได้ทั้ง Intel และ Apple Silicon การถอนแอปต้องคงข้อมูลโครงงานใน Application Support เพื่อรักษางานที่บันทึกไว้

## Business Rules

- BR-032-01: แพ็กเกจเดียวรองรับ Intel/Apple Silicon ตามเอกสาร ไม่ให้ผู้ใช้เลือก architecture
- BR-032-02: macOS ต้องควบคุมหุ่นจริงตามขอบเขต Arm Lab ได้เช่นเดียวกับ Windows; ข้อจำกัด hardware transport ของโค้ดเดิมต้องพัฒนาเพิ่ม
- BR-032-03: Developer build/ad-hoc signing ไม่เท่ากับ notarized release; ความเข้ากันได้ยังต้องพิสูจน์

## Acceptance Criteria

- AC-032-01: ติดตั้งแพ็กเกจเดียวบนเครื่องทดสอบ macOS 15+ ทั้ง Intel และ Apple Silicon แล้วเปิดแอปและงาน local ได้
- AC-032-02: บน macOS 15+ ทั้ง Intel และ Apple Silicon กับหุ่นรุ่นที่ผ่านการยืนยันแล้ว เชื่อมต่อและส่งคำสั่งควบคุมหุ่นผ่าน native transport ได้จริง โดยไม่ใช้ผลจำลองแทนการส่งคำสั่ง
- AC-032-03: ถอนแอปจาก Applications แล้วข้อมูลโครงงานใน Application Support ยังคงอยู่

## ยังไม่ยืนยัน

ยังต้องพิสูจน์ความเข้ากันได้และ native transport กับเครื่องจริงทั้ง Intel และ Apple Silicon; การเลือกเป้าหมายแพลตฟอร์มไม่ใช่ผลตรวจรับ
