# REQ-032 — ติดตั้งแอปบน macOS

## Purpose

ให้ใช้ Desktop รวมการควบคุมหุ่นจริงบน macOS ตามคำตอบผู้ใช้ ดู [มติ OS](decisions-008.md)

## ข้อเท็จจริงจากไฟล์

- `docs/INSTALLERS.md:8` ระบุ macOS 15+ Universal PKG
- บรรทัด 110–116 ระบุรวมสอง architecture ติดตั้งใน Applications และคง Projects เมื่อถอน
- บรรทัด 120–132 ระบุ signing/notarization และการตรวจเครื่องจริงที่ยังต้องทำ
- `engines/zide/docs/API.md:167` ระบุไม่มี macOS hardware transport

ผู้ใช้ในแชต 2026-10-21 ยืนยัน macOS 15+ Intel x86_64/Apple Silicon arm64 คงเดิมตาม [decisions-019](decisions-019.md); ยังต้องพิสูจน์กับเครื่องจริง

## Business Rules

- BR-032-01: แพ็กเกจเดียวรองรับ Intel/Apple Silicon ตามเอกสาร ไม่ให้ผู้ใช้เลือก architecture
- BR-032-02: macOS ต้องควบคุมหุ่นจริงตามขอบเขต Arm Lab ได้เช่นเดียวกับ Windows; ข้อจำกัด hardware transport ของโค้ดเดิมต้องพัฒนาเพิ่ม
- BR-032-03: Developer build/ad-hoc signing ไม่เท่ากับ notarized release; ความเข้ากันได้ยังต้องพิสูจน์

## Acceptance Criteria

- AC-032-01: ติดตั้งแพ็กเกจเดียวบนเครื่องทดสอบ macOS 15+ ทั้ง Intel และ Apple Silicon แล้วเปิดแอปและงาน local ได้
- AC-032-02: บน macOS 15+ ทั้ง Intel และ Apple Silicon กับหุ่นรุ่นที่ผ่านการยืนยันแล้ว เชื่อมต่อและส่งคำสั่งควบคุมหุ่นผ่าน native transport ได้จริง โดยไม่ใช้ผลจำลองแทนการส่งคำสั่ง
- AC-032-03: ถอนแอปจาก Applications แล้วข้อมูลโครงงานใน Application Support ยังคงอยู่

## Change Log

- 2026-10-22 — ยืนยัน target ตาม decisions-019 และตรวจ native ทั้งสอง architecture

- 2026-10-21 — สร้างจาก source repo ตามคำสั่งผู้ใช้ให้กลั่น requirement; ยังไม่ตรวจ macOS หรือแพ็กเกจจริง
- 2026-10-21 — ผู้ใช้ยืนยัน Windows/macOS ต้องควบคุมหุ่นจริงได้ทั้งคู่; ปรับ BR-032-02 และ AC-032-02 คง IDs เดิม
