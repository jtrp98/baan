# REQ-036 — Guest Local และ Login Cloud

## Purpose

เก็บโครงงานตามรูปแบบเข้าใช้งาน โดยยังต้องมี License ทั้งสองรูปแบบ

## แหล่งยืนยัน

ผู้ใช้ในแชต 2026-10-21: Guest เก็บ Local, Login เก็บ DB/Cloud และทั้งคู่เก็บหลายโครงงาน ดู decisions-001.md และ [decisions-009.md](decisions-009.md)

ผู้ใช้ชี้แจงเพิ่มเติมว่ามี Login/User เดิมใน Academic แล้ว ดู [decisions-010.md](decisions-010.md); การยืนยันตัวตนใน requirement นี้ต้องเชื่อมข้อมูลเดิมตามแบบที่ตรวจ source ไม่ใช่ถือว่าต้องสร้างบัญชีชุดใหม่

API ทั้งหมดรวม Login ทำใน `school-bot-v2/web`; แอปเรียก API, backend ใช้ DB เดิมทั้ง 4 ตัวตาม [decisions-011.md](decisions-011.md)

## Business Rules

- BR-036-01: Guest ไม่ต้องมีบัญชี แต่ต้องมี License ตาม REQ-009/034
- BR-036-02: Guest เก็บหลายโครงงานแต่ละโหมดในเครื่อง; Login เก็บหลายโครงงานผูกบัญชีเดิมที่ยืนยันตัวตนใน DB/Cloud
- BR-036-03: โครงงาน Login ต้องเก็บถาวร ไม่หายเมื่อบริการ restart; ใช้ชื่อ/ฟิลด์ข้อมูลตาม REQ-033
- BR-036-04: ผู้ใช้เลือกนำเข้า Guest หลัง Login ตาม REQ-041; ไม่ auto-upload งานทั้งหมด ประวัติตาม REQ-042

## Acceptance Criteria

- AC-036-01: Guest ที่มี License บันทึกและเปิดหลายงานทั้งสามโหมดในเครื่องได้โดยไม่ต้อง Login
- AC-036-02: Login ด้วยบัญชีเดิมที่ยืนยันตัวตนและ License แล้วบันทึกงานไป DB/Cloud และเปิดงานเดิมของบัญชีนั้นได้
- AC-036-03: Restart บริการแล้ว Login บัญชีเดิมยังเรียกโครงงานที่บันทึกสำเร็จได้
- AC-036-04: บันทึก Cloud ไม่สำเร็จแล้วแจ้งความล้มเหลว ไม่แสดงว่า Cloud บันทึกสำเร็จหรือผูกงานกับบัญชีอื่น
