# REQ-036 — Guest Local และ Login Cloud

## Purpose

เก็บโครงงานตามรูปแบบเข้าใช้งาน โดยยังต้องมี License ทั้งสองรูปแบบ

## แหล่งยืนยัน

ผู้ใช้ในแชต: 2026-10-21 [decisions-001](decisions-001.md)/[009](decisions-009.md) ยืนยัน Guest local/Login Cloud หลายโครงงาน; [010](decisions-010.md)/[011](decisions-011.md) ใช้บัญชีเดิมและ API ใน school-bot/web
ผู้ใช้ 2026-10-23 [decisions-032](decisions-032.md): ครูทดลอง local/เก็บโครงงาน Cloud แต่ไม่เก็บ submission/attempt Cloud

## Business Rules

- BR-036-01: Guest ไม่ต้องมีบัญชี แต่ต้องมี License ตาม REQ-009/034
- BR-036-02: Guest เก็บหลายโครงงานแต่ละโหมดในเครื่อง; นักเรียนและครู Login ด้วยบัญชีเดิมเพื่อเก็บโครงงาน DB/Cloud ได้
- BR-036-03: โครงงาน Login ต้องเก็บถาวร ไม่หายเมื่อบริการ restart; ใช้ชื่อ/ฟิลด์ข้อมูลตาม REQ-033
- BR-036-04: เลือกนำเข้า Guest ตาม REQ-041/042 ไม่ auto-upload; ครูทดลอง local ได้ แต่ห้ามสร้าง submission/attempt บน Cloud รวมทางนำเข้าประวัติ
- BR-036-05: การออกจากระบบของบัญชี Login ต้องเพิกถอนสิทธิ์ของเซสชันนั้นผ่านช่องทางบริการที่ได้รับอนุญาตเท่านั้น โดยไม่กระทบสิทธิ์ License ของเครื่อง ไม่เปิดเผยข้อมูลรับรองหรือรายละเอียดภายในเมื่อเกิดข้อผิดพลาด และหากคำขอไม่มีเซสชันที่ใช้งานอยู่ให้จบคำขอได้อย่างปลอดภัยโดยไม่เปลี่ยนสถานะระบบ

## Acceptance Criteria

- AC-036-01: Guest ที่มี License บันทึกและเปิดหลายงานทั้งสามโหมดในเครื่องได้โดยไม่ต้อง Login
- AC-036-02: นักเรียนและครู Login ด้วยบัญชีเดิมและ License แล้วบันทึก/เปิดโครงงาน Cloud ของตนได้
- AC-036-03: Restart บริการแล้ว Login บัญชีเดิมยังเรียกโครงงานที่บันทึกสำเร็จได้
- AC-036-04: บันทึก Cloud ไม่สำเร็จแล้วแจ้งความล้มเหลว ไม่แสดงว่า Cloud บันทึกสำเร็จหรือผูกงานกับบัญชีอื่น

- AC-036-05: ครูทดลองภารกิจ/ข้อสอบ local และเก็บโครงงาน Cloud ได้ แต่ส่ง submission/attempt ไป Cloud ทั้งทางตรงและนำเข้าประวัติไม่ได้; ไม่เกิดผลเรียนหรือคะแนน Cloud ของครู
- AC-036-06: เมื่อสั่งออกจากระบบของบัญชี Login ระบบยกเลิกเซสชันเฉพาะคำขอนั้นผ่านช่องทางที่ได้รับอนุญาตโดยไม่กระทบสิทธิ์ License ของเครื่อง; หากคำขอไม่มีเซสชันหรือข้อมูลเซสชันไม่สมบูรณ์ ระบบจบคำขอโดยไม่เกิดผลข้างเคียง และเมื่อคำขอไม่ผ่านเกณฑ์ความปลอดภัย เกินขีดจำกัด หรือบริการขัดข้อง ระบบปฏิเสธและแจ้งผลโดยไม่รั่วไหลข้อมูลลับหรือรายละเอียดภายใน
