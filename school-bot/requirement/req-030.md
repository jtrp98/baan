# REQ-030 — ตรวจข้อมูลอัปเดตจาก Desktop

## Purpose

(สมมติฐาน — ยังไม่ยืนยัน) ให้ทราบว่ามี metadata ของเวอร์ชันใหม่สำหรับเครื่องนี้หรือไม่

## ข้อเท็จจริงจากไฟล์

- `app/desktopservice.go:109` ขอ update ด้วย appVersion, stable และ platform ของเครื่อง
- `web/src/SchoolBot.Api/Program.cs:85` คืน available, release และ install_supported=false
- `docs/API.md:95` ระบุกรณีไม่มี release และ Desktop ไม่ download/execute
- `app/desktopservice.go:182` อนุญาต HTTPS หรือ HTTP เฉพาะ loopback

## Business Rules

- BR-030-01: Desktop ปัจจุบันตรวจ stable ตาม version และ platform ของตัวเอง
- BR-030-02: available=true ไม่อนุญาตให้ติดตั้งหรือรันไฟล์อัปเดต
- BR-030-03: การตรวจล้มเหลวต้องแจ้งข้อผิดพลาดและไม่ขัดขวางงาน local

## Acceptance Criteria

- AC-030-01: เมื่อไม่มี published release ใหม่กว่า ผลตรวจมี available=false, release=null และ install_supported=false
- AC-030-02: เมื่อมี release ที่เข้าเงื่อนไข ผู้ใช้เห็น metadata แต่ไม่มีไฟล์ถูกดาวน์โหลด ติดตั้ง หรือ execute จากการตรวจ
- AC-030-03: เมื่อ API เข้าไม่ได้ การตรวจแสดงข้อผิดพลาดและผู้ใช้กลับไปใช้งาน local ต่อได้
