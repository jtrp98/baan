# ผู้ดูแลย้าย License และสิทธิ์ออฟไลน์เดิม — 2026-10-21

## คำตอบผู้ใช้

ผู้ใช้ในแชตเลือกทั้งสองข้อต่อเนื่อง:

- "ให้ผู้ดูแลปลดเครื่องเดิมก่อน แล้วใช้ Key เดิมกับเครื่องใหม่"
- "ผู้ดูแลย้ายได้ทันที โดยยอมให้เครื่องเดิมอาจใช้ออฟไลน์ได้จนสิทธิ์เดิมหมด"

## กติกาที่ได้ข้อยุติ

- ผู้ดูแลเป็นผู้ปลดการผูกเครื่องเดิม ผู้ใช้ไม่ย้ายสิทธิ์เองโดยอัตโนมัติ
- หลังปลดแล้ว เครื่องใหม่เปิดใช้ Key เดิมออนไลน์ได้ทันที ไม่ต้องรอสิทธิ์ออฟไลน์เครื่องเดิมหมดและไม่ต้องออก Key ใหม่
- หนึ่ง Key ผูกกับเครื่องปัจจุบันบนเซิร์ฟเวอร์ได้หนึ่งเครื่องตาม decisions-006.md
- ผู้ใช้ยอมรับให้เครื่องเดิมออฟไลน์ต่อได้จนสิทธิ์เดิมหมดตามกำหนดเดิมไม่เกิน 3 วัน ไม่มีการต่ออายุสิทธิ์เครื่องเดิมเพราะการย้าย
- เครื่องเดิมกลับมาตรวจออนไลน์แล้วไม่ผ่านการยืนยันสิทธิ์ของเครื่องเดิม และไม่ได้รับสิทธิ์ออฟไลน์รอบใหม่
- เมื่อสิทธิ์เดิมหมด เครื่องเดิมเข้าโหมดหลักต่อไม่ได้

## ผลต่อเอกสาร

เพิ่ม REQ-035 และปิด OQ-010 จากคำตอบจริงของผู้ใช้ ข้อยกเว้นที่ใช้ออฟไลน์ทับซ้อนช่วงสั้นนี้เป็นมติผู้ใช้ ไม่ใช่การอ้างว่าปิดสิทธิ์เครื่องที่ออฟไลน์ได้ทันที
