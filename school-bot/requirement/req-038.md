# REQ-038 — ประเมิน Code/Block อัตโนมัติและ Arm โดยครู

## Purpose

ประเมินภารกิจด้วยวิธีที่ผู้ใช้ยืนยัน โดยเก็บผลจริงที่ตรวจย้อนกลับได้

## แหล่งยืนยัน

ผู้ใช้ 2026-10-21 ยืนยันวิธีประเมินตาม [decisions-009](decisions-009.md)

มติผู้ใช้ 2026-10-21: scope ครูตาม decisions-015 และผล Guest ตาม decisions-014/REQ-042

ผู้ใช้ 2026-10-22: [decisions-020](decisions-020.md), [decisions-021](decisions-021.md) และคำสั่งงานนี้

## Business Rules

- BR-038-01: Activity ภารกิจ Code/Block ใช้ระบบประเมินตามเกณฑ์ ไม่ถือว่ารันสำเร็จเท่ากับผ่านทุกภารกิจ
- BR-038-02: Activity ภารกิจ Arm ต้องมีครูตรวจและให้ผล ไม่ใช้ OS write ภาพจำลอง หรือ timer เป็นผลผ่าน
- BR-038-03: ผล Cloud ผูกนักเรียน Activity/revision งาน/วิธีตรวจ; Guest ตาม REQ-042; ครูทดลอง local ไม่สร้างผล Cloud (decisions-032)
- BR-038-04: ครูตรวจ Arm เฉพาะนักเรียนที่ผู้ดูแลกำหนดให้ครูคนนั้น ภายในโรงเรียน/บัญชีเดิม; เกณฑ์ตาม REQ-037 ไม่อนุมัติ grant table ใหม่จากนโยบายนี้
- BR-038-05: Quiz/Test ใช้ REQ-046/047; Mode ของภารกิจไม่ใช้กำหนด policy ข้อสอบ
- BR-038-06: หน้าครูตรวจภารกิจ Arm อยู่ใน sb-tech-upgrade-web-system ไม่อยู่ใน Desktop ตาม [decisions-022](decisions-022.md)

## Acceptance Criteria

- AC-038-01: Code/Block ที่มีเกณฑ์ภารกิจกำหนดแล้วได้รับผลอัตโนมัติตรงกับตัวอย่างผ่านและไม่ผ่านของเกณฑ์นั้น
- AC-038-02: ส่งภารกิจ Arm แล้วไม่กลายเป็นผ่านเองก่อนมีผลตรวจจากครู
- AC-038-03: ครูที่มีสิทธิ์บันทึกผล Arm แล้วเรียกดูผลที่บันทึก พร้อมผู้ตรวจและงานที่ตรวจได้
- AC-038-04: ผล Cloud อ้างนักเรียน Activity/Mode/revision และงานถูกต้อง ไม่ปนผลครู/ดาวตัวอย่าง

- AC-038-05: ครูตรวจ Arm ของนักเรียนนอกรายชื่อที่ได้รับมอบหมายหรือข้ามโรงเรียนไม่ได้ แม้อยู่ห้องเดียวกันหรือรู้รหัสงาน; ผลเดิมไม่เปลี่ยน
