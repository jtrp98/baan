# REQ-035 — ผู้ดูแลปลดเครื่องและย้าย Key เดิม

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

เมื่อเปลี่ยนเครื่องหรือเครื่องเดิมเสีย ผู้ดูแลต้องปลดการผูกเครื่องเดิมเพื่อให้ใช้ Key เดิมกับเครื่องใหม่ได้ทันที เครื่องเดิมใช้สิทธิ์ออฟไลน์ที่เหลือได้จนหมดอายุเดิม โดยการย้ายไม่เริ่มนับสิทธิ์ใหม่

## Business Rules

- BR-035-01: การปลดการผูกเครื่องเป็นหน้าที่ผู้ดูแล ไม่ใช่การย้ายเองจากผู้ใช้หรือการใส่ Key ซ้ำ
- BR-035-02: ปลดแล้วใช้ Key เดิมเปิดใช้เครื่องใหม่ออนไลน์ได้ทันที โดยคง License เดิม ไม่เพิกถอน Key ทั้งใบเพื่อย้ายเครื่อง
- BR-035-03: หนึ่ง Key ผูกกับเครื่องปัจจุบันได้หนึ่งเครื่องบนเซิร์ฟเวอร์
- BR-035-04: เครื่องเดิมออฟไลน์ได้จนสิทธิ์เดิมหมดตาม [REQ-034 (ตรวจ License ออนไลน์และสิทธิ์ออฟไลน์ 3 วัน)](req-034.md) ไม่เริ่มนับ 3 วันใหม่เพราะย้ายหรือเปิดแอปซ้ำ
- BR-035-05: เครื่องเดิมตรวจออนไลน์แล้วไม่ได้ต่อสิทธิ์ใหม่; สิทธิ์เดิมครบกำหนดแล้วเข้าโหมดหลักไม่ได้

## Acceptance Criteria

- AC-035-01: ผู้ไม่มีสิทธิ์ผู้ดูแลขอปลดเครื่องแล้วถูกปฏิเสธ และการผูกเครื่องไม่เปลี่ยน
- AC-035-02: ผู้ดูแลปลด A แล้ว B เปิดใช้ Key เดิมได้ทันที แม้ A ยังมีสิทธิ์ออฟไลน์เหลือ โดยไม่สร้าง License ใหม่
- AC-035-03: B ต้องเปิดใช้ Key ออนไลน์ครั้งแรก ไม่ใช้สิทธิ์ออฟไลน์ของ A แทน
- AC-035-04: หลัง Key ผูกกับ B แล้ว A ตรวจออนไลน์ไม่ผ่านและไม่ได้สิทธิ์ออฟไลน์รอบใหม่
- AC-035-05: A ที่ออฟไลน์ยังใช้ได้ก่อนสิทธิ์เดิมหมด แต่ครบกำหนดแล้วเข้าโหมดหลักไม่ได้; การย้ายไม่เลื่อนกำหนดเดิม

## ยังไม่ยืนยัน

ไม่มีข้อสมมติฐานหรือคำถามธุรกิจที่ยังไม่ยืนยันเพิ่มเติมในข้อกำหนดนี้

## หลักฐาน

ผู้ใช้ในแชต วันที่ 2026-10-21 ยืนยันให้ผู้ดูแลปลดเครื่องเดิมและย้ายได้ทันที โดยยอมให้เครื่องเดิมออฟไลน์จนสิทธิ์เดิมหมด ดู [มติ 007 (ผู้ดูแลย้าย License และสิทธิ์ออฟไลน์เดิม)](decisions-007.md)
