# REQ-011 — บันทึกและเปิดหลายโครงงาน

## Purpose

บันทึกและเปิดหลายโครงงานแต่ละโหมดได้ทั้ง Guest และ Login ตาม [มติผู้ใช้](decisions-009.md); ตำแหน่งเก็บแยกตาม REQ-036

## ข้อเท็จจริงจากไฟล์

- `app/desktopstorage.go:103` บันทึก JSON สูงสุด 1 MiB ไปไฟล์ของแต่ละ mode; บรรทัด 126 เปิดข้อมูล
- `app/desktopstorage.go:46` ย้ายข้อมูลจาก ArmStudioPoC โดยข้ามไฟล์ปลายทางที่มีแล้ว
- `app/README.md:50` ระบุหนึ่ง slot ต่อ mode
- `app/frontend/src/modes/robot-control/workspace/NativeWorkspace.tsx:397` แจ้งข้อจำกัด single-project เมื่อ Save As

## Business Rules

- BR-011-01: Block / Arm / Code มีหลายโครงงานต่อโหมดได้ทั้ง Guest/Login; บันทึกงานหนึ่งไม่แทนอีกงานโดยอัตโนมัติ ข้อจำกัดหนึ่ง slot ของโค้ดเดิมต้องเปลี่ยน
- BR-011-02: ปฏิเสธ JSON เสียหรือเกินขนาด; ไม่มีไฟล์ให้รายงานว่าไม่มีงาน
- BR-011-03: ย้ายข้อมูลเดิมโดยไม่ทับข้อมูลใหม่และไม่ลบต้นฉบับ

- BR-011-04: Guest ใช้พื้นที่ร่วม เก็บ/ส่งออก/กู้คืนตาม REQ-040; เลือกนำเข้า Login ตาม REQ-041

## Acceptance Criteria

- AC-011-01: บันทึกอย่างน้อยสองงานต่อโหมด Block/Arm/Code ทั้ง Guest และ Login แล้วเลือกเปิดแต่ละงานได้ครบและไม่ปะปนกัน
- AC-011-02: บันทึกการแก้ไขงาน A แล้วเปิดใหม่ได้ค่าล่าสุดของ A โดยงาน B ในโหมดเดียวกันไม่เปลี่ยน
- AC-011-03: เปิดไฟล์ JSON เสียหรือเกิน 1 MiB แล้วมีข้อผิดพลาด; ไม่แสดงว่าเปิดสำเร็จ
- AC-011-04: เมื่อมีข้อมูลทั้งชื่อแอปเก่าและใหม่ การเริ่มแอปไม่ทับข้อมูลใหม่; เมื่อปลายทางยังไม่มี ข้อมูลเก่าที่ถูกต้องถูกคัดลอกและต้นฉบับยังอยู่
