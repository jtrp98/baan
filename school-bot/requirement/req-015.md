# REQ-015 — โปรไฟล์หุ่นหกข้อต่อ

## Purpose

(สมมติฐาน — ยังไม่ยืนยัน) ให้ค่าที่แสดงในแอปสัมพันธ์กับการตั้งค่า servo ของอุปกรณ์เป้าหมาย

## ข้อเท็จจริงจากไฟล์

- `app/frontend/src/modes/robot-control/engineAdapter.ts:17` ค่าเริ่มต้นเป็น nominal profile
- ไฟล์เดียวกันบรรทัด 21–41 ตรวจหก servo, ID ไม่ซ้ำ 0–254, PWM 500–2500 และปลายช่วงต่างกัน
- `app/frontend/src/modes/robot-control/connect/NativeConnectScreen.tsx:23` การแก้โปรไฟล์ยกเลิกการยืนยันเดิม
- `engines/zide/docs/INTEGRATION.md:31` ระบุรองรับ PWM กลับทิศและต้อง calibration จริง

## Business Rules

- BR-015-01: โปรไฟล์ต้องมีชื่อและ servo ครบหกตัวตามช่วงที่รองรับ
- BR-015-02: ยอมรับปลาย PWM กลับทิศ แต่ห้ามเท่ากัน
- BR-015-03: การกดยืนยันโปรไฟล์ไม่ใช่หลักฐานว่าผ่าน calibration ทางกายภาพ

## Acceptance Criteria

- AC-015-01: โปรไฟล์ที่มี ID ซ้ำ, servo ไม่ครบหก, PWM นอกช่วง หรือปลาย PWM เท่ากัน ถูกปฏิเสธก่อนเชื่อมต่อ
- AC-015-02: โปรไฟล์ที่ถูกต้องและกำหนด PWM กลับทิศผ่านการตรวจรูปแบบได้
- AC-015-03: เมื่อแก้ชื่อโปรไฟล์หรือค่า servo หลังยืนยัน ต้องยืนยันใหม่ก่อนเชื่อมต่อ
