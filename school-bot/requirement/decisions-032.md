# มติผลทดลองของครูและ cardinality/การล็อก mapping คะแนน

## คำตอบผู้ใช้ — 2026-10-23

ผู้ตอบ: ผู้ใช้ในแชตนี้ ตอบคำถาม human gate ผ่าน request_user_input_async

1. ผลทดลองของครู: "ทดลองในเครื่องและบันทึกโครงงานบน Cloud ได้ แต่ไม่ส่งงานหรือสอบเก็บผลบน Cloud (แนะนำ: ใช้ schema ปัจจุบัน)"
2. Mapping: "1กิจกรรม ได้ หลายช่อง แต่ 1 ช่องได้ 1 กิจกรรม เพราะทำครั้งนึงอาจจะได้คะแนนหลายวิชา"
3. หลังส่งคะแนน: "ล็อก mapping ที่ส่งแล้ว การเปลี่ยนใช้กับชุดใหม่ (แนะนำ)"

## ข้อกำหนดที่ยืนยัน

- เลือกทาง A ของ [ข้อเสนอ LearnerId](../db/proposal-learnerkind.md): ครูทดลองในเครื่องและเก็บโครงงานบน Cloud ได้ แต่ไม่สร้างผลส่งงานหรือผลสอบบน Cloud; ไม่เพิ่ม LearnerKind ตามทาง B
- หนึ่งกิจกรรมเชื่อมช่องคะแนนได้หลายช่อง รวมถึงหลายวิชา; หนึ่งช่องคะแนนในบริบทโรงเรียน/เทอม/วิชาที่เกี่ยวข้องรับได้เพียงหนึ่งกิจกรรม ไม่รวมหลายกิจกรรมลงช่องเดียว
- Mapping ที่ส่งคะแนนแล้วล็อกไว้ การเปลี่ยนใช้กับชุดใหม่; มตินี้ไม่อนุมัติการย้ายหรือล้างคะแนนเดิม
