# REQ-033 — ชื่อและฟิลด์ข้อมูล SchoolBot

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

คำย่อในเอกสาร: PK = Primary Key หรือรหัสหลัก; FK = Foreign Key หรือข้อบังคับรหัสอ้างอิง; DB = Database หรือฐานข้อมูล; SQL = Structured Query Language

ข้อมูลของ SchoolBot ต้องใช้ชื่อตาราง รหัสหลัก และฟิลด์มาตรฐานตามที่ผู้ใช้กำหนด เพื่อให้ข้อมูลผลิตภัณฑ์ใช้มาตรฐานเดียวกันและตรวจสอบกับ catalog ของฐานข้อมูลที่ใช้งานจริงได้

## Business Rules

- BR-033-01: ชื่อตารางของผลิตภัณฑ์ขึ้นต้น `SchoolBot`; ตาราง License ต้องใช้ชื่อที่ผู้ใช้กำหนดตรงตัว
- BR-033-02: ตารางข้อมูลของผลิตภัณฑ์มีฟิลด์มาตรฐานทั้งหกตามชื่อข้างต้น
- BR-033-03: PK เป็น `int4`; คอลัมน์ที่เก็บรหัสอ้างอิงเดิมคงชนิดเดิม แต่ไม่มี SQL FK ตาม [มติ 044 (SQL constraints เหลือเฉพาะ Primary Key)](decisions-044.md). nullability ค่าเริ่มต้น และ logical relationships ระบุในแบบ ไม่อนุมานจากชื่อ

## Acceptance Criteria

- AC-033-01: ตรวจหลักฐาน catalog ของ DB ที่ระบบทดสอบใช้งานแล้วพบชื่อตาราง License เป็น `SchoolBotLicense` ตรงตามตัวพิมพ์
- AC-033-02: ตรวจ catalog ของ DB เดียวกันแล้วพบ `SchoolBotLicenseId` เป็น Primary Key ชนิด `int4`
- AC-033-03: ตรวจ catalog ของ DB เดียวกันแล้วพบฟิลด์มาตรฐานครบทั้งหกชื่อ โดยไม่เปลี่ยนชื่อเป็นรูปแบบอื่น
- AC-033-04: ตรวจ catalog ของ DB ที่ระบบทดสอบใช้งานแล้วทุกตารางข้อมูลของผลิตภัณฑ์ใช้ prefix `SchoolBot` และมีฟิลด์มาตรฐานทั้งหก

- AC-033-05: จาก catalog เดียวกัน PK ของตาราง SchoolBot ใหม่เป็น int4 และคอลัมน์รหัสอ้างอิงเดิมคงชนิดที่ระบุในแบบ; ไม่พบ UNIQUE/FK/CHECK ของ SchoolBot ตาม [มติ 044 (SQL constraints เหลือเฉพาะ Primary Key)](decisions-044.md)

## ยังไม่ยืนยัน

ไม่มีข้อสมมติฐานหรือคำถามธุรกิจที่ยังไม่ยืนยันเพิ่มเติมในข้อกำหนดนี้

## หลักฐาน

ผู้ยืนยัน: ผู้ใช้ในแชต วันที่ 2026-10-21; ที่มา [มติ 004 (License และมาตรฐานชื่อข้อมูล)](decisions-004.md)

- ข้อมูลของผลิตภัณฑ์อยู่ภายใต้ `SchoolBot`
- ตาราง `SchoolBotLicense` มี PK ชื่อ `SchoolBotLicenseId`; PK ตาราง SchoolBot ใหม่เป็น `int4` ตาม [มติ 012 (PK int4 และไฟล์ DBML)](decisions-012.md)
- ฟิลด์มาตรฐานครบทั้ง `IsDelete`, `CreateBy`, `CreateDate`, `UpdateBy`, `UpdateDate`, `SchoolId`
