# SchoolBot — หลักฐานฐานเดิม ณ 2026-10-21

คัดจาก scope.md โดยคงข้อความเดิม เป็นหลักฐานช่วงที่ตรวจ ไม่ใช่ผลตรวจรับหรือ scope ปัจจุบัน ดู [scope](scope.md)

### ความสามารถปัจจุบันจาก source

ความสามารถจากโค้ด ยังไม่ใช่ผลตรวจรับระบบเต็ม

| กลุ่ม | สิ่งที่พบ | ขอบเขตหลักฐาน |
|---|---|---|
| Desktop | สาม mode, ทำงานในเครื่อง, ไทย/อังกฤษ/จีน, ปุ่มหน้าต่างและคำยืนยันออกจากงาน | REQ-009..010, REQ-012 |
| โครงงาน | บันทึกหนึ่ง slot ต่อ mode, เปิดข้อมูลเดิม, ตรวจรูปแบบบางส่วน, ย้ายข้อมูลชื่อแอปเดิมโดยไม่ทับของใหม่ | REQ-011, REQ-017 |
| Robot native | ค้นหา Windows HID/Serial, ยืนยันโปรไฟล์หกข้อต่อและ probe, ส่งท่า, เล่นลำดับ, อัปโหลด, เล่นบนบอร์ด, stop, อ่าน servo, torque | REQ-014..024; ยังไม่มีผลยอมรับหุ่นจริงในงานนี้ |
| Code Lab | เขียนคำสั่งเดิน/กระโดด เล่นในฉาก รีเซ็ตและ Save/Load แยกจากบทเรียน | REQ-025 |
| Block programming | move/jump/repeat, จำกัดการแปลงโปรแกรม, ผลลัพธ์จาก demo engine, บันทึก workspace | REQ-026; ไม่มีหลักฐานส่งบล็อกไปหุ่นจริง |
| License API | สร้าง/รายการ/เพิกถอน, activate/validate, จำกัดจำนวน device ID | REQ-027..028; ข้อมูลอยู่ในหน่วยความจำ |
| Updates | สร้างและ publish metadata, ค้นหา published version ใหม่กว่า, Desktop ขอข้อมูล | REQ-029..030; ไม่มีการติดตั้งอัปเดต |
| Distribution | เอกสารระบุ Windows MSI และ macOS Universal PKG รวมแอปและ engines | REQ-031..032; ยังไม่ตรวจ artifact หรือติดตั้งจริง |

### Sample/preview/mock

- Browser `?preview=1` เลือกการจำลองโดยชัดแจ้งและบันทึกใน localStorage
- Home มีชื่อ/ดาวตัวอย่างและรายการโฟลเดอร์ตัวอย่าง; รายการ native ตรวจพบงานที่บันทึกไว้ของ Robot และ Blocks
- Arm เปิด LearnMap ซึ่งยังจำลองดาว/การเชื่อมต่อ; บทเรียน Block/Code ยัง unavailable ดู [ผลตรวจ](../design/source-review-001.md)
- เมนูครูจำลอง restart/reset/console ผ่าน state และ timer; ไม่ใช่ระบบดูแลบอร์ดหรือสิทธิ์ครูจริง
- WorksScreen มีรายการและการคัดลอก USB จำลอง จึงไม่ใช่หลักฐาน multi-project หรืออ่าน USB จริง
- บางหน้าจำลองถูกเรียกจากเส้นทาง Desktop ได้ การมีหน้าจอบน Desktop ไม่ยืนยันว่าเชื่อมบริการจริง
