# SchoolBot — ฐานขอบเขตฉบับแรก ณ 2026-10-21

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

เอกสารนี้เก็บความสามารถและส่วนจำลองที่พบจาก source ในการตรวจฐานขอบเขตฉบับแรกวันที่ 2026-10-21 ส่วน [scope.md (ขอบเขตส่งมอบปัจจุบัน)](scope.md) เก็บเป้าหมาย ผู้ใช้ มติและข้อจำกัดที่ใช้วันนี้ จึงใช้ไฟล์นี้อ่านข้อจำกัดของฐานเดิม โดยไม่ใช้แทนขอบเขตส่งมอบหรือผลตรวจรับระบบเต็ม


คำย่อในเอกสาร: MSI = Windows Installer package; API = Application Programming Interface หรือส่วนเชื่อมต่อบริการ; HID = Human Interface Device
## ความสามารถที่พบจาก source ณ วันที่ตรวจ

ความสามารถจากโค้ด ยังไม่ใช่ผลตรวจรับระบบเต็ม

| กลุ่ม | สิ่งที่พบ | ขอบเขตหลักฐาน |
|---|---|---|
| Desktop | สาม mode, ทำงานในเครื่อง, ไทย/อังกฤษ/จีน, ปุ่มหน้าต่างและคำยืนยันออกจากงาน | [REQ-009 (Desktop และการใช้งานออฟไลน์)](req-009.md) และ [REQ-010 (ภาษาของแอปและข้อมูลผู้ใช้)](req-010.md), [REQ-012 (ออกจากงานและปิดหน้าต่าง)](req-012.md) |
| โครงงาน | บันทึกหนึ่ง slot ต่อ mode, เปิดข้อมูลเดิม, ตรวจรูปแบบบางส่วน, ย้ายข้อมูลชื่อแอปเดิมโดยไม่ทับของใหม่ | [REQ-011 (บันทึกและเปิดหลายโครงงาน)](req-011.md), [REQ-017 (ข้อมูลท่า ลำดับ และกลุ่ม)](req-017.md) |
| Robot native | ค้นหา Windows HID/Serial, ยืนยันโปรไฟล์หกข้อต่อและ probe, ส่งท่า, เล่นลำดับ, อัปโหลด, เล่นบนบอร์ด, stop, อ่าน servo, torque | [REQ-014 (ค้นหาและเชื่อมต่อหุ่น)](req-014.md) ถึง [REQ-024 (การเชื่อมต่อขาดและคำสั่งล้มเหลว)](req-024.md); ยังไม่มีผลยอมรับหุ่นจริงในงานนี้ |
| Code Lab | เขียนคำสั่งเดิน/กระโดด เล่นในฉาก รีเซ็ตและ Save/Load แยกจากบทเรียน | [REQ-025 (Code Lab: เขียนและรันโปรแกรม)](req-025.md) |
| Block programming | move/jump/repeat, จำกัดการแปลงโปรแกรม, ผลลัพธ์จาก demo engine, บันทึก workspace | [REQ-026 (สร้างและทดลองโปรแกรมบล็อก)](req-026.md); ไม่มีหลักฐานส่งบล็อกไปหุ่นจริง |
| License API | สร้าง/รายการ/เพิกถอน, activate/validate, จำกัดจำนวน device ID | [REQ-027 (จัดการ license ผ่าน admin API)](req-027.md) และ [REQ-028 (Activate, validate และจำกัดอุปกรณ์)](req-028.md); ข้อมูลอยู่ในหน่วยความจำ |
| Updates | สร้างและ publish metadata, ค้นหา published version ใหม่กว่า, Desktop ขอข้อมูล | [REQ-029 (จัดการ release metadata)](req-029.md) และ [REQ-030 (ตรวจข้อมูลอัปเดตจาก Desktop)](req-030.md); ไม่มีการติดตั้งอัปเดต |
| Distribution | เอกสารระบุ Windows MSI และ macOS Universal PKG รวมแอปและ engines | [REQ-031 (ติดตั้งและดูแลแอปบน Windows)](req-031.md) และ [REQ-032 (ติดตั้งแอปบน macOS)](req-032.md); ยังไม่ตรวจ artifact หรือติดตั้งจริง |

## Sample, preview และ mock ณ วันที่ตรวจ

- Browser `?preview=1` เลือกการจำลองโดยชัดแจ้งและบันทึกใน localStorage
- Home มีชื่อ/ดาวตัวอย่างและรายการโฟลเดอร์ตัวอย่าง; รายการ native ตรวจพบงานที่บันทึกไว้ของ Robot และ Blocks
- Arm เปิด LearnMap ซึ่งยังจำลองดาว/การเชื่อมต่อ; บทเรียน Block/Code ยัง unavailable ดู ผลตรวจ
- เมนูครูจำลอง restart/reset/console ผ่าน state และ timer; ไม่ใช่ระบบดูแลบอร์ดหรือสิทธิ์ครูจริง
- WorksScreen มีรายการและการคัดลอก USB จำลอง จึงไม่ใช่หลักฐาน multi-project หรืออ่าน USB จริง
- บางหน้าจำลองถูกเรียกจากเส้นทาง Desktop ได้ การมีหน้าจอบน Desktop ไม่ยืนยันว่าเชื่อมบริการจริง

## ยังไม่ยืนยัน

ฐานนี้ยังไม่มีผลยอมรับหุ่นจริง ไม่มีหลักฐานส่งบล็อกไปหุ่นจริง และยังไม่ได้ตรวจ artifact หรือติดตั้งจริง ข้อมูล License อยู่ในหน่วยความจำ และ Updates ยังไม่รวมการติดตั้งอัปเดตตามช่วงตรวจเดิม
