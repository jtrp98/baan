# REQ-028 — Activate, validate และจำกัดอุปกรณ์

## Purpose

ตรวจ License เพื่ออนุญาตใช้แอป และจำกัด 1 เครื่องต่อ Key ตามคำตอบผู้ใช้

## ข้อเท็จจริงจากไฟล์

- `web/src/SchoolBot.Domain/Licensing/SchoolLicense.cs:20` activate ID เดิมไม่เพิ่มจำนวน; ตรวจ limit, expiry และ revoke
- `web/src/SchoolBot.Application/ManagementService.cs:45` แยก activate/validate และตรวจ device ID 8–128 ตัวอักษร
- `app/desktopservice.go:70` สร้าง local ID; บรรทัด 118 ส่ง key เพื่อ activate
- `README.md:110` ระบุไม่เก็บ key ใน Desktop และไม่มี offline token/enforcement

## Business Rules

ที่มา: คำตอบผู้ใช้ 2026-10-21 ดู [มติ License](decisions-004.md)

- BR-028-01: 1 Key ใช้ได้ 1 เครื่อง เปิดใช้ซ้ำจากเครื่องเดิมได้ แต่เครื่องอื่นใช้ Key ที่ยังผูกกับเครื่องเดิมไม่ได้ ตาม [มติ](decisions-006.md)
- BR-028-02: Validate ไม่เพิ่มอุปกรณ์ ต้อง activate ก่อน
- BR-028-03: ไม่ใช้ License ที่ระบบยืนยันว่าไม่ถูกต้อง หมดอายุ หรือถูกเพิกถอนเพื่อปลดล็อกแอป; ไม่อนุญาต bypass ด้วย Guest
- BR-028-04: ตรวจออนไลน์และสิทธิ์ 3 วันตาม REQ-034; ผู้ดูแลปลด/ย้ายตาม REQ-035 รวมข้อยกเว้นสิทธิ์ออฟไลน์เดิม

## Acceptance Criteria

- AC-028-01: เปิดใช้ Key เดียวบนเครื่อง A ซ้ำได้; ขณะยังผูกกับ A การเปิดใช้บน B ถูกปฏิเสธด้วย DEVICE_LIMIT
- AC-028-02: Validate device ที่ยังไม่ activate ได้ DEVICE_NOT_ACTIVATED; หลัง activate สำเร็จ validate ผ่าน
- AC-028-03: หลัง revoke หรือถึงเวลาหมดอายุ ทั้ง activate และ validate ถูกปฏิเสธว่า license inactive
- AC-028-04: เมื่อลองเปิดใช้ด้วย License ไม่ถูกต้องและไม่เคยมีสิทธิ์ที่ใช้ได้ แอปไม่ปลดล็อกโหมดหลัก และผู้ใช้สามารถกลับไปกรอก License ใหม่ได้
