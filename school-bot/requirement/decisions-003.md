# โครงสร้างผลิตภัณฑ์ 3 โหมด — 2026-10-21

## คำชี้แจงผู้ใช้

"ลองดู code เพิ่ม มันมี 3 mode block , arm , code"

ผู้ตอบ: ผู้ใช้ในแชตนี้

## โครงสร้างที่ใช้กลั่น requirement

1. Block — Block Lab
2. Arm — Arm Lab
3. Code — Code Lab

บทเรียนต้องพิจารณาตามสามโหมดนี้ด้วย; หน้าบทเรียนกับพื้นที่สร้างงานเป็นคนละเส้นทางในโค้ดปัจจุบัน ชื่อ implementation บางส่วนยังใช้ `coding-adventure` แม้หน้าใช้งานชื่อ Code Lab จึงต้องเทียบเส้นทางจริงก่อนสรุปความสามารถ

บัญชี โครงงาน Local/Cloud ภาษา License Updates และการติดตั้งเป็นส่วนกลางที่เกี่ยวข้องกับโหมดหลัก ไม่ใช่โหมดเพิ่มเติม

## ผลต่อเอกสาร

จัดหมวดจากสามโหมดหลักและระบบร่วม โดยรักษา REQ IDs เดิม ไม่ตีความว่า Block หรือ Code ไม่มีอยู่เพียงเพราะเนื้อหาบทเรียนบางโหมดยังไม่พร้อม เป้าหมายระบบเต็มยังคงตาม [decisions-002.md](decisions-002.md)
