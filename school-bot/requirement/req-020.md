# REQ-020 — เล่นชุดท่าบนบอร์ด

## Purpose

(สมมติฐาน — ยังไม่ยืนยัน) ให้สั่งบอร์ดเล่นชุดท่าที่แอปเพิ่งส่งไว้

## ข้อเท็จจริงจากไฟล์

- `app/frontend/src/modes/robot-control/workspace/NativeWorkspace.tsx:217` ต้องมี robotSeq และปฏิเสธวนไม่สิ้นสุด
- บรรทัด 231–239 ส่งช่วง 0 ถึงจำนวนท่าลบหนึ่ง และจำนวนรอบ 1–9999
- `engines/zide/docs/INTEGRATION.md:55` ระบุไม่มี completion event

## Business Rules

- BR-020-01: ต้องมีข้อมูลชุดอัปโหลดใน session และจำนวนรอบจำกัด
- BR-020-02: การสั่งเริ่มบนบอร์ดไม่ยืนยันว่าชุดท่าถูกเก็บหรือเล่นสำเร็จจริง
- BR-020-03: ไม่ตั้งสถานะจบจากการประมาณเวลา; ต้องขอ stop เพื่อออกจากสถานะเล่นบนบอร์ด

## Acceptance Criteria

- AC-020-01: เมื่อยังไม่มีชุดอัปโหลดใน session การเลือกเล่นจากบอร์ดไม่ส่งคำสั่งเริ่ม
- AC-020-02: เมื่อเลือกวนไม่สิ้นสุด ระบบไม่ส่ง group.run และแจ้งให้ระบุจำนวนรอบ
- AC-020-03: เมื่อ test bridge รับคำสั่งเริ่มสำเร็จ ระบบยังแสดงการเล่นบนบอร์ดแม้เลยเวลารวมของท่า จนมีการขอ stop หรือเกิดข้อผิดพลาด
