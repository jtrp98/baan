# มติ 052 — อายุ Desktop session นับจากเวลา bind สำเร็จ
> แก้ล่าสุด 2026-11-02 · บันทึกโดย นายช่าง · ผู้ตัดสิน ผู้ใช้

## มติ

Desktop login ได้ session ชั่วคราวอายุ 5 นาทีเพื่อเลือกและผูกตัวตน (bind) เมื่อ bind สำเร็จ Desktop session มีอายุ 8 ชั่วโมงนับจากเวลาที่ bind สำเร็จ โดย `ExpiresAt = เวลาที่ bind + 8 ชั่วโมง` ไม่ได้นับจากเวลาสร้าง session (`CreateDate`)

## ที่มา

ผู้ใช้ตอบคำถามของนายช่างในแชตวันที่ 2026-11-02 ให้ใช้เวลา bind สำเร็จเป็นจุดเริ่มนับอายุ 8 ชั่วโมง เพื่อยุติข้อขัดแย้งระหว่าง [DES-004 (ตัวตนและสิทธิ์) Rev12](../design/des-004.md) ที่ระบุ `ExpiresAt = CreateDate + 8 ชั่วโมง` กับ [DES-012 (Auth ข้ามระบบ) Rev9](../design/des-012.md) ที่ระบุ 8 ชั่วโมงหลัง bind

## ผลต่อแบบ

arch ต้องแก้ DES-004 เป็น Rev13 ให้ตรงกับมตินี้ งานที่เริ่มตรวจแล้วโดยใช้ DES-004 Rev12 ยังคงใช้ Rev12 เป็นเกณฑ์เดิมตามกติกาตรึงเกณฑ์เมื่อเริ่มงาน (CONVENTIONS §10) มตินี้ไม่เปลี่ยนเกณฑ์ของงานที่เริ่มตรวจไปแล้ว
