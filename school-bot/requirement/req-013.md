# REQ-013 — ขอบเขต sample/preview/mock

## Purpose

(สมมติฐาน — ยังไม่ยืนยัน) ให้ทดลองหน้าจอโดยไม่ตีความผลจำลองเป็นผลจากอุปกรณ์หรือการเรียนจริง

## ข้อเท็จจริงจากไฟล์

- `app/frontend/src/core/client.ts:5` เลือก preview ด้วย `preview=1`; บรรทัด 75 ใช้ localStorage และ 85 ปฏิเสธ cloud ใน preview
- `app/frontend/src/Home.tsx:26` ระบุชื่อ/ดาวเป็น placeholder
- `app/frontend/src/modes/coding-adventure/LearnMap.tsx:225` ให้ดาวจาก state; บรรทัด 237 เชื่อมต่อด้วย timer
- `app/frontend/src/modes/robot-control/teacher/TeacherMenu.tsx:136` จำลอง restart; บรรทัด 201 จำลอง console/reset
- `app/frontend/src/modes/robot-control/works/WorksScreen.tsx:182` จำลองคัดลอก USB

## Business Rules

- BR-013-01: Browser ที่ไม่มี native bridge ต้องไม่เปลี่ยนเป็น preview อัตโนมัติ
- BR-013-02: ผล mock ไม่ใช่สิทธิ์ครู ผลประเมิน การส่งคำสั่งจริง หรือ multi-project
- BR-013-03: ข้อเสนอที่รอยืนยัน: ทุกเส้นทาง mock ควรทำให้ผู้ใช้ทราบว่าเป็นการจำลอง ปัจจุบันยังไม่พิสูจน์ว่าติดป้ายครบ

## Acceptance Criteria

- AC-013-01: เปิด browser โดยไม่มี `preview=1` และไม่มี bridge แล้วพบข้อผิดพลาด native bridge แทนผลสำเร็จจำลอง
- AC-013-02: ใน preview บันทึกงานได้ใน browser แต่ activate และตรวจอัปเดตไม่เรียก API จริง
- AC-013-03: ทดลอง LearnMap, Teacher restart/reset/console และ USB ตัวอย่างแล้วไม่มีคำสั่งไปอุปกรณ์ ไม่มีไฟล์ USB ที่ถูกคัดลอกจริง และไม่มีผลประเมินถาวร
