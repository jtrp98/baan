# จำนวนเครื่องต่อ License — 2026-10-21

## คำตอบผู้ใช้

ผู้ใช้ในแชตเลือก "ใช้ได้เครื่องเดียวต่อ Key"

## กติกา

- 1 License Key ใช้ได้ 1 เครื่อง ไม่ตั้งจำนวนเครื่องหลายเครื่องต่อ Key
- เปิดใช้ซ้ำจากเครื่องเดิมได้ โดยไม่ถือเป็นเครื่องใหม่
- ขณะ Key ยังผูกกับเครื่องเดิม การเปิดใช้กับอีกเครื่องต้องถูกปฏิเสธ
- ใช้ร่วมกับออนไลน์ครั้งแรกและสิทธิ์ออฟไลน์ 3 วันตาม [decisions-005.md](decisions-005.md)
- ผู้ดูแลปลดเครื่องเดิมและย้ายได้ทันทีตาม [decisions-007.md](decisions-007.md) โดยเครื่องเดิมอาจใช้สิทธิ์ออฟไลน์คงเหลือจนหมด ไม่โอนอัตโนมัติจากการใส่ Key ซ้ำ

## ผลต่อเอกสาร

ปรับ REQ-027/028 ให้ 1 เครื่องต่อ Key แทน device limit อิสระ วิธีระบุตัวเครื่องและเก็บสิทธิ์ต้องออกแบบเพิ่มเติม
