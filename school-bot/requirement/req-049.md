# REQ-049 — Mapping หลักสูตรกับช่องคะแนน SchoolBright

## Purpose

กำหนดว่าผลกิจกรรมส่งไปช่องใดในบริบทโรงเรียนและเทอม

## แหล่งยืนยัน

ผู้ใช้ 2026-10-22: decisions-020/021; 2026-10-23: decisions-032/033; ชื่อช่องจาก source-review-004:11–12

## Business Rules

- BR-049-01: แมพคาบ/กิจกรรม/ตัวชี้วัด→วิชา/Pgtassessment ตามโรงเรียน/เทอม; ใช้ช่องเดิม ช่องใหม่สร้างผ่านระบบเกรดก่อน (decisions-033)
- BR-049-02: กิจกรรมหนึ่งได้หลายช่องข้ามวิชา แต่ช่องหนึ่งในบริบทโรงเรียน/เทอม/วิชารับกิจกรรมเดียว ไม่รวมหลายกิจกรรม (decisions-032)
- BR-049-03: Pgtassessment คือช่องคะแนน ไม่ใช่ตัวชี้วัดมาตรฐาน; แสดงตาม mapping
- BR-049-04: ส่งเฉพาะช่องที่แมพ ไม่เดาหมวดจาก Quiz/Test หรือแก้โครงสร้างเกรด
- BR-049-05: หน้า mapping/ส่งคะแนนอยู่ sb-tech-upgrade-web-system เรียก SchoolBot API (decisions-021/022)
- BR-049-06: เฉพาะ admin โรงเรียนสร้าง/แก้ mapping ครูแก้ไม่ได้ (decisions-023)
- BR-049-07: admin โรงเรียน = IsAdmin=1; ใช้เมื่อ License โรงเรียน active (decisions-025)

- BR-049-08: mapping ที่ส่งแล้วล็อก การเปลี่ยนใช้ชุดใหม่ ไม่ย้าย/ล้างคะแนนเดิม (decisions-032)

## Acceptance Criteria

- AC-049-01: admin เห็นโรงเรียน/เทอม คาบ/กิจกรรม/ตัวชี้วัด วิชา/ช่องเดิม; สร้างช่องใหม่ไม่ได้ ครูสร้าง/แก้ mapping ไม่ได้
- AC-049-02: กิจกรรม A แมพช่องวิชา X และ Y ได้; แมพ B ซ้ำช่องใดของ A ในบริบทเดียวกันถูกปฏิเสธ ทั้งแก้ชุดเดิมและสร้างชุดใหม่
- AC-049-03: สลับโรงเรียน/เทอมแล้ว mapping ไม่ถูกใช้ข้ามบริบทอัตโนมัติ
- AC-049-04: Preview ตรงคู่กิจกรรม–ช่องที่แมพ ไม่เพิ่มช่อง/เดาหมวดเอง

- AC-049-05: mapping ที่ส่งแล้วแก้คู่เดิมไม่ได้; เปลี่ยนใช้ชุดใหม่ คู่/คะแนนที่ส่งแล้วคงเดิม และยังห้ามช่องซ้ำ
