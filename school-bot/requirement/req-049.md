# REQ-049 — Mapping หลักสูตรกับช่องคะแนน SchoolBright

## Purpose

กำหนดว่าผลกิจกรรมส่งไปช่องใดในบริบทโรงเรียนและเทอม

## แหล่งยืนยัน

ผู้ใช้ในแชต 2026-10-22: [decisions-020](decisions-020.md):20–23 และ [decisions-021](decisions-021.md):14–17; [source-review-004](../design/source-review-004.md):11–12 ระบุ Pgtassessment เป็นช่องคะแนน

## Business Rules

- BR-049-01: มีหน้าแมพคาบ/กิจกรรม/ตัวชี้วัดของหลักสูตรกับวิชาและช่อง Pgtassessment ต่อโรงเรียน/เทอม
- BR-049-02: คาบเดียวแมพหลายช่องข้ามหลายวิชาได้ โดยระบุกิจกรรมต้นทางของคะแนน
- BR-049-03: Pgtassessment เป็นช่องคะแนน ไม่ถือว่าเท่ากับตัวชี้วัดมาตรฐาน; แสดงความเชื่อมโยงตามที่แมพ
- BR-049-04: ส่งเฉพาะช่องที่แมพไว้; ไม่เดาหมวดเกรดจากชื่อ Quiz/Test และไม่เปลี่ยนโครงสร้างระบบเกรด
- BR-049-05: หน้า mapping และหน้าครูส่งคะแนน (REQ-050/051) อยู่ใน sb-tech-upgrade-web-system เรียก API ฝั่ง school-bot ตาม [decisions-021](decisions-021.md)/[decisions-022](decisions-022.md)
- BR-049-06: สร้าง/แก้ mapping ได้เฉพาะ admin โรงเรียน; ครูไม่แก้ mapping ตาม [decisions-023](decisions-023.md)
- BR-049-07: admin โรงเรียน = บัญชี IsAdmin=1 ของโรงเรียน; หน้าเว็บ SchoolBot ใช้ได้เมื่อโรงเรียนมี License active ตาม [decisions-025](decisions-025.md)

## Acceptance Criteria

- AC-049-01: เปิด mapping แล้วเห็นโรงเรียน เทอม คาบ/กิจกรรม/ตัวชี้วัด วิชา และช่องคะแนนปลายทางของแต่ละรายการ
- AC-049-02: บันทึกคาบ A ไปช่องของวิชา X และ Y แล้วเปิดดูความสัมพันธ์ทั้งสองได้
- AC-049-03: สลับโรงเรียน/เทอมแล้ว mapping เดิมไม่ถูกใช้แทนบริบทใหม่โดยอัตโนมัติ
- AC-049-04: Preview ส่งคะแนนตรงคู่กิจกรรม–ช่องที่แมพไว้; ไม่เพิ่มช่องที่ไม่ได้แมพหรือเลือกหมวดให้เอง

## ประเด็นรอมนุษย์
