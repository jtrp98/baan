# REQ-049 — Mapping หลักสูตรกับช่องคะแนน SchoolBright

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

คำย่อในเอกสาร: API = Application Programming Interface หรือส่วนเชื่อมต่อบริการ

ผู้ดูแลโรงเรียนต้องกำหนดว่าผลกิจกรรมส่งไปช่องคะแนนใดในบริบทโรงเรียนและเทอมได้ การจับคู่ต้องใช้ช่องเดิมและป้องกันหลายกิจกรรมใช้ช่องเดียวกัน เพื่อให้ส่งคะแนนตรงปลายทางโดยไม่แก้โครงสร้างเกรด

## Business Rules

- BR-049-01: แมพคาบ/กิจกรรม/ตัวชี้วัด→วิชา/Pgtassessment ตามโรงเรียน/เทอม; ใช้ช่องเดิม ช่องใหม่สร้างผ่านระบบเกรดก่อน ([มติ 033 (ช่องคะแนนเดิม การแปลงคะแนนเต็ม และผลประเมินที่ยังไม่มี)](decisions-033.md))
- BR-049-02: กิจกรรมหนึ่งได้หลายช่องข้ามวิชา แต่ช่องหนึ่งในบริบทโรงเรียน/เทอม/วิชารับกิจกรรมเดียว ไม่รวมหลายกิจกรรม ([มติ 032 (ผลทดลองของครูและ cardinality/การล็อก mapping คะแนน)](decisions-032.md))
- BR-049-03: Pgtassessment คือช่องคะแนน ไม่ใช่ตัวชี้วัดมาตรฐาน; แสดงตาม mapping
- BR-049-04: ส่งเฉพาะช่องที่แมพ ไม่เดาหมวดจาก Quiz/Test หรือแก้โครงสร้างเกรด
- BR-049-05: หน้า mapping/ส่งคะแนนอยู่ sb-tech-upgrade-web-system เรียก SchoolBot API ([มติ 021 (การส่งคะแนนเข้าระบบเกรด SchoolBright)](decisions-021.md) / [มติ 022 (ที่อยู่ของหน้าจอ Admin / ครู / Desktop)](decisions-022.md))
- BR-049-06: เฉพาะ admin โรงเรียนสร้าง/แก้ mapping ครูแก้ไม่ได้ ([มติ 023 (writer คะแนน, ปัดเศษ, นำเข้า Sheet และเจ้าของ mapping)](decisions-023.md))
- BR-049-07: admin โรงเรียน = IsAdmin=1; ใช้เมื่อ License โรงเรียน active ([มติ 025 (auth ข้ามระบบ, admin โรงเรียน, publish, สอบซ่อม และ Desktop)](decisions-025.md))

- BR-049-08: mapping ที่ส่งแล้วล็อก การเปลี่ยนใช้ชุดใหม่ ไม่ย้าย/ล้างคะแนนเดิม (มติ 032)

## Acceptance Criteria

- AC-049-01: admin เห็นโรงเรียน/เทอม คาบ/กิจกรรม/ตัวชี้วัด วิชา/ช่องเดิม; สร้างช่องใหม่ไม่ได้ ครูสร้าง/แก้ mapping ไม่ได้
- AC-049-02: กิจกรรม A แมพช่องวิชา X และ Y ได้; แมพ B ซ้ำช่องใดของ A ในบริบทเดียวกันถูกปฏิเสธ ทั้งแก้ชุดเดิมและสร้างชุดใหม่
- AC-049-03: สลับโรงเรียน/เทอมแล้ว mapping ไม่ถูกใช้ข้ามบริบทอัตโนมัติ
- AC-049-04: Preview ตรงคู่กิจกรรม–ช่องที่แมพ ไม่เพิ่มช่อง/เดาหมวดเอง

- AC-049-05: mapping ที่ส่งแล้วแก้คู่เดิมไม่ได้; เปลี่ยนใช้ชุดใหม่ คู่/คะแนนที่ส่งแล้วคงเดิม และยังห้ามช่องซ้ำ

## ยังไม่ยืนยัน

ไม่มีข้อสมมติฐานหรือคำถามธุรกิจที่ยังไม่ยืนยันเพิ่มเติมในข้อกำหนดนี้
