# REQ-022 — อ่านค่าตำแหน่ง servo

## Purpose

(สมมติฐาน — ยังไม่ยืนยัน) ให้ใช้ค่าที่อุปกรณ์ตอบกลับมาปรับข้อมูลท่า โดยไม่ใช้ภาพจำลองแทนการวัด

## ข้อเท็จจริงจากไฟล์

- `app/frontend/src/modes/robot-control/engineAdapter.ts:58` จับ ID ในคำตอบ ตรวจ PWM ตามโปรไฟล์ แล้วแปลงกลับเป็นค่าหน้าจอ
- `app/frontend/src/modes/robot-control/workspace/NativeWorkspace.tsx:325` อ่านหนึ่งหรือหลายข้อต่อและ commit เมื่ออ่านครบ
- บรรทัด 341 สร้างท่าใหม่จากค่าที่อ่าน; บรรทัด 363 จัดการความผิดพลาด

## Business Rules

- BR-022-01: รับเฉพาะคำตอบของ ID ที่กำหนดและค่าในช่วงโปรไฟล์
- BR-022-02: คำตอบขาด ผิดรูปแบบ หรือเกินช่วง ต้องไม่แก้ข้อมูลท่าจากผลอ่านไม่ครบ
- BR-022-03: ค่าที่แปลงเป็นพิกัด UI ไม่ได้ยืนยันความแม่นยำมุมทางกล ดู OQ-008

## Acceptance Criteria

- AC-022-01: เมื่อ test device ตอบ PWM ที่ถูกต้องของ ID ที่ขอ ค่าในท่าเปลี่ยนตามการแปลงโปรไฟล์
- AC-022-02: เมื่ออ่านครบหกข้อแล้วสร้างท่าใหม่ ท่านั้นมีค่าจากคำตอบทั้งหกข้อ
- AC-022-03: เมื่อข้อใดข้อหนึ่งไม่ตอบ ตอบผิด ID หรือเกินช่วง ข้อมูลท่าเดิมไม่ถูกแทนด้วยผลอ่านบางส่วนและมีข้อผิดพลาด
