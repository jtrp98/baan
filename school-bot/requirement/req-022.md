# REQ-022 — อ่านค่าตำแหน่ง servo

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

ให้ใช้ค่าที่อุปกรณ์ตอบกลับมาปรับข้อมูลท่า โดยไม่ใช้ภาพจำลองแทนการวัด. ผลอ่านที่ไม่ครบต้องไม่แทนข้อมูลท่าเดิม.

UI (User Interface) คือส่วนติดต่อผู้ใช้; PWM (Pulse Width Modulation) คือค่าพัลส์ควบคุม servo.

## Business Rules

- BR-022-01: รับเฉพาะคำตอบของ ID ที่กำหนดและค่าในช่วงโปรไฟล์
- BR-022-02: คำตอบขาด ผิดรูปแบบ หรือเกินช่วง ต้องไม่แก้ข้อมูลท่าจากผลอ่านไม่ครบ
- BR-022-03: ค่าที่แปลงเป็นพิกัด UI ไม่ได้ยืนยันความแม่นยำมุมทางกล ดู [OQ-008 (ขอบเขตหุ่นและการยอมรับความปลอดภัย)](../open-questions/oq-008.md)

## Acceptance Criteria

- AC-022-01: เมื่อ test device ตอบ PWM ที่ถูกต้องของ ID ที่ขอ ค่าในท่าเปลี่ยนตามการแปลงโปรไฟล์
- AC-022-02: เมื่ออ่านครบหกข้อแล้วสร้างท่าใหม่ ท่านั้นมีค่าจากคำตอบทั้งหกข้อ
- AC-022-03: เมื่อข้อใดข้อหนึ่งไม่ตอบ ตอบผิด ID หรือเกินช่วง ข้อมูลท่าเดิมไม่ถูกแทนด้วยผลอ่านบางส่วนและมีข้อผิดพลาด

## ยังไม่ยืนยัน

- เจตนาทางธุรกิจที่กลั่นจากฐานเดิมยังไม่ยืนยัน: ให้ใช้ค่าที่อุปกรณ์ตอบกลับมาปรับข้อมูลท่า โดยไม่ใช้ภาพจำลองแทนการวัด ต้องให้เจ้าของผลิตภัณฑ์ยืนยันเจตนานี้ โดยแยกจากกฎหรือเกณฑ์ที่มีมติยืนยันแล้ว
