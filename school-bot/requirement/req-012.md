# REQ-012 — ออกจากงานและปิดหน้าต่าง

## Purpose

(สมมติฐาน — ยังไม่ยืนยัน) ลดการออกจากงานโดยไม่ตั้งใจและพยายามหยุดงานหุ่นก่อนปิด

## ข้อเท็จจริงจากไฟล์

- `app/frontend/src/App.tsx:127` ยืนยันก่อนเปลี่ยนจาก mode ยกเว้น Home และรายการงาน Robot
- `app/frontend/src/App.tsx:86` เตรียมปิด ยกเลิกงาน แล้วปิดหน้าต่าง; หากล้มเหลวแสดงข้อผิดพลาด
- `app/frontend/src/modes/robot-control/workspace/NativeWorkspace.tsx:369` ลงทะเบียน stop ก่อนปิด
- ไฟล์เดียวกันบรรทัด 398 ออกจาก workspace หลัง Save สำเร็จเท่านั้น

## Business Rules

- BR-012-01: คำยืนยันเปลี่ยน mode ไม่ได้พิสูจน์ว่าบันทึกงานแล้ว
- BR-012-02: เส้นทาง Save แล้วออกต้องรอ Save สำเร็จ
- BR-012-03: การเตรียมปิดล้มเหลวต้องไม่แสดงว่าปิดสำเร็จ; stop เป็นเพียงคำขอ ตาม REQ-021

## Acceptance Criteria

- AC-012-01: เมื่ออยู่ระหว่างทำงานใน mode แล้วเลือก mode อื่น มีคำยืนยัน; เลือกยกเลิกแล้วอยู่ที่เดิม
- AC-012-02: เมื่อเลือก Save แล้วออกและจำลอง storage ล้มเหลว หน้ายังไม่ออกและมีข้อความบันทึกล้มเหลว
- AC-012-03: เมื่อจำลอง close guard ล้มเหลว หน้าต่างยังเปิดและแสดงเหตุผลให้ผู้ใช้เห็น
