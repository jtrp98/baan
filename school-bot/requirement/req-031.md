# REQ-031 — ติดตั้งและดูแลแอปบน Windows

## Purpose

(สมมติฐาน — ยังไม่ยืนยัน) ให้ติดตั้งแอปพร้อม engines โดยไม่ต้องเตรียมเครื่องมือพัฒนา

## ข้อเท็จจริงจากไฟล์

- `docs/INSTALLERS.md:7` ระบุ Windows 10/11 x64 MSI; บรรทัด 11 รวมสาม mode และ engines แต่แยก API
- บรรทัด 54–63 ระบุ per-user, shortcuts, WebView2 และคงข้อมูลเมื่อถอน
- บรรทัด 69–81 ระบุ repair/uninstall/major upgrade และกัน downgrade
- บรรทัด 127 ระบุ MSI ยังไม่ลงนาม; งานนี้ไม่ได้ตรวจตัวแพ็กเกจ

## มติปัจจุบัน

ผู้ใช้ในแชต 2026-10-21 ยืนยัน Windows 11 25H2 x64 ตาม [decisions-019](decisions-019.md); ข้อความ Windows 10/11 ข้างต้นเป็นหลักฐานเดิม ไม่ใช่ target ปัจจุบัน

## Business Rules

- BR-031-01: ผู้ใช้ไม่ต้องติดตั้ง Go/Node/.NET/Qt เพื่อรัน Desktop
- BR-031-02: หากไม่มี WebView2 ขอความยินยอมติดตั้ง runtime และอาจต้องต่ออินเทอร์เน็ต
- BR-031-03: ถอนแอปต้องเก็บ Projects, Device ID และ WebView2
- BR-031-04: ต้องปิดแอปก่อนอัปเกรด; ไม่ถือว่า checksum เป็นลายเซ็นผู้เผยแพร่

- BR-031-05: ส่งมอบบน Windows 11 25H2 x64 รวมควบคุมหุ่นจริง; ไม่ต้องรองรับ Windows 10 ตามมติใหม่

## Acceptance Criteria

- AC-031-01: บน Windows 11 25H2 x64 บัญชีทดสอบสะอาดที่มี WebView2 ติดตั้ง MSI แล้วเปิดสาม mode และ engines ที่บรรจุมาได้โดยไม่ติดตั้งเครื่องมือพัฒนา
- AC-031-02: เมื่อไม่มี WebView2 มีขั้นตอนขอให้ติดตั้ง; ยกเลิกแล้วไม่แสดงว่าแอปพร้อมใช้งานสำเร็จ
- AC-031-03: ใน installation ทดสอบ ลบไฟล์ engine แล้ว repair คืนได้; uninstall เก็บ Projects และ Device ID เดิม
- AC-031-04: แพ็กเกจเวอร์ชันใหม่อัปเกรด installation ทดสอบได้ และแพ็กเกจเก่ากว่าไม่ downgrade ทับ

- AC-031-05: บน Windows 11 25H2 x64 กับหุ่นที่ผ่านการยืนยันรุ่นแล้ว เชื่อมต่อและส่งคำสั่งควบคุมผ่าน native transport ได้จริง ไม่ใช้ผลจำลองแทน
