# REQ-043 — หลักสูตรกลางแบบ Level และ Activity

## Purpose

ให้โรงเรียนใช้หลักสูตรกลางตามความพร้อมของห้อง

## แหล่งยืนยัน

ผู้ใช้ในแชต 2026-10-22: [decisions-020](decisions-020.md):7–14,27–30 และคำสั่งงานนี้ยืนยันโครง Course → Lesson → Activity

## Business Rules

- BR-043-01: SchoolBright ส่วนกลางสร้าง/แก้หลักสูตร โรงเรียนเลือกใช้แต่แก้เนื้อหาไม่ได้
- BR-043-02: Course หนึ่งชุดเป็นหนึ่ง Level ต่อภาคเรียนประมาณ 22 สัปดาห์; Level เรียงจาก Beginner ถึง Expert เป็นแกน ระดับชั้นเป็นค่าเริ่มต้น และผูกวิชาได้
- BR-043-03: Course มี Lesson (คาบ/หน่วย) และ Activity ได้แก่ slide, lesson plan ครู, ใบงาน, mission Block/Arm/Code, quiz, test
- BR-043-04: Mode อยู่ที่ Activity ภารกิจ; Course/Lesson เดียวมีหลาย Mode ได้ สื่อและข้อสอบไม่ถูกบังคับเป็นภารกิจหุ่น
- BR-043-05: หน้าสร้าง/แก้/อนุมัติ/publish หลักสูตรกลางอยู่ในหน้า admin (Next.js ใน school-bot/web); Desktop ใช้เรียนอย่างเดียว ตาม [decisions-022](decisions-022.md)

## Acceptance Criteria

- AC-043-01: ส่วนกลางสร้าง/แก้หลักสูตรได้; บัญชีโรงเรียนเลือกใช้ได้แต่แก้เนื้อหากลางไม่ได้
- AC-043-02: เปิด Course แล้วเห็น Level ระดับชั้นเริ่มต้น วิชาที่ผูก และ Lesson/Activity ของมัน
- AC-043-03: ห้องใช้ Level ต่างจากค่าเริ่มต้นของระดับชั้นได้ โดยยังอ้าง Level ที่เลือก
- AC-043-04: Lesson เดียวเปิด Activity ครบชนิดใน BR-043-03 และภารกิจสาม Mode ได้ โดยแต่ละภารกิจใช้ Mode ของตน
