# REQ-025 — Code Lab: เขียนและรันโปรแกรม

## Purpose

(สมมติฐาน — ยังไม่ยืนยัน) ให้ฝึกลำดับคำสั่งพื้นฐานและดูผลเคลื่อนที่จำลอง

## ข้อเท็จจริงจากไฟล์

- `app/frontend/src/modes/coding-adventure/CodeLabMode.tsx:4` เปิดพื้นที่เขียนโค้ดแยกจาก LessonsMode
- `app/frontend/src/modes/coding-adventure/useCodeLab.ts:17` ส่ง program.run; บรรทัด 35–63 บันทึก/เปิด schema 1 และจำกัด source ที่โหลด 16384 ตัวอักษร (บรรทัด 56 ใช้ `value.source.length` ของ JavaScript จึงนับเป็น UTF-16 code unit ไม่ใช่ UTF-8 bytes)
- `app/README.md:49` ระบุ hero.move_right(n), hero.move_left(n), hero.jump()
- `README.md:89` ระบุ bounded DSL ไม่ใช่ Python เต็มหรือ grading
- `app/internal/engine/demo.go:24` รัน Code/Block ผ่าน demo; บรรทัด 37–57 จำกัด 1–64 คำสั่ง การเดิน 1–10 ช่อง และรวมไม่เกิน 100 steps; บรรทัด 65 จำกัด source ไม่เกิน 16384 bytes

## Business Rules

- BR-025-01: โปรแกรมมีผลในฉากจำลอง ไม่ใช่การควบคุมแขนกล
- BR-025-02: รองรับเฉพาะ DSL ที่ประกาศ ไม่ใช่ arbitrary Python
- BR-025-03: ขอบเขตรันปัจจุบันคือ 1–64 คำสั่ง เดินครั้งละ 1–10 ช่อง รวมไม่เกิน 100 steps และ source ไม่เกิน 16384 bytes; การโหลดฝั่ง UI ตรวจ 16384 ตัวอักษร (UTF-16 code unit ตาม `String.length`) แยกต่างหาก — สองจุดตรวจใช้หน่วยต่างกันตามที่ source เป็นจริง ยังไม่มีมติผู้ใช้ให้รวมเป็นหน่วยเดียวหรือเปลี่ยนหน่วย; ข้อความหลายไบต์ (เช่น ไทย 1 ตัวอักษร = 3 UTF-8 bytes) อาจผ่านการโหลดแต่ถูกปฏิเสธตอนรันเมื่อเกิน 16384 bytes

## Acceptance Criteria

- AC-025-01: รันชุด move_right, jump, move_left ที่ถูกต้องแล้วได้รายการคำสั่ง จำนวน steps และผลเล่นในฉาก โดยไม่มีคำสั่งไปหุ่น
- AC-025-02: ส่งคำสั่งนอก DSL แล้วแสดงข้อผิดพลาด ไม่ดำเนินเป็น Python ทั่วไป
- AC-025-03: บันทึกแล้วเปิด source เดิมได้; เมื่อโหลด schema ผิดหรือ source ยาวเกิน 16384 ตัวอักษร (หน่วยตาม BR-025-03) แสดงข้อผิดพลาด; เพดาน bytes ตอนรันอยู่ใน BR-025-03 ไม่ใช่เกณฑ์ของข้อนี้
