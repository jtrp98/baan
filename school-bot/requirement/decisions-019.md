# มติ Windows 11 ตามข้อเสนอแรก

## คำตอบผู้ใช้ — 2026-10-21

ผู้ตอบ: ผู้ใช้ในแชตนี้ หลังได้รับคำถามว่ามีเครื่องหรือ VM Windows 10 แยกสำหรับทดสอบหรือไม่

คำตอบ: "งั้นให้รอบรับแค่ 11 ละกัน ตามที่เสนอไปตอนแรก"

## เป้าหมายที่ใช้ต่อ

- ฝั่ง Windows ใช้ Windows 11 25H2 x64 ตามข้อเสนอแรกของ SA และคำถามเลือก OS ที่ผู้ใช้ตอบก่อนหน้า
- macOS 15+ ทั้ง Intel x86_64 และ Apple Silicon arm64 คงตามข้อเสนอแรกและมติเดิมว่าทั้งสอง OS ต้องควบคุมหุ่นจริง การพูดว่า "แค่ 11" ในคำถาม Windows 10 เป็นการปรับฝั่ง Windows ไม่ใช่ยกเลิก macOS
- Windows 10 x64 ออกจากขอบเขตที่ต้องรองรับตามคำสั่งใหม่ ใช้มตินี้แทนข้อกำหนด Windows 10 ใน decisions-017; ยุติงานหา environment และเตรียม runtime test Win10 ในสาขาของ decisions-018
- เก็บผลสำรวจ Windows 10 เป็นประวัติ ไม่ใช้ candidate Home/Pro/LTSC จากเอกสารนั้นเป็น product target ปัจจุบัน

## ขอบเขตการยืนยัน

ผู้ใช้เลือกเป้าหมาย OS แล้ว ไม่ต้องถามซ้ำว่าให้รองรับ Windows 10 หรือไม่ ตัวเลขเป้าหมายเป็นชุดที่เสนอให้เลือกครั้งแรก ไม่ใช่หลักฐานว่าแอป/Setup/หุ่นผ่านทดสอบบนรุ่นเหล่านั้นแล้ว

ข้อกำหนด License, Guest/Login, สามโหมด, หลักสูตรและ scope ครูคงตามมติเดิม ส่วน signing/performance/installation/hardware acceptance ที่ยังไม่ได้ตรวจยังคงต้องเตรียมหลักฐานตาม gate ไม่อนุมัติ release จากการเลือก OS

## ส่งต่อ

ให้ BA/SA/PM ใช้มติใหม่นี้เมื่อ amend requirement/design/รายละเอียดทดสอบตาม ownership โดยรักษา IDs มติเปลี่ยนขอบเขตมาจากผู้ใช้โดยตรง ไม่ใช่ทีมตัด platform เอง และไม่เปลี่ยน task เป็น verified จากคำตอบนี้
