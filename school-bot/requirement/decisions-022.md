## ข้อกำหนดที่ยืนยัน

- **Admin (ฝั่ง SchoolBright):** หน้าจัดการทั้งหมดทำเป็น Next.js อยู่ใน `target/school-bot-v2/web` เช่น dashboard, เลือกปล่อยอัปเดตให้บางโรงเรียนหรือบางเครื่อง และหน้าจัดการอื่น
- **ครู:** หน้าของครู เช่น map หลักสูตร อยู่ใน `target/sb-tech-upgrade-web-system`
- **Desktop app:** ใช้เรียนรู้อย่างเดียว ไม่มีหน้าจัดการหรือหน้าครู

## การตีความที่ยังไม่ยืนยัน (สมมติฐาน — ยังไม่ยืนยัน)

- ณ วันที่บันทึก `target/school-bot-v2/web` เป็น .NET solution (`SchoolBot.slnx`, `src`, `tests`) ยังไม่มี Next.js จึงถือว่าต้องเพิ่มโปรเจกต์ Next.js สำหรับ admin ในโฟลเดอร์ web คู่กับ API เดิม
- การสร้าง/แก้/อนุมัติ/publish หลักสูตรกลาง และจัดการ License/Release รวมอยู่ในหน้า admin นี้
- หน้าครูอื่นนอกจาก mapping ได้แก่ preview/ยืนยันส่งคะแนน, แก้คะแนนชน, ยืนยันเลื่อน Level ทั้งห้อง, ตรวจภารกิจ Arm, ตั้งค่า quiz นับคะแนน และดูความคืบหน้า ย้ายไปอยู่ใน web-system ทั้งหมด
- หน้าครูใน web-system เรียก API ของ school-bot ตาม decisions-021 ("api ทุกเส้น" อยู่ฝั่ง school-bot) วิธี auth ข้ามระบบยังต้องให้ SA ออกแบบ
