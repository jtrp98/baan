# REQ-014 — ค้นหาและเชื่อมต่อหุ่น

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

ให้เลือกอุปกรณ์เป้าหมายก่อนส่งคำสั่ง. การค้นพบอุปกรณ์เพียงอย่างเดียวยังไม่ใช่การเชื่อมต่อสำเร็จ.

## Business Rules

- BR-014-01: ค้นพบอุปกรณ์ไม่เท่ากับเชื่อมต่อสำเร็จ
- BR-014-02: ต้องเลือกอุปกรณ์ ยืนยันโปรไฟล์ และ probe สำเร็จก่อนใช้งาน native
- BR-014-03: การเชื่อมต่อไม่ส่งคำสั่งเคลื่อนไหว; hardware transport ปัจจุบันรองรับ Windows

## Acceptance Criteria

- AC-014-01: เปิด native ใหม่แล้วไม่แสดงว่าหุ่นเชื่อมต่ออยู่โดยอัตโนมัติ
- AC-014-02: เมื่อไม่เลือกอุปกรณ์หรือไม่ยืนยันโปรไฟล์ การกดเชื่อมต่อไม่สำเร็จ
- AC-014-03: ใช้ test device ที่ไม่ตอบ probe แล้วไม่เข้าสถานะ connected; เมื่อตอบถูกต้องจึงเชื่อมต่อ โดย trace ไม่มีคำสั่งเคลื่อนไหวระหว่างเชื่อมต่อ

## ยังไม่ยืนยัน

- เจตนาทางธุรกิจที่กลั่นจากฐานเดิมยังไม่ยืนยัน: ให้เลือกอุปกรณ์เป้าหมายก่อนส่งคำสั่ง ต้องให้เจ้าของผลิตภัณฑ์ยืนยันเจตนานี้ โดยแยกจากกฎหรือเกณฑ์ที่มีมติยืนยันแล้ว
