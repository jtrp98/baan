# REQ-009 — Desktop และการใช้งานออฟไลน์

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

ให้ใช้งาน Block / Arm / Code ภายใต้ License โดยเปิดใช้ครั้งแรกออนไลน์ แล้วใช้สิทธิ์ออฟไลน์ได้ 3 วันตาม [REQ-034 (ตรวจ License ออนไลน์และสิทธิ์ออฟไลน์ 3 วัน)](req-034.md). การเลือก Guest หรือ Login ต้องไม่ข้ามเงื่อนไข License.

OS (Operating System) คือระบบปฏิบัติการ.

## Business Rules

มติล่าสุดจากผู้ใช้ 2026-10-21: ต้องใส่ License ก่อนใช้แอป ดู [มติ 004 (License และมาตรฐานชื่อข้อมูล — 2026-10-21)](decisions-004.md) หลักฐานโค้ดข้างต้นอธิบายพฤติกรรมเดิมที่ต้องเปลี่ยน

- BR-009-01: ไม่มี License ที่ผ่านการยอมรับตามนโยบาย ไม่อนุญาตใช้งานแอปทั้งสามโหมด
- BR-009-02: Guest/Local และ Login/Cloud ต่างต้องมี License; Login ไม่ใช่สิ่งเดียวกับการเปิดใช้ License
- BR-009-03: เปิดใช้ครั้งแรกต้องออนไลน์; ใช้ออฟไลน์จากสิทธิ์ในเครื่องได้ 3 วันจากตรวจออนไลน์สำเร็จล่าสุด ครบแล้วต้องตรวจ Key ว่ายัง Active ตาม REQ-034

- BR-009-04: OS เป้าหมายตาม [มติ 019 (มติ Windows 11 ตามข้อเสนอแรก)](decisions-019.md) คือ Windows 11 25H2 x64 และ macOS 15+ Intel/Apple Silicon; ทั้งคู่ต้องใช้หุ่นจริงตาม [REQ-031 (ติดตั้งและดูแลแอปบน Windows)](req-031.md) · [REQ-032 (ติดตั้งแอปบน macOS)](req-032.md)

## Acceptance Criteria

- AC-009-01: เริ่มแอปโดยไม่เคยใส่ License แล้วเข้าใช้งาน Block Lab, Arm Lab และ Code Lab ไม่ได้ และมีทางให้กรอก License
- AC-009-02: เลือก Guest หรือ Login โดยยังไม่มี License แล้วไม่สามารถข้ามข้อกำหนด License เพื่อเข้าใช้โหมดหลักได้
- AC-009-03: ใน Desktop ผู้ใช้ย่อ สลับเต็มจอ และขอปิดหน้าต่างจากแอปได้

## ยังไม่ยืนยัน

ไม่มีสมมติฐานเพิ่มเติมที่ระบุไว้ในข้อกำหนดฉบับเดิม; การมีข้อกำหนดไม่ใช่หลักฐานว่า implementation ผ่านการตรวจรับแล้ว
