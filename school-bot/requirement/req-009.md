# REQ-009 — Desktop และการใช้งานออฟไลน์

## Purpose

ใช้งาน Block / Arm / Code ภายใต้ License; เปิดใช้ครั้งแรกออนไลน์และใช้สิทธิ์ออฟไลน์ได้ 3 วันตาม REQ-034

## ข้อเท็จจริงจากไฟล์

- `README.md:22` ระบุเปิดสาม mode ได้โดยไม่เปิด API
- `docs/ARCHITECTURE.md:73` ระบุการรัน mode และ Save/Load ไม่เรียก API
- `app/desktopservice.go:149` แจ้ง API unavailable พร้อมให้ใช้งาน local learning ต่อ
- `docs/INSTALLERS.md:17` ระบุ fullscreen/frameless และปุ่มหน้าต่างในแอป

## Business Rules

มติล่าสุดจากผู้ใช้ 2026-10-21: ต้องใส่ License ก่อนใช้แอป ดู [decisions-004.md](decisions-004.md) หลักฐานโค้ดข้างต้นอธิบายพฤติกรรมเดิมที่ต้องเปลี่ยน

- BR-009-01: ไม่มี License ที่ผ่านการยอมรับตามนโยบาย ไม่อนุญาตใช้งานแอปทั้งสามโหมด
- BR-009-02: Guest/Local และ Login/Cloud ต่างต้องมี License; Login ไม่ใช่สิ่งเดียวกับการเปิดใช้ License
- BR-009-03: เปิดใช้ครั้งแรกต้องออนไลน์; ใช้ออฟไลน์จากสิทธิ์ในเครื่องได้ 3 วันจากตรวจออนไลน์สำเร็จล่าสุด ครบแล้วต้องตรวจ Key ว่ายัง Active ตาม REQ-034

- BR-009-04: OS เป้าหมายตาม decisions-019 คือ Windows 11 25H2 x64 และ macOS 15+ Intel/Apple Silicon; ทั้งคู่ต้องใช้หุ่นจริงตาม REQ-031/032

## Acceptance Criteria

- AC-009-01: เริ่มแอปโดยไม่เคยใส่ License แล้วเข้าใช้งาน Block Lab, Arm Lab และ Code Lab ไม่ได้ และมีทางให้กรอก License
- AC-009-02: เลือก Guest หรือ Login โดยยังไม่มี License แล้วไม่สามารถข้ามข้อกำหนด License เพื่อเข้าใช้โหมดหลักได้
- AC-009-03: ใน Desktop ผู้ใช้ย่อ สลับเต็มจอ และขอปิดหน้าต่างจากแอปได้
