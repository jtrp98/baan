# REQ-037 — หลักสูตรและภารกิจสามโหมด

## Purpose

ให้นักเรียนเรียนและทำภารกิจจริงใน Block / Arm / Code

## แหล่งยืนยัน

ผู้ใช้ในแชต 2026-10-21 ต้องการหลักสูตร ภารกิจ และประเมินผลจริง ดู [decisions-001.md](decisions-001.md), [decisions-003.md](decisions-003.md), [decisions-009.md](decisions-009.md)

ผู้ใช้ในแชต 2026-10-21 ให้ทีมร่างเนื้อหา/ภารกิจ/เกณฑ์ทั้งสามโหมด แล้วผู้ใช้หรือผู้ที่ผู้ใช้ระบุตรวจอนุมัติ ตาม [decisions-015](decisions-015.md)

ผู้ใช้ 2026-10-22: [decisions-020](decisions-020.md), [decisions-021](decisions-021.md) และคำสั่งงานนี้

## Business Rules

- BR-037-01: บทเรียนใช้ Course → Lesson → Activity ตาม REQ-043; Mode อยู่ที่ Activity ภารกิจ และพื้นที่สร้างงานแต่ละโหมดแยกจากบทเรียน
- BR-037-02: Lesson มีเป้าหมาย คำแนะนำ และ Activity ที่ใช้งานจริง; มีภารกิจเมื่อหลักสูตรกำหนด ไม่ใช้ scenario เป็นผลการเรียนจริง
- BR-037-03: เนื้อหาและเกณฑ์มีที่มาและการอนุมัติโดยผู้ใช้หรือผู้ที่ผู้ใช้ระบุ; publish/revision ตาม REQ-044 และการนำเข้า Sheet ตาม REQ-045

## Acceptance Criteria

- AC-037-01: เลือก Activity ภารกิจ Block, Arm และ Code แล้วเข้าถึงเนื้อหาและภารกิจตรง Mode ได้ แม้อยู่ใน Course/Lesson เดียวกัน
- AC-037-02: เปิด Lesson แล้วเห็นเป้าหมาย คำแนะนำ และรายการ Activity ตรงกับบทเรียนที่เลือก
- AC-037-03: งานและผลภารกิจอ้าง Activity, Mode, Lesson และ revision ที่เรียนถูกต้อง ไม่ปะปนข้ามโหมดหรือฉบับ
- AC-037-04: เพียงเปิดหรือกดปิดบทเรียนไม่สร้างผลผ่านจริงโดยไม่มีการประเมินตาม REQ-038

- AC-037-05: เมื่อยังไม่มีหลักฐานอนุมัติเนื้อหาและเกณฑ์ บทเรียนนั้นไม่ถูกเสนอเป็นบทเรียนจริงที่อนุมัติแล้ว
- AC-037-06: กิจกรรมภารกิจจริงทุกโหมดอ้างกลับไปยังเนื้อหา ภารกิจ เกณฑ์ และหลักฐานผู้อนุมัติ revision ที่ใช้ได้
