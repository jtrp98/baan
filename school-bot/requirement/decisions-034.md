# มติสูตรรวมหลักสูตร น้ำหนักรอบเรียน และขอบเขตครูปรับ policy ข้อสอบ

## คำตอบผู้ใช้ — 2026-10-23

ผู้ตอบ: ผู้ใช้ในแชตนี้ ผ่าน request_user_input_async

1. "กำหนดน้ำหนักแต่ละกิจกรรม/Quiz/Test รวม 100% แปลงแต่ละรายการเป็น 0–100 แล้วถ่วงน้ำหนัก; Quiz ที่ไม่นับมีน้ำหนัก 0 (แนะนำ)"
2. "ใช้ได้เฉพาะรอบเรียนใหม่ รอบปัจจุบันคงน้ำหนักเดิม (แนะนำ: ผลเดิมตรวจย้อนกลับได้)"
3. "ปรับได้เฉพาะเวลาสอบและช่วงเปิด–ปิด; จำนวนครั้ง การสุ่ม และเวลาเปิดเฉลยใช้ค่าส่วนกลาง (แนะนำ)"

## ข้อกำหนดที่ยืนยัน

- คะแนนรวมหลักสูตรสำหรับความคืบหน้า/ประเมินเลื่อน Level ใช้น้ำหนักแต่ละกิจกรรม/Quiz/Test รวม 100%; แปลงคะแนนแต่ละรายการเป็นสเกล 0–100 แล้วถ่วงน้ำหนัก Quiz ที่ไม่นับมีน้ำหนัก 0
- เขียนสูตรเทียบเท่าได้เป็น SUM((คะแนนที่ได้_i / คะแนนเต็ม_i) × น้ำหนัก_i) เมื่อน้ำหนักใช้หน่วยเปอร์เซ็นต์และรวม 100
- ตัวอย่างคำนวณจากสูตรที่ผู้ใช้เลือก (ตัวเลขสมมติเพื่ออธิบาย ไม่ใช่น้ำหนักเริ่มต้น): กิจกรรม 8/10 น้ำหนัก 20%, Quiz 6/10 น้ำหนัก 30%, Test 18/20 น้ำหนัก 50% → 16 + 18 + 45 = 79/100
- การแก้น้ำหนักมีผลเฉพาะรอบเรียนใหม่ รอบปัจจุบันคงน้ำหนักเดิม ไม่คำนวณผลย้อนหลังด้วยน้ำหนักใหม่
- ครูปรับรายห้องได้เฉพาะเวลาสอบและช่วงเปิด–ปิด; จำนวนครั้ง การสุ่ม และเวลาเปิดเฉลยใช้ค่าส่วนกลาง คำถาม/เฉลยยังแก้ผ่านคลังข้อสอบส่วนกลาง
- มตินี้จำกัดขอบเขตคำว่า "ครูปรับได้" ใน decisions-024; ไม่ยกเลิกการเปิดสอบซ่อมรายคนตาม decisions-024/025
- สูตรรวมหลักสูตรนี้แยกจากสูตรแปลงคะแนนลงแต่ละช่องเกรดใน decisions-033; กฎงานขาดสำหรับเลื่อน Level และกฎข้ามผลที่ยังไม่มีตอนส่งเกรดคงตาม decisions-024/033
