# Windows และ macOS ควบคุมหุ่นจริง — 2026-10-21

## คำตอบผู้ใช้

ผู้ใช้ในแชตเลือก "รองรับทั้ง Windows และ macOS โดยทั้งคู่ควบคุมหุ่นจริงได้" ในคำถาม OQ-011

## กติกา

- เป้าหมายระบบเต็มต้องรองรับทั้ง Windows และ macOS รวมเส้นทางควบคุมหุ่นจริง
- macOS ไม่จำกัดให้ใช้เพียงบทเรียนหรือตัวจำลอง
- ใช้นโยบายรุ่นหุ่นที่ทีมกำหนดและให้ผู้ดูแลตรวจ calibration กับการหยุดก่อนใช้ ตามมติเดิม
- โค้ดที่ตรวจพบยังมี native hardware transport เฉพาะ Windows จึงต้องให้ SA ออกแบบส่วนรองรับ macOS เพิ่ม ไม่ถือว่าความสามารถนั้นมีแล้ว

## ผลต่อเอกสาร

ปรับ REQ-032 และ scope ให้ขอบเขต macOS เป็นหุ่นจริงด้วย พร้อมส่งมตินี้ให้ SA เมื่อเริ่มออกแบบ รุ่น OS ขั้นต่ำ เกณฑ์ performance และผลตรวจ installer จริงยังไม่ได้ยืนยันเพิ่มจากคำตอบนี้
