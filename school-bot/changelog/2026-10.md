# Changelog 2026-10 — SchoolBot

ประวัติการแก้เอกสารของ module นี้ เดือนละไฟล์ จัดตามวัน เพิ่มต่อท้ายเท่านั้น · หาประวัติของไฟล์ไหน ค้นชื่อไฟล์นั้นในหน้านี้

รายการที่ย้ายมาจากหัวข้อ "Change Log" ที่เคยอยู่ท้ายแต่ละไฟล์ (ย้ายเมื่อ 2026-11-02) เป็นข้อความตามต้นฉบับ จัดตามไฟล์ ยกเว้นชื่อผู้คุมทีมเดิม MYCELIUM เปลี่ยนเป็น นายช่าง · คำที่ยังเจอในข้อความเดิม: "ใบงาน NNN" = เลขงานภายในของทีม AI (รายละเอียดอยู่ใน memory ไม่ได้อยู่ใน knowledge) · "decisions-NNN" = มติ NNN · ชื่อ role รุ่นเก่า: SA = arch, BA = spec, UX = int, PM = gm, TP = inspect, QA = check, DBA = vault, BE = sys, FE = front · รหัสอย่าง BE-039, FE-002, QA-001 = เลขงานในแผน ([plan/index.md](../plan/index.md))
