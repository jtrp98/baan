หน้าตาของ School Bot Studio (สี ตัวอักษร ระยะ มุม เงา focus z-index motion ไอคอน · component 15 ตัว · ภาษา · มาสคอต · ของที่ยังไม่มีแบบ) ย้ายเข้า knowledge จาก brand.md ของ sketchbook และแตกเป็นไฟล์ละเรื่อง เพราะไฟล์เดิมยาวเกินที่ agent อ่านได้ในครั้งเดียว ส่วน component หลุดทุกครั้ง หน้าใน Claude Design จึงไม่เหมือนกัน · เขียนเฉพาะค่าปัจจุบัน และตัดสินข้อที่เดิมขัดกันเอง: focus ring เป็น `action-primary` ทุก control (เดิมช่องพิมพ์บอกว่าปุ่มอื่นยังใช้วงส้ม) · ปุ่มหยุดทั้งหมดเป็นสี่เหลี่ยมมน (เดิม token `radius-circle` ยังเขียนว่าใช้กับปุ่มหยุด) · เส้นคั่นแถบบนสูงเต็มแถบ 60 (เดิมมีทั้ง 28 และ 60) · ตั้งชื่อ token ให้ค่าที่ใช้อยู่แล้ว: `action-primary-halo` #D0EBFD และ `shadow-tab` · token เดียวกันอยู่ใน Design System "School Bot Studio" บน Claude Design (https://claude.ai/artifact/BK3TUSLzMLSWgryiT7wPP1) ที่ canvas ทุกอันต้องดึง component ไปใช้ · หนี้ของบอร์ดเก่าอยู่ที่ [shared/brand/backlog.md](../shared/brand/backlog.md)
