# 1. ภาพรวมลำดับ Entry (ข้อเสนอ — proposal)

> แก้ล่าสุด 2026-11-02 · แก้โดย int · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

[กลับint-001-entry](int-001-entry.md) · ส่วนหนึ่งของ UX ชุดเดียวกับตาราง Sign-off ในไฟล์ทางเข้า


เปิดแอป → ตรวจสิทธิ์ในเครื่อง ─┬─ ไม่เคย activate → **E1** หน้ากรอก+เปิดใช้งาน License (ต้องออนไลน์)
                                  ├─ valid + ออนไลน์ → ตรวจใหม่ → **E2**
                                  ├─ valid + ออฟไลน์ ยังไม่พ้น 3 วัน → **E2** (พร้อมป้ายวันสิ้นสิทธิ์)
                                  └─ หมดสิทธิ์ / denied / clock_untrusted → **E3** หน้าล็อก
**E2** → เลือก Guest (พื้นที่ร่วม ไม่มี PIN — G1 (Guest ใช้พื้นที่ร่วมโดยไม่มี PIN)) หรือ Login (บัญชีเดิม ผ่าน HTTP API Gateway (`sb-api-gateway`) → ระบบบัญชีเดิม) → **Home shell** (Arm/Block/Code Lab + ปุ่มหน้าต่าง) → ปิดผ่าน close guard

สถานะ License ฝั่ง UI ตาม [DES-002 (License และ device binding)](../design/des-002.md) (`unactivated → valid → expired|denied|clock_untrusted`; UI เห็นเฉพาะ "สถานะ + วันหมดอายุ" เท่านั้น — EntitlementResult เป็น host-only):

| สถานะ UI | เข้า Labs ได้? | ที่มา |
|---|---|---|
| unactivated | ไม่ได้ — อยู่ E1 | [BR-009-01 (ไม่มี License ที่ผ่านการยอมรับตามนโยบาย ไม่อนุญาตใช้งานแอปทั้งสามโหมด)](../requirement/req-009.md), [AC-009-01 (เริ่มแอปโดยไม่เคยใส่ License แล้วเข้าใช้งาน Block Lab, Arm Lab และ Code Lab ไม่ได้ และมีทางให้กรอก License)](../requirement/req-009.md) |
| checking (กำลังตรวจ) | ไม่ได้ — รอ | [BR-034-01 (ครั้งแรกต้องตรวจ License ออนไลน์สำเร็จ ไม่ใช้ Key ที่เพียงกรอกไว้ปลดล็อก)](../requirement/req-034.md) |
| valid (ออนไลน์ผ่านล่าสุด) | ได้ | [AC-034-02 (ตรวจออนไลน์ได้ Active แล้วเข้าใช้งานได้และมีสิทธิ์ในเครื่อง)](../requirement/req-034.md) |
| offline-valid (ยังไม่พ้น 3 วัน) | ได้ + ป้ายวันหมด | [AC-034-03 (ออฟไลน์ภายใน 3 วันจากตรวจสำเร็จล่าสุดใช้งานได้)](../requirement/req-034.md), [BR-034-03 (สิทธิ์ออฟไลน์ใช้ได้ 3 วันนับจากการตรวจออนไลน์สำเร็จล่าสุด การเปิดแอปไม่ต่ออายุสิทธิ์)](../requirement/req-034.md) |
| expired / offline พ้น 3 วัน | ไม่ได้ — E3 | [AC-034-04 (ครบ 3 วันและติดต่อเซิร์ฟเวอร์ไม่ได้ เข้าโหมดหลักไม่ได้และแจ้งให้ต่ออินเทอร์เน็ต)](../requirement/req-034.md), [BR-034-04 (ครบกำหนดต้องตรวจออนไลน์ใหม่)](../requirement/req-034.md) |
| denied (รู้ผลปฏิเสธชัด) | ไม่ได้ — E3 | [BR-034-05 (ตรวจไม่ได้เมื่อสิทธิ์ครบกำหนด หรือได้ผลไม่ Active ไม่ปลดล็อกแอป)](../requirement/req-034.md), [BR-034-06 (ใช้กับทั้งสามโหมด รวม Guest/Login)](../requirement/req-034.md) |
| clock_untrusted | ไม่ได้ — ต้องตรวจออนไลน์ใหม่ | DES-002 |
| locked (403 ไม่ทราบรหัส) | ไม่ได้ — locked รอ online recovery เท่านั้น (DES-002) | DES-002 |
