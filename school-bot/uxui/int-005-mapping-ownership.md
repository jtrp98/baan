### 2.2 ขั้นที่ 1 — ถือครองช่องเดิม (GradeSlot ownership)

อ้างอิง: [BR-049-01 (แมพคาบ/กิจกรรม/ตัวชี้วัด→วิชา/Pgtassessment ตามโรงเรียน/เทอม)](../requirement/req-049.md) ถึง [BR-049-04 (ส่งเฉพาะช่องที่แมพ ไม่เดาหมวดจาก Quiz/Test หรือแก้โครงสร้างเกรด)](../requirement/req-049.md) · [AC-049-01 (admin เห็นโรงเรียน/เทอม คาบ/กิจกรรม/ตัวชี้วัด วิชา/ช่องเดิม)](../requirement/req-049.md) · [DES-008 (Mapping หลักสูตรกับช่องคะแนน SchoolBright)](../design/des-008.md) "การได้มาซึ่ง GradeSlot" · [มติ 033 (ช่องคะแนนเดิม การแปลงคะแนนเต็ม และผลประเมินที่ยังไม่มี)](../requirement/decisions-033.md)

| State | เงื่อนไข | UI + คำ copy ไทย (ข้อเสนอ) |
|---|---|---|
| loading | กำลังอ่านช่องจากระบบเกรด | "กำลังอ่านช่องคะแนนจากระบบเกรด…" |
| empty: ยังไม่มีช่อง | วิชา/ห้องยังไม่มีช่องคะแนนเดิม | "ยังไม่มีช่องคะแนนสำหรับวิชานี้ — สร้างช่องใหม่ได้จากระบบเกรดเดิมเท่านั้น" + ลิงก์ไประบบเกรด · **ไม่มีปุ่มสร้างช่องในหน้านี้** (BR-049-01, AC-049-01, มติ 033) |
| disabled: ช่องเลือกไม่ได้ | editable=false หรือ owned แล้ว | แถวแสดงป้ายเหตุผล ("ปิดแก้ไขโดยระบบเกรด" / "มีเจ้าของแล้ว") กดเลือกไม่ได้ (aria-disabled) |
| ยืนยันถือครอง | เลือกช่องที่ยังว่าง | dialog: "ยืนยันให้ SchoolBot ดูแลช่อง '<ชื่อช่อง>' (คะแนนเต็ม <max>)" + คำเตือน "ห้ามเลือกช่องที่ครูใช้กรอกคะแนนเอง" + ช่องกรอก "เหตุผลการใช้ช่องนี้" จำเป็น (ownership_reason — Q31 (ยืนยันถือครองช่องพร้อมเหตุผล)) |
| error: SLOT_ALREADY_OWNED | ช่องมีเจ้าของ/มีคะแนนครูอยู่ก่อน | "ช่องนี้มีคะแนนหรือมีเจ้าของอยู่แล้ว (SLOT_ALREADY_OWNED) — กรุณาเลือกช่องอื่น" |
| error: TARGET_AMBIGUOUS | identifier กำกวม/ไม่ตรงหนึ่งรายการ | "ไม่พบช่องที่ระบุตรงกันหนึ่งรายการ (TARGET_AMBIGUOUS) — กรุณาเลือกช่องใหม่" |
| error: SLOT_UNAVAILABLE | ไม่มีช่องว่างที่จัดสรรได้ | "ไม่มีช่องว่างที่ SchoolBot จะใช้ได้ (SLOT_UNAVAILABLE) — ให้สร้างช่องใหม่ผ่านระบบเกรดก่อน" · ไม่มีปุ่ม force/ตั้งชื่อเอง (DES-008) |
| success | บันทึก ownership สำเร็จ | "ถือครองช่อง '<ชื่อช่อง>' แล้ว" — แถวเปลี่ยนเป็นป้าย "SchoolBot ดูแล" |

หมายเหตุ: ชื่อช่องที่มีคำว่า SchoolBot ไม่ใช่หลักฐาน ownership — หน้าจอไม่มีทางลัดข้ามการตรวจของ server ใด ๆ (DES-008)
