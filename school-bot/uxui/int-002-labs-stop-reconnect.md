### 2.9 หยุด / ยกเลิก / งานค้าง (REQ-021)

| State | คำ copy (ข้อเสนอ) |
|---|---|
| กดหยุดระหว่าง busy | "กำลังขอหยุด…" (ยกเลิกงานค้างให้จบก่อน แล้วจึงส่ง stop — [AC-021-01 (ระหว่างเล่นผ่าน test bridge เมื่อกดหยุด พบการยกเลิกและจบงานค้างก่อนคำขอ stop)](../requirement/req-021.md)) ปุ่มอื่น disabled ระหว่างนี้ ห้ามงานใหม่แทรก ([DES-006 (หุ่นจริง Windows/macOS)](../design/des-006.md)) |
| stop สำเร็จ | "ส่งคำขอหยุดแล้ว" (ไม่ใช่ "หุ่นหยุดแล้ว" — [BR-021-03 (ส่ง stop สำเร็จหมายถึงส่งคำขอ ไม่ใช่ physical stop หรือ emergency stop ที่รับรองแล้ว)](../requirement/req-021.md), [AC-021-03 (เมื่อส่ง stop ล้มเหลว ผู้ใช้เห็นข้อผิดพลาดและไม่มีข้อความยืนยันว่าหุ่นหยุดจริง)](../requirement/req-021.md)) |
| stop ล้มเหลว | "ส่งคำขอหยุดไม่สำเร็จ — ตรวจสอบสาย/บอร์ดแล้วลองอีกครั้ง" (AC-021-03) |
| คำตอบเก่า/timer เก่า มาถึงหลังหยุด | log แถว "ได้รับผลเก่าจากงานที่ยกเลิกแล้ว — ไม่นำไปส่งท่าถัดไป" ไม่มีคำสั่งใหม่ออก ([AC-021-02 (หลังหยุดแล้วปล่อยคำตอบเก่าหรือ timer ค้าง ไม่มีคำสั่งท่าถัดไปออกไป)](../requirement/req-021.md)) |
| ออกจาก workspace ขณะเชื่อมต่อ | ส่ง stop อัตโนมัติแม้ไม่มีคำสั่งรอผล ([AC-021-04 (เมื่อออกจาก native workspace ที่เชื่อมต่ออยู่ พบคำขอ stop แม้ไม่มีคำสั่งกำลังรอผล)](../requirement/req-021.md)) — กล่องยืนยันออก: "จะขอหยุดหุ่นก่อนออก" |

### 2.10 การเชื่อมต่อขาดระหว่างใช้งาน (REQ-024)

| State | UI + คำ copy (ข้อเสนอ) |
|---|---|
| lost ขณะ idle | overlay ครอบทั้ง workspace (ใช้ NativeReconnectOverlay เดิม — Q7 (overlay เมื่อขาดการเชื่อมต่อ)): "การเชื่อมต่อขาด — ตรวจสอบสาย USB แล้วกดเชื่อมต่อใหม่" ([AC-024-01 (จำลองอุปกรณ์หายจาก discovery ขณะ idle แล้วสถานะเปลี่ยนเป็น lost และแสดงทางเชื่อมต่อใหม่ใน workspace)](../requirement/req-024.md)) |
| transport error ระหว่างส่ง | ข้อผิดพลาดตรงจุด + "ส่งคำสั่งไม่สำเร็จ — ไม่มีการส่งซ้ำอัตโนมัติ" ([AC-024-02 (จำลอง transport error ระหว่างส่งท่าแล้วเห็นข้อผิดพลาดและไม่มีการส่งท่าเดิมซ้ำเอง)](../requirement/req-024.md), [BR-024-02 (ความผิดพลาดการสื่อสารต้องแสดงให้ผู้ใช้เห็น และไม่ retry การเคลื่อนไหวเอง)](../requirement/req-024.md)) |
| เชื่อมต่อใหม่สำเร็จ | เริ่มต้นว่าง ไม่เล่นท่าเดิม/ไม่คืนสถานะอัปโหลดเดิม — ป้าย "เชื่อมต่อใหม่แล้ว ต้องอัปโหลดชุดท่าใหม่ก่อนสั่งเล่นจากบอร์ด" ([AC-024-03 (เชื่อมต่อใหม่หลัง lost แล้วไม่มีคำสั่งเคลื่อนไหวจนผู้ใช้สั่ง)](../requirement/req-024.md), [DES-006 (หุ่นจริง Windows/macOS)](../design/des-006.md)) |
| busy/cancelled | **ไม่แสดง overlay lost** — เป็นผลงาน ไม่ใช่สายหลุด ([BR-024-03 (Reconnect ไม่เล่นท่าเดิมอัตโนมัติ)](../requirement/req-024.md)) |
