### 2.11 โครงงานท่า/ลำดับ/กลุ่ม (REQ-017)

- validation inline: ท่าต้องมีค่าครบ 6 ข้อ · เวลาท่า 1,000–9,000 ms · รวมไม่เกิน 10,000 ท่า · **ID ท่าห้ามซ้ำ** ([AC-017-02 (โหลดโครงงานที่มี ID ท่าซ้ำหรือค่าท่านอกช่วงแล้วมีข้อผิดพลาด)](../requirement/req-017.md)) · ข้อเสนอเพิ่มเติม (แยกจาก AC): ชื่อท่าซ้ำ → แจ้งเตือนให้ผู้ใช้ยืนยัน แต่ไม่บล็อก (Q11 (validation โครงงาน Arm และชื่อซ้ำ))
- กลุ่ม: ต้องมีชื่อ + อ้างท่าที่มีอยู่ ≥2 รายการ — กลุ่มไม่ผ่านถูกละออกพร้อมแจ้ง "กลุ่ม 'ท่าทักษิณ' อ้างท่าที่ไม่มีอยู่ — ไม่นำไปใช้" ([AC-017-01 (โหลดโครงงานถูกต้องที่มีสองท่าและกลุ่ม แล้วได้ชื่อ ค่า เวลา ลำดับ และสมาชิกกลุ่มเดิม)](../requirement/req-017.md), AC-017-02)
- เปิดโครงงานใหม่: ป้าย "สถานะบนบอร์ด: ยังไม่ได้อัปโหลดใน session นี้" ไม่อ้างว่าบอร์ด/หุ่นอยู่ตรงท่าบันทึก ([AC-017-03 (บันทึกและเปิดใหม่แล้วไม่มีสถานะยืนยันว่าอัปโหลดตรงกับบอร์ดหรืออยู่ตรงท่าที่บันทึกโดยอัตโนมัติ)](../requirement/req-017.md), [BR-017-03 (เปิดโครงงานไม่ยืนยันว่าข้อมูลตรงกับบอร์ดหรือหุ่นอยู่ในตำแหน่งนั้น)](../requirement/req-017.md))

## 3. Code Lab — [REQ-025 (Code Lab: เขียนและรันโปรแกรม)](../requirement/req-025.md)

เลย์เอาต์: กล่อง editor DSL ซ้าย + ฉากจำลองขวา + แถบผล (รายการคำสั่ง จำนวน steps) · ป้ายคงที่ "ฉากจำลอง — ผลลัพธ์ไม่ได้ควบคุมแขนกลจริง" ([BR-025-01 (โปรแกรมมีผลในฉากจำลอง ไม่ใช่การควบคุมแขนกล)](../requirement/req-025.md))

| State | คำ copy (ข้อเสนอ) |
|---|---|
| empty | ตัวอย่างเริ่มต้น `hero.move_right(2)` + คำแนะนำคำสั่งที่ใช้ได้: `hero.move_right(n)` · `hero.move_left(n)` · `hero.jump()` ([BR-025-02 (รองรับเฉพาะ DSL ที่ประกาศ ไม่ใช่ arbitrary Python)](../requirement/req-025.md)) |
| loading (รัน) | "กำลังรันโปรแกรม…" สั้น ๆ + ปุ่มรันกลายเป็น disabled |
| success | รายการคำสั่ง + "รวม 5 steps" + ภาพเล่นในฉาก — ไม่มีคำสั่งไปหุ่น ([AC-025-01 (รันชุด move_right, jump, move_left ที่ถูกต้องแล้วได้รายการคำสั่ง จำนวน steps และผลเล่นในฉาก โดยไม่มีคำสั่งไปหุ่น)](../requirement/req-025.md)) |
| error: คำสั่งนอก DSL | "ไม่รองรับคำสั่ง 'for' — ใช้ได้เฉพาะ hero.move_right(n), hero.move_left(n), hero.jump()" ([AC-025-02 (ส่งคำสั่งนอก DSL แล้วแสดงข้อผิดพลาด ไม่ดำเนินเป็น Python ทั่วไป)](../requirement/req-025.md)) |
| error: เกินขอบเขตรัน | "โปรแกรมเกินขีดจำกัดการรัน — สูงสุด 64 คำสั่ง, เดินครั้งละ 1–10 ช่อง, รวมไม่เกิน 100 ช่อง" ([BR-025-03 (ขอบเขตรันปัจจุบันคือ 1–64 คำสั่ง เดินครั้งละ 1–10 ช่อง รวมไม่เกิน 100 steps และ source ไม่เกิน 16384 bytes)](../requirement/req-025.md)) |
| error: โหลดไฟล์ | schema ผิด/ยาวเกิน: "ไฟล์โครงงานไม่ถูกต้อง หรือโค้ดยาวเกิน 16,384 ตัวอักษร" ([AC-025-03 (บันทึกแล้วเปิด source เดิมได้)](../requirement/req-025.md)) |
| abnormal: สองหน่วยนับ 16,384 | โค้ดไทยผ่านการโหลด (นับ UTF-16) แต่ติดตอนรัน (นับ bytes): "โปรแกรมยาวเกินขีดจำกัดตัวรัน (16,384 ไบต์) — ข้อความภาษาไทยนับไบต์มากกว่าจำนวนตัวอักษร" + ข้อเสนอแสดงตัวนับความยาวใกล้ editor (BR-025-03, Q10 (ตัวนับความยาวโค้ด) — การรวมหน่วยเป็นสิทธิ์ของ arch ไม่เสนอเอง) |
| บันทึก/เปิด | schema 1 — บันทึกเงียบ + toast "บันทึกแล้ว" · เปิดคืน source เดิมได้ (AC-025-03 ครึ่งแรก) |
