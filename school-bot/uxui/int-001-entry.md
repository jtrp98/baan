## 1. ภาพรวมลำดับ Entry (ข้อเสนอ — proposal)

เปิดแอป → ตรวจสิทธิ์ในเครื่อง ─┬─ ไม่เคย activate → **E1** หน้ากรอก+เปิดใช้งาน License (ต้องออนไลน์)
                                  ├─ valid + ออนไลน์ → ตรวจใหม่ → **E2**
                                  ├─ valid + ออฟไลน์ ยังไม่พ้น 3 วัน → **E2** (พร้อมป้ายวันสิ้นสิทธิ์)
                                  └─ หมดสิทธิ์ / denied / clock_untrusted → **E3** หน้าล็อก
**E2** → เลือก Guest (พื้นที่ร่วม ไม่มี PIN — G1) หรือ Login (บัญชีเดิม ผ่าน gateway→C) → **Home shell** (Arm/Block/Code Lab + ปุ่มหน้าต่าง) → ปิดผ่าน close guard

สถานะ License ฝั่ง UI ตาม DES-002 (`unactivated → valid → expired|denied|clock_untrusted`; UI เห็นเฉพาะ "สถานะ + วันหมดอายุ" เท่านั้น — EntitlementResult เป็น host-only):

| valid (ออนไลน์ผ่านล่าสุด) | ได้ | AC-034-02 |
| offline-valid (ยังไม่พ้น 3 วัน) | ได้ + ป้ายวันหมด | AC-034-03, BR-034-03 |
| expired / offline พ้น 3 วัน | ไม่ได้ — E3 | AC-034-04, BR-034-04 |

## 2. E1 — First-run: กรอก Key และเปิดใช้งาน

อ้างอิง: BR-009-01/02/03 · BR-028-01..04 · BR-034-01 · AC-009-01 · AC-028-01..04 · AC-034-01 · DES-002 (key ≤256 ตัวอักษร, challenge อายุ 120 วินาที)

| State | เงื่อนไข | UI + คำ copy ไทย (ข้อเสนอ) |
|---|---|---|
| empty | ยังไม่กรอก | หัว "เปิดใช้งาน SchoolBot" · "กรอก License Key ที่ได้รับจากผู้ดูแลโรงเรียน" · ช่องกรอก 1 ช่อง (ไม่เกิน 256 ตัวอักษร) |
| disabled | กรอกไม่ครบ/เว้นวรรคผิด | ปุ่ม "เปิดใช้งาน" สีจาง กดไม่ได้ (aria-disabled) |
| loading | กดเปิดใช้งาน | "กำลังตรวจสอบ License กับเซิร์ฟเวอร์…" ปุ่มกลายเป็น "กำลังตรวจสอบ…" กดซ้ำไม่ได้ |
| error: ไม่มีอินเทอร์เน็ต | ครั้งแรกต้องออนไลน์ | "การเปิดใช้งานครั้งแรกต้องเชื่อมต่ออินเทอร์เน็ต กรุณาตรวจสอบการเชื่อมต่อแล้วลองอีกครั้ง" (AC-034-01) |
| error: อื่น ๆ | ตามตาราง §5 | ตามตาราง §5 |
| success | ผูกเครื่องสำเร็จ | "เปิดใช้งานสำเร็จ — สิทธิ์ใช้ได้ถึง 28 ต.ค. 2569" → ไป E2 |

หมายเหตุ: ปุ่ม "ตรวจสอบสิทธิ์เครื่องนี้ (validate)" แสดงเฉพาะเครื่องที่ activate แล้ว — validate ก่อน activate ติด DEVICE_NOT_ACTIVATED (AC-028-02) · เปิด Key เดิมบนเครื่องเดิมซ้ำได้ (BR-028-01) · challenge หมดอายุ 120 วินาที → "คำขอหมดเวลา กรุณากดเปิดใช้งานอีกครั้ง" (DES-002)

## 3. การตรวจตอนเปิดแอปทุกครั้ง (validate + หน้าต่างออฟไลน์ 3 วัน)

อ้างอิง: BR-034-02..06 · AC-034-02..06 · DES-002 (exp = checked_at+259,200 วินาที หรือวันหมด License แล้วแต่อันไหนถึงก่อน · ไม่มี grace · เปิดแอปไม่ต่ออายุ)

| State | UI + คำ copy (ข้อเสนอ) |
|---|---|
| loading | สแปลช "กำลังตรวจสอบสิทธิ์การใช้งาน…" — ถ้าเน็ตช้าแต่สิทธิ์เดิมยัง valid แสดงปุ่ม "ใช้สิทธิ์ในเครื่องแล้วเข้าไปก่อน" (ตาม DES-002: network/5xx/429 ใช้สิทธิ์เดิมได้เฉพาะยัง valid ไม่เลื่อนวันหมด) |
| offline-valid | ป้ายบน shell: "โหมดออฟไลน์ — ใช้งานได้ถึง 28 ต.ค. 2569 (อีก 2 วัน)" — วันหมด **ไม่เลื่อน** เพราะเปิดแอปซ้ำ (BR-034-03) |
| offline พ้น 3 วัน | E3 บล็อก: "สิทธิ์การใช้งานออฟไลน์หมดแล้ว กรุณาเชื่อมต่ออินเทอร์เน็ตแล้วตรวจสอบสิทธิ์ใหม่" ปุ่ม "ตรวจสอบอีกครั้ง" (AC-034-04) |
| ตรวจใหม่ได้ Active | "ต่ออายุสิทธิ์สำเร็จ — ใช้ได้ถึง 30 ต.ค. 2569" นับ 3 วันใหม่จากตรวจครั้งใหม่ (AC-034-05) · retry คำขอเดิมได้ผล/expiry เดิม ไม่ถือเป็นการตรวจใหม่ (DES-002) |
| ผลไม่ Active | E3: หมดอายุ → "License หมดอายุแล้ว ติดต่อผู้ดูแลโรงเรียน" / ถูกเพิกถอน → "License ถูกเพิกถอน ติดต่อผู้ดูแล" — ผลปฏิเสธมีผลเหนือค่าที่เก็บเดิม ไม่มีปุ่มข้าม (AC-034-06, BR-034-05) |
| เครื่องเก่าหลังผู้ดูแลย้าย Key | ใช้ต่อได้ถึงวันหมดเดิมตามมติ แต่เมื่อเจอผลปฏิเสธออนไลน์ต้องหยุดใช้ทันที (DES-002) |
| clock_untrusted | E3: "ตรวจพบเวลาเครื่องผิดปกติ ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อตรวจสอบสิทธิ์ก่อนใช้งาน" |
| หมดสิทธิ์ระหว่างใช้งาน (ไม่มี grace) | ข้อเสนอ: กล่องแจ้ง "สิทธิ์หมดลงแล้ว" ให้บันทึกงาน/ขอหยุดหุ่นแล้วจึงกลับ E3 ห้ามเริ่มงานใหม่ — **รอเซ็น (Q4)** |

## 4. E2 — เลือก Guest หรือ Login + Login flow

อ้างอิง: BR-009-02 · BR-036-01..04 · AC-009-02 · AC-036-01..04 · pack-guest G1/G2/G6 · มติ035 (auth ทาง C/gateway — target)

หน้าจอ: สองการ์ดใหญ่ (แสดงทุกครั้งที่เปิดแอป — ข้อเสนอ Q5)
- **การ์ด Guest**: ปุ่ม "เริ่มใช้แบบผู้เยี่ยมชม (Guest)" + คำอธิบาย "งานทั้งหมดเก็บในเครื่องนี้และทุกคนที่ใช้เครื่องนี้เปิดดูได้ ไม่มีรหัสลับ" — ไม่มีช่อง PIN ใด ๆ (G1) ไม่มีการล้างงานอัตโนมัติ (G2) · คำ "ไม่มีรหัสลับ" ตั้งใจให้ครูเห็นก่อนกด
- **การ์ด Login**: ปุ่ม "เข้าสู่ระบบด้วยบัญชีเดิม (นักเรียน/ครู)" + ฟิลด์ ชื่อผู้ใช้/รหัสผ่าน — เรียก auth ทาง gateway→C ตามมติ035

Login states:

| State | คำ copy (ข้อเสนอ) |
|---|---|
| loading | "กำลังเข้าสู่ระบบ…" ปุ่มเข้าสู่ระบบ disabled |
| รหัสไม่ถูก | inline ใต้ฟิลด์: "ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง" คงชื่อผู้ใช้เดิมไว้ |
| ไม่มีเน็ต | "ไม่สามารถเชื่อมต่อระบบได้ ตรวจสอบอินเทอร์เน็ต หรือใช้งานแบบ Guest ต่อได้" (Login ≠ License — ออฟไลน์ใช้ Guest ได้ตราบสิทธิ์ License ยัง valid) |
| SESSION_EXPIRED ระหว่างใช้งาน | แจ้ง "เซสชันหมดอายุ กรุณาเข้าสู่ระบบอีกครั้ง" แล้วกลับ E2 — ไม่ทำงานต่อในนามบัญชีเดิม |
| บันทึก Cloud ล้มเหลว (AC-036-04) | inline: "บันทึกบน Cloud ไม่สำเร็จ — งานยังเก็บในเครื่อง ลองบันทึกใหม่" ห้ามแสดงว่าสำเร็จหรือผูกกับบัญชีอื่น |

กติกาแสดงผล: แถบสถานะบัญชี (ชื่อผู้ใช้/Guest) แยกบรรทัดจากแถบสถานะ License — Login/Logout ไม่ต่ออายุหรือเพิกถอน License (DES-002)

## 5. ตาราง mapping ผลตรวจ → สถานะ → คำ copy (จาก DES-002 "Local state/errors")

| 403 ไม่ทราบรหัส | locked รอ online recovery เท่านั้น (DES-002:79 — ไม่มีทาง offline ต่อ) | "ไม่สามารถยืนยันสิทธิ์ได้ (รหัสที่ไม่รู้จัก)" | "ตรวจสอบอีกครั้ง" (ต้องออนไลน์) |
| CREDENTIAL_STORE_FAILED | ไม่รายงานว่า activated พร้อมใช้ | "บันทึกข้อมูลเครื่องไม่สำเร็จ — ยังไม่ถือว่าเปิดใช้งานแล้ว กรุณาลองอีกครั้ง" | "ลองอีกครั้ง" |

## 6. Home shell + ปุ่มหน้าต่าง

## 8. a11y พื้นฐาน (int-001)

- คีย์บอร์ด: Tab ไล่ หัว→ช่อง Key→ปุ่ม ตามลำดับ; Enter ในฟอร์ม = ส่ง; Esc ปิดกล่องยืนยัน (ยกเว้น E1/E3 ที่เป็น blocking gate — ไม่มีทางออกให้กดข้าม) · **visible focus** ชัดเจนทุก interactive element (outline ที่เห็นได้ ไม่พึ่งสีอย่างเดียว) · เปิด dialog แล้ว focus ย้ายเข้าสู่ dialog ทันที ปิดแล้วคืน focus ไปยังปุ่มที่เปิด (focus management)
- ป้าย/ชื่อ: ทุกปุ่ม icon-only (ย่อ/เต็มจอ/ปิด) มี `aria-label` ไทย · ข้อความแจ้งเปลี่ยนสถานะใช้ `aria-live="polite"`; ข้อความบล็อก (E3) ใช้ `role="alert"`
- สี/ความคมชัด: ตัวหนังสือบนพื้น ≥ 4.5:1 (WCAG AA) · ไม่ใช้สีอย่างเดียวแยกสถานะ — มีไอคอน/ข้อความกำกับเสมอ (เช่น ป้ายออฟไลน์มีทั้งสีและคำ "ออฟไลน์")
- reduced-motion: `prefers-reduced-motion` ปิดอนิเมชันสแปลช/ทรานซิชัน
- ภาษา: copy หลักภาษาไทย ศัพท์เทคนิค/รหัส error เป็นอังกฤษในวงเล็บ (เช่น "(DEVICE_LIMIT)") เพื่อให้ผู้ดูแลสืบค้นต่อได้
(เพิ่ม visible focus/dialog focus management ตามข้อเสนอ check 060f)
