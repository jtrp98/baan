## 5. นำเข้าโครงงาน Guest หลัง Login — explicit เท่านั้น (REQ-041 · guest-import-001 · TP001-027/028/078)

อ้างอิง: [BR-041-01 (Login สำเร็จไม่อัปโหลดงาน Guest อัตโนมัติ ต้องเลือกงานและสั่งนำเข้าเอง)](../requirement/req-041.md)..04 · [AC-041-01 (มีงาน Guest หลายงานแล้ว Login โดยไม่สั่งนำเข้า ไม่เกิดงานเหล่านั้นในบัญชี)](../requirement/req-041.md)..05 · G4 (นำเข้าโครงงานหลัง Login โดยผู้ใช้สั่ง) · [BR-036-04 (เลือกนำเข้า Guest ตาม REQ-041/042 ไม่ auto-upload)](../requirement/req-036.md)

- ทางเข้า: ปุ่ม "นำเข้างานจาก Guest" บนหน้าโครงงาน **เฉพาะเมื่อ Login** — Login เฉย ๆ ไม่อัปโหลดอะไรเลย (BR-041-01, AC-041-01)
- ก่อนสั่ง: แสดงปลายทาง "นำเข้าสู่บัญชี: <ชื่อ> (นักเรียน/ครู) · โรงเรียน <ชื่อ> · บัญชีที่ Login อยู่" + checklist งาน Guest ทั้งสามโหมด (guest-import-001 บังคับเห็นปลายทางก่อนสั่ง; snapshot ถูก freeze ตอนสั่ง)

| State | คำ copy (ข้อเสนอ) |
|---|---|
| empty | "ไม่มีงานในพื้นที่ Guest ของเครื่องนี้" |
| loading/กำลังนำเข้า | ไทเมอร์รายชิ้น "กำลังนำเข้า 'ชื่องาน'…" · **รายงานผลรายชิ้น ไม่สรุป "ทั้งหมดสำเร็จ"** (guest-import-001) |
| สำเร็จ (รายชิ้น) | ✓ "นำเข้าแล้ว — เปิดได้จากรายการ Cloud" |

| 409 IDEMPOTENCY_CONFLICT | "งานนี้เคยนำเข้าแล้วแต่เนื้อหาปัจจุบันต่างจากที่นำเข้า (IDEMPOTENCY_CONFLICT) — เปิดงานเดิมในบัญชี หรือสร้างสำเนาใหม่จาก Guest แล้วนำเข้าอีกครั้ง" [เปิดงานเดิม] [ยกเลิก] |

| IDEMPOTENCY_EXPIRED (พ้น 24 ชม.) | แอปไปอ่านยืนยันจากเซิร์ฟเวอร์เอง (GET) แล้วอัปเดตสถานะ — **ไม่ POST ใหม่**; ถ้างานปลายทางถูกลบ/ไม่มีสิทธิ์: "ไม่พบงานปลายทางบน Cloud หรือไม่มีสิทธิ์ (unavailable) — ระบบไม่สร้างสำเนาใหม่เอง" |
| disabled: ออฟไลน์ | ปุ่มนำเข้า disabled + "ต้องเชื่อมต่ออินเทอร์เน็ตจึงนำเข้าสู่บัญชีได้" |
