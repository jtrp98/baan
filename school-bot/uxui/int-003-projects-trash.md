## 4. Export ไฟล์ และเปิดกลับ (guest-workspace-001 · [AC-040-03 (ส่งออกงานแต่ละโหมดแล้วได้ไฟล์ที่เปิดกลับได้เนื้อหาเดิม และต้นฉบับ Guest ยังอยู่)](../requirement/req-040.md))

- ส่งออก: หนึ่งงาน = หนึ่งไฟล์ `.schoolbot-project.json` ผ่าน **save dialog ที่ host คุม** (UI ไม่พิมพ์ path เอง)

| State | คำ copy (ข้อเสนอ) |
|---|---|
| สำเร็จ | toast "ส่งออกแล้ว — <ชื่อไฟล์>" · ต้นฉบับ Guest ยังอยู่ (AC-040-03) |
| EXPORT_CANCELLED | ผู้ใช้ยกเลิก dialog เอง — **เงียบ ไม่แสดง error** |
| STORE_UNAVAILABLE | "เขียนไฟล์ไม่สำเร็จ — ตรวจสอบตำแหน่งจัดเก็บแล้วลองอีกครั้ง (STORE_UNAVAILABLE)" |
| PROJECT_TOO_LARGE | "งานนี้ใหญ่เกินขนาดที่ส่งออกได้ (เกิน 1 MiB) (PROJECT_TOO_LARGE)" |
