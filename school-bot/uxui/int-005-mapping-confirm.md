### 3.4 ยืนยันส่ง (confirm) — receipt / idempotent

อ้างอิง: [BR-050-04 (ส่งเมื่อครูกดยืนยัน preview นั้นเท่านั้น)](../requirement/req-050.md) · [AC-050-02 (ก่อนยืนยันหรือเมื่อออกจาก preview โดยไม่ยืนยัน คะแนนปลายทางไม่เปลี่ยน)](../requirement/req-050.md), [AC-050-04 (เปลี่ยนคะแนนต้นทางหรือ mapping หลัง preview แล้วส่งค่าใหม่ด้วยการยืนยัน preview เก่าไม่ได้)](../requirement/req-050.md) · [BR-052-01 (ตรวจสิทธิ์ครูรายวิชา/ห้อง/โรงเรียน/เทอมและล็อกที่ server ขณะบันทึก)](../requirement/req-052.md) ถึง [BR-052-03 (audit อ้างต้นทางและ revision, mapping ที่ใช้, ปลายทาง, เดิม/ใหม่, ผู้ยืนยัน, เวลา, การแก้ชน และผลส่ง)](../requirement/req-052.md) · [AC-052-01 (ครูไม่มีสิทธิ์วิชา/ห้อง ข้ามโรงเรียน/เทอม หรือปลายทางล็อก ส่งแล้วถูกปฏิเสธและคะแนนไม่เปลี่ยน)](../requirement/req-052.md) ถึง [AC-052-03 (ส่งรายการเดิมซ้ำรวมกรณีไม่ทราบผลครั้งก่อน คะแนนไม่บวกซ้ำและไม่เกิดผลซ้ำ)](../requirement/req-052.md) · [DES-009 (Preview ยืนยัน และส่งคะแนนกลับ SchoolBright)](../design/des-009.md) (snapshot/If-Match/idempotency/receipt/outbox)

- ปุ่ม "ยืนยันส่งคะแนน" (disabled จนมีรายการพร้อมส่ง ≥1 และผ่าน gates) → dialog สรุป: จำนวน พร้อมส่ง/ข้าม/ถูกกั้น/ชน + รายวิชา-ชื่อช่อง + "เขียนเฉพาะช่องที่ SchoolBot ดูแล คงช่องอื่นทุกค่าไว้" → ยืนยัน → 202 รับ export_id
- การเขียนเป็นแบบ assignment เปลี่ยนเฉพาะ Score ของช่อง SchoolBot ใน ScoreData (owned-only merge) คงรายการอื่น/ผลพิเศษไว้ทั้งหมด ไม่ส่งผลรวมแทนค่าเดิม (DES-009)
- Receipt: รายการที่ apply สำเร็จแสดง "ส่งแล้ว — รหัสรับรอง <receipt_id>" ต่อนักเรียน (บันทึกใน PgtgradeAuditLog — [BR-052-03 (audit อ้างต้นทางและ revision, mapping ที่ใช้, ปลายทาง, เดิม/ใหม่, ผู้ยืนยัน, เวลา, การแก้ชน และผลส่ง)](../requirement/req-052.md), G-DB (เงื่อนไขฐานข้อมูลก่อนส่งคะแนน))
- Idempotent: ปุ่มยืนยัน disabled ระหว่างรอผล; ไม่ทราบผล (unknown) แสดง "กำลังตรวจสอบผลคำสั่งเดิม… ไม่ส่งซ้ำอัตโนมัติ" — ส่งซ้ำ/ไม่ทราบผลครั้งก่อน คะแนนไม่บวกซ้ำ ไม่เกิดผลซ้ำ ([AC-052-03 (ส่งรายการเดิมซ้ำรวมกรณีไม่ทราบผลครั้งก่อน คะแนนไม่บวกซ้ำและไม่เกิดผลซ้ำ)](../requirement/req-052.md)) · IDEMPOTENCY_CONFLICT → "คำสั่งเดิมมีเนื้อหาต่างไป — กรุณาสร้างพรีวิวใหม่"
- ข้อมูลเปลี่ยนหลังพรีวิว: 409 PREVIEW_STALE / TARGET_CHANGED → "ข้อมูลคะแนนหรือปลายทางเปลี่ยนหลังพรีวิว — กรุณาสร้างพรีวิวใหม่แล้วยืนยันอีกครั้ง" ไม่เขียนทับเงียบ (AC-050-04, [AC-051-03 (แก้ปลายทางหลัง preview หรือหลังเลือกแก้ชนแล้ว ระบบหยุดให้ตรวจใหม่ ไม่เขียนทับค่าล่าสุดเงียบ)](../requirement/req-051.md))
- พรีวิวหมดอายุ 15 นาที: เตือนเมื่อเหลือ ≤2 นาที · หมดอายุ → "พรีวิวหมดอายุ — สร้างใหม่เพื่อใช้ค่าที่อ่านล่าสุด" (DES-009 snapshot bound)
- ออกโดยไม่ยืนยัน: ไม่มีการเขียนใด ๆ (AC-050-02) — toast "ยังไม่ได้ส่ง — พรีวิวนี้จะหมดอายุเอง"
- Release gates: แถบสถานะ 5 gate (parity/coexistence/target/authz/db จาก PreviewView); gate ใดไม่ผ่าน ปุ่มยืนยัน disabled + "ระบบยังไม่เปิดให้ส่งจริง (เช่น CALCULATOR_NOT_VERIFIED)" — environment ที่ไม่ใช่ production เห็นพรีวิวก่อนได้พร้อมสถานะ gate (DES-009) — Q36 (แสดงห้าเงื่อนไขเปิดส่งจริง)
