## 3. หน้าส่งคะแนน (ครูรายวิชา): พรีวิว → ยืนยัน → แก้ชน → สถานะส่ง — DES-009 · REQ-050, REQ-051, REQ-052

### 3.1 เริ่มพรีวิว

อ้างอิง: [BR-049-06 (เฉพาะ admin โรงเรียนสร้าง/แก้ mapping ครูแก้ไม่ได้)](../requirement/req-049.md) (ครูอ่าน mapping อย่างเดียว) · DES-009 HTTP · [BR-050-02 (ก่อนส่งแสดงผู้เรียน กิจกรรม โรงเรียน/เทอม วิชา ช่องปลายทาง และค่าเดิม → ค่าใหม่)](../requirement/req-050.md)

- ครูเลือก CourseRun ของวิชาที่ตนสอน → เห็นรายการ mapping "ใช้งาน" (อ่านอย่างเดียว ไม่มีปุ่มแก้) → เลือก mapping ที่จะส่ง + รายชื่อผู้เรียน (ค่าเริ่มต้นทั้ง roster ของห้อง — รายชื่อมาจาก roster นักเรียนเท่านั้น กัน LearnerId ครูชนนักเรียน — DES-009) — Q34 (ค่าเริ่มเลือกผู้เรียนทั้ง roster)
- ปุ่ม "สร้างพรีวิว" → POST /v2/score-previews → สรุป counts พร้อมส่ง/ชน/ถูกกั้น + ตัวนับอายุพรีวิวถอยหลัง (หมดอายุ 15 นาที — DES-009)

| State | UI + คำ copy (ข้อเสนอ) |
|---|---|
| loading | "กำลังเตรียมพรีวิวคะแนน… (อ่านค่าเดิมจากระบบเกรด)" |
| empty: ยังไม่มี mapping | "ยังไม่มีช่องที่ผูกกิจกรรม — ให้ผู้ดูแลโรงเรียนจัด mapping ก่อน" (ไม่มีทางให้ครูสร้างเอง — BR-049-06) |

| error: 403 SUBJECT_PERMISSION_REQUIRED | "คุณไม่มีสิทธิ์ส่งคะแนนวิชา/ห้องนี้" |
| error: 503 GRADE_SOURCE_UNAVAILABLE | "อ่านคะแนนจากระบบเกรดไม่ได้ชั่วคราว — ลองสร้างพรีวิวใหม่ภายหลัง" |

### 3.2 ตารางพรีวิว: นักเรียน × ช่องคะแนน

อ้างอิง: [BR-050-02 (ก่อนส่งแสดงผู้เรียน กิจกรรม โรงเรียน/เทอม วิชา ช่องปลายทาง และค่าเดิม → ค่าใหม่)](../requirement/req-050.md), [BR-050-03 (คะแนนส่งแต่ละช่อง = earned/max กิจกรรม × max ช่อง แล้วปัดจำนวนเต็ม half-up)](../requirement/req-050.md), [BR-050-05 (ปัดจำนวนเต็มแบบ half-up: 7.5 เป็น 8 และ 7.4 เป็น 7)](../requirement/req-050.md) ตาม [มติ 023 (ผู้เขียนคะแนน การปัดคะแนน การนำเข้า Sheet และเจ้าของ mapping)](../requirement/decisions-023.md) · [AC-050-01 (preview ตรวจค่าเดิม/ใหม่และปลายทางตาม BR-050-02/03 ได้)](../requirement/req-050.md), [AC-050-03 (กิจกรรม 8/10 ไปช่องเต็ม 20 ได้ 16)](../requirement/req-050.md) · [AC-049-04 (Preview ตรงคู่กิจกรรม–ช่องที่แมพ ไม่เพิ่มช่อง/เดาหมวดเอง)](../requirement/req-049.md) · [BR-049-04 (ส่งเฉพาะช่องที่แมพ ไม่เดาหมวดจาก Quiz/Test หรือแก้โครงสร้างเกรด)](../requirement/req-049.md) · grade-rules ("สูตรและ skip")

- **หัวแถว** แสดง รายวิชา (plan_course) · เทอม · CourseRun นอกเหนือจากรหัส+ชื่อนักเรียน · **หัวคอลัมน์** แสดงกิจกรรมปลายทางพร้อมชื่อเดิมและชื่อช่องคะแนน (วิชา/เทอม/ชื่อกิจกรรม+ช่อง หมวดจากข้อมูลจริง — **ไม่เดาหมวดจาก Quiz/Test**) ตาม BR-050-02/AC-050-01
- แสดงเฉพาะคู่ที่แมพเท่านั้น ไม่เพิ่มช่องเอง
- เซลล์แสดงครบทางเดียว: `8/10 → 16/20` + ค่าก่อนปัด (raw_target) ตามค่าจริงที่ server คำนวณ (ไม่ปัดสองตำแหน่ง) ใน tooltip/แถวขยาย + ค่าเดิมของช่อง (old_score) และค่าที่ SchoolBot เคยส่งล่าสุด (last_exported_score) — Q33 (รูปแบบคะแนนพรีวิวและการปัด)
- ท้ายตารางแสดงสูตรคงที่: "คะแนนช่อง = (คะแนนที่ได้ ÷ คะแนนเต็มกิจกรรม) × คะแนนเต็มช่อง แล้วปัด half-up คำนวณรายช่องจากต้นทางเดียวกัน ปัดครั้งเดียว"
- ตัวอย่างประกอบหน้าตาม decimal จริงที่ server คำนวณ: 8/10 → ช่องเต็ม 20 = 16 · **7499/10000 × 10 = 7.499 → 7** · **7500/10000 × 10 = 7.5 → 8** (แสดง raw_target ตามค่าที่ server คำนวณจริงใน tooltip/แถวขยาย ไม่ปัดสองตำแหน่งเพื่อความสวย)
