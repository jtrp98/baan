- เนื้อหา: เป้าหมาย + คำแนะนำ + รายการ Activity (AC-037-02): สื่อ (slide/เอกสารฝึก) เปิดดูอย่างเดียว · ภารกิจ chip "ภารกิจ Block/Arm/Code" ปุ่ม "เริ่มภารกิจ" · ข้อสอบ chip "Quiz/Test" (AC-037-01: แม้ Lesson เดียวกัน เข้าถึงภารกิจตรง Mode ได้)
- **ไม่มีปุ่ม "จบบทเรียน→รับดาว"** — พฤติกรรมดาวจากการกดของ LearnMap เดิม (LearnMap.tsx:227) ต้องเอาออก: เพียงเปิด/ปิดบทเรียนไม่สร้างผลผ่าน (AC-037-04)
- สลับลำดับ Lesson มาจากข้อมูล รหัสถาวร/ผลเดิมคงเดิม (AC-044-01) — นักเรียนไม่มีปุ่มจัดลำดับ (แก้ที่ admin)

## 4. โหมดที่ยังไม่มีเนื้อหา — empty state จริง

อ้างอิง: [AC-037-05 (เมื่อยังไม่มีหลักฐานอนุมัติเนื้อหาและเกณฑ์ บทเรียนนั้นไม่ถูกเสนอเป็นบทเรียนจริงที่อนุมัติแล้ว)](../requirement/req-037.md) · [pack-content-inventory-001 (ชุดเนื้อหาสามโหมด เกณฑ์ผ่านและดาว)](../requirement/pack-content-inventory-001.md) §1 · LessonsMode.tsx:7 (LessonModeUnavailable เดิม)

| State | UI + คำ copy (ข้อเสนอ) |
|---|---|
| Block / Code ยังไม่มีเนื้อหาอนุมัติ | หน้าโหมดแสดง empty state จริง (ใช้ LessonModeUnavailable เดิมต่อ): "ยังไม่มีบทเรียน <โหมด> ที่อนุมัติเผยแพร่ — เนื้อหาจะเปิดเมื่อทีมงานอนุมัติเผยแพร่" — **ห้ามใส่เนื้อหาตัวอย่างปลอมแทน** |
| Arm ตัวอย่าง 7 stages (LearnMap เดิม) | ติดป้ายคงที่ "เนื้อหาตัวอย่าง — ยังไม่ใช่บทเรียนที่อนุมัติ" · ดาวที่ได้เป็นค่าจำลองในเครื่อง แสดงคู่ป้าย "ผลจำลอง — ไม่ใช่ผลเรียนจริง" ([BR-039-03 (ผลที่ยังรอครูตรวจไม่แสดงเป็นผ่าน)](../requirement/req-039.md), [AC-038-04 (ผล Cloud อ้างนักเรียน Activity/Mode/revision และงานถูกต้อง ไม่ปนผลครู/ดาวตัวอย่าง)](../requirement/req-038.md): ไม่ปนดาวตัวอย่างกับผลจริง) — Q23 (empty state และเนื้อหาตัวอย่าง) |
| มี published revision แล้ว | แสดงเนื้อหาจริง + ป้าย revision "ฉบับ R<หมายเลข> · อนุมัติโดยเจ้าหน้าที่ผู้อนุมัติ (four-eyes)" ([AC-037-06 (กิจกรรมภารกิจจริงทุกโหมดอ้างกลับไปยังเนื้อหา ภารกิจ เกณฑ์ และหลักฐานผู้อนุมัติ revision ที่ใช้ได้)](../requirement/req-037.md), [BR-044-02 (revision ผ่าน draft → อนุมัติโดยมนุษย์ → publish พร้อมที่มา ผู้อนุมัติ และวันเวลา)](../requirement/req-044.md), [BR-044-03 (ฉบับ publish ไม่แก้ย้อนหลัง)](../requirement/req-044.md)) |
