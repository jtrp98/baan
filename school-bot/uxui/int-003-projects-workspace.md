# 1. ภาพรวม: หน้า "โครงงาน" และพื้นที่เก็บตาม session (ข้อเสนอ)

> แก้ล่าสุด 2026-11-02 · แก้โดย int · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

ข้อกำหนดที่ใช้ในไฟล์นี้: [REQ-009 (Desktop และการใช้งานออฟไลน์)](../requirement/req-009.md)

[กลับint-003-projects](int-003-projects.md) · ส่วนหนึ่งของ UX ชุดเดียวกับตาราง Sign-off ในไฟล์ทางเข้า


- ทางเข้า: ปุ่ม "โครงงาน" บน Home shell + ปุ่ม "งานของฉัน" บน toolbar ของ Lab ทั้งสาม (Q14 (หน้าโครงงานเดียวแยกแท็บตามโหมด))
- โครงหน้า (ข้อเสนอ): หน้าเดียวมีแท็บสามโหมด **Block / Arm / Code** — รายการงานต่อโหมด แยกไม่ปะปน ([BR-011-01 (Block / Arm / Code มีหลายโครงงานต่อโหมดได้ทั้ง Guest/Login)](../requirement/req-011.md), [AC-011-01 (บันทึกอย่างน้อยสองงานต่อโหมด Block/Arm/Code ทั้ง Guest และ Login แล้วเลือกเปิดแต่ละงานได้ครบและไม่ปะปนกัน)](../requirement/req-011.md)) แถวละ: ชื่อ · อัปเดตล่าสุด · ปุ่ม [เปิด] [เมนู: เปลี่ยนชื่อ · สำเนา · ส่งออกไฟล์ · ย้ายไปถังขยะ]
- พื้นที่เก็บตาม session อัตโนมัติ ([DES-003 (หลายโครงงาน Local/Cloud)](../design/des-003.md) — UI ไม่มีช่องเลือกตำแหน่งเก็บ/owner): Guest → chip "เก็บในเครื่อง (Guest)" · Login → chip "Cloud — <ชื่อผู้ใช้>" ([BR-036-01 (Guest ไม่ต้องมีบัญชี แต่ต้องมี License ตาม REQ-009/034)](../requirement/req-036.md), [BR-036-02 (Guest เก็บหลายโครงงานแต่ละโหมดในเครื่อง)](../requirement/req-036.md))
- แถบบนหน้า (เมื่ออยู่ Guest) ต่อจาก copy การ์ด Guest ที่อนุมัติแล้ว (int-001 §4): **"พื้นที่ผู้เยี่ยมชม — งานเก็บในเครื่องนี้ ทุกคนที่ใช้เครื่องนี้เปิดดูได้ ไม่มีรหัสลับ"** ไม่มีการล้างงานอัตโนมัติ (G1 (Guest ใช้พื้นที่ร่วมโดยไม่มี PIN)/G2 (ไม่ล้างงาน Guest อัตโนมัติ), [BR-040-01 (Guest ใน OS account เดียวใช้พื้นที่ร่วม ทุกคนเปิดงานได้ ไม่แยก PIN/โปรไฟล์ Guest)](../requirement/req-040.md), [BR-040-02 (เก็บงานปกติจนสั่งลบ ไม่ล้างเมื่อจบใช้งาน)](../requirement/req-040.md), [AC-040-01 (ผู้ใช้สองคนใช้ Guest ใน OS account เดียวกัน เปิดงานที่อีกคนบันทึกไว้ได้ทั้ง Block/Arm/Code โดยไม่ขอ PIN แยก)](../requirement/req-040.md), [AC-040-02 (จบใช้งานและเปิดใหม่ รวมเมื่อผ่าน 30 วัน งานที่ไม่เคยสั่งลบยังเปิดได้)](../requirement/req-040.md)) — ยืนยัน Q15 (แบนเนอร์พื้นที่ Guest ร่วม)
- ชื่อโครงงาน 1–200 ตัวอักษร ใช้แสดงผลเท่านั้น ไม่ใช่ชื่อไฟล์ (DES-003) · ขนาดเอกสาร ≤1 MiB
