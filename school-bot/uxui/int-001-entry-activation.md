[กลับint-001-entry](int-001-entry.md) · ส่วนหนึ่งของ UX ชุดเดียวกับตาราง Sign-off ในไฟล์ทางเข้า


อ้างอิง: [BR-009-01 (ไม่มี License ที่ผ่านการยอมรับตามนโยบาย ไม่อนุญาตใช้งานแอปทั้งสามโหมด)](../requirement/req-009.md), [BR-009-02 (Guest/Local และ Login/Cloud ต่างต้องมี License)](../requirement/req-009.md), [BR-009-03 (เปิดใช้ครั้งแรกต้องออนไลน์)](../requirement/req-009.md) · [[BR-028-01 (1 Key ใช้ได้ 1 เครื่อง เปิดใช้ซ้ำจากเครื่องเดิมได้ แต่เครื่องอื่นใช้ Key ที่ยังผูกกับเครื่องเดิมไม่ได้ ตาม [มติ])](../requirement/req-028.md) (1 Key ใช้ได้ 1 เครื่อง เปิดใช้ซ้ำจากเครื่องเดิมได้ แต่เครื่องอื่นใช้ Key ที่ยังผูกกับเครื่องเดิมไม่ได้ ตาม [มติ])](../requirement/req-028.md)..04 · [BR-034-01 (ครั้งแรกต้องตรวจ License ออนไลน์สำเร็จ ไม่ใช้ Key ที่เพียงกรอกไว้ปลดล็อก)](../requirement/req-034.md) · [AC-009-01 (เริ่มแอปโดยไม่เคยใส่ License แล้วเข้าใช้งาน Block Lab, Arm Lab และ Code Lab ไม่ได้ และมีทางให้กรอก License)](../requirement/req-009.md) · [AC-028-01 (เปิดใช้ Key เดียวบนเครื่อง A ซ้ำได้)](../requirement/req-028.md) ถึง [AC-028-04 (เมื่อลองเปิดใช้ด้วย License ไม่ถูกต้องและไม่เคยมีสิทธิ์ที่ใช้ได้ แอปไม่ปลดล็อกโหมดหลัก และผู้ใช้สามารถกลับไปกรอก License ใหม่ได้)](../requirement/req-028.md) · [AC-034-01 (ครั้งแรกไม่มีอินเทอร์เน็ต เข้าโหมดหลักไม่ได้แม้กรอก Key แล้ว)](../requirement/req-034.md) · [DES-002 (License และ device binding)](../design/des-002.md) (key ≤256 ตัวอักษร, challenge อายุ 120 วินาที)

| State | เงื่อนไข | UI + คำ copy ไทย (ข้อเสนอ) |
|---|---|---|
| empty | ยังไม่กรอก | หัว "เปิดใช้งาน SchoolBot" · "กรอก License Key ที่ได้รับจากผู้ดูแลโรงเรียน" · ช่องกรอก 1 ช่อง (ไม่เกิน 256 ตัวอักษร) |
| disabled | กรอกไม่ครบ/เว้นวรรคผิด | ปุ่ม "เปิดใช้งาน" สีจาง กดไม่ได้ (aria-disabled) |
| loading | กดเปิดใช้งาน | "กำลังตรวจสอบ License กับเซิร์ฟเวอร์…" ปุ่มกลายเป็น "กำลังตรวจสอบ…" กดซ้ำไม่ได้ |
| error: ไม่มีอินเทอร์เน็ต | ครั้งแรกต้องออนไลน์ | "การเปิดใช้งานครั้งแรกต้องเชื่อมต่ออินเทอร์เน็ต กรุณาตรวจสอบการเชื่อมต่อแล้วลองอีกครั้ง" (AC-034-01) |
| error: อื่น ๆ | ตามตาราง §5 | ตามตาราง §5 |
| success | ผูกเครื่องสำเร็จ | "เปิดใช้งานสำเร็จ — สิทธิ์ใช้ได้ถึง 28 ต.ค. 2569" → ไป E2 |

หมายเหตุ: ปุ่ม "ตรวจสอบสิทธิ์เครื่องนี้ (validate)" แสดงเฉพาะเครื่องที่ activate แล้ว — validate ก่อน activate ติด DEVICE_NOT_ACTIVATED ([AC-028-02 (Validate device ที่ยังไม่ activate ได้ DEVICE_NOT_ACTIVATED)](../requirement/req-028.md)) · เปิด Key เดิมบนเครื่องเดิมซ้ำได้ (BR-028-01) · challenge หมดอายุ 120 วินาที → "คำขอหมดเวลา กรุณากดเปิดใช้งานอีกครั้ง" (DES-002)
