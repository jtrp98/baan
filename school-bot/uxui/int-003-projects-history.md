## 6. ประวัติเรียน Guest + ตรวจใหม่หลัง Login (REQ-042 · guest-history-001 · TP001-029/030)

อ้างอิง: [BR-042-01 (ผลภารกิจ/ความคืบหน้า Guest เก็บ local)](../requirement/req-042.md) ถึง [BR-042-04 (ไม่เชื่อผลผ่านจาก client)](../requirement/req-042.md) · [AC-042-01 (Guest ทำภารกิจแล้วเปิดแอปใหม่ ยังเรียกประวัติและความคืบหน้า local ของภารกิจนั้นได้)](../requirement/req-042.md) ถึง [AC-042-06 (เปิดประวัติที่ย้ายแล้วแยกผล Guest กับผลตรวจใหม่ได้ อ้างภารกิจ/งานถูกต้อง และไม่แสดง Guest ว่าเป็นตัวตนผู้เรียนที่ยืนยันแล้ว)](../requirement/req-042.md) · G5 (ประวัติ Guest และตรวจใหม่)

หน้า "ประวัติเรียน (ในเครื่อง)" — เข้าได้ทั้ง Guest:

| State | UI + คำ copy (ข้อเสนอ) |
|---|---|
| loading | "กำลังเปิดประวัติ…" |
| empty | "ยังไม่มีประวัติ — ทำภารกิจแล้วผลจะเก็บในเครื่องนี้" |
| รายการ | ภารกิจ · โหมด · วันที่ทำ · chip ผลในเครื่อง: **ผ่าน / ยังไม่ผ่าน / รอครูตรวจ / ผิดพลาด** + ป้ายคงที่ "ผลในเครื่อง — ไม่ใช่ผลในบัญชี" (authority local); ไม่แสดงชื่อผู้ทำ (พื้นที่ร่วมไม่พิสูจน์ตัวตน — BR-042-01) · เปิดแอปใหม่ยังเห็น (AC-042-01) |

หลัง Login — ปุ่ม "ย้ายประวัติที่เลือกไปตรวจใหม่" (แยกจากนำเข้าโครงงาน — Login หรือนำเข้าโครงงานเฉย ๆ ไม่ย้ายประวัติ: [BR-042-02 (หลัง Login ผู้ใช้เลือกย้ายประวัติเอง ไม่ย้ายเพียงเพราะ Login หรือนำเข้าโครงงาน)](../requirement/req-042.md), [AC-042-02 (Login หรือนำเข้าเฉพาะโครงงาน ไม่สร้างผลจากประวัติ Guest ในบัญชีจนเลือกย้ายประวัติ)](../requirement/req-042.md)):

| State | คำ copy (ข้อเสนอ) |
|---|---|
| ยืนยันปลายทาง | "ย้ายประวัติ X รายการไปตรวจใหม่ในบัญชี: <ชื่อ> · โรงเรียน <ชื่อ>?" [ย้ายและตรวจใหม่] [ยกเลิก] — เลือกเฉพาะรายการที่ติ๊ก ([AC-042-03 (เลือกย้ายประวัติ A เท่านั้น แล้วมีเฉพาะ A เข้ากระบวนการตรวจใหม่ในบัญชีปัจจุบัน ไม่ย้าย B ที่ไม่เลือก)](../requirement/req-042.md)) |

| Arm | "รอครูตรวจ" — ไม่นับผ่านก่อนครูบันทึกผล ([AC-042-05 (ย้ายประวัติ Arm แล้วแสดงรอครูตรวจ ไม่นับผ่านก่อนครูที่มีสิทธิ์บันทึกผล)](../requirement/req-042.md)) |
| error: GRADER_UNAVAILABLE | "ระบบตรวจไม่พร้อม (GRADER_UNAVAILABLE) — ยังไม่นับผล ลองใหม่ได้โดยไม่เกิดรายการซ้ำ" |
| error: PROGRAM_INVALID / ไม่ผ่านเกณฑ์ | "ชิ้นงานไม่ผ่านการตรวจใหม่ (PROGRAM_INVALID) — ผลในเครื่องเดิมไม่ถูกใช้" (AC-042-04: ไม่เชื่อผลผ่านจาก client) |

## 7. a11y ของ int-003 (ต่อมาตรฐานที่อนุมัติแล้ว int-001 §8 / int-002 §6)

- รายการโครงงาน/ถังขยะ/ประวัติ เป็นตาราง/ลิสต์ที่ Tab ครบทุกปุ่ม · visible focus ทุก interactive element · เปิด dialog (ยืนยันลบ/กู้คืน/นำเข้า/ส่งออก) focus เข้าทันที ปิดแล้วคืนตำแหน่งเดิม
- ป้ายวันหมดอายุถังขยะ/สถานะนำเข้ารายชิ้น ใช้ `aria-live="polite"`; ข้อความบล็อก (TRASH_EXPIRED, VERSION_CONFLICT) ใช้ `role="alert"`
- chip สถานะทุกชนิดมีข้อความกำกับ ไม่ใช้สีอย่างเดียว · ความคมชัด ≥ 4.5:1 · reduced-motion ปิดอนิเมชัน toast/transition
- ตัวเลือก "เลือกทั้งหมด" ในหน้านำเข้า/ย้ายประวัติมี label ไทยชัดเจน ผูก `aria-describedby` กับข้อความปลายทางบัญชี
