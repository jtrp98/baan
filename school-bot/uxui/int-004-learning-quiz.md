## 8. ข้อสอบ Quiz / Test (policy มติ 024, มติ 034 ผ่าน pack §2)

อ้างอิง: [BR-038-05 (Quiz/Test ใช้ REQ-046/047)](../requirement/req-038.md) (Quiz/Test ใช้ [REQ-046 (Quiz/Test และคลังข้อสอบแบบ revision)](../requirement/req-046.md), [REQ-047 (การนับคะแนน Quiz รายหลักสูตร)](../requirement/req-047.md) — policy ค่าเริ่มตามมติ) · ActivityConfig question-v1 ([DES-005 (หลักสูตร ภารกิจ และผลประเมิน)](../design/des-005.md))

## 9. เลื่อน Level ทั้งห้อง — มุมมอง Desktop ([DES-011 (ระบบเสนอเลื่อน Level และครูยืนยันทั้งห้อง)](../design/des-011.md) Rev5)

- การเสนอ/ยืนยัน/ตั้งเกณฑ์ **ไม่อยู่ใน Desktop**: หน้าครูอยู่ web-system หน้าตั้งเกณฑ์อยู่ admin (DES-011, [มติ 022 (ที่อยู่ของหน้าจอ Admin / ครู / Desktop)](../requirement/decisions-022.md)) — Desktop ไม่มีปุ่มเลื่อน/ยืนยัน Level
- ที่นักเรียนเห็น (ข้อเสนอ — Q28 (สถานะ Level ของนักเรียน)): หัวหน้าบทเรียนแสดง "Level ปัจจุบันของห้อง" + หลังสิ้นเทอมเป็นข้อความสถานะอย่างเดียว:
  - promoted: "ห้องของคุณย้ายไป Level <ถัดไป> ในภาคเรียนถัดไปแล้ว"
  - retained: "ห้องยังเรียน Level เดิมต่อในภาคเรียนถัดไป" (เหตุผลค่าเฉลี่ย/gap แสดงฝั่งครูเว็บ — สอดคล้อง §7)
  - max_level: "Level นี้เป็นระดับสูงสุด — ห้องเรียน Level เดิมต่อ"
- เกณฑ์: ค่าเฉลี่ยห้องต้อง **สูงกว่า** เกณฑ์ (ค่าเริ่ม 70 — เท่ากับเกณฑ์ยังไม่ผ่าน) นับทุกคนใน roster งานไม่ส่งนับ 0 ([มติ 024 (เกณฑ์เลื่อน Level และ policy Quiz/Test)](../requirement/decisions-024.md), DES-011)
