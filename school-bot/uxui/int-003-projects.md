## 1. ภาพรวม: หน้า "โครงงาน" และพื้นที่เก็บตาม session (ข้อเสนอ)

- ทางเข้า: ปุ่ม "โครงงาน" บน Home shell + ปุ่ม "งานของฉัน" บน toolbar ของ Lab ทั้งสาม (Q14)
- โครงหน้า (ข้อเสนอ): หน้าเดียวมีแท็บสามโหมด **Block / Arm / Code** — รายการงานต่อโหมด แยกไม่ปะปน (BR-011-01, AC-011-01) แถวละ: ชื่อ · อัปเดตล่าสุด · ปุ่ม [เปิด] [เมนู: เปลี่ยนชื่อ · สำเนา · ส่งออกไฟล์ · ย้ายไปถังขยะ]
- พื้นที่เก็บตาม session อัตโนมัติ (DES-003 — UI ไม่มีช่องเลือกตำแหน่งเก็บ/owner): Guest → chip "เก็บในเครื่อง (Guest)" · Login → chip "Cloud — <ชื่อผู้ใช้>" (BR-036-01/02)
- แถบบนหน้า (เมื่ออยู่ Guest) ต่อจาก copy การ์ด Guest ที่อนุมัติแล้ว (int-001 §4): **"พื้นที่ผู้เยี่ยมชม — งานเก็บในเครื่องนี้ ทุกคนที่ใช้เครื่องนี้เปิดดูได้ ไม่มีรหัสลับ"** ไม่มีการล้างงานอัตโนมัติ (G1/G2, BR-040-01/02, AC-040-01/02) — ยืนยัน Q15
- ชื่อโครงงาน 1–200 ตัวอักษร ใช้แสดงผลเท่านั้น ไม่ใช่ชื่อไฟล์ (DES-003) · ขนาดเอกสาร ≤1 MiB

## 7. a11y ของ int-003 (ต่อมาตรฐานที่อนุมัติแล้ว int-001 §8 / int-002 §6)
