### 2.5 ล็อกหลังส่ง + ใช้ชุดใหม่เมื่อเปลี่ยน (G8)

อ้างอิง: [BR-049-08 (mapping ที่ส่งแล้วล็อก การเปลี่ยนใช้ชุดใหม่ ไม่ย้าย/ล้างคะแนนเดิม)](../requirement/req-049.md) · [AC-049-05 (mapping ที่ส่งแล้วแก้คู่เดิมไม่ได้)](../requirement/req-049.md) · grade-rules ("ช่องและล็อก") · [DES-008 (Mapping หลักสูตรกับช่องคะแนน SchoolBright)](../design/des-008.md)

| State | เงื่อนไข | UI + คำ copy (ข้อเสนอ) |
|---|---|---|
| mapping ใช้งาน (ยังไม่เคยส่ง) | ยังไม่มี export ที่ confirm | แก้กิจกรรมได้ (PUT + If-Match) · ปุ่ม "ปลดชุด mapping" (retire พร้อมเหตุผล) — การแก้ก่อน confirm ทำให้พรีวิวเก่าใช้ไม่ได้ทันที (DES-008) |
| mapping ล็อก (ส่งแล้ว) | มีการ confirm export แล้ว | แถวติดป้าย **"ส่งแล้ว — ล็อกชุดนี้"** ปุ่มแก้/ปลด disabled พร้อม tooltip "mapping ที่ส่งคะแนนแล้วห้ามแก้ (MAPPING_LOCKED)" (รวม retire/soft-delete — grade-rules) |
| ใช้ชุดใหม่ | admin ต้องการเปลี่ยนหลังล็อก | ปุ่ม "ใช้ชุดใหม่" → ผูกกิจกรรมเข้า**ช่องอื่นที่ยังไม่ถูกจอง** (หรือบริบทใหม่ที่ resolve เป็นคนละช่องจริง) — คู่เดิม/คะแนนที่ส่งแล้วคงเดิม ไม่ย้าย ไม่ล้าง (AC-049-05) · ห้าม PK/run ใหม่ทับช่องล็อก — เลือกช่องเดิม server ปฏิเสธ (grade-rules) — Q32 (ล็อก mapping หลังส่งและใช้ช่องใหม่) |
| retire เกษียณ | mapping เก่าที่ยังไม่ล็อก | dialog "ปลดชุด mapping นี้? กรุณากรอกเหตุผล" → แสดง "เกษียณ (retired) <วันที่> — <เหตุผล>" ในตารางและแท็บประวัติ |
