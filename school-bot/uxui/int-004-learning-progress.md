## 7. ความคืบหน้ารายภารกิจ (REQ-039)

อ้างอิง: [BR-039-01 (ความคืบหน้า Cloud อ้างบทเรียน ภารกิจ และผลจริงของนักเรียน แยกคน/โหมด)](../requirement/req-039.md), [BR-039-03 (ผลที่ยังรอครูตรวจไม่แสดงเป็นผ่าน)](../requirement/req-039.md), [BR-039-04 (Guest เก็บประวัติ local และเลือกย้ายหลัง Login ตาม REQ-042)](../requirement/req-039.md) · [AC-039-01 (นักเรียน Login ทำภารกิจและได้ผลแล้ว เปิดครั้งถัดไปยังเห็นผล/ความคืบหน้าของตน)](../requirement/req-039.md), [AC-039-03 (ภารกิจ Arm ที่ยังไม่ตรวจแสดงแยกจากภารกิจที่ครูยืนยันผลแล้ว)](../requirement/req-039.md), [AC-039-04 (ผล Block/Arm/Code ของผู้เรียนไม่ปะปนกับบัญชีอื่นหรือค่าจาก scenario)](../requirement/req-039.md) · ProgressView ([DES-005 (หลักสูตร ภารกิจ และผลประเมิน)](../design/des-005.md))

- หน้า "ความคืบหน้าของฉัน" — state ของหน้า: **loading** "กำลังโหลดความคืบหน้า…" · **empty** "ยังไม่มีผลงาน — เริ่มทำภารกิจแรกได้เลย" · **โหลดล้มเหลว** "โหลดความคืบหน้าไม่สำเร็จ (ลองใหม่)" — แยกจาก "ยังไม่ส่งงาน" ซึ่งเป็นสถานะรายกิจกรรมหลังโหลดสำเร็จแล้ว
- ตาราง Activity × chip สถานะ — **ยังไม่ส่ง / รอตรวจอัตโนมัติ / รอครูตรวจ / ผ่าน / ยังไม่ผ่าน / ผิดพลาด** + คะแนนเมื่อมี (EarnedScore/MaxScore) + ดาวตาม §6
- "รอครูตรวจ" แสดงแยกจาก "ผ่าน" ชัดเจน (AC-039-03) · เปิดครั้งถัดไปยังเห็นของตนเอง ไม่ปนผลทดลองครู/scenario/บัญชีอื่น (AC-039-01, AC-039-04)
- ข้อเสนอ (Q27 (ความคืบหน้าเฉพาะของตน)): นักเรียนเห็นเฉพาะผลของตน — **ไม่แสดงค่าเฉลี่ยห้อง/gap** (เป็นข้อมูลครูฝั่งเว็บตาม [DES-011 (ระบบเสนอเลื่อน Level และครูยืนยันทั้งห้อง)](../design/des-011.md))
