# 4. E2 — เลือก Guest หรือ Login + Login flow

> แก้ล่าสุด 2026-11-02 · แก้โดย int · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

[กลับint-001-entry](int-001-entry.md) · ส่วนหนึ่งของ UX ชุดเดียวกับตาราง Sign-off ในไฟล์ทางเข้า


อ้างอิง: [BR-009-02 (Guest/Local และ Login/Cloud ต่างต้องมี License)](../requirement/req-009.md) · [BR-036-01 (Guest ไม่ต้องมีบัญชี แต่ต้องมี License ตาม REQ-009/034)](../requirement/req-036.md) ถึง [BR-036-04 (เลือกนำเข้า Guest ตาม REQ-041/042 ไม่ auto-upload)](../requirement/req-036.md) · [AC-009-02 (เลือก Guest หรือ Login โดยยังไม่มี License แล้วไม่สามารถข้ามข้อกำหนด License เพื่อเข้าใช้โหมดหลักได้)](../requirement/req-009.md) · [AC-036-01 (Guest ที่มี License บันทึกและเปิดหลายงานทั้งสามโหมดในเครื่องได้โดยไม่ต้อง Login)](../requirement/req-036.md) ถึง [AC-036-04 (บันทึก Cloud ไม่สำเร็จแล้วแจ้งความล้มเหลว ไม่แสดงว่า Cloud บันทึกสำเร็จหรือผูกงานกับบัญชีอื่น)](../requirement/req-036.md) · pack-guest G1 (Guest ใช้พื้นที่ร่วมโดยไม่มี PIN)/G2 (ไม่ล้างงาน Guest อัตโนมัติ)/G6 (บังคับ License ทั้ง Guest และ Login) · [มติ035 (แหล่งสิทธิ์แอดมินโรงเรียน)](../requirement/decisions-035.md) (auth ผ่านระบบบัญชีเดิมและ HTTP API Gateway (`sb-api-gateway`) — target)

หน้าจอ: สองการ์ดใหญ่ (แสดงทุกครั้งที่เปิดแอป — ข้อเสนอ Q5 (แสดงตัวเลือก Guest/Login ทุกครั้ง))
- **การ์ด Guest**: ปุ่ม "เริ่มใช้แบบผู้เยี่ยมชม (Guest)" + คำอธิบาย "งานทั้งหมดเก็บในเครื่องนี้และทุกคนที่ใช้เครื่องนี้เปิดดูได้ ไม่มีรหัสลับ" — ไม่มีช่อง PIN ใด ๆ (G1) ไม่มีการล้างงานอัตโนมัติ (G2) · คำ "ไม่มีรหัสลับ" ตั้งใจให้ครูเห็นก่อนกด
- **การ์ด Login**: ปุ่ม "เข้าสู่ระบบด้วยบัญชีเดิม (นักเรียน/ครู)" + ฟิลด์ ชื่อผู้ใช้/รหัสผ่าน — เรียก auth ทาง HTTP API Gateway (`sb-api-gateway`) → ระบบบัญชีเดิม ตามมติ 035

Login states:

| State | คำ copy (ข้อเสนอ) |
|---|---|
| loading | "กำลังเข้าสู่ระบบ…" ปุ่มเข้าสู่ระบบ disabled |
| รหัสไม่ถูก | inline ใต้ฟิลด์: "ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง" คงชื่อผู้ใช้เดิมไว้ |
| ไม่มีเน็ต | "ไม่สามารถเชื่อมต่อระบบได้ ตรวจสอบอินเทอร์เน็ต หรือใช้งานแบบ Guest ต่อได้" (Login ≠ License — ออฟไลน์ใช้ Guest ได้ตราบสิทธิ์ License ยัง valid) |
| SESSION_EXPIRED ระหว่างใช้งาน | แจ้ง "เซสชันหมดอายุ กรุณาเข้าสู่ระบบอีกครั้ง" แล้วกลับ E2 — ไม่ทำงานต่อในนามบัญชีเดิม |
| บันทึก Cloud ล้มเหลว ([AC-036-04 (บันทึก Cloud ไม่สำเร็จแล้วแจ้งความล้มเหลว ไม่แสดงว่า Cloud บันทึกสำเร็จหรือผูกงานกับบัญชีอื่น)](../requirement/req-036.md)) | inline: "บันทึกบน Cloud ไม่สำเร็จ — งานยังเก็บในเครื่อง ลองบันทึกใหม่" ห้ามแสดงว่าสำเร็จหรือผูกกับบัญชีอื่น |

กติกาแสดงผล: แถบสถานะบัญชี (ชื่อผู้ใช้/Guest) แยกบรรทัดจากแถบสถานะ License — Login/Logout ไม่ต่ออายุหรือเพิกถอน License ([DES-002 (License และ device binding)](../design/des-002.md))

## 5. ตาราง mapping ผลตรวจ → สถานะ → คำ copy (จาก DES-002 "Local state/errors")

| ผลตรวจ | พฤติกรรมแอป | คำ copy ไทย (ตาม Q2 (ข้อความไทยและ accessibility ของ Entry/Labs)) | ปุ่ม |
|---|---|---|---|
| 409 DEVICE_LIMIT | อยู่ E1 ไม่ unlock | "Key นี้ผูกกับเครื่องอื่นอยู่ (DEVICE_LIMIT) — ให้ผู้ดูแลปลดเครื่องเดิมก่อนจึงย้ายมาเครื่องนี้ได้" | กรอก Key ใหม่ / "ติดต่อผู้ดูแล" |
| 403 DEVICE_NOT_ACTIVATED / DEVICE_PROOF_INVALID | ไม่ unlock/renew → recovery | "เครื่องนี้ยังไม่ได้เปิดใช้งาน หรือไม่สามารถพิสูจน์ตัวเครื่องได้" | "เปิดใช้งานใหม่" |
| 403 LICENSE_INVALID / LICENSE_INACTIVE / BINDING_REVOKED | denied + ล้าง cache | "สิทธิ์การใช้งานไม่ถูกต้อง / หมดอายุ / ถูกเพิกถอน — ติดต่อผู้ดูแลโรงเรียน" | กรอก Key ใหม่ |
| malformed / signature ผิด (INVALID_ENTITLEMENT) | ไม่รับสิทธิ์ใหม่ | "ได้รับข้อมูลสิทธิ์ที่ไม่ถูกต้องจากเซิร์ฟเวอร์ กรุณาตรวจสอบใหม่" | "ตรวจสอบอีกครั้ง" |
| 403 ไม่ทราบรหัส | locked รอ online recovery เท่านั้น (DES-002) | "ไม่สามารถยืนยันสิทธิ์ได้ (รหัสที่ไม่รู้จัก)" | "ตรวจสอบอีกครั้ง" (ต้องออนไลน์) |
| CREDENTIAL_STORE_FAILED | ไม่รายงานว่า activated พร้อมใช้ | "บันทึกข้อมูลเครื่องไม่สำเร็จ — ยังไม่ถือว่าเปิดใช้งานแล้ว กรุณาลองอีกครั้ง" | "ลองอีกครั้ง" |
| network / 5xx / 429 | ใช้สิทธิ์เดิมเฉพาะยัง valid ไม่เลื่อนวันหมด | "ตรวจสอบออนไลน์ไม่สำเร็จ — ใช้สิทธิ์ในเครื่องได้ถึง 28 ต.ค. 2569" | "ดำเนินการต่อ" / "ลองใหม่" |
