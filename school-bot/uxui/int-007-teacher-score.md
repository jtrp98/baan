# int-007 — เว็บครู / คะแนน / เลื่อน Level

วันที่ของงาน: 2026-10-26 · ต่อจาก [ไฟล์หลักและ Sign-off](int-007-attempt-policy.md)

รายละเอียดการนำเสนอทั้งหมดเป็น **ข้อเสนอ (proposal)** รอ Q44–Q46; ใช้ [state กลาง](int-007-states.md) กับทุก flow และตรวจ [หลักฐาน](int-007-trace.md) ก่อน implement

## T1. เลือกบริบทและปรับเวลา — Q44

หัวหน้าเว็บแสดงโรงเรียน ปี/เทอม ห้อง วิชา หลักสูตร Level และรอบเรียนตามข้อมูลจริง เปลี่ยนบริบทแล้วโหลดใหม่ ไม่ใช้ร่างหรือผลข้ามห้อง

สิทธิ์ครูใช้ course-teacher ∩ roster ∩ term ภายในโรงเรียน ครูอยู่ห้องเดียวกันไม่ได้แปลว่าเห็นทุกวิชา/นักเรียน ไม่เพิ่ม TeacherGrant หรือสิทธิ์ทั้งโรงเรียน; ผู้ดูแลโรงเรียนอ่าน policy/proposal ได้ตาม DES แต่สิทธิ์ admin อย่างเดียวไม่ให้แก้เวลา เปิดซ่อม หรือยืนยันเลื่อน

แผง “เวลาทำข้อสอบ” แก้ได้เฉพาะเวลาทำและเปิด–ปิด แสดงจำนวนครั้ง การสุ่ม เวลาเฉลย ข้อ/เฉลยเป็นอ่านอย่างเดียวพร้อมคำว่า “กำหนดโดยส่วนกลาง” เวลาทำต้องเป็นวินาทีเต็ม ≥1 หรือไม่จำกัดเมื่อสัญญาอนุญาต; Test ต้องมีเวลา และเวลาปิดต้องหลังเวลาเปิดเมื่อมีทั้งคู่

ก่อนบันทึกแสดงค่าก่อน→หลังและห้องปลายทาง พร้อมข้อความ “ใช้กับการเริ่มทำครั้งใหม่ ข้อสอบที่เริ่มแล้วคงเวลาและกติกาเดิม” การกลับค่าเริ่มใช้ override null ตามสัญญา ไม่แก้บาง field เงียบ ๆ

## T2. เปิดซ่อมรายคน — Q44

แผง “เปิดสอบซ่อม” เลือกได้จากนักเรียนในขอบเขตของครู แสดงชื่อกิจกรรม/ห้อง/ผู้รับและเหตุผลไม่เกิน 1,000 ตัวอักษร ก่อนยืนยันใช้ข้อความ “เพิ่มสิทธิ์ทำอีก 1 ครั้งให้นักเรียน ก เท่านั้น” ไม่ตีความเป็นเปิดทั้งห้อง

หลังสำเร็จแสดง “เปิดสิทธิ์สอบซ่อมแล้ว” ไม่แสดงว่านักเรียนสอบแล้วหรือคะแนนเพิ่มแล้ว ตัวอย่างจาก AC: ครั้งจริง 6/10 ซ่อม 9/10 ใช้ 9/10; ถ้าซ่อม 5/10 ยังคง 6/10 นักเรียน ข ไม่ได้สิทธิ์จากใบของ ก การลองคำขอเดิมซ้ำไม่สร้างใบเพิ่ม

## S1. น้ำหนักและผลรวมหลักสูตร — Q45

ครูตั้งราย CourseRun ที่ยัง planned และไม่เคยเริ่ม: สวิตช์ “นับ Quiz ในคะแนนรวม” พร้อมตารางกิจกรรม/น้ำหนัก/ยอดรวม ต้องครบกิจกรรมให้คะแนน ไม่ซ้ำ และรวม 100%; ปิดนับ Quiz แล้วน้ำหนัก Quiz เป็น 0 แต่ยังดูผล Quiz ได้ ไม่กำหนดน้ำหนักเริ่มแทนผู้ใช้

ตัวอย่างตรวจสูตร ไม่ใช่ค่าตั้งต้น:

| รายการ | คะแนน | น้ำหนัก | ส่วนคะแนนรวม |
|---|---|---|---|
| กิจกรรม | 8/10 | 20% | 16 |
| Quiz | 6/10 | 30% | 18 |
| Test | 18/20 | 50% | 45 |

รวม 79/100 ตาม SUM((earned/max)×weight) ไม่ปัดรายส่วน เมื่อรอบเริ่มแล้วแสดง policy revision ที่ตรึงไว้และอ่านอย่างเดียว น้ำหนัก 30/20/50 ใช้รอบใหม่เท่านั้น; คะแนนตัวอย่างเท่ากันได้ 81 รอบเดิมยัง 79 และหลักสูตรอื่นไม่เปลี่ยน

แยก “คะแนนครั้งนี้” จาก “ผลที่ใช้คิดคะแนน” ตาม selection ของกิจกรรม; Test รวมซ่อมใช้ best ไม่ลดด้วยเพดาน แสดงแหล่งผล/รอบ/ฉบับน้ำหนักเมื่อมีข้อมูลตามสัญญา ไม่คำนวณย้อนหลังจาก policy ล่าสุด ไม่ใช้ดาวหรือ passed แทนคะแนนเต็ม

คะแนนรวมนี้เป็นคะแนนหลักสูตร ไม่ใช่ผลรวม/เกรดทางการของ SchoolBright; ส่งเกรดคง int-005 งานขาดนับ 0 เฉพาะเลื่อน Level ส่วน export ข้ามผลที่ยังไม่มีและคงช่องเดิม

## L1. ประเมินสิ้นเทอมและยืนยัน — Q46

ปุ่ม “ประเมินปลายเทอม” ใช้ได้เมื่อ closing/closed ก่อนกดแจ้งว่าหากไม่ผ่าน ระบบจะเตรียมรอบ Level เดิมสำหรับเทอมถัดไปตามสัญญา จึงไม่เรียกการทำรายการนี้ว่า preview ที่ไม่มีผล

หน้าผลแสดงจำนวนสมาชิก roster ค่าเฉลี่ย เกณฑ์ ส่วนที่ขาด และวันที่มีผลจาก proposal ที่ server คืน ไม่ให้เอานักเรียน/งานขาดออกเพื่อเพิ่มเฉลี่ย

- ตัวอย่าง AC: roster 2 คน ได้ 80 และ 0 → เฉลี่ย 40 เกณฑ์ 70 ขาด 30 อยู่เดิม
- เฉลี่ย 70 เท่ากับเกณฑ์ 70 → ไม่เสนอเลื่อน ส่วนที่ขาด 0 พร้อมคำว่า “เท่ากับเกณฑ์ จึงยังไม่เสนอเลื่อน”; เปรียบเทียบ strict > ก่อนปัดและเปิดดูค่าละเอียดได้
- ผ่านและมีระดับถัดไป → proposed แสดง “รอครูยืนยัน” กล่องยืนยันสรุปทั้งห้อง Level เดิม→ใหม่ และเทอมที่จะมีผล ไม่มีตัวเลือกบางคน ก่อนยืนยันทุกคนยัง Level เดิม เทอมปัจจุบันไม่เปลี่ยน
- ไม่ผ่าน → retained; ระดับสูงสุด → max_level พร้อม “ระดับสูงสุด — เรียน Level เดิมต่อ” ไม่มีปุ่มเลื่อนเกินระดับ
- เลือกไม่เลื่อนข้อเสนอที่ผ่าน ใช้ decline พร้อมเหตุผล; ยกเลิกกล่องยังไม่ส่งคำสั่ง ไม่เปลี่ยนข้อเสนอ

proposal stale ต้องประเมินใหม่และตรวจทานใหม่; ยังไม่มีเทอมหน้าไม่สร้าง successor ไม่เดาปี/เทอมขึ้นเอง เมื่อสำเร็จอ่านผลเดิมเพื่อแสดงสถานะ ไม่สร้างรอบซ้ำ

## A1. เกณฑ์ส่วนกลาง — Q46

เฉพาะ level_policy_admin บนเว็บ admin ตั้ง threshold ราย Level ช่วง 0–100 ค่าเริ่ม Level ใหม่ 70 แสดงฉบับปัจจุบัน ค่าใหม่ และเหตุผลก่อนบันทึกเป็น revision ใหม่ ไม่เขียนทับเกณฑ์ snapshot เดิม การสร้าง/เผยแพร่คลังข้อสอบอยู่ UX-005 และใช้ four-eyes เดิม
