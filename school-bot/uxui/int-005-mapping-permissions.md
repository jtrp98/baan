## 1. ภาพรวมหน้าและสิทธิ์ (ข้อเสนอ)

สามหน้าในเว็บโรงเรียน (Desktop ไม่มีส่วนใดของงานนี้):
1) **"จัด mapping คะแนน"** (admin โรงเรียน) — ถือครองช่อง (GradeSlot) + ผูกกิจกรรม→ช่อง ([DES-008 (Mapping หลักสูตรกับช่องคะแนน SchoolBright)](../design/des-008.md))
2) **"ส่งคะแนนเข้าระบบเกรด"** (ครูรายวิชา) — พรีวิว → ยืนยัน → แก้ชน → ติดตามผลส่ง ([DES-009 (Preview ยืนยัน และส่งคะแนนกลับ SchoolBright)](../design/des-009.md))
3) **"ผลการส่ง / ประวัติ (audit)"** (ครู + admin)

| Actor | จัด mapping | พรีวิว/ยืนยัน/แก้ชน | ดูผลส่ง/audit |
|---|---|---|---|
| admin โรงเรียน (`IsAdmin=1` — [BR-049-06 (เฉพาะ admin โรงเรียนสร้าง/แก้ mapping ครูแก้ไม่ได้)](../requirement/req-049.md), [BR-049-07 (admin โรงเรียน = IsAdmin=1)](../requirement/req-049.md)) | ได้ (school_admin) | **ไม่ได้** — school_admin ไม่มีสิทธิ์ส่งคะแนน (DES-009) | อ่านได้ทั้งโรงเรียน |
| ครูรายวิชา ([DES-012 (Auth ข้ามระบบสำหรับเว็บโรงเรียน, admin และ Desktop)](../design/des-012.md)) | ไม่ได้ — เห็น mapping แบบอ่านอย่างเดียว (เขียนพบ 403 SCHOOL_ADMIN_REQUIRED) | ได้เฉพาะ plan_course ที่ตนสอน | อ่านรายการที่ตนยืนยัน |
| ครูประจำห้อง / TeacherGrant | ไม่ได้ | ไม่ได้ (ไม่มีสิทธิ์เพิ่ม — DES-008) | ตามสิทธิ์เดิม |

เงื่อนไขเปิดใช้ทั้งสองหน้า: License ของโรงเรียน active (BR-049-07 · 403 LICENSE_REQUIRED)

## 2. หน้าจัด mapping (admin โรงเรียน) — DES-008 · REQ-049

### 2.1 โครงหน้า (ข้อเสนอ — Q30 (หน้า mapping รายช่องคะแนน))

- บริบทด้านบน: ปีการศึกษา/เทอม + วิชา (plan_course) + ห้อง — server resolve เป็น NYear/NTerm จริงแล้วแสดงค่าที่ resolve (DES-008: ห้ามใช้ term "1" แทน legacy NTerm) · เปลี่ยนบริบท = โหลดชุดข้อมูลใหม่ **ไม่ใช้ mapping ข้ามบริบท** ([AC-049-03 (สลับโรงเรียน/เทอมแล้ว mapping ไม่ถูกใช้ข้ามบริบทอัตโนมัติ)](../requirement/req-049.md))
- ตารางหลัก **"รายช่องคะแนน (GradeSlot)"**: แถว = ช่อง; คอลัมน์ = ชื่อช่อง · หมวด (ก่อนกลางภาค/หลังกลางภาค/กลางภาค/ปลายภาค จากข้อมูลจริง) · คะแนนเต็ม · สถานะช่อง (ว่างให้เลือก / SchoolBot ดูแล / ล็อกโดยระบบเกรด block_code) · กิจกรรมที่ผูก · สถานะ mapping (ใช้งาน / ล็อกแล้ว-ส่งแล้ว / เกษียณ) · ปุ่ม action
- เหตุผลที่เสนอให้ "รายช่องเป็นแถวหลัก": กฎ 1 ช่อง = 1 กิจกรรม ทำให้เห็นการชนได้ตรงแถว
