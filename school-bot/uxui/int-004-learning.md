## 6. ดาวตาม rubric ที่ยืนยันแล้ว (pack-content-inventory-001 §2 · decisions-038 spec Q2)

- นิยาม **ยืนยันแล้ว**: ดาว 1 = ผ่านเกณฑ์ขั้นต่ำ · ดาว 2 = ผ่าน + อยู่ในโควตา (จำนวนคำสั่ง/บล็อก/เวลาตามรายภารกิจ) · ดาว 3 = ผ่าน + ภารกิจเสริม/ทางเลือก · **ดาวไม่ใช่เงื่อนไขเลื่อน Level**
- การนำเสนอ (ข้อเสนอ — Q24): แสดงดาว **เฉพาะเมื่อมีผลตรวจจริง** (ยังไม่มีผล = ขีดว่าง ไม่ใช่ดาวจางตามค่าคงที่ — BR-039-03) · tooltip/`aria-label` "ได้ 2 ดาวจาก 3 — ผ่านและอยู่ในโควตา" · ข้อความกำกับหน้าผล: "ดาวเป็นสัญลักษณ์ความสำเร็จของภารกิจ ไม่ใช่เกณฑ์เลื่อนระดับ" · ค่าดาวมาจากผลตรวจตาม rubric ที่อนุมัติ ไม่คำนวณที่ client (BR-042-04)

## 7. ความคืบหน้ารายภารกิจ (REQ-039)

อ้างอิง: BR-039-01/03/04 · AC-039-01/03/04 · ProgressView (DES-005)

- หน้า "ความคืบหน้าของฉัน" — state ของหน้า (แก้ตาม check-061-verify4): **loading** "กำลังโหลดความคืบหน้า…" · **empty** "ยังไม่มีผลงาน — เริ่มทำภารกิจแรกได้เลย" · **โหลดล้มเหลว** "โหลดความคืบหน้าไม่สำเร็จ (ลองใหม่)" — แยกจาก "ยังไม่ส่งงาน" ซึ่งเป็นสถานะรายกิจกรรมหลังโหลดสำเร็จแล้ว
- ตาราง Activity × chip สถานะ — **ยังไม่ส่ง / รอตรวจอัตโนมัติ / รอครูตรวจ / ผ่าน / ยังไม่ผ่าน / ผิดพลาด** + คะแนนเมื่อมี (EarnedScore/MaxScore) + ดาวตาม §6
- "รอครูตรวจ" แสดงแยกจาก "ผ่าน" ชัดเจน (AC-039-03) · เปิดครั้งถัดไปยังเห็นของตนเอง ไม่ปนผลทดลองครู/scenario/บัญชีอื่น (AC-039-01/04)
- ข้อเสนอ (Q27): นักเรียนเห็นเฉพาะผลของตน — **ไม่แสดงค่าเฉลี่ยห้อง/gap** (เป็นข้อมูลครูฝั่งเว็บตาม DES-011)

## 9. เลื่อน Level ทั้งห้อง — มุมมอง Desktop (DES-011 Rev4)

- การเสนอ/ยืนยัน/ตั้งเกณฑ์ **ไม่อยู่ใน Desktop**: หน้าครูอยู่ web-system หน้าตั้งเกณฑ์อยู่ admin (DES-011, decisions-022) — Desktop ไม่มีปุ่มเลื่อน/ยืนยัน Level
- ที่นักเรียนเห็น (ข้อเสนอ — Q28): หัวหน้าบทเรียนแสดง "Level ปัจจุบันของห้อง" + หลังสิ้นเทอมเป็นข้อความสถานะอย่างเดียว:
  - promoted: "ห้องของคุณย้ายไป Level <ถัดไป> ในภาคเรียนถัดไปแล้ว"
  - retained: "ห้องยังเรียน Level เดิมต่อในภาคเรียนถัดไป" (เหตุผลค่าเฉลี่ย/gap แสดงฝั่งครูเว็บ — สอดคล้อง §7)
  - max_level: "Level นี้เป็นระดับสูงสุด — ห้องเรียน Level เดิมต่อ"
- เกณฑ์: ค่าเฉลี่ยห้องต้อง **สูงกว่า** เกณฑ์ (ค่าเริ่ม 70 — เท่ากับเกณฑ์ยังไม่ผ่าน) นับทุกคนใน roster งานไม่ส่งนับ 0 (decisions-024, DES-011)

## 10. a11y ของ int-004 (ต่อมาตรฐานที่อนุมัติแล้ว)
