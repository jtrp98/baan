### 3.3 ข้าม (missing) vs จริง 0 vs ผลพิเศษ

อ้างอิง: [BR-050-06 (ไม่มีผลประเมินให้ข้ามและแสดงเหตุผล คงคะแนนเดิม ส่งภายหลังได้)](../requirement/req-050.md) · [BR-051-03 (ห้ามทับช่องที่ครูกรอกเองนอกช่อง SchoolBot, PgtgradeEdit override และผลพิเศษ เช่น รอผล/ขาดสอบ)](../requirement/req-051.md), [BR-051-05 (ไม่มีผลประเมินกิจกรรมให้ข้าม คงช่องเดิม ไม่แทน 0)](../requirement/req-051.md) · [AC-050-01 (preview ตรวจค่าเดิม/ใหม่และปลายทางตาม BR-050-02/03 ได้)](../requirement/req-050.md) · [AC-051-04 (ส่งคะแนนในข้อมูลที่มีช่องครู override และผลพิเศษแล้วค่าคุ้มครองคงเดิม ไม่มีการแทนด้วยศูนย์)](../requirement/req-051.md), [AC-051-05 (A ยังไม่มีผลกิจกรรมแต่ช่องเดิมมี 5 ส่งแล้วคง 5 และแสดงข้าม)](../requirement/req-051.md) · grade-rules (skipped_cells)

| กรณี | แสดงในเซลล์ (ข้อเสนอ) |
|---|---|
| ยังไม่มีผลกิจกรรม (SOURCE_RESULT_MISSING) | ป้าย "ข้าม — ยังไม่มีผลกิจกรรม" + "คงคะแนนเดิม <old_score>" (ไม่มีค่าเดิม → "ช่องนี้ยังว่าง") · **ห้ามเสนอ 0 ทับค่าเดิม** · มีผลภายหลังส่งตามพรีวิวใหม่ได้ |
| ยังไม่ตรวจ / ผลต้นทางผิดพลาด (SOURCE_RESULT_UNGRADED / SOURCE_RESULT_ERROR) | "ข้าม — ยังไม่ตรวจ / ผลต้นทางผิดพลาด" คงค่าเดิม |
| ผลจริง 0 | เซลล์ปกติ `0/10 → 0/20` **พร้อมส่ง** — จริง 0 ไม่ถูกข้ามเพราะเป็น 0 (AC-051-05) |
| ข้ามทั้งคน (ทุกช่อง missing) | แถว state ready + ป้าย "ข้ามทั้งหมด — ไม่มีผลกิจกรรม" ไม่สร้างรายการเขียน (grade-rules: Outbox skipped) |
| ผลพิเศษ (รอผล/ขาดสอบ) หรือ PgtgradeEdit (has_grade_edit) | เซลล์/แถว state **ถูกกั้น (blocked)**: "คงผลพิเศษ/ค่าที่ครูแก้ไว้ — SchoolBot ไม่แตะช่องนี้" · ไม่มีตัวเลือกให้ทับ ไม่แปลงเป็นศูนย์ (BR-051-03, AC-051-04) |
| ปลายทางล็อก / ไม่มีสิทธิ์เขียน | blocked: "ปลายทางถูกล็อก หรือไม่มีสิทธิ์เขียนช่องนี้" ([AC-052-01 (ครูไม่มีสิทธิ์วิชา/ห้อง ข้ามโรงเรียน/เทอม หรือปลายทางล็อก ส่งแล้วถูกปฏิเสธและคะแนนไม่เปลี่ยน)](../requirement/req-052.md)) |
| SOURCE_SCOPE_UNPROVEN | blocked แยกจาก missing: "ยังพิสูจน์ขอบเขตผลไม่ได้ (SOURCE_SCOPE_UNPROVEN)" (grade-rules) |
