## โมเดล

CourseRun = การใช้ curriculum revision หนึ่งกับห้องและเทอมหนึ่ง ผูกวิชา (PlanCourseIds) ที่ admin โรงเรียนเลือกตอนเปิดใช้ เพื่อใช้ตรวจสิทธิ์ครู

GradeSlot = ช่อง PGGradeDB ที่ได้รับการยืนยันให้ SchoolBot ดูแล ระบุ n_grade_id, assessment_id และ score_identifier แบบ exact รวม school/year/term/plan_course/course/classroom context

ScoreMapping = GradeSlot หนึ่งกับแหล่งคะแนน Activity
Source={activity_id:K,indicator_key:U|null,weight_bps:0..10000}

ข้อเสนอ SA (รอ OQ-016 — การรวมหลายกิจกรรมลงช่องเดียว):
contract รองรับหลาย source ที่ผลรวม weight_bps = 10000 แต่จนกว่า OQ-016 มีมติ server รับได้ 1 source ต่อ mapping (weight_bps = 10000) และตอบ 409 MAPPING_MULTI_SOURCE_NOT_ENABLED

Lesson เป็นตัวเลือกกลุ่มกิจกรรม ไม่เป็นคะแนนที่สร้างขึ้นเอง การเลือก Lesson/Indicator ในหน้า mapping ต้องขยายเป็นรายการ activity_id ที่แน่นอนก่อนบันทึก ห้ามตามกิจกรรมเพิ่มใน revision ใหม่เอง

หนึ่ง Activity แมพได้หลาย GradeSlot ข้ามหลายวิชา (decisions-020 คำชี้แจง, BR-049-02)
ใน CourseRun หนึ่งมี active mapping ต่อ GradeSlot ได้หนึ่งชุด (`ux_schoolbot_scoremapping_active`) ห้ามสร้าง mapping ซ้ำเพื่อส่งคะแนนไปช่องเดียวกันสองครั้ง

## การได้มาซึ่ง GradeSlot และการตรวจซ้ำข้าม DB ก่อน Commit

1. อ่านช่องเดิมจาก PGGradeDB และ resolve context แผนการเรียน/ห้อง/เทอมจาก School DB ฝั่ง server ผ่าน connection แยก
2. ต้องพบ header/assessment/identifier ที่ไม่กำกวมและยังใช้งาน
3. admin โรงเรียนยืนยันว่าช่องนั้นเป็นช่องเฉพาะ SchoolBot
4. ตรวจว่าไม่มีคะแนนครูหรือเจ้าของช่องอื่นอยู่ก่อนเริ่มถือครอง
5. **Re-check ก่อน Commit ([decisions-027](../requirement/decisions-027.md))**: เนื่องจากไม่มี transaction เดียวครอบ SchoolBot DB กับ School DB / PGGradeDB ก่อนเปิดและ commit transaction ใน **SchoolBot DB** ต้อง re-check สิทธิ์ `school_admin`, สถานะ `SchoolBotLicense` active ของโรงเรียน, การมีอยู่ของ `PlanCourseId`/เทอมใน School DB และสถานะช่องว่างใน PGGradeDB อีกครั้ง แล้วจึงบันทึก ownership (`SchoolBotGradeSlot`) พร้อม `SchoolBotAuditEvent` และ `SchoolBotIdempotency` ใน **SchoolBot DB** transaction เดียว (`ux_schoolbot_gradeslot_active_ownership` บน `(SchoolId, NGradeId, AssessmentId, ScoreIdentifier) WHERE RetiredAt IS NULL` โดยไม่กรอง `IsDelete=false`)

ชื่อช่องที่มีคำว่า SchoolBot ไม่ใช่หลักฐาน ownership ห้ามยึดช่องของครูด้วยการตั้งชื่อใหม่หรือเลือก force หากไม่พบช่องว่างที่จัดสรรได้ ให้ SLOT_UNAVAILABLE การสร้าง Pgtassessment ใหม่ต้องรอ writer contract/DBA review (DES-009) ห้ามใช้ MAX(id)+1 หรือเดา ScoreIdentifier จาก ordinal

## Validation, Tenant Check และสิทธิ์

ตรวจ school_admin หรือสิทธิ์ครูรายวิชาตาม DES-012 ทั้ง ณ request และ re-check ซ้ำก่อน commit ใน SchoolBot DB
ครูอ่านได้เฉพาะวิชาที่ตนสอน ไม่รวมสิทธิ์ครูคนหนึ่งไปยังวิชาอื่น
เนื่องจาก FK ใน `db/schoolbot_db.sql` เป็น single-column FK ชี้ PK ([db/review-005.md](../db/review-005.md)) ชั้น application ต้องตรวจว่า `CourseRun`, `GradeSlot` และ `ScoreMapping` อยู่ `SchoolId` เดียวกับ session และ `GradeSlot.CourseRunId == ScoreMapping.CourseRunId`
plan_course_id ของ GradeSlot ต้องอยู่ใน PlanCourseIds ของ CourseRun
source ต้องเป็น published Activity ใน curriculum revision ของ run และ indicator ต้องถูกประกาศอยู่บน Activity นั้น
source ต้องมีผลตัวเลขที่นิยามได้ ไม่แปลง passed เป็น 100 เอง; quiz ที่ ScoringPolicy ไม่นับคะแนนเป็น source ไม่ได้ (DES-010); ค่าหายไม่ถือเป็นศูนย์
ข้อเสนอ SA (รอ OQ-016 — การแก้ mapping หลังส่ง): mapping ที่ใช้งานแล้วเปลี่ยนได้เฉพาะอนาคต ประวัติ export เก็บ snapshot เดิม การแก้/retire mapping ทำให้ preview ที่ยังไม่ยืนยันหมดความใช้ได้

## ทางเลือกและการตรวจ

เลือก explicit many-to-many และ GradeSlot ownership ใน SchoolBot DB; ปัดตก FK จากหลักสูตรกลางไป Pgtassessment, ปัดตกสร้างช่องอัตโนมัติจากชื่อ/เลขลำดับ, ปัดตกตั้ง quiz→คะแนนเก็บ/test→สอบเป็นกฎตายตัว, ปัดตกให้ครูรายวิชาแก้ mapping และปัดตกเปิดหลาย source ต่อช่องก่อน OQ-016
พิสูจน์หนึ่งคาบส่งหลายวิชา, slot ซ้ำ, context ไม่ตรง, indicator ไม่อยู่ Activity, เปลี่ยน revision แล้วไม่ remap อัตโนมัติ, ครูพยายามสร้าง/แก้ mapping → 403 SCHOOL_ADMIN_REQUIRED, ครูอ่านวิชาที่ไม่ได้สอน → 403, admin โรงเรียนอื่น → 404/SCHOOL_MISMATCH, ส่งสอง source ก่อน OQ-016 → 409, session channel desktop → 403, และไม่มี PGGradeDB mutation จากการบันทึก mapping
