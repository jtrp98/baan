# DES-004 — Identity และ school authorization — Rev1

อ้าง REQ-027, 033, 035–039; OQ-007/009

## ข้อเท็จจริง

`web/src/SchoolBot.Api/Program.cs:96` มี static admin Bearer เท่านั้น
`app/frontend/src/shell.tsx:10` ระบุ profile/progress เป็น placeholder
`AppView.tsx:352` เปิดเมนูครูเป็น navigation ไม่ใช่หลักฐาน authorization

## Actor / trigger / preconditions

Guest เข้า local ภายใต้ License; ผู้เรียน login เพื่อ Cloud; ครูขอดู/ตรวจงาน; ผู้ดูแลจัดการ License/ขอบเขตสิทธิ์ ทุกคำขอ private ต้องตรวจ server authorization ซ้ำ

## ข้อเสนอ: integration seam

Host `SignIn`, `SignOut`, `GetSession`; identity adapter คืน verified `{issuer,subject}` และ server directory แปลงเป็น User/School/roles ห้ามเชื่อ role หรือ SchoolId จากชื่อเมนู/client payload

เสนอ authorization-code + PKCE ผ่าน system browser ถ้า provider รองรับ แต่ยังไม่เลือก provider, client ID, callback registration หรือ external FK Adapter ที่ไม่พร้อมคืน `503 IDENTITY_NOT_CONFIGURED` ไม่ใช้ sample login แทน

| Endpoint `/v2` | Input/ผล |
|---|---|
| GET /me | Bearer → `{user_id,display_name,memberships:[{school_id,roles}]}` |
| GET /admin/teacher-grants | scope/pagination → grant list |
| POST /admin/teacher-grants | `{teacher_id,learner_id,mode,can_view,can_assess,valid_from,valid_until}` → 201 grant |
| DELETE /admin/teacher-grants/{id} | If-Match → 200 `{id,deleted:true,version}` |

Grant result คือ input + id/version; fields common เป็น server-managed เปิด endpoints นี้หลังยืนยันเจ้าของสิทธิ์เท่านั้น

## Permissions ที่เสนอ ไม่ใช่มติขอบเขตครู

| Actor | อนุญาต |
|---|---|
| Guest + License | local projects/Labs/cached published lessons; ไม่มี Cloud learner identity |
| Student | CRUD งานตน ส่ง/อ่าน submission และผลตน |
| Teacher | อ่านผลตาม live grant; ตรวจ Arm เมื่อ CanAssess=true; ไม่แก้งานนักเรียน |
| School admin | License ในโรงเรียนและ grant management หาก directory มอบ scope |
| Platform publisher/admin | release/catalog หรือ cross-school license เฉพาะ scope ที่ระบุใน trusted adapter |

ไม่ให้ครูเห็นทั้งโรงเรียนโดยปริยาย; administrative role ไม่ได้รับสิทธิ์อ่าน source นักเรียนอัตโนมัติ Content-author/publisher scopes แยกจาก teacher

Cloud request มี Bearer, school context, entitlement และ device proof; server resolve membership แล้วตรวจ SchoolId ตรง entitlement/resource การเปลี่ยน school ต้องตรวจใหม่ ไม่ใช้ client header เป็น authority

## State / invariants / failure

`guest → authenticating → authenticated → expired|signed_out`
Auth refresh ล้มเหลว: เก็บ draft แยก ไม่ปลอมเป็น cloud saved; License ยังมีวงจรของมันเอง Logout drain งานหุ่น/close guards ก่อนสลับ principal; clear tokens และ UI state; การเก็บ recovery ข้ามผู้ใช้รอ OQ-007

401 UNAUTHORIZED เมื่อ token หาย/หมดอายุ/issuer ผิด; 403 FORBIDDEN เมื่อ scope ไม่พอ; SCHOOL_MISMATCH เมื่อ school context ไม่ถูกต้อง; object ที่ผู้เรียกไม่ควรรู้คืน 404

ตรวจ grant ณ commit ของ assessment ไม่ใช่เฉพาะตอนเปิดหน้า การถอน grant ต้องมีผลกับคำขอถัดไปและไม่ปล่อย in-flight commit ที่ authorization หมดแล้ว

Static admin key เดิมเป็น adapter เฉพาะ development/compatibility ที่ระบุ deployment ชัด Production ใช้ตัวตนรายคน/บริการพร้อม audit; config หายยัง 503 และ token ผิด 401 ตาม AC-027-01 การเปลี่ยนนี้ต้อง breaking review

## ทางเลือกและการตรวจ

ปัดตก PIN/ชื่อเมนูเป็นสิทธิ์ และ role จาก client เลือก deny-by-default + explicit grants ทดสอบ cross-school IDs, teacher ไม่มี grant, grant ถูกถอนขณะตรวจ และ logout/login บัญชีใหม่ไม่รับ callback/ข้อมูลบัญชีเก่า ตาม AC-035-01, AC-038-03, AC-039-02/04
