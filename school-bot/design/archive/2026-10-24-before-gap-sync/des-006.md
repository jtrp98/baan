## ข้อเสนอ platform boundary

ใช้ `TransportOptions`, `ExchangeResult`, command builders/actions เดิม เพิ่ม Darwin discovery/HID/serial implementations:

| ใช้ร่วม | เพิ่ม/เปลี่ยน |
|---|---|
| command text, group bounds, HID packet format, reply semantics | แยก platform helper ออกจาก transport_windows.hpp |
| 4 วินาที transport / 5 วินาที host budget | Darwin HID backend และ IOKit discovery; serial ใช้ POSIX/termios adapter |
| CHECK_FW guard และ partial-write failure | ตรวจ report-ID framing/permissions บน Intel และ ARM64 จริง |
| no movement retry | target validation จาก enumeration ของ OS |

Darwin serial รับเฉพาะ enumerated callout device identity ไม่เปิด arbitrary `/dev` path; Windows คง COM policy และตรวจ target ปัจจุบัน ทุก request revalidate target ก่อน open ป้องกัน stale/replaced path

UI device shape คง `{transport:"hid"|"serial",path,name}` โดย path เป็น opaque OS token ไม่ให้ผู้ใช้พิมพ์ filesystem path Capability ของ engine ต้องรายงานตาม backend ที่ build ได้จริง; ไม่อ้าง darwin hardware support ก่อน acceptance

## Lifecycle / failure

`off → probing → connected → busy → connected|lost`
board playback คง active จน stop/error ไม่ตั้งจบจากเวลา

Stop: host ปิด admission → generation++/ล้าง timers/คิว → cancel child → reap/drain → `$DST!` เป้าหมายเดิม → relock เฉพาะคำขอที่ระบุไว้ การส่ง stop ล้มเหลวไม่แสดง stopped/locked สำเร็จ ห้ามงานใหม่แทรกก่อน stop เสร็จ

CHECK_FW ทุก HID open คงไว้ แม้เพิ่ม latency; การข้ามอาจส่งข้อมูลเข้า bootloader ไม่ใช่ optimization ที่อนุญาตเอง App loop รอผลส่งและระยะท่าก่อนท่าถัดไป; upload failure หยุด batches และ invalidates board session

TRANSPORT_ERROR/DEVICE_TIMEOUT/ENGINE_TIMEOUT → lost/unknown delivery ไม่ retry movement; ENGINE_BUSY/ENGINE_CANCELLED ไม่เท่ากับ cable loss แต่ cancellation อาจเกิดหลังส่งบางส่วน ต้องไม่อ้างว่าไม่มีผลทางกายภาพ Reconnect ต้อง probe ใหม่ ไม่ replay/restore upload session อัตโนมัติ

## ทางเลือก / release guard / การตรวจ

เลือกต่อ C++ platform adapter; ปัดตก rewrite engine, simulator-only Mac, skip CHECK_FW และ timer-confirmed stop

Dry-run/fake bridge ตรวจ AC-014–024 ได้เฉพาะ logic ต้องตรวจจริงบน Windows/Mac ทั้ง HID/Serial ที่ประกาศรองรับ: calibration, unplug/replug, partial download, stale serial reply, stop latency และ emergency-stop provisions รุ่น/เกณฑ์/ผู้รับรองรอ OQ-008 ห้ามส่งมอบ Mac simulator แทน AC-032-02
