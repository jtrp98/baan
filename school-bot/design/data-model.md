# SchoolBot — ตารางและข้อมูลของระบบ (Rev8)

เอกสารนี้อธิบายแบบข้อมูลเป้าหมายของ SchoolBot ตาม SQL ปัจจุบัน **32 ตาราง / 450 ฟิลด์ / PK32** เพื่อให้รู้ว่าตารางไหนเก็บอะไรและใช้ข้อมูลเก่าจากที่ไหน การมีแบบและ SQL ไม่ได้หมายความว่าระบบเชื่อมฐานข้อมูลจริงแล้ว

ร่าง SQL ปัจจุบันคง PRIMARY KEY 32 รายการ; UNIQUE/FK/CHECK เป็น 0. ความสัมพันธ์ ความไม่ซ้ำ และเงื่อนไขข้อมูลเดิมเป็นกฎเชิงตรรกะของ application; งานนี้ไม่เพิ่มหรือพิสูจน์ implementation ทดแทน (NOT_IMPLEMENTED). ชนิดข้อมูล NOT NULL/NULL ค่าเริ่มต้น และ identity เดิมยังอยู่; ยังไม่ได้รันฐานจริง

## มองระบบเป็น 7 กลุ่ม

| กลุ่ม | เก็บเรื่องอะไร | ตารางหลัก |
|---|---|---|
| สิทธิ์ใช้แอป | โรงเรียนมี License อะไร ผูกเครื่องไหน และใครเข้าใช้งาน | License, LicenseBinding, Session, StaffRole |
| โครงงาน | งานของนักเรียน/ครู และเนื้อหาแต่ละฉบับที่บันทึก | Project, ProjectRevision |
| เนื้อหากลาง | Level หลักสูตร บทเรียน กิจกรรม ภารกิจ เกณฑ์ตรวจ และคลังข้อสอบ | Level, Curriculum, Lesson, Activity, Mission, Criteria, QuestionBank |
| เปิดสอนจริง | ห้องไหนเรียนหลักสูตรอะไรในปี/เทอมใด ใช้นโยบายคะแนนอะไร | CourseRun, ScoringPolicy, CourseRunActivity |
| ผลการเรียน | ส่งงานอะไร ตรวจได้ผลอย่างไร ทำข้อสอบครั้งไหน และได้สิทธิ์สอบซ่อมหรือไม่ | Submission, GradingJob, Assessment, Attempt, RetakeGrant |
| ส่งคะแนน/เลื่อน Level | ใช้ผลใดส่งเข้าช่องคะแนนเดิม ยืนยันชุดไหน ส่งสำเร็จหรือยัง และเลื่อน Level หรือไม่ | GradeSlot, ScoreMapping, ScorePreview/Item, ScoreExport, ScoreOutbox, LevelProposal, LevelPromotionPolicy |
| งานระบบ | รุ่นแอป การกันคำขอซ้ำ และประวัติการทำรายการ | Release, Idempotency, AuditEvent |

ในตารางด้านบนละ prefix `SchoolBot` เพื่อให้อ่านง่าย เช่น `Project` คือ `SchoolBotProject` ชื่อจริงในฐานข้อมูลมี prefix ครบ

## เส้นทางข้อมูล

เนื้อหากลาง → เปิดสอนให้ห้องในปี/เทอม → นักเรียนส่งโครงงานหรือทำข้อสอบ → ประเมินผล → ตรวจ preview → ครูยืนยันส่งเข้าช่องคะแนนเดิม

อ่าน [คำอธิบายทีละขั้นพร้อมแผนภาพ](data-relations-001.md) โดยแยกความสัมพันธ์ในงานออกจาก FK ใน SQL

## ข้อมูลใหม่กับข้อมูลเดิมอยู่ที่ไหน

**32 ตาราง SchoolBot อยู่ใน SchoolBot DB ของตัวเอง** ที่ `10.0.0.128:9499`, schema `public` ชื่อ database `SchoolBot` ยังเป็นสมมติฐานตามแบบเดิม ส่วนบัญชี นักเรียน ครู วิชา ห้อง เทอม และคะแนนทางการยังอยู่ในฐานเดิม

| ฐานข้อมูล | SchoolBot ใช้เพื่ออะไร |
|---|---|
| Master DB | ตรวจบัญชีเดิม เช่น `TMasterDBUser`; ไม่สร้างบัญชีหรือสำเนารหัสผ่านใหม่ |
| School DB | อ่านนักเรียน บุคลากร โรงเรียน แผนรายวิชา สิทธิ์ครู ห้อง และปี/เทอม |
| PGGradeDB | อ่านช่อง/สถานะคะแนน และเตรียมส่งเฉพาะช่องที่ SchoolBot ดูแล ภายใต้เงื่อนไขของระบบเกรด |
| Logs DB | มี connection ในระบบเดิม แต่แบบปัจจุบันยังไม่ระบุตารางที่ SchoolBot ต้องใช้ชัดเจน |

`AccountId` ของบัญชี, `SId` ของนักเรียน และ `SEmp` ของครู **เป็นคนละรหัส** ตัวเลขเท่ากันไม่ได้แปลว่าเป็นคนเดียวกัน การอ้างนักเรียน/ครูต้องใช้ `SchoolId` และชนิด profile ร่วมด้วย รายละเอียดคอลัมน์จริงอยู่ใน [แผนที่ตารางเก่า](data-legacy-001.md)
