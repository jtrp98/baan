# SchoolBotLicense

[ตารางทั้งหมด](index.md) · [คู่มือภาพรวม](../data-model.md) · [ตารางเดิม](../data-legacy-001.md)

**หน้าที่:** เก็บสิทธิ์ใช้งาน SchoolBot ของโรงเรียน รวมวันหมดอายุและเครื่องที่ผูกอยู่

**หนึ่งแถว:** หนึ่งใบอนุญาตของหนึ่งโรงเรียน

**ใช้ตอนไหน/ใครใช้:** ผู้ดูแลออก/ถอนใบอนุญาต; Desktop activate/validate; เว็บโรงเรียนตรวจสิทธิ์ใช้งาน

**ตัวอย่างสมมติ:** สมมติ: โรงเรียน ก มีใบอนุญาตที่ยังใช้งานได้ และผูกกับคอมพิวเตอร์ห้องหุ่นยนต์

**ขอบเขต:** ข้อมูลรายโรงเรียน: SchoolId ต้องมากกว่า 0 และอ่าน/เขียนภายใต้โรงเรียนนั้น

## ทุกฟิลด์ในตาราง

เรียงตาม SQL; “ว่างได้” หมายถึงเก็บ NULL ได้ ค่าจาก server ยังต้องผ่านกฎใน [สัญญาข้อมูล](../data-contract-rules.md)

| ฟิลด์ | ชนิดจริงใน SQL | ว่างได้ | เก็บอะไร / ใช้ทำอะไร |
|---|---|---|---|
| `SchoolBotLicenseId` | `integer` | ไม่ได้ | รหัสแถวของ SchoolBotLicense (PK); ฐานข้อมูลสร้างให้ ไม่รับรหัสจาก client; เป็น Primary Key ของตารางนี้; สร้างอัตโนมัติแบบ identity |
| `SchoolName` | `varchar(200)` | ไม่ได้ | ชื่อโรงเรียนที่บันทึกประกอบใบอนุญาต ไม่ใช่รหัสเชื่อมโรงเรียน; การเชื่อมใช้ SchoolId |
| `KeyHash` | `varchar(64)` | ไม่ได้ | ค่า SHA-256 สำหรับตรวจ License Key โดยไม่เก็บ Key ฉบับอ่านได้; ห้ามซ้ำทั้งระบบ |
| `KeyHint` | `varchar(32)` | ไม่ได้ | ข้อความช่วยให้ผู้ดูแลแยกแยะ Key โดยไม่แสดง Key เต็ม |
| `ExpiresAt` | `timestamptz` | ไม่ได้ | เวลา UTC ที่ใบอนุญาตหมดอายุ; เมื่อถึงเวลานี้ใช้ต่อไม่ได้ |
| `RevokedAt` | `timestamptz` | ได้ | เวลา UTC ที่ถอนใบอนุญาตก่อนหมดอายุ; null หมายถึงยังไม่มีการถอน |
| `CurrentBindingId` | `integer` | ได้ | ชี้ SchoolBotLicenseBinding ที่ผูกอยู่ปัจจุบัน; null หมายถึงไม่มี binding ปัจจุบัน และไม่ได้แปลว่า License หมดอายุ |
| `BindingEpoch` | `integer` | ไม่ได้ | เลขรุ่นของการผูกเครื่อง ใช้แยกสิทธิ์เครื่องก่อนและหลังย้ายเครื่อง; ไม่ใช่ row ID |
| `AllowedNextJkt` | `varchar(64)` | ได้ | ลายนิ้วมือ public key ของเครื่องที่ผู้ดูแลระบุให้ activate ครั้งถัดไป; null หมายถึงไม่ได้ระบุเครื่องถัดไปเฉพาะเจาะจง แต่ยังต้องตรวจประวัติเครื่องที่ถูกถอด |
| `IsDelete` | `boolean` | ไม่ได้ | ระบุว่าแถวถูกลบแบบเก็บประวัติหรือไม่; false = ยังใช้, true = ซ่อนจากการอ่านตามปกติ ไม่ใช่การลบข้อมูลถาวร; ค่าเริ่มต้นใน SQL = false |
| `CreateBy` | `integer` | ได้ | รหัสนักเรียน sId หรือบุคลากร sEmp ผู้สร้างรายการ; NULL = ระบบ/ผู้ทำที่ไม่มีรหัส profile นี้ เลขอย่างเดียวไม่บอกชนิดคน ให้ดู Actor ใน AuditEvent ประกอบ; ค่าเริ่มต้นใน DB = NULL |
| `CreateDate` | `timestamptz` | ได้ | วันเวลาสร้างรายการตามเวลา UTC จาก server; ค่าเริ่มต้นใน DB = NULL |
| `UpdateBy` | `integer` | ได้ | รหัสนักเรียน sId หรือบุคลากร sEmp ผู้แก้ล่าสุด; NULL = ระบบ/ผู้ทำที่ไม่มีรหัส profile นี้ ใช้กฎเดียวกับ CreateBy; ค่าเริ่มต้นใน DB = NULL |
| `UpdateDate` | `timestamptz` | ได้ | วันเวลาแก้ล่าสุด UTC จาก server; ใช้ตรวจว่ามีคนแก้แทรกก่อนบันทึกผ่าน ETag/If-Match แทนคอลัมน์ Version; ค่าเริ่มต้นใน DB = NULL |
| `SchoolId` | `integer` | ไม่ได้ | รหัสโรงเรียนที่ข้อมูลแถวนี้สังกัด; ไม่ใช่รหัสผู้ใช้ ดูขอบเขตส่วนกลาง/รายโรงเรียนที่ต้นหน้านี้ |

## ความสัมพันธ์เชิงตรรกะ (ไม่มี SQL FK)

| ฟิลด์ฝั่งนี้ | อ้างไปที่ |
|---|---|
| `CurrentBindingId` | [SchoolBotLicenseBinding](table-002.md) (`SchoolBotLicenseBindingId`) |

**ตารางที่อ้างกลับมา:** [SchoolBotLicenseBinding](table-002.md) (LicenseId)

ร่าง SQL คงเฉพาะ PK; ความสัมพันธ์/ความไม่ซ้ำ/เงื่อนไขข้อมูลในหน้านี้เป็นกฎฝั่ง application ไม่มี UNIQUE/FK/CHECK บังคับ และงานนี้ยังไม่เพิ่ม implementation ทดแทน. ชั้น application ต้องตรวจแถวอ้างอิง โรงเรียน และบริบทของข้อมูลเอง การอ้างฐานเดิมข้าม DB ดู [แผนที่ legacy](../data-legacy-001.md)
