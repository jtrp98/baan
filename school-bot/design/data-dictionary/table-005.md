# SchoolBotAuditEvent

[ตารางทั้งหมด](index.md) · [คู่มือภาพรวม](../data-model.md) · [ตารางเดิม](../data-legacy-001.md)

**หน้าที่:** เก็บร่องรอยว่าใครทำอะไรกับข้อมูล SchoolBot เพื่อย้อนตรวจเหตุการณ์

**หนึ่งแถว:** หนึ่งเหตุการณ์ของหนึ่ง resource; เป็นประวัติแบบ append-only

**ใช้ตอนไหน/ใครใช้:** API และ worker บันทึกเหตุการณ์ใน transaction ของ SchoolBot; ผู้มีสิทธิ์อ่านประวัติ

**ตัวอย่างสมมติ:** สมมติ: ครูยืนยันส่งคะแนนใบหนึ่ง และระบบบันทึกผู้ยืนยันกับ RequestId

**ขอบเขต:** รองรับทั้งส่วนกลาง (SchoolId=NULL) และรายโรงเรียน (SchoolId>0)

## ทุกฟิลด์ในตาราง

เรียงตาม SQL; “ว่างได้” หมายถึงเก็บ NULL ได้ ค่าจาก server ยังต้องผ่านกฎใน [สัญญาข้อมูล](../data-contract-rules.md)

| ฟิลด์ | ชนิดจริงใน SQL | ว่างได้ | เก็บอะไร / ใช้ทำอะไร |
|---|---|---|---|
| `SchoolBotAuditEventId` | `integer` | ไม่ได้ | รหัสแถวของ SchoolBotAuditEvent (PK); ฐานข้อมูลสร้างให้ ไม่รับรหัสจาก client; เป็น Primary Key ของตารางนี้; สร้างอัตโนมัติแบบ identity |
| `Actor` | `varchar(512)` | ไม่ได้ | ตัวตนผู้กระทำแบบมีชนิดและโรงเรียน แยกนักเรียน พนักงาน legacy admin เครื่อง และระบบได้ชัดกว่า CreateBy |
| `Event` | `varchar(64)` | ไม่ได้ | ชื่อเหตุการณ์หรือ operation ตาม DES เพื่อบอกว่าเกิดการสร้าง ยืนยัน ถอน หรือเปลี่ยนสถานะใด |
| `EntityType` | `varchar(64)` | ไม่ได้ | ชื่อตาราง SchoolBot ที่เหตุการณ์อ้างถึง ใช้ตีความ EntityId |
| `EntityId` | `integer` | ไม่ได้ | PK ของ resource ตาม EntityType; เป็น logical reference เพราะคอลัมน์เดียวอ้างได้หลายตาราง |
| `RequestId` | `uuid` | ไม่ได้ | UUID เชื่อมเหตุการณ์กับคำขอหรือกระบวนการเดียวกันสำหรับติดตามปัญหา |
| `Reason` | `varchar(1000)` | ไม่ได้ | เหตุผลหรือหลักฐานประกอบการกระทำ ไม่ใส่ password, Key, token, claims ทั้งก้อน หรือ source ของนักเรียน |
| `IsDelete` | `boolean` | ไม่ได้ | ระบุว่าแถวถูกลบแบบเก็บประวัติหรือไม่; false = ยังใช้, true = ซ่อนจากการอ่านตามปกติ ไม่ใช่การลบข้อมูลถาวร; ค่าเริ่มต้นใน SQL = false |
| `CreateBy` | `integer` | ได้ | รหัสนักเรียน sId หรือบุคลากร sEmp ผู้สร้างรายการ; NULL = ระบบ/ผู้ทำที่ไม่มีรหัส profile นี้ เลขอย่างเดียวไม่บอกชนิดคน ให้ดู Actor ใน AuditEvent ประกอบ |
| `CreateDate` | `timestamptz` | ไม่ได้ | วันเวลาสร้างรายการตามเวลา UTC จาก server |
| `UpdateBy` | `integer` | ได้ | รหัสนักเรียน sId หรือบุคลากร sEmp ผู้แก้ล่าสุด; NULL = ระบบ/ผู้ทำที่ไม่มีรหัส profile นี้ ใช้กฎเดียวกับ CreateBy |
| `UpdateDate` | `timestamptz` | ไม่ได้ | วันเวลาแก้ล่าสุด UTC จาก server; ใช้ตรวจว่ามีคนแก้แทรกก่อนบันทึกผ่าน ETag/If-Match แทนคอลัมน์ Version |
| `SchoolId` | `integer` | ได้ | รหัสโรงเรียนที่ข้อมูลแถวนี้สังกัด; ไม่ใช่รหัสผู้ใช้ ดูขอบเขตส่วนกลาง/รายโรงเรียนที่ต้นหน้านี้ |

## ความสัมพันธ์ที่ SQL บังคับจริง

ตารางนี้ไม่มี Foreign Key ขาออกใน SQL; การอ้างบัญชี/โรงเรียน/ผู้เรียนเดิมหรือรหัสใน JSON ต้องตรวจผ่าน application

การมี FK ภายใน SchoolBot ไม่ได้ตรวจ SchoolId ให้ทุกคู่โดยอัตโนมัติ ชั้น application ต้องตรวจโรงเรียนและบริบทของข้อมูลด้วย การอ้างฐานเดิมข้าม DB ดู [แผนที่ legacy](../data-legacy-001.md)
