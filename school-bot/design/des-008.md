# DES-008 — Mapping หลักสูตรกับช่องคะแนน SchoolBright

> Rev 6 · แก้ล่าสุด 2026-11-02 · แก้โดย arch · ขอโดย ผู้ใช้ (มติ 044 — SQL constraints เหลือเฉพาะ Primary Key)

สัญญานี้กำหนดให้ admin โรงเรียนถือครองช่องคะแนนเดิมและสร้าง mapping จาก Activity ไป GradeSlot โดยครูอ่านได้ตามวิชาที่สอน

SchoolBot ทั้ง 32 ตารางคงเฉพาะ PRIMARY KEY ไม่มี SQL FOREIGN KEY, UNIQUE หรือ CHECK ตาม [มติ 044 (SQL constraints เหลือเฉพาะ Primary Key)](../requirement/decisions-044.md) ความสัมพันธ์และการอยู่ `SchoolId` เดียวกันต้องตรวจที่ application ใน SchoolBot DB transaction เดียวกับการเขียน โดยการตรวจข้อมูลข้ามฐานยังใช้การ re-check ก่อน commit ตามสัญญาเดิม

## ยังไม่ยืนยัน

- สมมติฐาน — ยังไม่ยืนยัน ตาม [มติ 023 (writer คะแนน, ปัดเศษ, นำเข้า Sheet และเจ้าของ mapping)](../requirement/decisions-023.md)
- ตำแหน่งหน้าจอในโฟลเดอร์ school-bot ของ sb-tech-upgrade-web-system ยังไม่ยืนยัน ต้องให้ผู้รับผิดชอบเว็บยืนยัน.

## หลักฐาน

- ตรวจร่าง SQL ซ้ำ 2026-11-02: `db/schoolbot_db.sql:30–676` มี 32 ตารางและ PRIMARY KEY 32 รายการ; เมื่อตัดคอมเมนต์ออกไม่มี FOREIGN KEY, REFERENCES, UNIQUE หรือ CHECK ที่บังคับข้อมูล การตรวจนี้ไม่ใช่ผลรันฐานข้อมูลหรือหลักฐาน application enforcement
- [มติ 044 (SQL constraints เหลือเฉพาะ Primary Key)](../requirement/decisions-044.md) ยืนยันให้ความสัมพันธ์และ validation เป็นกฎของ application
