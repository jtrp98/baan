# DES-007 — Release และ trusted update

> Rev 5 · แก้ล่าสุด 2026-11-03 · แก้โดย arch · ขอโดย ผู้ใช้ (มติ 054 — approval_ref/evidence_ref ไม่เกิน 1,000 ตัวอักษรและไม่ขยาย schema)

สัญญานี้กำหนด release manifest ที่เชื่อถือได้ การตรวจ ดาวน์โหลด เตรียมติดตั้ง และกู้คืน โดยแยกการกระทำของผู้ใช้แต่ละขั้น

การบันทึก `evidence_ref:T1000` ใช้ Reason ของ Release.Published ตรงตัว และให้ withdraw อ่าน evidence จาก event เดิม ตาม [storage ร่วม](audit-evidence-storage-001.md) และ [มติ 054 (จำกัดเลขอ้างอิงไม่เกิน 1,000 ตัวอักษรโดยไม่ขยาย schema)](../../shared/decisions/decisions-054.md) เกิน 1,000 ตัวอักษร → `400 INVALID_INPUT` ไม่ตัดข้อความหรือเก็บ hash แทน [ไม่มี migration](audit-evidence-migration-001.md) และไม่เพิ่ม evidence ลง manifest/public check
