# DES-005 — หลักสูตร ภารกิจ และผลประเมิน

> Rev 11 · แก้ล่าสุด 2026-11-03 · แก้โดย arch · ขอโดย ผู้ใช้ (ใบงาน 096 — ตัดสินข้อค้าง importer จาก schema และโค้ดจริง)

สัญญานี้กำหนดหลักสูตรกลางแบบ Level และ Activity การส่ง immutable project revision การประเมินอัตโนมัติหรือโดยครู และความคืบหน้าของผู้เรียน

รายละเอียดร่างหลักสูตรอยู่ใน [การอ่านและแก้ร่าง](learning-curriculum-draft-001.md), [การนำเข้า Sheet](learning-sheet-import-001.md) และ [typed manifest ผ่าน gRPC](learning-grpc-manifest-001.md) การทำงานด้วย local fake ทำได้เฉพาะขอบเขตที่ระบุ ส่วน `approval_ref:T1000` สำหรับ publish เก็บตรงตัวใน Reason เดิมตาม [สัญญา storage ร่วม](audit-evidence-storage-001.md) และ [มติ 054 (จำกัดเลขอ้างอิงไม่เกิน 1,000 ตัวอักษรโดยไม่ขยาย schema)](../../shared/decisions/decisions-054.md) เกิน 1,000 ตัวอักษร → `400 INVALID_INPUT` ไม่ตัดข้อความหรือเก็บ hash แทน [ไม่มี migration](audit-evidence-migration-001.md) ส่วน import รอ human gate ด้าน storage ตามคำตัดสินด้านล่าง ผลรับกฎ learning/คะแนนที่ต้องใช้ก่อน freeze อยู่ใน [การเทียบแบบปัจจุบัน](learning-design-reconciliation-001.md).

Course Plan importer ตรวจได้เฉพาะ transformation/preview ในขณะนี้: schema Rev8 ไม่มี provenance/D ราย Lesson และ mutation/read model เดิมไม่ส่งค่าดังกล่าว อ่าน [คำตัดสิน storage, operation, persisted state และประตูระบบจริง](des-005-import.md) ก่อนเปิดงาน persistence
