# DES-005 — หลักสูตร ภารกิจ และผลประเมิน

> Rev 12 · แก้ล่าสุด 2026-11-03 · แก้โดย arch · ขอโดย ผู้ใช้ (ใบงาน 097 — ตรึงสัญญา importer BE-028 บน migration-002 Rev2)

สัญญานี้กำหนดหลักสูตรกลางแบบ Level และ Activity การส่ง immutable project revision การประเมินอัตโนมัติหรือโดยครู และความคืบหน้าของผู้เรียน

รายละเอียดร่างหลักสูตรอยู่ใน [การอ่านและแก้ร่าง](learning-curriculum-draft-001.md), [การนำเข้า Sheet](learning-sheet-import-001.md) และ [typed manifest ผ่าน gRPC](learning-grpc-manifest-001.md) การทำงานด้วย local fake ทำได้เฉพาะขอบเขตที่ระบุ ส่วน `approval_ref:T1000` สำหรับ publish เก็บตรงตัวใน Reason เดิมตาม [สัญญา storage ร่วม](audit-evidence-storage-001.md) และ [มติ 054 (จำกัดเลขอ้างอิงไม่เกิน 1,000 ตัวอักษรโดยไม่ขยาย schema)](../../shared/decisions/decisions-054.md) เกิน 1,000 ตัวอักษร → `400 INVALID_INPUT` ไม่ตัดข้อความหรือเก็บ hash แทน [ไม่มี migration](audit-evidence-migration-001.md) ผลรับกฎ learning/คะแนนที่ต้องใช้ก่อน freeze อยู่ใน [การเทียบแบบปัจจุบัน](learning-design-reconciliation-001.md).

Course Plan importer (BE-028) นำเข้าแถวที่ normalize แล้วลง draft revision ด้วย `POST /v2/admin/curricula/{id}/import` เก็บที่มาและค่า D ราย Lesson ใน `SchoolBotLesson.ImportSource` (jsonb NULL จาก migration-002 Rev2 ที่ผู้ใช้อนุญาตให้เพิ่มเฉพาะคอลัมน์ ยังไม่รัน SQL) กฎรูปทรงและการกันนำเข้าซ้ำอยู่ฝั่ง application ทั้งหมด อ่าน [สัญญา importer](des-005-import.md) และ [persisted state, stub และประตูระบบจริง](des-005-import-state.md)

| ส่วนของ importer | เนื้อหา |
|---|---|
| [สัญญา importer](des-005-import.md) | รูป ImportSource, การอ่านกลับ, endpoint/Operation/hash, การค้นก่อนเขียน |
| [persisted state และประตู](des-005-import-state.md) | ผลที่คาดราย case, stub vs PostgreSQL, ความเสี่ยงที่ไม่มี constraint |
| [ผลเทียบกับโค้ดจริง](des-005-import-evidence.md) | as-built และสิ่งที่ BE-028 ต้องเปลี่ยน |
