## Scope

ดำเนินงาน ทบทวน threat/trust ภายในขอบเขต references และส่ง outputs ที่ระบุด้านล่าง รักษาพฤติกรรมที่ไม่เกี่ยวข้องและกติกา repository ผู้ลงมืออ่าน README/เอกสาร/as-built เฉพาะส่วนก่อนแก้จริง แยกข้อเท็จจริง ข้อเสนอ และสิ่งรอยืนยัน ตรวจ preconditions ตาม Dependencies และ [gates](../../../knowledge/school-bot/plan/gates-001.md) ก่อนส่วนที่พึ่งพา; ส่วนอิสระเดินต่อได้ DBA เตรียม SQL/rollback และตรวจ human-provided SQL/catalog evidence เท่านั้น ไม่รัน SQL เอง งาน robot ใช้ dry-run จนมีคำสั่งอนุญาตทดสอบอุปกรณ์จริง

## Out of Scope

งานนอก outputs/AC/references ของ task นี้ การเลือกนโยบายธุรกิจหรือเซ็นอนุมัติแทนคน การเพิ่มหรือตัด frozen release scope และ speculative feature ห้ามแก้ข้ามเขต Owns ของ role ห้าม state-changing git หรือเรียก role ต่อเอง Shared SQL/deploy/publish, installer tests และการเปลี่ยนสถานะหุ่นต้องมีหลักฐานอนุญาตเฉพาะตาม gate ไม่ถือว่าได้สิทธิ์จากการรับแผน

## Expected Output

- security review pack

ส่ง artifact จริงในเขต Owns ของ role พร้อม references ที่ตรวจย้อนกลับได้ ไม่สร้างสำเนาเอกสารข้ามหมวด หากมีไฟล์เดิมให้ amend พร้อม Change Log วันที่ 2026-10-21

**AC (ข้อความตามต้นฉบับ):**

- [AC-027-01](../../../knowledge/school-bot/requirement/req-027.md) เมื่อระบบยืนยันตัวตนพนักงานที่ `/v2/admin` ยังไม่ถูกตั้งค่า (เดิมเรียก "ไม่ตั้ง admin key") เรียก admin API ได้ 503; ไม่มี staff session หรือ session/token ไม่ถูกต้อง (เดิมเรียก "token หายหรือผิด") ได้ 401; มี session แต่ไม่มีบทบาท StaffRole ที่ active ซึ่งมีสิทธิ์จัดการ License ได้ 403; เรียก `/v1/admin` ด้วย static bearer แล้วไม่สามารถสร้างหรือดูรายการ License ได้
- [AC-028-01](../../../knowledge/school-bot/requirement/req-028.md) เปิดใช้ Key เดียวบนเครื่อง A ซ้ำได้; ขณะยังผูกกับ A การเปิดใช้บน B ถูกปฏิเสธด้วย DEVICE_LIMIT
- [AC-028-03](../../../knowledge/school-bot/requirement/req-028.md) หลัง revoke หรือถึงเวลาหมดอายุ ทั้ง activate และ validate ถูกปฏิเสธว่า license inactive
- [AC-030-04](../../../knowledge/school-bot/requirement/req-030.md) การเตรียมอัปเดตเริ่มเฉพาะเมื่อผู้ใช้สั่งเอง และตรวจ trust ครบ (hash ตรง manifest จาก registry + publisher pin ตาม DES-007) ก่อนเก็บลง staging — ตรวจไม่ผ่านต้องไม่มี artifact ถูกเก็บหรือติดตั้ง และผู้ใช้เห็นเหตุผลการปฏิเสธ
- [AC-030-05](../../../knowledge/school-bot/requirement/req-030.md) artifact ใน staging ถูกตรวจความสมบูรณ์ซ้ำ (กัน TOCTOU) ตอนสั่งติดตั้ง — ผิด/เปลี่ยน/หมดอายุ/ถูก withdraw หรือเก่ากว่าที่ติดตั้งอยู่ (downgrade) ต้องปฏิเสธพร้อมข้อความ ไม่ติดตั้ง
- [AC-034-06](../../../knowledge/school-bot/requirement/req-034.md) ได้ผล Key ไม่ Active แล้วไม่ต่อสิทธิ์หรือใช้ค่าเดิมข้ามผลปฏิเสธเพื่อปลดล็อก
- [AC-035-01](../../../knowledge/school-bot/requirement/req-035.md) ผู้ไม่มีสิทธิ์ผู้ดูแลขอปลดเครื่องแล้วถูกปฏิเสธ และการผูกเครื่องไม่เปลี่ยน
- [AC-035-04](../../../knowledge/school-bot/requirement/req-035.md) หลัง Key ผูกกับ B แล้ว A ตรวจออนไลน์ไม่ผ่านและไม่ได้สิทธิ์ออฟไลน์รอบใหม่
- [AC-036-06](../../../knowledge/school-bot/requirement/req-036.md) เมื่อสั่งออกจากระบบของบัญชี Login ระบบยกเลิกเซสชันเฉพาะคำขอนั้นผ่านช่องทางที่ได้รับอนุญาตโดยไม่กระทบสิทธิ์ License ของเครื่อง; หากคำขอไม่มีเซสชันหรือข้อมูลเซสชันไม่สมบูรณ์ ระบบจบคำขอโดยไม่เกิดผลข้างเคียง และเมื่อคำขอไม่ผ่านเกณฑ์ความปลอดภัย เกินขีดจำกัด หรือบริการขัดข้อง ระบบปฏิเสธและแจ้งผลโดยไม่รั่วไหลข้อมูลลับหรือรายละเอียดภายใน
- [AC-038-05](../../../knowledge/school-bot/requirement/req-038.md) ครูตรวจ Arm ของนักเรียนนอกรายชื่อที่ได้รับมอบหมายหรือข้ามโรงเรียนไม่ได้ แม้อยู่ห้องเดียวกันหรือรู้รหัสงาน; ผลเดิมไม่เปลี่ยน
