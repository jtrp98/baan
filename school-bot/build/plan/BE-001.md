## Scope

ตรวจ legacy auth จาก source เดิมตาม ตรวจ legacy auth จาก source เดิม เพื่อพิสูจน์ username lookup/normalization, password encoding/hash/verification, active flags, account-profile mapping, SchoolId/tenant และ role/scope rules จัด sanitized fixtures กับ source:line ไม่อ่านหรือเผยรหัสจริง ไม่เชื่อม DB/รัน SQLเพื่อหาคำตอบในงานนี้ ไม่เดาว่า account ID เท่ากับ student/employee ID และไม่สร้าง SchoolBotUser/mapping table ชดเชย หากหลักฐานไม่พอให้ระบุ source/fixture ที่ต้องหาเพิ่มและส่งเจ้าของระบบเดิมด้านเทคนิค ไม่ผลักข้อเท็จจริง algorithm เป็นคำถามธุรกิจ

## Out of Scope

งานนอก outputs/AC/references ของ task นี้ การเลือกนโยบายธุรกิจหรือเซ็นอนุมัติแทนคน การเพิ่มหรือตัด frozen release scope และ speculative feature ห้ามแก้ข้ามเขต Owns ของ role ห้าม state-changing git หรือเรียก role ต่อเอง Shared SQL/deploy/publish, installer tests และการเปลี่ยนสถานะหุ่นต้องมีหลักฐานอนุญาตเฉพาะตาม gate ไม่ถือว่าได้สิทธิ์จากการรับแผน

## Expected Output

- compatibility matrix/fixtures

ส่ง artifact จริงในเขต Owns ของ role พร้อม references ที่ตรวจย้อนกลับได้ ไม่สร้างสำเนาเอกสารข้ามหมวด หากมีไฟล์เดิมให้ amend พร้อม Change Log วันที่ 2026-10-21
