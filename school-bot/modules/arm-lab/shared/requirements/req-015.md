# REQ-015 — โปรไฟล์หุ่นหกข้อต่อ

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

ให้ค่าที่แสดงในแอปสัมพันธ์กับการตั้งค่า servo ของอุปกรณ์เป้าหมาย. การตรวจรูปแบบโปรไฟล์ยังไม่ใช่ผล calibration ทางกายภาพ.

PWM (Pulse Width Modulation) คือค่าพัลส์ควบคุม servo.

## Business Rules

- BR-015-01: โปรไฟล์ต้องมีชื่อและ servo ครบหกตัวตามช่วงที่รองรับ
- BR-015-02: ยอมรับปลาย PWM กลับทิศ แต่ห้ามเท่ากัน
- BR-015-03: การกดยืนยันโปรไฟล์ไม่ใช่หลักฐานว่าผ่าน calibration ทางกายภาพ

## Acceptance Criteria

- AC-015-01: โปรไฟล์ที่มี ID ซ้ำ, servo ไม่ครบหก, PWM นอกช่วง หรือปลาย PWM เท่ากัน ถูกปฏิเสธก่อนเชื่อมต่อ
- AC-015-02: โปรไฟล์ที่ถูกต้องและกำหนด PWM กลับทิศผ่านการตรวจรูปแบบได้
- AC-015-03: เมื่อแก้ชื่อโปรไฟล์หรือค่า servo หลังยืนยัน ต้องยืนยันใหม่ก่อนเชื่อมต่อ

## ยังไม่ยืนยัน

- เจตนาทางธุรกิจที่กลั่นจากฐานเดิมยังไม่ยืนยัน: ให้ค่าที่แสดงในแอปสัมพันธ์กับการตั้งค่า servo ของอุปกรณ์เป้าหมาย ต้องให้เจ้าของผลิตภัณฑ์ยืนยันเจตนานี้ โดยแยกจากกฎหรือเกณฑ์ที่มีมติยืนยันแล้ว
