# REQ-011 — บันทึกและเปิดหลายโครงงาน

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

ให้บันทึกและเลือกเปิดหลายโครงงานในแต่ละโหมดได้ทั้ง Guest และ Login ตาม [มติ 009 (หลายโครงงานและผู้ประเมินภารกิจ — 2026-10-21)](../../../../shared/decisions/decisions-009.md). งานแต่ละชิ้นต้องไม่แทนกันโดยอัตโนมัติ และตำแหน่งเก็บแยกตาม [REQ-036 (Guest Local และ Login Cloud)](../../../app-shell/shared/requirements/req-036.md).

JSON (JavaScript Object Notation) คือรูปแบบข้อมูลที่บันทึกหรือรับส่ง.

## Business Rules

- BR-011-01: Block / Arm / Code มีหลายโครงงานต่อโหมดได้ทั้ง Guest/Login; บันทึกงานหนึ่งไม่แทนอีกงานโดยอัตโนมัติ ข้อจำกัดหนึ่ง slot ของโค้ดเดิมต้องเปลี่ยน
- BR-011-02: ปฏิเสธ JSON เสียหรือเกินขนาด; ไม่มีไฟล์ให้รายงานว่าไม่มีงาน
- BR-011-03: ย้ายข้อมูลเดิมโดยไม่ทับข้อมูลใหม่และไม่ลบต้นฉบับ

- BR-011-04: Guest ใช้พื้นที่ร่วม เก็บ/ส่งออก/กู้คืนตาม [REQ-040 (พื้นที่ร่วมและถังขยะ Guest)](req-040.md); เลือกนำเข้า Login ตาม [REQ-041 (เลือกนำเข้าโครงงาน Guest)](req-041.md)

## Acceptance Criteria

- AC-011-01: บันทึกอย่างน้อยสองงานต่อโหมด Block/Arm/Code ทั้ง Guest และ Login แล้วเลือกเปิดแต่ละงานได้ครบและไม่ปะปนกัน
- AC-011-02: บันทึกการแก้ไขงาน A แล้วเปิดใหม่ได้ค่าล่าสุดของ A โดยงาน B ในโหมดเดียวกันไม่เปลี่ยน
- AC-011-03: เปิดไฟล์ JSON เสียหรือเกิน 1 MiB แล้วมีข้อผิดพลาด; ไม่แสดงว่าเปิดสำเร็จ
- AC-011-04: เมื่อมีข้อมูลทั้งชื่อแอปเก่าและใหม่ การเริ่มแอปไม่ทับข้อมูลใหม่; เมื่อปลายทางยังไม่มี ข้อมูลเก่าที่ถูกต้องถูกคัดลอกและต้นฉบับยังอยู่

## ยังไม่ยืนยัน

ไม่มีสมมติฐานเพิ่มเติมที่ระบุไว้ในข้อกำหนดฉบับเดิม; การมีข้อกำหนดไม่ใช่หลักฐานว่า implementation ผ่านการตรวจรับแล้ว
