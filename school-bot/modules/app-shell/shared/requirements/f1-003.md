**แถบหน้าต่าง (R2–R5)** [Observed ใน FRM-05 ที่ผู้ใช้อนุมัติ 2026-10-21]
- สูง 60 (เดิม 44 · 2026-10-22) · Windows ปุ่ม ย่อ/ซ่อน/ปิด ขวา (ลำดับใหม่ 2026-10-22) ขนาด 48×44 · Mac **ปุ่มระบบจริงของ macOS 100%** (วงกลมแดง/เหลือง/เขียว ตามภาพอ้างอิงของผู้ใช้ · ถ้า dev ใช้ปุ่ม native ได้ไม่วาดเอง · แก้ 2026-10-30 ตาม block-lab R20 (2) · brand §11.5 · ยกเลิกวงกลม 28 และพื้นที่กด 40×44/44×44 AUD-F05 เฉพาะปุ่มนี้) ปุ่ม ปิด/ย่อ/ซ่อน ซ้าย
- สีปุ่ม Mac: ตามระบบ macOS (ไม่ใช้สีแบน #FF5F57/#FEBC2E/#28C840 และไอคอน #14243D ของ DSG-11 เดิม · ยกเลิก 2026-10-30) · ข้อยกเว้นเฉพาะปุ่มนี้: ไม่ต้องเป้ากด ≥ 44 และความต่างสี 3:1 เพราะเป็นปุ่มของระบบ (brand §11.5) · ปุ่ม Windows ยังใช้ไอคอน Lucide inline เส้น 2.4
- ซ่อน = arrow-down-to-line (Windows) / arrow-up-to-line (Mac) ตามตำแหน่ง tray / menu bar · ไอคอนซ่อนบน Windows หน้าเหมือน "ดาวน์โหลด" และ Mac ใช้ปุ่มเขียว (ธรรมเนียม macOS = เต็มจอ) → ดู AUD-F04, OQ3
- ป้ายสถานะบันทึก (ไอคอน + ข้อความ 16px): "บันทึกขึ้นคลาวด์แล้ว" / "กำลังบันทึกขึ้นคลาวด์" / "ไม่มีเน็ต · เก็บงานในเครื่องไว้ก่อน" / "บันทึกขึ้นคลาวด์ไม่สำเร็จ" → popover กว้าง 330 + ปุ่ม "ลองอีกครั้ง" (เมื่อไม่สำเร็จ) + รหัส E-CLOUD · ปิด popover ด้วย Esc หรือแตะข้างนอก
- ชิปอุปกรณ์: popover แสดงพอร์ตและรหัส error (เช่น E-USB) · กดชิป → หน้าเชื่อมต่อของ lab นั้น (Proposed)
- ซ่อน/ย่อ → การแจ้งจำลอง (prototype) · ปิดตอนหุ่นขยับ → dialog หยุดหุ่นแล้วปิด · ปิดตอนยังไม่ขึ้นคลาวด์ → แจ้งงานอยู่ในเครื่อง · dialog ใช้ z-dialog เว้นแถบล่าง 76px (สูง 764 ใน 840 · เดิม 780 ใน 856)
- ภาษา th/en/zh · zh ใช้ IBM Plex Sans SC (DSG-02) · prop สำหรับ import: robotMoving, onRetry, onStopRobot (preview=false)
- **ห้ามให้แถบหน้าต่างอยู่เหนือปุ่มหยุด:** ชั้นเดิม z 80 สูงกว่า `z-stop` 70 → ผู้ใช้ตัดสินทาง ก (CR-10): ลดชั้นแถบให้ต่ำกว่า `z-stop` + ฉากหลัง dialog/popover ของแถบเว้นปุ่มหยุด + tooltip ไม่ทับปุ่มหยุด + เพิ่มชั้นแถบหน้าต่างในตาราง D-18 · ใช้กติกาเดียวกันทุกหน้าที่ import แถบ

**Login (R6)**
- AC-03: **Given** บัญชีถูกต้อง **When** เลือกโรงเรียน กรอก username และ password **Then** เข้าหน้าหลักได้ · **When** กรอกผิด **Then** เห็นข้อความบอกวิธีแก้ (ภาษาเด็ก + รหัส error)
- ไม่มีเน็ตตอน login → "ต่อเน็ตแล้วลองใหม่" (ST-04) · ค้นหาโรงเรียนไม่พบ → "ตรวจคำค้น / ถามครู" (ST-06)
- WCAG 3.3.8: ไม่บังคับให้จำ/ถอดรหัส ต้องวางรหัสหรือใช้ตัวช่วยได้ · ช่องกรอกมี label (DSG-04)

**หน้าหลัก (R7)** · AC-04: **When** login แล้ว **Then** แสดง sidebar 4 เมนู ส่วนเรียนต่อ งานล่าสุด และความสำเร็จ

- งานล่าสุด: 2 กลุ่ม หัวกลุ่มมีไอคอนสีประจำแอป (D-04) + "ดูทั้งหมด →" ไปหน้างานของโปรแกรมนั้น (my-work) · **กลุ่มละไม่เกิน 3 ใบ** เรียงเวลาแก้ล่าสุด (ผู้ใช้ตัดสิน 2026-10-21) · กลุ่มว่าง = ข้อความ + ปุ่มรอง "ไปที่ Arm Lab / Block Lab" (ไม่ใช่ปุ่มสร้าง) · ไม่มีช่องค้นหางานทุกประเภท (ตัดแล้ว EDIT-06)
