# REQ-034 — ตรวจ License ออนไลน์และสิทธิ์ออฟไลน์ 3 วัน

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

ผู้ใช้ต้องตรวจ License ออนไลน์สำเร็จก่อนเริ่มใช้แอป และใช้ออฟไลน์ได้ 3 วันจากการตรวจสำเร็จล่าสุด เมื่อครบกำหนดต้องตรวจ Key เดิมอีกครั้ง เพื่อไม่ให้สิทธิ์ในเครื่องข้ามผลปฏิเสธหรือการเพิกถอนจากเซิร์ฟเวอร์

## Business Rules

- BR-034-01: ครั้งแรกต้องตรวจ License ออนไลน์สำเร็จ ไม่ใช้ Key ที่เพียงกรอกไว้ปลดล็อก
- BR-034-02: เก็บสิทธิ์ที่ตรวจผ่านและข้อมูลสำหรับส่ง Key เดิมตรวจใหม่ในเครื่อง
- BR-034-03: สิทธิ์ออฟไลน์ใช้ได้ 3 วันนับจากการตรวจออนไลน์สำเร็จล่าสุด การเปิดแอปไม่ต่ออายุสิทธิ์
- BR-034-04: ครบกำหนดต้องตรวจออนไลน์ใหม่; Active จึงต่อสิทธิ์ได้อีก 3 วัน
- BR-034-05: ตรวจไม่ได้เมื่อสิทธิ์ครบกำหนด หรือได้ผลไม่ Active ไม่ปลดล็อกแอป; ผลที่ยืนยันว่า License ใช้ไม่ได้มีผลเหนือค่าที่เก็บเดิม
- BR-034-06: ใช้กับทั้งสามโหมด รวม Guest/Login; ไม่ใช้สิทธิ์ที่รู้ว่าหมดอายุหรือถูกเพิกถอน

## Acceptance Criteria

- AC-034-01: ครั้งแรกไม่มีอินเทอร์เน็ต เข้าโหมดหลักไม่ได้แม้กรอก Key แล้ว
- AC-034-02: ตรวจออนไลน์ได้ Active แล้วเข้าใช้งานได้และมีสิทธิ์ในเครื่อง
- AC-034-03: ออฟไลน์ภายใน 3 วันจากตรวจสำเร็จล่าสุดใช้งานได้; เปิดซ้ำไม่เลื่อนวันสิ้นสุด
- AC-034-04: ครบ 3 วันและติดต่อเซิร์ฟเวอร์ไม่ได้ เข้าโหมดหลักไม่ได้และแจ้งให้ต่ออินเทอร์เน็ต
- AC-034-05: ตรวจ Key เดิมออนไลน์ได้ Active อีกครั้ง แล้วต่อสิทธิ์ 3 วันจากการตรวจครั้งใหม่
- AC-034-06: ได้ผล Key ไม่ Active แล้วไม่ต่อสิทธิ์หรือใช้ค่าเดิมข้ามผลปฏิเสธเพื่อปลดล็อก

## ยังไม่ยืนยัน

ไม่มีข้อสมมติฐานหรือคำถามธุรกิจที่ยังไม่ยืนยันเพิ่มเติมในข้อกำหนดนี้

## หลักฐาน
