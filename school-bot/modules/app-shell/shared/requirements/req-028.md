# REQ-028 — Activate, validate และจำกัดอุปกรณ์

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

ให้ตรวจ License ก่อนอนุญาตใช้แอปและจำกัดหนึ่งเครื่องต่อ Key ตามคำตอบผู้ใช้. เครื่องเดิมเปิดใช้ซ้ำได้ แต่เครื่องอื่นใช้ Key ที่ยังผูกกับเครื่องเดิมไม่ได้.

## Business Rules

ที่มา: คำตอบผู้ใช้ 2026-10-21 ดู [มติ 004 (License และมาตรฐานชื่อข้อมูล — 2026-10-21)](../../../../shared/decisions/decisions-004.md)

- BR-028-01: 1 Key ใช้ได้ 1 เครื่อง เปิดใช้ซ้ำจากเครื่องเดิมได้ แต่เครื่องอื่นใช้ Key ที่ยังผูกกับเครื่องเดิมไม่ได้ ตาม [มติ 006 (จำนวนเครื่องต่อ License — 2026-10-21)](../../../../shared/decisions/decisions-006.md)
- BR-028-02: Validate ไม่เพิ่มอุปกรณ์ ต้อง activate ก่อน
- BR-028-03: ไม่ใช้ License ที่ระบบยืนยันว่าไม่ถูกต้อง หมดอายุ หรือถูกเพิกถอนเพื่อปลดล็อกแอป; ไม่อนุญาต bypass ด้วย Guest
- BR-028-04: ตรวจออนไลน์และสิทธิ์ 3 วันตาม [REQ-034 (ตรวจ License ออนไลน์และสิทธิ์ออฟไลน์ 3 วัน)](req-034.md); ผู้ดูแลปลด/ย้ายตาม [REQ-035 (ผู้ดูแลปลดเครื่องและย้าย Key เดิม)](req-035.md) รวมข้อยกเว้นสิทธิ์ออฟไลน์เดิม

## Acceptance Criteria

- AC-028-01: เปิดใช้ Key เดียวบนเครื่อง A ซ้ำได้; ขณะยังผูกกับ A การเปิดใช้บน B ถูกปฏิเสธด้วย DEVICE_LIMIT
- AC-028-02: Validate device ที่ยังไม่ activate ได้ DEVICE_NOT_ACTIVATED; หลัง activate สำเร็จ validate ผ่าน
- AC-028-03: หลัง revoke หรือถึงเวลาหมดอายุ ทั้ง activate และ validate ถูกปฏิเสธว่า license inactive
- AC-028-04: เมื่อลองเปิดใช้ด้วย License ไม่ถูกต้องและไม่เคยมีสิทธิ์ที่ใช้ได้ แอปไม่ปลดล็อกโหมดหลัก และผู้ใช้สามารถกลับไปกรอก License ใหม่ได้

## ยังไม่ยืนยัน

ไม่มีสมมติฐานเพิ่มเติมที่ระบุไว้ในข้อกำหนดฉบับเดิม; การมีข้อกำหนดไม่ใช่หลักฐานว่า implementation ผ่านการตรวจรับแล้ว
