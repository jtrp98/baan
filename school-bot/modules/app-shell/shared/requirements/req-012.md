# REQ-012 — ออกจากงานและปิดหน้าต่าง

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

ลดการออกจากงานโดยไม่ตั้งใจและพยายามหยุดงานหุ่นก่อนปิด. เส้นทาง Save แล้วออกต้องรอให้บันทึกสำเร็จ.

## Business Rules

- BR-012-01: คำยืนยันเปลี่ยน mode ไม่ได้พิสูจน์ว่าบันทึกงานแล้ว
- BR-012-02: เส้นทาง Save แล้วออกต้องรอ Save สำเร็จ
- BR-012-03: การเตรียมปิดล้มเหลวต้องไม่แสดงว่าปิดสำเร็จ; stop เป็นเพียงคำขอ ตาม [REQ-021 (ขอหยุดหุ่นและยกเลิกงานค้าง)](../../../arm-lab/shared/requirements/req-021.md)

## Acceptance Criteria

- AC-012-01: เมื่ออยู่ระหว่างทำงานใน mode แล้วเลือก mode อื่น มีคำยืนยัน; เลือกยกเลิกแล้วอยู่ที่เดิม
- AC-012-02: เมื่อเลือก Save แล้วออกและจำลอง storage ล้มเหลว หน้ายังไม่ออกและมีข้อความบันทึกล้มเหลว
- AC-012-03: เมื่อจำลอง close guard ล้มเหลว หน้าต่างยังเปิดและแสดงเหตุผลให้ผู้ใช้เห็น

## ยังไม่ยืนยัน

- เจตนาทางธุรกิจที่กลั่นจากฐานเดิมยังไม่ยืนยัน: ลดการออกจากงานโดยไม่ตั้งใจและพยายามหยุดงานหุ่นก่อนปิด ต้องให้เจ้าของผลิตภัณฑ์ยืนยันเจตนานี้ โดยแยกจากกฎหรือเกณฑ์ที่มีมติยืนยันแล้ว
