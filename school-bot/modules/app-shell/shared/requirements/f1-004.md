## การตัดสินใจที่ผูกกับ module
DEC-01 ชื่อทางการ · DEC-03 login = โรงเรียน → username → password (CHG-02: เดิมใช้ "ID นักเรียน") · DEC-05 โปรแกรมติดตั้ง Win/Mac มีแถบหน้าต่างของตัวเอง (ปิด ย่อ ซ่อน) + installer ทันสมัย · DEC-06 UI เดียว ป.1–6 · DEC-08 HomeV6A ยังเป็นร่าง → FRM-01 ผู้ใช้อนุมัติ 2026-10-21 · DEC-14 ครูจัดการผ่านเว็บ (แอปไม่มีหน้าจัดการครู) · DEC-19 ไม่มีตัวช่วยเพิ่ม ป.1–3 · DEC-29/30 มาสคอต

## Edge cases
- ไม่มีเน็ตตอนเปิดโปรแกรม/login (ST-04): login ต้องออนไลน์ ต้องต่อเน็ตก่อน · หลัง login ทำงานต่อออฟไลน์ได้ แถบแสดง "ไม่มีเน็ต · เก็บงานในเครื่องไว้ก่อน" (ดู my-work · ARC-I05)
- ลืม password หรือ login ผิด (EC-02): นักเรียน → "บอกครูให้ช่วยรีเซ็ต" (Proposed) · ครู → ไปที่ SchoolBright (DEV-Q09 Answered)
- ติดตั้งไม่สำเร็จ (ST-02): ไม่มีสิทธิ์ / พื้นที่ไม่พอ → บอกสาเหตุ + ลองใหม่
- ปิดโปรแกรมระหว่างหุ่นกำลังขยับ หรือก่อนขึ้นคลาวด์ (R5)
- ชื่อไทยยาวสุด ~30 ตัวอักษร · ภาษา EN/中文 ยาว +40% · ห้อง 45 คน/งาน 60 ชิ้น (ข้อมูลตัวอย่างทดสอบ layout) → ป้าย/ปุ่มต้องไม่ล้น
- นักเรียนเปลี่ยนเครื่อง (EC-04): เปิดงานต่อจาก cloud ได้ (my-work)
- เมื่อแถบหน้าต่างมี popover/dialog เปิดอยู่ ปุ่มหยุดทั้งหมดของ lab ต้องกดได้ครั้งแรก (R5)

คำถามที่ยังไม่ตัดสินอยู่ใน `../oq.md`
