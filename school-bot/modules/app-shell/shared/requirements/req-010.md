# REQ-010 — ภาษาของแอปและข้อมูลผู้ใช้

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

ให้เปลี่ยนภาษาใช้งานได้โดยไม่สูญเสียงาน. ข้อมูลและงานที่ผู้ใช้ทำค้างต้องคงเดิมเมื่อเปลี่ยนภาษา.

## Business Rules

- BR-010-01: ภาษาเริ่มต้นและ fallback เป็นไทย; รองรับอังกฤษและจีน
- BR-010-02: การเปลี่ยนภาษาไม่แปลชื่องาน ชื่อท่า ชื่อหุ่น source หรือ diagnostics ต้นทาง
- BR-010-03: ถ้าเก็บ preference ไม่ได้ ยังเปลี่ยนภาษาใน session ได้

## Acceptance Criteria

- AC-010-01: ผู้ใช้เปลี่ยนไทย/อังกฤษ/จีนได้โดยไม่ต่อเครือข่าย และข้อความควบคุมที่แปลไว้เปลี่ยนตาม
- AC-010-02: หลังเปลี่ยนภาษา งานที่ยังไม่บันทึก ลำดับบล็อก และข้อมูลที่ผู้ใช้ตั้งชื่อยังคงเดิม
- AC-010-03: เมื่อ storage ใช้งานได้ เปิดแอปใหม่แล้วใช้ภาษาที่เลือกครั้งล่าสุด; ถ้าไม่มีค่าที่รองรับ เริ่มด้วยภาษาไทย

## ยังไม่ยืนยัน

- เจตนาทางธุรกิจที่กลั่นจากฐานเดิมยังไม่ยืนยัน: ให้เปลี่ยนภาษาใช้งานได้โดยไม่สูญเสียงาน ต้องให้เจ้าของผลิตภัณฑ์ยืนยันเจตนานี้ โดยแยกจากกฎหรือเกณฑ์ที่มีมติยืนยันแล้ว
