## 7. ปิดหน้าต่าง / Save แล้วออก ([REQ-012 (ออกจากงานและปิดหน้าต่าง)](../../shared/requirements/req-012.md) + [AC-021-04 (เมื่อออกจาก native workspace ที่เชื่อมต่ออยู่ พบคำขอ stop แม้ไม่มีคำสั่งกำลังรอผล)](../../../arm-lab/shared/requirements/req-021.md))

ลำดับเมื่อกดปิดจากใน Lab: ยืนยัน → บันทึก (ถ้าเลือก) → ขอหยุดหุ่น → ปิด

## 8. a11y พื้นฐาน (int-001)

- คีย์บอร์ด: Tab ไล่ หัว→ช่อง Key→ปุ่ม ตามลำดับ; Enter ในฟอร์ม = ส่ง; Esc ปิดกล่องยืนยัน (ยกเว้น E1/E3 ที่เป็น blocking gate — ไม่มีทางออกให้กดข้าม) · **visible focus** ชัดเจนทุก interactive element (outline ที่เห็นได้ ไม่พึ่งสีอย่างเดียว) · เปิด dialog แล้ว focus ย้ายเข้าสู่ dialog ทันที ปิดแล้วคืน focus ไปยังปุ่มที่เปิด (focus management)
- ป้าย/ชื่อ: ทุกปุ่ม icon-only (ย่อ/เต็มจอ/ปิด) มี `aria-label` ไทย · ข้อความแจ้งเปลี่ยนสถานะใช้ `aria-live="polite"`; ข้อความบล็อก (E3) ใช้ `role="alert"`
- สี/ความคมชัด: ตัวหนังสือบนพื้น ≥ 4.5:1 (WCAG AA) · ไม่ใช้สีอย่างเดียวแยกสถานะ — มีไอคอน/ข้อความกำกับเสมอ (เช่น ป้ายออฟไลน์มีทั้งสีและคำ "ออฟไลน์")
- reduced-motion: `prefers-reduced-motion` ปิดอนิเมชันสแปลช/ทรานซิชัน
- ภาษา: copy หลักภาษาไทย ศัพท์เทคนิค/รหัส error เป็นอังกฤษในวงเล็บ (เช่น "(DEVICE_LIMIT)") เพื่อให้ผู้ดูแลสืบค้นต่อได้
