## กฎ/Logic (AC เดิมย่อ)
- AC-10: รายการบล็อกมีเฉพาะสิ่งที่ Uno ทำได้ และรูปทรงบอกหน้าที่ (มน/หกเหลี่ยม)
- AC-11: **When** เปิดดูโค้ดในโหมดบล็อก **Then** เห็น Arduino C++ ที่ตรงกับบล็อกและแก้ไม่ได้ (โหมดโค้ดแก้ได้ ดู AC-20) · ส่งลงบอร์ดและหยุดใช้ได้เมื่อเชื่อมต่อ Uno แล้ว
- AC-12: **When** กดทดสอบโดยไม่มีบอร์ด **Then** ตัวจำลองหรือ stage แสดงผลตามโปรแกรม · **Given** งานใหม่ **Then** ตัวจำลองเริ่มจาก Uno + breadboard เปล่าและต่อสายเองได้ · วงจรยังอยู่เมื่อเปิดงานอีกครั้ง
- AC-16: **When** จำลองแล้วอุปกรณ์เสีย **Then** การจำลองหยุด เห็นอุปกรณ์ที่เสีย สาเหตุ และปุ่มเปลี่ยนอุปกรณ์ใหม่ โดยไม่มีแสงกะพริบ · **When** กำลังจำลอง **Then** กดปุ่มกดหรือหมุน potentiometer ได้ทั้งเมาส์และคีย์บอร์ด และผลเปลี่ยนตาม
- AC-17: **When** โปรแกรมมี Serial print **Then** ข้อความแสดงในแผงข้อความจากบอร์ด ทั้งตอนจำลองและตอนต่อ Uno
- AC-18: **When** ส่งลง Uno และมีบล็อก Stage **Then** ส่งสำเร็จได้ และเห็นข้อความว่าบล็อกตัวละครทำงานเฉพาะในจอ · **When** กดส่งลงบอร์ด **Then** เห็นการเตือนให้ต่อสายจริงตามวงจรในจอ
- AC-20: **Given** อยู่ในโหมดโค้ดและแก้โค้ดแล้ว **When** สลับกลับโหมดบล็อก **Then** เห็นคำเตือนว่าโค้ดที่แก้ไม่กลับเป็นบล็อก · **When** กดส่ง/จำลองแล้วแปลงโค้ดไม่ผ่าน **Then** Output เปิดเองและบอก "ยังไม่ได้ส่ง" + บรรทัดที่ผิดและวิธีแก้ภาษา ป.3–4 (แก้ 2026-10-28) · **When** กดส่งลงบอร์ดแล้ว compile ไม่ผ่าน **Then** เห็น "แปลงโค้ดไม่ผ่าน (บรรทัด N)" และส่งไม่ได้ (OQ152)
- AC-21: **Given** โปรแกรมบล็อกใช้ "มีข้อความเข้ามา" **When** พิมพ์ข้อความใน terminal แล้วกด Enter **Then** ข้อความไปที่ตัวจำลองเมื่อกำลังจำลอง ไม่เช่นนั้นไป Uno และโปรแกรมอ่านได้ (OQ153)
- AC-19: มาสคอตในหน้าใดก็ตามใช้เฉพาะ 10 ท่า ข้อความกำกับบอกความหมายเสมอ ภาพตกแต่ง alt ว่าง ภาพที่มีความหมายมี alt ไม่กะพริบ
- ถ้อยคำ: Block Lab ใช้ **"ส่งลงบอร์ด"** (frame เดิมเขียน "ส่งลงหุ่น") · Arm Lab ใช้ "อัปโหลดลงบอร์ด" · ชื่อ "Block Lab" ห้าม "Block Studio"/"Code Lab" (CF-05, BUG-19)
- Block Lab ไม่ส่งคะแนนเข้า SchoolBright และไม่แสดงบนเว็บครู (DEC-18)
- UJ-04 (เส้นทางผู้ใช้): สร้างงาน → ต่อวงจรในตัวจำลอง (อิสระ) → ต่อบล็อก → ดูโค้ด C++ → ทดสอบในตัวจำลอง (กดปุ่ม/หมุนค่า ดูข้อความจากบอร์ด) หรือ stage → ต่อสายจริงตามวงจรในจอ → เชื่อม Uno → ส่งลงบอร์ด → หยุด

## การตัดสินใจที่ผูกกับ module
- DEC-10 Block Lab ใช้ Arduino Uno และแสดงโค้ด Arduino C++ · DEC-11 MVP มีตัวจำลองบอร์ดและ stage/แอนิเมชัน
- DEC-12 ~~Block Lab สั่งแขนกล~~ Superseded โดย DEC-17 · DEC-17 FR-21 นอก MVP ไม่มีหมวดบล็อกแขนกล (CR-02)
- DEC-20 หมวดบล็อก ~~10 หมวด~~ → 15 หมวด 3 กลุ่ม + ตัวละคร ตาม R18 (2026-10-28) (2026-10-22 · การจับคู่รายตัว Delegated → Designer + dev) · DEC-21 ต่อสายอิสระแบบ Tinkercad เริ่มจาก Uno + breadboard เปล่า · DEC-22 ความเสียหายสมจริง ห้ามกะพริบ/ระเบิด (ระดับ OQ-18)
- DEC-23 บล็อก Stage ทำงานเฉพาะในจอ ส่งลง Uno โดยข้ามและแจ้ง · DEC-24 Serial print ในแผงข้อความจากบอร์ด · DEC-25 ไม่มีภารกิจ (พื้นที่เล่นอิสระ) ตัดแถบภารกิจ
- DEC-26 ตัวละคร stage = มาสคอต School Bot · DEC-27 วงจรบันทึกกับงานบน cloud เป็นแบบให้ดู ตอนส่งลง Uno แจ้งให้ต่อสายจริงตามวงจร · DEC-28 โต้ตอบอุปกรณ์รับค่าและใช้คีย์บอร์ดได้
- DEC-29/30 (ร่วม) มาสคอตทั่วแอป 10 ท่า ห้ามดัดแปลง → `../../../../shared/context.md`
