## ส่วนที่คงจากรอบแรก
- **แผงภารกิจขวา** กว้าง 384 ลอย (เลือก node แล้วแผนที่เลื่อนให้ node อยู่ในพื้นที่ซ้าย 1,040px): ชิป "ภารกิจที่ n" + แท็ก "แบบทดสอบ" + สถานะ (ไอคอน+ข้อความ) · ชื่อ · คำอธิบาย · สิ่งที่ได้เรียนรู้ · วิธีทำ · รางวัล · ปุ่มหลักน้ำเงิน "เริ่มภารกิจ"/"เล่นอีกครั้ง" ปักล่าง
- **ด่านล็อก:** แผง "ยังเล่นภารกิจนี้ไม่ได้" + เหตุผล (ภารกิจก่อนหน้า ≥1 ดาว / ด่านแรกเทอม 2: ผ่านภารกิจที่ 22 ก่อน) + "ตอนนี้ไปถึงภารกิจที่ c" + ปุ่ม "ไปที่ภารกิจที่ c"
- **แถบตัวบอกเทอม:** กลับ · "เทอม 1 | เทอม 2" (เทอม 2 ล็อกมีไอคอน แตะแล้วเลื่อนไปดู + แผงเหตุผล) · "ผ่าน x/22 ภารกิจ" · ไปที่ฉัน · ‹ › เลื่อน 700px · เทอมที่เห็นตัดสินจากกลางพื้นที่ซ้ายเทียบจุดพัก
- **แผนที่ย่อ:** ธงจุดพัก/เส้นชัย · ส่วนที่ผ่านเขียว · จุดตำแหน่งปัจจุบัน · กรอบดำ = ช่วงที่เห็น · แตะ/ลูกศรซ้ายขวา
- **ฉลองจุดพัก:** dialog ดาว ≤3 ป๊อปครั้งเดียว + มาสคอตกอดหัวใจ + "ไปเทอม 2" · ปิดด้วยปุ่ม/Esc
- **สถานะ:** loading / contentFail / progFail (ไม่แสดงเหมือนครั้งแรก) · offline (ชิปบนแถบ) / offlineNoCache (ปุ่มเริ่ม aria-disabled + ข้อความ)
