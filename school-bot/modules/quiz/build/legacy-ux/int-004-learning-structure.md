# 1. ภาพรวม: โครง Course → Lesson → Activity (ข้อเสนอ)

> แก้ล่าสุด 2026-11-02 · แก้โดย int · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

ข้อกำหนดที่ใช้ในไฟล์นี้: [REQ-043 (หลักสูตรกลางแบบ Level และ Activity)](../../shared/requirements/req-043.md)

[กลับint-004-learning](int-004-learning.md) · ส่วนหนึ่งของ UX ชุดเดียวกับตาราง Sign-off ในไฟล์ทางเข้า


- ทางเข้า: ปุ่ม "บทเรียน" บน Home shell **แยกจากปุ่มสาม Labs** ([มติ 003 (โครงสร้างผลิตภัณฑ์ 3 โหมด)](../../../../shared/decisions/decisions-003.md), [BR-037-01 (บทเรียนใช้ Course → Lesson → Activity ตาม REQ-043)](../../shared/requirements/req-037.md)) — Q22 (บทเรียนและตัวกรองโหมด)
- โหมดอยู่ที่ Activity ไม่ใช่ Course: Lesson เดียวมีภารกิจได้หลายโหมด ([BR-043-04 (Mode อยู่ที่ Activity ภารกิจ)](../../shared/requirements/req-043.md)) — ทุกภารกิจมี chip โหมดกำกับเสมอ ([AC-037-01 (เลือก Activity ภารกิจ Block, Arm และ Code แล้วเข้าถึงเนื้อหาและภารกิจตรง Mode ได้ แม้อยู่ใน Course/Lesson เดียวกัน)](../../shared/requirements/req-037.md))
- นักเรียนผูก revision ที่เรียน: ป้าย "กำลังเรียนฉบับ R3"; publish ใหม่ไม่ย้ายฉบับ/ไม่แก้ผลเดิมอัตโนมัติ ([BR-044-03 (ฉบับ publish ไม่แก้ย้อนหลัง)](../../shared/requirements/req-044.md), [BR-044-04 (นักเรียนที่เรียนอยู่ผูก revision เดิม การ publish ใหม่ไม่ย้ายฉบับหรือแก้ผลเดิมอัตโนมัติ)](../../shared/requirements/req-044.md), [AC-044-04 (เมื่อ publish revision ใหม่ ผู้เรียนเดิมยังเปิดฉบับเดิมและดูผลเดิมได้)](../../shared/requirements/req-044.md)) — ข้อเสนอ: ไม่มีป้ายเตือน "มีฉบับใหม่" รบกวนผู้เรียน
- ผลงาน/ผลภารกิจอ้าง Activity/Mode/Lesson/revision ที่เรียน ไม่ปะปนข้ามโหมดหรือฉบับ ([AC-037-03 (งานและผลภารกิจอ้าง Activity, Mode, Lesson และ revision ที่เรียนถูกต้อง ไม่ปะปนข้ามโหมดหรือฉบับ)](../../shared/requirements/req-037.md))
