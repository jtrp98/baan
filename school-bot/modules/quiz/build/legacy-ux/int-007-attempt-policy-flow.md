# ลำดับเริ่ม ทำ ส่ง และอ่านผลข้อสอบ

> แก้ล่าสุด 2026-11-02 · แก้โดย int · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

[กลับเอกสารข้อสอบและผล Sign-off](int-007-attempt-policy.md) · ส่วนนี้ครอบคลุม Q43 (บันทึก ส่ง กู้ผล และหมดเวลาข้อสอบ)

## 2. ก่อนเริ่ม → ทำข้อสอบ → ส่ง → ดูผล (ข้อเสนอ Q43)

ก่อนเริ่ม แสดงชนิดข้อสอบพร้อมกติกาที่มีผลจริง: จำนวนครั้ง วิธีเลือกคะแนน เวลาทำ เวลาเฉลย การสุ่มข้อ/ตัวเลือก และช่วงเปิด–ปิดพร้อมเขตเวลา ไม่อนุมาน policy จากชื่อ Quiz/Test

ค่าเริ่มตามมติ: Quiz ไม่จำกัดครั้ง/คะแนนสูงสุด/ไม่จับเวลา/ไม่สุ่ม/เฉลยหลังส่ง; Test ครั้งปกติ 1 ครั้ง/กำหนดเวลา/สุ่มข้อ/ไม่สุ่มตัวเลือก/เฉลยหลังปิด การซ่อม Test ใช้คะแนนสูงสุดรวมครั้งจริง ไม่มีเพดานลดคะแนน

เข้า Test ผ่านกล่องยืนยันที่เซ็นแล้ว จากนั้นรอผลเริ่มสำเร็จก่อนแสดงโจทย์ ใช้ `questions` ตามลำดับที่ server คืน ไม่สุ่มใหม่เมื่อเปลี่ยนหน้า เปิดซ้ำ หรือ resume; รองรับปรนัยคำตอบเดียวและถูก–ผิด

หัวพื้นที่ทำข้อสอบแสดงครั้งที่ทำและเวลาคงเหลือจาก `deadline_at`; เวลา server เป็นผู้ตัดสินรับคำตอบ ตัวนับในเครื่องเป็นข้อมูลประกอบ ไม่ใช้ต่อเวลาเองหรือรีเซ็ตเมื่อเปิดแอปใหม่

แถบคำตอบแยก “ยังมีคำตอบที่ไม่ได้บันทึก” / “กำลังบันทึกคำตอบ…” / “บันทึกคำตอบแล้ว” ปุ่ม “บันทึกคำตอบ” ใช้คำสั่ง answers เดิม ไม่อ้างว่าบันทึกอัตโนมัติ การส่งแนบคำตอบชุดที่ผู้เรียนตรวจทานและล็อกชุดนั้นระหว่างรอผล

กลับเข้าครั้งเดิม: อ่าน attempt เดิมเมื่อทราบ ID; `started` ทำต่อได้ตามเวลาที่ server ยอมรับ, `submitted` อ่านผล, `expired` ไม่รับคำตอบเพิ่ม, `voided` แจ้งว่าครั้งนี้ถูกยกเลิก ไม่เริ่มครั้งใหม่เงียบ ๆ ข้อจำกัดการค้นหา ID/คืนคำตอบอยู่ใน companion หลักฐาน

ส่งแล้วใช้ข้อความเดิมของ int-004: Test “ส่งแล้ว — เฉลยและคะแนนจะแสดงหลังปิดสอบ” ไม่เผยค่าที่ซ่อนไว้ก่อนเวลา ไม่คำนวณคะแนนหรือเฉลยเองจากคลังฉบับใหม่

รายละเอียดครั้งเดิมใช้ข้อและลำดับจาก attempt เดิม การแก้คลัง/เฉลย/เวลาใหม่ไม่เปลี่ยน snapshot, deadline หรือผลครั้งเดิม ข้อมูล revision ที่ response ยังไม่คืนไม่สร้างป้ายเลขฉบับขึ้นเอง
