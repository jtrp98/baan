# Lesson Missions · คะแนน Arm/Block Lab

วันที่ 2026-11-06 · ผู้ใช้ยืนยันว่า Admin ตั้งคะแนนเต็มรายด่านและครูกรอกคะแนนตอนตรวจงาน · รายละเอียดสัญญาด้านล่างเป็นร่างสำหรับ `G-SCHEMA`

เอกสารนี้เสนอส่วนเพิ่มของ [payload/gRPC Rev 1](lesson-missions-payload-v1.md) เฉพาะคะแนน Lab ใช้ DDL Rev 8 และช่องคะแนนเดิมของผลประเมินงาน

## ตั้งค่าและเผยแพร่

- ด่าน Arm/Block Lab ที่ใช้ `scoring.kind = points` ต้องมี `scoring.max_score` เป็น decimal string มากกว่า 0 และอยู่ในช่วง `numeric(18,6)` ด่านใช้ Mission ที่ครูตรวจและมีเกณฑ์ตรวจงานที่อนุมัติแล้ว
- เกณฑ์ผ่านด้วยคะแนนและเกณฑ์ดาวทุกค่าต้องอยู่ระหว่าง 0 ถึงคะแนนเต็ม กติกาดาวและการใช้คะแนนของ Quiz อ้าง Rev 1
- Mission ของด่านแบบมีคะแนนต้องผูกกับ Project Activity เดียวใน revision ที่เผยแพร่ หากมีหลายด่านอ้าง Mission เดียวกัน ให้แจ้งข้อผิดพลาดตอนเผยแพร่ เพื่อให้ระบบหาคะแนนเต็มของงานส่งได้จาก Mission ของ revision นั้น

## ตรวจงานและอ่านผล

- ขยายคำสั่ง `ReviewSubmission` เดิมด้วย `optional string earned_score = 10` และใช้ชื่อ `earned_score` ใน HTTP เมื่อ Gateway รองรับ ฟิลด์เป็น decimal string สูงสุด 6 ตำแหน่ง ครูกรอกได้ตั้งแต่ 0 ถึงคะแนนเต็ม และส่งคะแนนเมื่อเป็นด่านแบบมีคะแนน บริการอ่านคะแนนเต็มจาก config ของ revision ที่งานส่งอ้างถึง
- บันทึก `EarnedScore` และ `MaxScore` ในผลประเมินเดิม พร้อมผลตาม rubric และประวัติผู้ตรวจ ใช้สิทธิ์ตรวจงานเดิม, `If-Match`, idempotency และการแทนผลเดิมด้วย `supersedes_id` กับเหตุผล การส่งซ้ำโดยใช้ key เดิมแต่เปลี่ยนคะแนนต้องคืนข้อขัดแย้ง
- ด่านที่กำหนดให้ผ่านด้วยคะแนนใช้ `minimum_score` ด่านที่กำหนดให้ครูอนุมัติใช้ผล `passed` ของการตรวจ ดาวคิดจากคะแนนและ `star_thresholds` ตาม config ด่านที่ไม่มีคะแนนยังใช้คำขอตรวจแบบเดิมและคืนคะแนนเป็นค่าว่าง
- Phase 1 แสดงคะแนนใน SchoolBot การนำคะแนนไปใช้กับรอบเรียนยังใช้การกำหนดน้ำหนักและช่องส่งเกรดที่มีอยู่แล้ว

## กรณีตรวจรับ

| กรณี | ผลที่ต้องได้ |
|---|---|
| Arm และ Block ตั้งคะแนนเต็ม 20 เกณฑ์ผ่าน 12 | เผยแพร่ได้เมื่ออ้าง Mission แบบครูตรวจและมีเกณฑ์ที่อนุมัติ ครูให้ 0, 12 หรือ 20 ได้ |
| คะแนนเต็มหายหรือเป็น 0, เกณฑ์ผ่านหรือดาวเกินคะแนนเต็ม, Mission แบบตรวจอัตโนมัติหรืออ้าง Mission เดียวกันหลาย Activity | ปฏิเสธการเผยแพร่ |
| ให้คะแนนติดลบ เกินคะแนนเต็ม รูปแบบไม่ถูกต้อง หรือผู้ตรวจไม่มีสิทธิ์ | ปฏิเสธคำขอและเก็บผลเดิม |
| เผยแพร่ revision ใหม่เปลี่ยนคะแนนเต็มจาก 20 เป็น 30 | งานที่อ้าง revision เก่ายังใช้คะแนนเต็ม 20 |
| ส่งคำขอตรวจเดิมซ้ำ หรือแก้ผลด้วยคำขอใหม่ | คำขอซ้ำได้ผลเดิม การแก้เพิ่มประวัติผล และการใช้ key เดิมกับคะแนนใหม่คืนข้อขัดแย้ง |
| งานเดิมหรือด่านไม่มีคะแนน | ยังส่งคำขอตรวจเดิมได้และอ่านผลผ่านหรือไม่ผ่านตามกติกาที่ตั้ง |
