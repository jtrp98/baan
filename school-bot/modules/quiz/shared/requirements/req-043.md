# REQ-043 — หลักสูตรกลางแบบ Level และ Activity

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

โรงเรียนต้องเลือกใช้หลักสูตรกลางตาม Level ที่เหมาะกับความพร้อมของห้องได้ โดยส่วนกลางเป็นผู้สร้างและแก้เนื้อหา Course ต้องจัด Lesson และ Activity หลายชนิดได้ เพื่อให้สื่อ ข้อสอบ และภารกิจสามโหมดอยู่ในโครงหลักสูตรเดียวกัน

## Business Rules

- BR-043-01: SchoolBright ส่วนกลางสร้าง/แก้หลักสูตร โรงเรียนเลือกใช้แต่แก้เนื้อหาไม่ได้
- BR-043-02: Course หนึ่งชุดเป็นหนึ่ง Level ต่อภาคเรียนประมาณ 22 สัปดาห์; Level เรียงจาก Beginner ถึง Expert เป็นแกน ระดับชั้นเป็นค่าเริ่มต้น และผูกวิชาได้
- BR-043-03: Course มี Lesson (คาบ/หน่วย) และ Activity ได้แก่ slide, lesson plan ครู, แบบฝึกกิจกรรม, mission Block/Arm/Code, quiz, test
- BR-043-04: Mode อยู่ที่ Activity ภารกิจ; Course/Lesson เดียวมีหลาย Mode ได้ สื่อและข้อสอบไม่ถูกบังคับเป็นภารกิจหุ่น
- BR-043-05: หน้าสร้าง/แก้/อนุมัติ/publish หลักสูตรกลางอยู่ในหน้า admin (Next.js ใน school-bot/web); Desktop ใช้เรียนอย่างเดียว ตาม [มติ 022 (ที่อยู่ของหน้าจอ Admin / ครู / Desktop)](../../../../shared/decisions/decisions-022.md)

## Acceptance Criteria

- AC-043-01: ส่วนกลางสร้าง/แก้หลักสูตรได้; บัญชีโรงเรียนเลือกใช้ได้แต่แก้เนื้อหากลางไม่ได้
- AC-043-02: เปิด Course แล้วเห็น Level ระดับชั้นเริ่มต้น วิชาที่ผูก และ Lesson/Activity ของมัน
- AC-043-03: ห้องใช้ Level ต่างจากค่าเริ่มต้นของระดับชั้นได้ โดยยังอ้าง Level ที่เลือก
- AC-043-04: Lesson เดียวเปิด Activity ครบชนิดใน BR-043-03 และภารกิจสาม Mode ได้ โดยแต่ละภารกิจใช้ Mode ของตน

## ยังไม่ยืนยัน

ไม่มีข้อสมมติฐานหรือคำถามธุรกิจที่ยังไม่ยืนยันเพิ่มเติมในข้อกำหนดนี้
