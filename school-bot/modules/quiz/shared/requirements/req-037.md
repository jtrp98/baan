# REQ-037 — หลักสูตรและภารกิจสามโหมด

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

นักเรียนต้องเรียนและทำภารกิจจริงใน Block, Arm และ Code โดยเนื้อหาและภารกิจตรงกับ Activity และ revision ที่เรียน เนื้อหาและเกณฑ์ต้องมีที่มาและผู้อนุมัติ เพื่อแยกผลเรียนจริงออกจากข้อมูลตัวอย่าง

## Business Rules

- BR-037-01: บทเรียนใช้ Course → Lesson → Activity ตาม [REQ-043 (หลักสูตรกลางแบบ Level และ Activity)](req-043.md); Mode อยู่ที่ Activity ภารกิจ และพื้นที่สร้างงานแต่ละโหมดแยกจากบทเรียน
- BR-037-02: Lesson มีเป้าหมาย คำแนะนำ และ Activity ที่ใช้งานจริง; มีภารกิจเมื่อหลักสูตรกำหนด ไม่ใช้ scenario เป็นผลการเรียนจริง
- BR-037-03: เนื้อหาและเกณฑ์มีที่มาและการอนุมัติโดยผู้ใช้หรือผู้ที่ผู้ใช้ระบุ; publish/revision ตาม [REQ-044 (รหัสบทเรียนและ revision หลักสูตร)](req-044.md) และการนำเข้า Sheet ตาม [REQ-045 (นำเข้า Course Plan Sheet)](req-045.md)

## Acceptance Criteria

- AC-037-01: เลือก Activity ภารกิจ Block, Arm และ Code แล้วเข้าถึงเนื้อหาและภารกิจตรง Mode ได้ แม้อยู่ใน Course/Lesson เดียวกัน
- AC-037-02: เปิด Lesson แล้วเห็นเป้าหมาย คำแนะนำ และรายการ Activity ตรงกับบทเรียนที่เลือก
- AC-037-03: งานและผลภารกิจอ้าง Activity, Mode, Lesson และ revision ที่เรียนถูกต้อง ไม่ปะปนข้ามโหมดหรือฉบับ
- AC-037-04: เพียงเปิดหรือกดปิดบทเรียนไม่สร้างผลผ่านจริงโดยไม่มีการประเมินตาม [REQ-038 (ประเมิน Code/Block อัตโนมัติและ Arm โดยครู)](req-038.md)

- AC-037-05: เมื่อยังไม่มีหลักฐานอนุมัติเนื้อหาและเกณฑ์ บทเรียนนั้นไม่ถูกเสนอเป็นบทเรียนจริงที่อนุมัติแล้ว
- AC-037-06: กิจกรรมภารกิจจริงทุกโหมดอ้างกลับไปยังเนื้อหา ภารกิจ เกณฑ์ และหลักฐานผู้อนุมัติ revision ที่ใช้ได้

## ยังไม่ยืนยัน

เนื้อหาและเกณฑ์เฉพาะ revision ต้องมีหลักฐานอนุมัติจริงโดยผู้ใช้หรือผู้ที่ผู้ใช้ระบุ การกำหนดผู้อนุมัติไม่แทนการอนุมัติเนื้อหารายฉบับ

## หลักฐาน

ผู้ใช้ในแชต 2026-10-21 ต้องการหลักสูตร ภารกิจ และประเมินผลจริง ดู [มติ 001 (จากคำตอบผู้ใช้)](../../../../shared/decisions/decisions-001.md), [มติ 003 (โครงสร้างผลิตภัณฑ์ 3 โหมด)](../../../../shared/decisions/decisions-003.md), [มติ 009 (หลายโครงงานและผู้ประเมินภารกิจ)](../../../../shared/decisions/decisions-009.md)

ผู้ใช้ในแชต 2026-10-21 ให้ทีมร่างเนื้อหา/ภารกิจ/เกณฑ์ทั้งสามโหมด แล้วผู้ใช้หรือผู้ที่ผู้ใช้ระบุตรวจอนุมัติ ตาม [มติ 015 (ถังขยะ Guest ผู้ร่างหลักสูตร และขอบเขตครู)](../../../../shared/decisions/decisions-015.md)
