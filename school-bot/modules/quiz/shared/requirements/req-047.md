# REQ-047 — การนับคะแนน Quiz รายหลักสูตร

> แก้ล่าสุด 2026-11-02 · แก้โดย spec · ขอโดย ผู้ใช้ (เรียบเรียงตามกติกาเอกสารใหม่ ความหมายไม่เปลี่ยน)

## ต้องการอะไร/ทำไม

ครูต้องตั้งการนับ Quiz และน้ำหนักคะแนนรายหลักสูตรได้ โดยน้ำหนักกิจกรรมที่ใช้รวมต้องเป็น 100% การเปลี่ยนน้ำหนักต้องใช้เฉพาะรอบหลักสูตรใหม่ เพื่อคงสูตรและผลของรอบเดิมไว้

## Business Rules

- BR-047-01: ครูตั้งการนับ Quiz/น้ำหนักรายหลักสูตร; น้ำหนักแต่ละกิจกรรม/Quiz/Test รวม 100% ตาม [มติ 034 (สูตรรวมหลักสูตร น้ำหนักรอบเรียน และขอบเขตครูปรับ policy ข้อสอบ)](../../../../shared/decisions/decisions-034.md)
- BR-047-02: Quiz ไม่นับมีน้ำหนัก 0 แต่ดูผลได้; ค่าเริ่ม Quiz ใช้คะแนนสูงสุด Test ซ่อมใช้คะแนนสูงสุดไม่มีเพดาน ([มติ 024 (เกณฑ์เลื่อน Level และ policy Quiz/Test)](../../../../shared/decisions/decisions-024.md) / [มติ 025 (auth ข้ามระบบ, admin โรงเรียน, publish, สอบซ่อม และ Desktop)](../../../../shared/decisions/decisions-025.md))
- BR-047-03: การนับคะแนนหลักสูตรไม่กำหนดหมวดเกรดปลายทางอัตโนมัติ; ใช้ mapping ตาม [REQ-049 (Mapping หลักสูตรกับช่องคะแนน SchoolBright)](../../../../../schoolbright-web/modules/school-bot/shared/requirements/req-049.md)
- BR-047-04: คะแนนรวม 0–100 = SUM((earned_i/max_i) × weight_i) โดย weight เป็นเปอร์เซ็นต์รวม 100; เปลี่ยนน้ำหนักใช้เฉพาะ CourseRun ใหม่ รอบเดิมคงค่า/ผลเดิม (มติ 034); งานขาดตอนเลื่อน Level ใช้ 0 ตาม [REQ-048 (เสนอและยืนยันเลื่อน Level ทั้งห้อง)](req-048.md) แยกจาก export ตาม [REQ-050 (Preview และยืนยันส่งคะแนนกิจกรรม)](../../../../../schoolbright-web/modules/school-bot/shared/requirements/req-050.md) / [REQ-051 (คะแนนชนและการคุ้มครองคะแนนครู)](../../../../../schoolbright-web/modules/school-bot/shared/requirements/req-051.md)

## Acceptance Criteria

- AC-047-01: ครูตั้ง A ให้นับ Quiz และ B ไม่นับ แล้วเห็นค่ารายหลักสูตร; แต่ละชุดน้ำหนักบันทึกใช้ได้เมื่อรวม 100% เท่านั้น
- AC-047-02: Quiz ของ B มีผลให้ดูและน้ำหนัก 0; เปลี่ยนคะแนน Quiz อย่างเดียวแล้วคะแนนรวม B ไม่เปลี่ยน
- AC-047-03: ครูกำหนดสัดส่วน A แล้วเรียกดูสัดส่วนที่บันทึกได้ โดยไม่เปลี่ยน B
- AC-047-04: กิจกรรม 8/10 น้ำหนัก 20%, Quiz 6/10 น้ำหนัก 30%, Test 18/20 น้ำหนัก 50% ได้รวม 79/100 และแสดงส่วน 16+18+45 (ตัวเลขทดสอบจากสูตร ไม่ใช่ค่าเริ่ม)

- AC-047-05: เปลี่ยนน้ำหนักจาก 20/30/50 เป็น 30/20/50 แล้ว CourseRun เดิมยังได้ 79/100 ด้วยค่าเดิม; CourseRun ใหม่ใช้ค่าใหม่ได้ 81/100 เมื่อคะแนนเท่ากัน

## ยังไม่ยืนยัน

ยังไม่มีมติน้ำหนักเริ่มต้นรายกิจกรรม/Quiz/Test; ต้องให้ผู้ใช้กำหนดหากต้องใช้ค่าเริ่มต้น
