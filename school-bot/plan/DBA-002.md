## Scope

ดำเนินงาน เตรียม core DDL/rollback ภายในขอบเขต references และส่ง outputs ที่ระบุด้านล่าง รักษาพฤติกรรมที่ไม่เกี่ยวข้องและกติกา repository ผู้ลงมืออ่าน README/เอกสาร/as-built เฉพาะส่วนก่อนแก้จริง แยกข้อเท็จจริง ข้อเสนอ และสิ่งรอยืนยัน ตรวจ preconditions ตาม Dependencies และ [gates](gates-001.md) ก่อนส่วนที่พึ่งพา; ส่วนอิสระเดินต่อได้ DBA เตรียม SQL/rollback และตรวจ human-provided SQL/catalog evidence เท่านั้น ไม่รัน SQL เอง งาน robot ใช้ dry-run จนมีคำสั่งอนุญาตทดสอบอุปกรณ์จริง

## Out of Scope

งานนอก outputs/AC/references ของ task นี้ การเลือกนโยบายธุรกิจหรือเซ็นอนุมัติแทนคน การเพิ่มหรือตัด frozen release scope และ speculative feature ห้ามแก้ข้ามเขต Owns ของ role ห้าม state-changing git หรือเรียก role ต่อเอง Shared SQL/deploy/publish, installer tests และการเปลี่ยนสถานะหุ่นต้องมีหลักฐานอนุญาตเฉพาะตาม gate ไม่ถือว่าได้สิทธิ์จากการรับแผน

## Expected Output

- core SQL/rollback/runbook

ส่ง artifact จริงในเขต Owns ของ role พร้อม references ที่ตรวจย้อนกลับได้ ไม่สร้างสำเนาเอกสารข้ามหมวด หากมีไฟล์เดิมให้ amend พร้อม Change Log วันที่ 2026-10-21

ผู้ตรวจ (check/jpo) ตัดสินจาก pack นี้ · เปิดต้นฉบับเฉพาะหัวข้อที่ลิงก์ · อ่านเอกสารเต็มใหม่เมื่อ revision ข้างล่างเปลี่ยน / มี NEEDS_REQUIREMENT_CHANGE หรือ NEEDS_DESIGN_CHANGE / pack ตอบความกำกวมไม่ได้ (แก้ pack ไม่เดา)

**AC (ข้อความตามต้นฉบับ):**

- [AC-033-01](../requirement/req-033.md) ตรวจหลักฐาน catalog ของ DB ที่ระบบทดสอบใช้งานแล้วพบชื่อตาราง License เป็น `SchoolBotLicense` ตรงตามตัวพิมพ์
- [AC-033-02](../requirement/req-033.md) ตรวจ catalog ของ DB เดียวกันแล้วพบ `SchoolBotLicenseId` เป็น Primary Key ชนิด `int4`
- [AC-033-03](../requirement/req-033.md) ตรวจ catalog ของ DB เดียวกันแล้วพบฟิลด์มาตรฐานครบทั้งหกชื่อ โดยไม่เปลี่ยนชื่อเป็นรูปแบบอื่น
- [AC-033-04](../requirement/req-033.md) ตรวจ catalog ของ DB ที่ระบบทดสอบใช้งานแล้วทุกตารางข้อมูลของผลิตภัณฑ์ใช้ prefix `SchoolBot` และมีฟิลด์มาตรฐานทั้งหก
- [AC-033-05](../requirement/req-033.md) จาก catalog เดียวกัน PK ของตาราง SchoolBot ใหม่เป็น int4 และคอลัมน์รหัสอ้างอิงเดิมคงชนิดที่ระบุในแบบ; ไม่พบ UNIQUE/FK/CHECK ของ SchoolBot ตาม decisions-044

**revision ที่ตรึง:** [DES-002 Rev3](../design/des-002.md) · REQ ปัจจุบัน: [REQ-033](../requirement/req-033.md)

**test-plan cases** ([TP-001](../test-plan/tp-001.md) + amendments): TP001-052, TP001-053

**non-goals:** AC อื่นของ REQ ที่อ้างแต่ไม่อยู่ในรายการข้างบน ไม่ใช่เส้นชัยของ task นี้ · ทุกอย่างในหัวข้อ Out of Scope · finding นอก AC → backlog ไม่ใช่เหตุ FAIL

**เกณฑ์งานเดิมของ task (ใช้คู่กับ AC ข้างบน):**

core SQL/rollback review ได้; int4/FK/audit ครบ; ยังไม่รัน shared

แนบตาราง criterion/AC → วิธีตรวจ → expected/actual → evidence path หรือ source:line และข้อจำกัด งานเตรียมแบบ/คำตัดสินต้องมีรายการประเด็น ผู้ตอบ และผลกระทบที่ตรวจทานได้; ถ้ายังไม่มี AC association ให้ตรวจตาม references โดยไม่สร้าง AC เอง งาน implementation ส่งคำสั่ง/exit code และผล checks ตามส่วนที่เปลี่ยน แยก automated logic, UI, hardware และ installer evidence ห้ามอ้างผ่านเมื่อไม่ได้ตรวจหรืออ้าง task นี้ปิด AC ก่อน QA ตรวจ เกินสองรอบแก้ให้หยุดส่งคนตัดสิน
