## Scope

คง performance/assets และ AC-029-01..03 เดิม ตรวจ AC-030-01..08 โดยแยก metadata-only Check ออกจาก explicit Prepare/Install ตาม TP001-048/080; ตรวจ Host logic จาก BE-019 และ package recovery จริงจาก BE-020/021 หลัง prerequisites QA-008/009 และ G-DELIVERY เดิมพร้อม แยก fake/UI/OS/installer/หุ่นจริง ไม่ถือ fake failure handler เป็นหลักฐานใช้เวอร์ชันเดิมได้จริง

## Out of Scope

งานนอก outputs/AC/references ของ task นี้ การเลือกนโยบายธุรกิจหรือเซ็นอนุมัติแทนคน การเพิ่มหรือตัด frozen release scope และ speculative feature ห้ามแก้ข้ามเขต Owns ของ role ห้าม state-changing git หรือเรียก role ต่อเอง Shared SQL/deploy/publish, installer tests และการเปลี่ยนสถานะหุ่นต้องมีหลักฐานอนุญาตเฉพาะตาม gate ไม่ถือว่าได้สิทธิ์จากการรับแผน

## Expected Output

- benchmark/trust report และหลักฐาน TP001-048/080 แยก logic-fake/UI/OS installer; ระบุผลราย AC-030-01..08 และราย platform

ส่ง artifact จริงในเขต Owns ของ role พร้อม references ที่ตรวจย้อนกลับได้ ไม่สร้างสำเนาเอกสารข้ามหมวด หากมีไฟล์เดิมให้ amend พร้อม Change Log วันที่ 2026-10-26

## Acceptance

คง signed RC benchmarkตามเกณฑ์ และ hash/signature/payload/notices; AC-029-01..03 ตามเดิม; AC-030-01..03 checkไม่download/install/execute และ API fail ไม่ขวางlocal; ตรวจ AC-030-04..08 ตาม REQ-030/TP Amendment003 ครบ explicit intent/trust rejection/TOCTOU/expiry/withdraw/downgrade/stop-close-confirm/failure recovery/cancel-cleanup; AC-030-07 ต้อง inject fail กลาง update และแสดงเวอร์ชันเดิมกลับมาใช้ได้จริงจาก MSI และ Universal PKG ทั้ง Intel/ARM พร้อมสาเหตุ ไม่เหลือครึ่งติดตั้ง; แยก fake จาก runtime/signed installer/หุ่นจริง ผลที่ยังไม่รันคง NOT_RUN และ release NOT_READY

แนบตาราง criterion/AC → วิธีตรวจ → expected/actual → evidence path หรือ source:line และข้อจำกัด งานเตรียมแบบ/คำตัดสินต้องมีรายการประเด็น ผู้ตอบ และผลกระทบที่ตรวจทานได้; ถ้ายังไม่มี AC association ให้ตรวจตาม references โดยไม่สร้าง AC เอง งาน implementation ส่งคำสั่ง/exit code และผล checks ตามส่วนที่เปลี่ยน แยก automated logic, UI, hardware และ installer evidence ห้ามอ้างผ่านเมื่อไม่ได้ตรวจหรืออ้าง task นี้ปิด AC ก่อน QA ตรวจ เกินสองรอบแก้ให้หยุดส่งคนตัดสิน
