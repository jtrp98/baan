## Scope

คงงาน คง update check แยก install และ AC-030-01..03 ตามต้นฉบับ หลัง SA-001 เสนอ disposition และ G-RELEASE-DB มีหลักฐานครบก่อน freeze/implementation ของส่วนนี้ การ check ต้องไม่ download/install/execute และ failure ไม่ขวาง local ที่ License ยัง valid ไม่เพิ่ม PrepareUpdate/InstallPreparedUpdate โดยตีความเอง และไม่ใช้ใบงานนี้ประกาศตัด workflow ที่ DES เสนอ หาก disposition ที่ผ่านผู้มีอำนาจต้องเปลี่ยน coverage ให้ PM amend ใบงาน/แผนและส่ง BA/SA ตามหน้าที่ก่อนเริ่มส่วนที่เปลี่ยน โดยรักษา IDs และ frozen scope

## Out of Scope

งานนอก outputs/AC/references ของ task นี้ การเลือกนโยบายธุรกิจหรือเซ็นอนุมัติแทนคน การเพิ่มหรือตัด frozen release scope และ speculative feature ห้ามแก้ข้ามเขต Owns ของ role ห้าม state-changing git หรือเรียก role ต่อเอง Shared SQL/deploy/publish, installer tests และการเปลี่ยนสถานะหุ่นต้องมีหลักฐานอนุญาตเฉพาะตาม gate ไม่ถือว่าได้สิทธิ์จากการรับแผน

## Expected Output

- update bridge

ส่ง artifact จริงในเขต Owns ของ role พร้อม references ที่ตรวจย้อนกลับได้ ไม่สร้างสำเนาเอกสารข้ามหมวด หากมีไฟล์เดิมให้ amend พร้อม Change Log วันที่ 2026-10-21
