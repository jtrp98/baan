## Scope

ดำเนินงาน เชื่อม app sequence/cancel/stop ภายในขอบเขต references และส่ง outputs ที่ระบุด้านล่าง รักษาพฤติกรรมที่ไม่เกี่ยวข้องและกติกา repository ผู้ลงมืออ่าน README/เอกสาร/as-built เฉพาะส่วนก่อนแก้จริง แยกข้อเท็จจริง ข้อเสนอ และสิ่งรอยืนยัน ตรวจ preconditions ตาม Dependencies และ [gates](gates-001.md) ก่อนส่วนที่พึ่งพา; ส่วนอิสระเดินต่อได้ DBA เตรียม SQL/rollback และตรวจ human-provided SQL/catalog evidence เท่านั้น ไม่รัน SQL เอง งาน robot ใช้ dry-run จนมีคำสั่งอนุญาตทดสอบอุปกรณ์จริง

## Out of Scope

งานนอก outputs/AC/references ของ task นี้ การเลือกนโยบายธุรกิจหรือเซ็นอนุมัติแทนคน การเพิ่มหรือตัด frozen release scope และ speculative feature ห้ามแก้ข้ามเขต Owns ของ role ห้าม state-changing git หรือเรียก role ต่อเอง Shared SQL/deploy/publish, installer tests และการเปลี่ยนสถานะหุ่นต้องมีหลักฐานอนุญาตเฉพาะตาม gate ไม่ถือว่าได้สิทธิ์จากการรับแผน
