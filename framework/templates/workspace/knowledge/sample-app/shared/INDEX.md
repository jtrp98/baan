# shared — สัญญาร่วมและข้อกำหนดระดับโครงการ

หน้านี้เก็บความจริงร่วมที่ทุกบทบาท (วิศวกรรม, ออกแบบ, บริหารโครงการ) ใช้ร่วมกันทั้งโปรเจกต์

## เอกสารในหมวดนี้
- [context.md](context.md) — บริบทธุรกิจ ภาพรวมระบบ และคำศัพท์กลาง (Domain Glossary)
- [requirements.md](requirements.md) — ตารางดัชนีรวมข้อกำหนดทั้งโปรเจกต์ ชี้ไปยังโมดูลย่อย
- [knowledge-gaps.md](knowledge-gaps.md) — บันทึกช่องว่างความรู้ทางวิศวกรรมที่พบระหว่างดำเนินงาน
- [adr/INDEX.md](adr/INDEX.md) — บันทึกการตัดสินใจสถาปัตยกรรม (Architecture Decision Records)
- [oq/INDEX.md](oq/INDEX.md) — คำถามค้างระดับระบบที่กระทบข้ามโมดูล
