# WCAG 2.2 ระดับ AA สำหรับทีมออกแบบ (WA1–WA42)

ใช้ทุกงาน อ้างเป็นเลขข้อคู่เลข WCAG เช่น "WA23 (2.5.8): ปุ่มปิด 16×16 ไม่มีระยะเว้น"
ครอบคลุม success criterion ระดับ A + AA ของ WCAG 2.2 ที่ผู้ออกแบบ/ผู้ตรวจลงมือได้ ข้อที่เป็นงานโค้ดให้ ui เขียน annotation บอก dev
ไม่ซ้ำไฟล์อื่น: หลักการกว้าง `universal-design.md` (UD#) · error/feedback `usability-heuristics.md` (H#) · ค่าตัวอักษร/สี/motion `ui-design-58-rules.md` (UI#)
**เกณฑ์ภายในของทีมอาจเข้มกว่า ดู brand ของ project** (`<project>/shared/brand/`) และ `_shared/` ของ knowledge — ค่าที่เข้มกว่าชนะ ไฟล์นี้คือเส้นขั้นต่ำ

## อ่านก่อนใช้
- **หน่วย:** WCAG เขียนสำหรับเว็บ ค่าเป็น CSS px · ตีความของทีม: แอป native ใช้หน่วยเทียบของ platform (pt/dp) ตาม brand หรือ `../desktop/apple/hig-foundations.md`
- **ห้ามปัดเศษ contrast:** 4.499:1 ไม่ผ่าน 4.5:1 · 2.999:1 ไม่ผ่าน 3:1
- **ข้อความใหญ่** = ≥ 18 pt หรือ ≥ 14 pt ตัวหนา (≈ 24 px / ≈ 18.5 px) · นิยามพูดถึงขนาดเทียบของ CJK เท่านั้น **ไม่พูดถึงอักษรไทย** → ใช้ค่า pt ตรง ๆ ถ้าฟอนต์ไทยเส้นบาง Understanding แนะให้ใช้ฟอนต์เส้นหนาขึ้นหรือทำ contrast เกินขั้นต่ำ
- **คอลัมน์ mockup:** **ภาพ** = ตรวจจาก canvas ได้ · **โน้ต** = ต้องมี annotation บนแบบ ไม่มี = ไม่ผ่าน · **proto** = พฤติกรรม ถ้ามีแต่ภาพนิ่งให้ผล "ไม่เกี่ยวข้อง (ตรวจตอน prototype/build)" ไม่ใช่ "ผ่าน" · **โค้ด** = ไม่เกี่ยวข้องกับ mockup

## วิธีใช้
- **survey:** หา requirement ที่ชนเกณฑ์แล้วรายงานเป็นช่องโหว่ (ไม่แก้ requirement เอง): จับเวลา (WA38), ลากวาง (WA24), swipe/เขย่า (WA25), login ที่ต้องจำ (WA34), ส่งข้อสอบ/ลบข้อมูล (WA32), กรอกซ้ำ (WA33), สื่อ/เสียง (WA41, WA42)
- **ui:** ออกแบบ state ครบ (focus, error, disabled) ตรวจ contrast จากสีจริง ทำปุ่มทางเลือกของการลาก/ท่าทาง เขียน annotation ทุกข้อที่ช่อง mockup เป็น "โน้ต" ถ้าใช้ข้อยกเว้น (จำเป็น, ลิงก์ในประโยค, ปุ่มทดแทน) เขียนเหตุผล ใช้ค่าของ brand เมื่อเข้มกว่า
- **review:** ให้ผล ผ่าน/ไม่ผ่าน/ไม่เกี่ยวข้อง รายข้อ WA1–WA42 ในหัวข้อ Review พร้อมเลข WCAG และค่าที่วัดได้ (เช่น "WA1 (1.4.3): ข้อความรอง #9A9A9A บนขาว 2.8:1") · ช่อง "โน้ต" ที่ไม่มี annotation = ไม่ผ่าน · ช่อง "proto" ที่มีแต่ภาพนิ่ง = ไม่เกี่ยวข้อง (ตรวจตอน prototype/build) · ใช้คู่กับ H#, UD#, UI#
