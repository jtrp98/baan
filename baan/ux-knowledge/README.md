# ux-knowledge/ — ความรู้ UX ทั่วไปของทีมออกแบบ

ความรู้ที่ไม่ผูกกับบริษัทหรือ project ใด ใช้ได้ทุก workspace · มากับ package baan และอัปเดตพร้อม role ที่ใช้มัน (`survey`, `ui`, `review`)
ของเฉพาะบริษัท (เกณฑ์ WCAG ของทีม · component กลางของบริษัท) อยู่ที่ `_shared/` ของ knowledge ใน workspace · หน้าตาของแต่ละ project อยู่ที่ `<project>/shared/brand/` + Design System ของ project บน Claude Design

| hig.md | ui, review, survey | สารบัญ Apple HIG + หลักตัดสินเมื่อไม่มีกฎเฉพาะ (เปิดก่อน แล้วเลือกไฟล์ย่อย) |
