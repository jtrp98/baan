# BE-001 — Lift GetSubjectAveragesAsync to CompassScoreService

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `project-manager` · Owner/Phase/Depends/Status → `plan\index.md` (index ชนะ)

## Goal

ย้าย `GetSubjectAveragesAsync` จาก `private static` บน `CompassApiController` ขึ้นเป็น `public static GetCanonicalSubjectAveragesAsync(int schoolId, int sID)` บน `CompassScoreService` แล้วให้ `CompassApiController` เดิมเรียกตัวใหม่แทน — ย้ายเนื้อในครบทุกบรรทัด ห้ามเขียนสูตรใหม่ และห้ามคัดลอกกติกา fallback ไปไว้ที่อื่น (fallback หน่วยกิตรวม = 0 ต้องยังทำงานจากข้างใน `AggregateByCanonicalSubjectWeighted` ตามเดิม) — โมดูลนี้ต้องใช้คะแนนกลุ่มสาระชุดเดียวกับที่ `sb-compass` คำนวณ — ถ้าเกิดสำเนาสูตรชุดที่สอง การแก้สูตรฝั่งต้นทางจะไม่ไหลมาให้โมดูลนี้โดยอัตโนมัติอีก

## References

REQ-005, AC-005.2, DES-020, DEC-020

## Scope

เป็นการย้ายเมธอดล้วน ไม่แตะสูตร ไม่แตะสิทธิ์ ไม่รับ input ภายนอกใหม่ · caller เดิมบน `CompassApiController` ต้องชี้เมธอดใหม่ในการเปลี่ยนแปลงชุดเดียวกัน · ต้องประสานลำดับกับ `sb-compass` Phase 1 ที่กำลังแตะไฟล์เดียวกัน (DEP-F05)

- Security-sensitive: no

## Out of Scope

สูตรถ่วงน้ำหนักและกติกา fallback ข้างใน `AggregateByCanonicalSubjectWeighted` · caller อื่นของ `sb-compass` นอกจากจุดเรียกที่ระบุ · ตาราง/สคีมาใด ๆ

## Expected Output

none

## Acceptance

AC-005.2: คะแนนกลุ่มสาระที่ได้จากเมธอดใหม่เป็นค่าชุดเดียวกับที่ `sb-compass` REQ-012 คำนวณ (fallback หน่วยกิตรวม = 0 ยังทำงานจากข้างในเมธอดเดิมโดยอัตโนมัติ) — ไม่มีการคำนวณคะแนนกลุ่มสาระชุดที่สองเกิดขึ้นในโมดูลนี้
