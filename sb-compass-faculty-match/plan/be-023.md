# BE-023 — Program match percent (TARGET_SCORE)

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `project-manager` · Owner/Phase/Depends/Status → `plan\index.md` (index ชนะ)

## Goal

สูตร % ความเหมาะสมของสาขา — `TARGET_SCORE=75` เป็นค่าคงที่มีชื่อ, coverage-penalty ตามสัญญา (กลุ่มสาระที่เด็กไม่มีคะแนน: ตัวตั้งถือ 0 แต่น้ำหนักยังอยู่ในตัวหาร), ปัดเป็นจำนวนเต็ม, `min(1, score/75)` กันคะแนนเกินเป้าดันคะแนนรวมให้เฟ้อ (หมวด Program Matching §3) — % คือตัวเลขที่เด็กเห็นเป็นอันดับแรก — สูตรและค่าคงที่ต้องมาจากสัญญาจุดเดียว ไม่กระจาย magic number ในโค้ด

## References

REQ-006, AC-006.1, DES-020, DEC-020

## Scope

`TARGET_SCORE = 75.0` เป็น named constant แก้ที่เดียว · ใช้คะแนนกลุ่มสาระจาก BE-001 (ค่าเดียว) · คำนวณสดทุก request ไม่เก็บผลจับคู่ลงฐานข้อมูล

- Security-sensitive: yes

## Out of Scope

ค่า TARGET_SCORE (เป็นสมมติฐานที่บันทึกไว้เปิดเผย — แก้ต้อง amend) · สูตร studentLevel/T-Score (คนละชั้น) · ตารางคลัง (อ่านอย่างเดียว)
