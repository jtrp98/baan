# BE-054 — Development Plan calculation & recommendations

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `project-manager` · Owner/Phase/Depends/Status → `plan\index.md` (index ชนะ)

## Goal

endpoint แผนพัฒนาตนเอง (Development Plan, REQ-018 / DES-026): ตรวจสอบ active target major ของนักเรียน (`public."TCompassTargetProgram"` มีแถว `Status = 'active'`) — หากไม่มี คืน `RequiresTargetMajor = true`; คำนวณ Gap Analysis รายกลุ่มสาระที่สาขากำหนดไว้ใน `public."TCompassProgramSubjectWeight"` ด้วยสูตร `Gap = max(0, TARGET_SCORE - StudentScore)` เทียบกับ `TARGET_SCORE = 75.0` (ดึงคะแนนกลุ่มสาระผ่าน `GetCanonicalSubjectAveragesAsync`); ดึงโจทย์แบบฝึกหัดทบทวน 4 ข้อเพื่อประเมินความพร้อม; แนะนำตัวช่วยติวเตอร์/คอร์สจาก Orbit Tutor สำหรับกลุ่มสาระที่มี Gap สูงสุด — REQ-018 กำหนดให้มีแท็บแผนพัฒนาตนเองหลังเลือกเป้าหมายแล้ว เพื่อให้นักเรียนทราบจุดที่ต้องปรับปรุงก่อนสอบเข้ามหาวิทยาลัย (DES-026, DEC-027)

## References

REQ-018, AC-018.1, AC-018.2, AC-018.3, DES-026, DEC-027

## Scope

ตรวจสอบเงื่อนไข active target ก่อนคำนวณเสมอ · คำนวณ Gap จากกลุ่มสาระของสาขาเป้าหมายเท่านั้น · กรณีไม่มีคะแนนในบางวิชาถือ `CurrentScore = 0` และ `Gap = TARGET_SCORE` พร้อมแฟล็ก `missing_score` · คืนโครงสร้าง ViewModels: `VMDevelopmentPlan`, `VMSubjectGapItem`, `VMReviewExerciseItem`, `VMSupportRecommendation` ตามสัญญา DES-026 · fail-closed หากเกิดข้อผิดพลาด

- Security-sensitive: yes

## Out of Scope

สูตร Gap Analysis (`max(0, TARGET_SCORE - score)`) · ค่าคงที่ `TARGET_SCORE = 75.0` · ตารางฐานข้อมูล (สัญญา Data/schema: unchanged) · กติกา fallback ของ DES-026

## Expected Output

none

## Acceptance

AC-018.1: หากนักเรียนยังไม่มี active target major คืน `RequiresTargetMajor = true` และไม่คำนวณ Gap
AC-018.2: เมื่อมี active target major คำนวณ Gap Analysis ครบทุกกลุ่มสาระที่สาขากำหนด โดยวิชาที่มีคะแนน ≥ 75.0 มี `Gap = 0` และวิชาที่ต่ำกว่ามี Gap ตามส่วนต่าง
AC-018.3: คืนโจทย์ทบทวน 4 ข้อ และการ์ดแนะนำ Orbit Tutor สำหรับวิชาที่ Gap สูงสุดอย่างถูกต้อง
