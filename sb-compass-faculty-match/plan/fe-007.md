## Goal

หน้าจอแบบทดสอบพฤติกรรมรอบ 2 (Likert 1-5 + บล็อกเรียงลำดับ) ทำซ้ำได้ — ต้องบังคับตอบครบทุกข้อก่อนกดส่งได้ในชั้น UI ด้วย (ไม่ใช่แค่ server-side ตาม BE-028 — กัน request ที่ตั้งใจส่งไม่ครบ ซึ่งยังโดนเซิร์ฟเวอร์ปฏิเสธเสมอ) — ประสบการณ์ส่งแล้วโดนปฏิเสธทั้งคำขอเป็นประสบการณ์ที่แย่ต่อเด็ก — UI ต้องกันไว้ก่อน โดยเซิร์ฟเวอร์ยังเป็นแหล่งความจริงเดียว

## References

## Scope

- Security-sensitive: yes
