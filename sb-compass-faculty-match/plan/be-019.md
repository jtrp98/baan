# BE-019 — Retire program endpoint

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `project-manager` · Owner/Phase/Depends/Status → `plan\index.md` (index ชนะ)

## Goal

endpoint retire สาขา — ตั้ง `status='retired'`, เด็กไม่เห็น, เก็บประวัติไว้ (DES-023 §1) — สาขาที่เลิกใช้ต้องหายจากผลของเด็กแบบชัดเจนโดยคนตัดสิน ไม่ใช่ลบข้อมูลทิ้งจนตามประวัติไม่ได้

## References

REQ-003, AC-003.1, DES-023, DEC-023

## Scope

retire = set status เท่านั้น ห้ามลบแถว · ทำได้เฉพาะผ่าน console หลัง SSO

- Security-sensitive: yes

## Out of Scope

แถวอื่นของสาขา · state machine อื่น · สคีมา

## Expected Output

none

## Acceptance

AC-003.1 (ฐานสถานะ): สาขาที่ถูก retire ออกจากผลของเด็กทันที และแถวยังอยู่ในระบบให้ตามประวัติได้

## Dependencies

BE-013

## Handoff

ตรวจ AC-003.1 (ฐานสถานะ) ด้วยการ retire สาขาจริงแล้วตรวจสถานะ/ผล query ฝั่งผู้บริโภคที่กรอง status — เก็บผลเป็นหลักฐาน
set status ย้อนกลับได้ด้วยตัว endpoint การจัดการสถานะ — ไม่มีข้อมูลสูญ
