# BE-044 — Target Major Rules ownership enforcement

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `project-manager` · Owner/Phase/Depends/Status → `plan\index.md` (index ชนะ)

## Goal

บังคับความเป็นเจ้าของ (`school_id`/`s_id` จาก JWT เท่านั้น ห้ามรับจาก client) บนทุก endpoint ใหม่ของหมวดนี้ (BE-041/042/043) — กติกาเดียวกับ BE-036 ที่ครอบ Module I-b อยู่แล้ว แต่ endpoint ตั้ง/สลับเป้าหมายเป็นจุดเขียนข้อมูลใหม่ที่ต้องมี ownership check ของตัวเองครบ กัน IDOR ผ่าน `program_id` ที่ส่งมาตั้งเป้าหมาย — endpoint ตั้งเป้าหมายเป็นจุดเขียนใหม่ล้วน — ถ้ารับ SchoolID/SID จาก body เด็กแก้เลขแล้วตั้งเป้าหมายในบัญชีอื่นได้ทันที

## References

REQ-010, AC-010.1, DES-018, DEC-018, DES-021, DEC-021

## Scope

ครอบ BE-041/042/043 ทุกตัว · gate query ต้องใช้ค่าจาก JWT เท่านั้น (BE-041 ต้องไม่รับ SchoolID/SID เป็นพารามิเตอร์จาก client) · fail-closed

- Security-sensitive: yes

## Out of Scope

กลไก JWT ของระบบเดิม · query gate (แก้เฉพาะแหล่งค่าตัวตน) · สคีมา

## Expected Output

none

## Acceptance

AC-010.1: endpoint ตั้ง/สลับ/ตรวจเป้าหมายทุกตัวยึดตัวตนจาก session เท่านั้น — การแนบ SchoolID/SID ของคนอื่นใน body/header ไม่มีผลกับการเขียน/อ่านทุกจุด

## Dependencies

BE-042, BE-043, BE-036

## Handoff

ตรวจ AC-010.1 ด้วยการยิง BE-041/042/043 ด้วยตัวตนของเด็กอื่นแนบใน body (ต้องไม่มีผล) + ยืนยันการเขียนเกิดใต้ JWT จริงเสมอ — เก็บผลทดสอบราย endpoint เป็นหลักฐาน
ชั้นตรวจครอบ endpoint ใหม่ — revert ได้ทางเทคนิคแต่ห้ามปล่อย endpoint เป้าหมายใช้จริงโดยไม่มีชั้นนี้
