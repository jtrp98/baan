# BE-046 — Cluster weight seeds

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `project-manager` · Owner/Phase/Depends/Status → `plan\index.md` (index ชนะ)

## Goal

seed/ยืนยัน `public."TCompassClusterSubjectWeight"` (11×8) และ `public."TCompassClusterRiasecWeight"` (11×6) ตาม PRE-F07 (OQ-F07 sign-off ปิดแล้ว 2026-08-31) — **v9: ทั้งสองตารางผูกด้วย Id (`"ClusterID"`, `"DimensionID"` เป็น `integer` FK) ไม่ใช่ text code อีกต่อไป จึงต้อง seed ด้วย `INSERT ... SELECT ... JOIN` ที่แปลง `"ClusterCode"`/`"DimensionCode"` → Id ตอนรัน · ห้ามใส่เลข Id ลงในไฟล์ seed** — ยังมาร์กเป็นสมมติฐานไม่มีแหล่งอ้างอิงภายนอก (RISK-F15) ต่อไปแม้ sign-off ให้ใช้แล้ว — ไม่แตะ `public."TCompassInterestCluster"` เดิม (สร้าง/seed แล้วที่ Module F) — ตารางน้ำหนักเป็นตัวกำหนดทิศทางการจัดอันดับทั้งระบบ — เก็บเป็นข้อมูลแก้ได้ (ไม่ hardcode) เพื่อให้แก้ทีหลังได้โดยไม่ redeploy และเพื่อให้สถานะสมมติฐานถูกเห็นตลอด

## References

REQ-011, AC-011.1, DES-022, DEC-022, DES-018, DEC-018

## Scope

seed ผ่าน migration เท่านั้น · ค่าตามชุดที่ OQ-F07 ปิดไว้ — ห้ามปรับค่าเอง · ตารางเก็บเป็นข้อมูล (ไม่ hardcode ในโค้ด) · **ไฟล์ seed เขียนด้วย code เสมอ แล้ว JOIN แปลงเป็น Id ตอนรัน (`JOIN public."TCompassInterestCluster" c ON c."ClusterCode" = v.cluster_code` และแบบเดียวกันกับมิติ) · code ที่ JOIN ไม่ติด = seed ต้องล้ม ห้ามข้ามแถวเงียบ ๆ และห้ามสร้างแถว master ใหม่**

- Security-sensitive: yes

## Out of Scope

`public."TCompassInterestCluster"` / `public."TCompassRiasecDimension"` (seed แล้วที่ Module F — อ่านเพื่อ JOIN เท่านั้น) · ค่าน้ำหนักที่ sign-off ไว้ (ห้ามแต่ง) · สคีมา
