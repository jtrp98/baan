## Goal

ตั้งโปรเจกต์ Curriculum Service (Python/FastAPI) ใหม่ทั้งก้อน — skeleton, dependency management, และกลไกโหลด secret/config ของ service เอง (ยังไม่ใช่การตั้งค่าคีย์ `glm-5.2` เอง) — ทำเองเพราะ `setup` agent ไม่รองรับ stack นี้ (DEP-F06) — งาน import ทั้งหมดของโมดูลต้องมี service แยกของตัวเองเป็นฐาน และ secret/config ต้องมีกลไกโหลดที่ถูกต้องตั้งแต่โครง เพื่อไม่ให้งานลับไหลไปอยู่ใน config ฝั่ง .NET ตามเคย
