# BE-040 — TCompassTargetProgram migration

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `project-manager` · Owner/Phase/Depends/Status → `plan\index.md` (index ชนะ)

## Goal

Migration `public."TCompassTargetProgram"` — append-only (เหมือน `TCompassRiasecResult`/`TCompassQuestAttempt`): `SchoolID`, `SID`, `ProgramID`, `RiasecResultID` (snapshot สำหรับ audit เท่านั้น ไม่ใช่ตัวตัดสิน gate), `Status` (`active`/`superseded`), `SupersededAt` พร้อม **Partial Unique Index `"UX_TCompassTargetProgram_Active_Student"` บน `("SchoolID", "SID") WHERE "Status" = 'active'`** ตามมติปิด OQ-F14 (จำกัด 1 active target ต่อคน, DES-021 §0-§1) เพื่อการันตีระดับฐานข้อมูล — ปิด OQ-F14 แล้ว (ผู้ใช้ยืนยัน 2026-09-15): บังคับให้มี active target ได้เพียง 1 สาขาต่อคน — การันตีด้วย Partial Unique Index เพื่อป้องกัน race condition

## References

REQ-017, AC-017.1, DES-021, DEC-021

## Scope

DDL ตาม `## Data Model`/DES-021 §1 เป๊ะ (รวม Partial Unique Index `"UX_TCompassTargetProgram_Active_Student"`) · append-only — ไม่มีเส้นทาง DELETE แถวสถานะ · quote identifier ครบตามกฎ

- Security-sensitive: yes

## Out of Scope

ตารางอื่นทั้งหมด · ตาราง `public."TCompassRiasecResult"` (มีแล้ว — ไม่แตะ) · เงื่อนไข constraint ที่สัญญากำหนดโดยเจตนา

none
