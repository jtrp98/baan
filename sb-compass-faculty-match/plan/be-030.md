# BE-030 — RIASEC match percent formula

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `project-manager` · Owner/Phase/Depends/Status → `plan\index.md` (index ชนะ)

## Goal

สูตร % ความเหมาะสมเชิง RIASEC — intersection ของมิติที่ทั้งสาขามี desired_level และเด็กมี studentLevel เท่านั้น, `n=0` → ไม่มี % (แสดงข้อความว่ายังประเมินด้านนี้ไม่ได้) ห้ามหารด้วยศูนย์ ห้าม error, ปัดเป็นจำนวนเต็มเมื่อแสดง, มิติที่มีอยู่ฝั่งเดียวตัดออกทั้งคู่ — % ที่ผิดเงียบ ๆ (เช่นคืน 0% เมื่อเทียบไม่ได้) อ่านเป็นคำตัดสินต่อเด็ก — สัญญาบังคับให้ "ไม่มี %" ต่างจาก "0%"

## References

REQ-007, AC-007.1, DES-025, DEC-025, DES-018, DEC-018

## Scope

คำนวณสดจาก studentLevel + โปรไฟล์มิติของสาขาที่อนุมัติแล้ว · ห้ามคืน 0% แทนกรณีเทียบไม่ได้ · ทุกมิติน้ำหนักเท่ากันในขั้นนี้

- Security-sensitive: yes

## Out of Scope

โปรไฟล์สาขา (อ่านอย่างเดียว) · สูตร studentLevel · สคีมา

## Expected Output

none

## Acceptance

AC-007.1 (ฐานตัวเลข): ตัวเลข % ที่ได้คำนวณจากมิติที่เทียบกันได้จริงเท่านั้น และกรณีเทียบไม่ได้ต้องเป็น "ไม่มี %" ไม่ใช่ 0% — เป็นฐานให้การชี้จุดไม่เข้ากันของข้อ ถัดไปมีตัวเลขที่ถูกต้องใช้
