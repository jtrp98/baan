# BE-049 — Cluster combined score formula

> Budget ≤ 4 KB (`policies\documentation.md` §4) · เขียนโดย `project-manager` · Owner/Phase/Depends/Status → `plan\index.md` (index ชนะ)

## Goal

สูตรรวม cluster (สัญญา §3): `AcademicFit(c) = Σ(clusterSubjectWeight×TScore_s)/Σ(weight)` พร้อม clamp สเกล `min(100, max(0, 50+(TScore_s−50)×5))` · `InterestFit(c) = Σ(clusterRiasecWeight×riasecScore_r)/Σ(weight)` (riasecScore_r จาก studentLevel ของ BE-029 แปลงเป็น 0-100 ด้วย `(level−1)/4×100`) · `CombinedScore(c) = 0.5×AcademicFit + 0.5×InterestFit` (น้ำหนัก 50/50 ยืนยันแล้ว REQ-016) — แสดง top-3 พร้อม % เสมอ ไม่ใช่ผู้ชนะเดียว · นักเรียนยังไม่ทำ RIASEC → `InterestFit`/`CombinedScore` NULL ทั้งคู่ ใช้ `AcademicFit` แสดงแทนชั่วคราว — สูตรนี้คือคำตอบของ OQ-F03 ที่ผู้ใช้ปิดแล้ว — การเปลี่ยนน้ำหนักหรือรูปแบบผลลัพธ์ (ผู้ชนะเดียว) คือการกลับคำตัดสินที่ปิดไปแล้ว

## References

REQ-011, AC-011.1, REQ-016, AC-016.1, DES-022, DEC-022

## Scope

น้ำหนัก 50/50 คงตาม REQ-016 · เขียนผลลง `public."TCompassStudentClusterScore"` ต่อรอบ · ฐานการคำนวณเดียวกันทุก cluster (ผ่าน BE-048)

## Out of Scope

สูตร T-Score/fallback (BE-047/BE-048) · studentLevel (BE-029 — อ่านค่า) · น้ำหนัก 50/50 (คงตาม REQ-016)

AC-016.1: น้ำหนัก Academic:Interest ใน CombinedScore คงที่ 50/50 — ไม่ปรับเป็นสัดส่วนอื่น
